## 3. 来月の基礎テーマ (1つ) と非技術書1冊

### 基礎テーマ: **古典的な計画アルゴリズムと到達可能性 (classical motion planning & reachability)**

**なぜこれか (提案の根拠)**: スキルマップの弱点 (古典的手法 2 / 実験設計 2) と、4週連続で止まっている成果物が**同じ一点で交差する**。
solvability (いまの状態から「まだ助かる」候補が何本残っているか) も mode coverage (その候補が何**種類**あるか) も、
**新しい深層学習ではなく1970〜2010年代の古典そのもの**である。ここを埋めれば notebook が書け、notebook が書ければ実験設計も評価も同時に上がる。

**学習プラン (3週 + 1週)**
| 週 | 内容 | 成果物 |
|---|---|---|
| W36 | LaValle *Planning Algorithms* Ch.5–6 (sampling-based / combinatorial) と Ch.13–14 (differential constraints)。**必要なのは「微分制約下の到達可能集合」の節だけ**。古典論文: Werling+2010 (Frenet frame optimal trajectory), Dolgov & Thrun 2008 (Hybrid A*) | 用語ノート1枚 (surveys/planner-evaluation の空欄に書く) |
| W37 | **homotopy class** の実務的近似: Bhattacharya+2010 (homotopy class の識別), McNaughton+2011 (state lattice)。「左を通る/右を通る/停止」の3値ラベルが何の近似かを言えるようにする | 判定関数の擬似コード |
| W38 | **reachability**: Mitchell の HJ reachability の**考え方だけ** (実装はしない) と Althoff の CommonRoad 系 over-approximation。**目的は「kinematic rollout は到達可能集合の楽観的な下界である」と一行で言えるようになること** (= R1 の留保条項) | R1 の「未解決」節の下書き |
| 全期間 | **実装課題 = §4 の notebook そのもの** (2D toy + bicycle model + rollout 積分)。教材と実装を分けない | 図3枚 |
