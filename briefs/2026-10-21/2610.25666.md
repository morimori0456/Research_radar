# 2610.25666 — Fréchet Forcing: Training Long-Horizon Streaming World Models from Short Clips

- 元論文: https://arxiv.org/abs/2610.25666
- トピック: next_arch (P3) / 評価 4.0 / hf_upvotes 15
- 根拠: abstract のみ。MiniWorld-1B の構成、評価 metric の数値、コードの有無は未確認

## 何を解決する論文か

streaming video world model (次のフレームの塊を、自分の過去と action の列から順に生成して未来を予測するモデル) は、短い clip で学習すると、学習した長さを超えた rollout (自分の出力を入力に戻して先を生成すること) で誤差が積み重なって崩れる (drift)。よくある対策は、自分の rollout 上で DMD (Distribution Matching Distillation; 生成分布を teacher の分布に合わせる蒸留) をすること。しかし action 条件付きの world model では、外部の動画モデルは action を知らず、自分の事前学習済みネットワークは student と同じ drift をするので、teacher が役に立たない。この論文は teacher を使わず、短い実 clip だけで長期安定性を学習する。

## 手法の核心

- **発想**: 長い rollout は teacher に一致する必要はない。「同じシーンの現実的な続き」であり、「指示した action に従っている」ことが言えれば十分、と考える。現実らしさとシーンの忠実さは実データの統計と比べれば horizon によらず測れ、action への追従は元の条件付き生成 loss で保たれる。
- **Fréchet Forcing の 3 つの制約**で、world model と、実際に使う multi-step sampler (数ステップで生成する推論器) を一緒に fine-tuning する:
  1. **Generative anchoring**: 自分で生成した履歴の後に実データが続く形にして flow-matching loss (ノイズから実データへの流れを回帰する生成 loss) をかける。
  2. **Context fidelity**: 自由 rollout の latent 統計と、その clip 自身の正解との Fréchet distance (FD; 2 つの分布の平均・共分散のずれを測る距離) を取り、rollout がそのシーンに忠実であり続けるようにする。
  3. **Reality matching**: 生成フレームと実フレームの FD を、固定した知覚 encoder の空間で取り、見た目の現実らしさを保つ。
- **必要なものが少ない**: teacher も online critic (学習中に同時に更新する評価器) も長い動画も要らない。長い録画との比較をせずに、短い実 clip から 3 つの目標を作れる。
- **結果**: 253 フレームで事前学習した MiniWorld-1B を、381 フレームの clip で最大 36 GPU 時間 fine-tuning すると、4,000 フレーム超でも安定し、robot manipulation とカメラ操作の探索の両方で action に従い続ける。

## 適用可能性と実験アイデア

- **P3 (次世代アーキテクチャ)**: 運転の world model は、短い走行 clip で学習して長い horizon の rollout に使うので、drift は同じ問題。teacher 不要で、36 GPU 時間という費用感は試しやすい。
  - 実験案 1: 手元の action 条件付き world model (または公開の運転 world model) で、学習 horizon の 2〜4 倍まで rollout したときの崩れ方を測る。drift の出方を先に確認しないと手法の効果は判断できない。
  - 実験案 2: 3 つの制約のうち context fidelity だけを足して、長い rollout の FD が下がるかを見る (最小の ablation)。
- **P1 (Planner AI + 評価)**: 長期 rollout が安定すれば、world model 内の closed-loop simulation で planner を評価する土台になる。評価に使うには action への追従の強さも測る必要がある (論文は追従が保たれると述べるが、数値は未確認)。
- **P2**: DMD の teacher 不要版という点は、蒸留の代替としての読み方もできる。
- 注意: 評価対象は robot manipulation とカメラ探索で、運転ではない。運転では他車の挙動が確率的で、FD で測る scene fidelity と交通の物理的な一貫性が一致するとは限らない。
