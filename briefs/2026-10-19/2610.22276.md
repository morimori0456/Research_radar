## 何を解決する論文か

VLM (Vision-Language Model; 画像と言語を扱う LLM) は「どの空間関係が成り立つか」「物体までの距離」「配置する位置」といった空間判断を、free-form の text generation で答える。しかし出力は選択肢のいずれか、スカラー値、2D 点のどれかと小さい空間にすぎず、autoregressive decoding (1 token ずつ順に生成する方式) と answer parsing のコストが無駄になる。本論文は、こうした判断を生成ではなく classification として 1 回の forward pass で出す System 1 モデル (System 1 = 熟考せず直感的に素早く判断する側) を提案する。

## 手法の核心

- 各候補を class とみなし、backbone が元々持つ query / key projection (attention の Q と K を作る線形変換) でスコアを付ける。追加パラメータはなし (native attention matching)。
- 候補の種類は 3 つ。選択問題では与えられた選択肢、数値予測では value bin、点予測では画像上の領域 (region)。数値と点は coarse-to-fine classification (粗い bin から細かい bin へ段階的に絞る) で精度を上げる。
- 推論は 1 判断につき forward pass 1 回で、answer token を一切生成しない。
- 学習では、coarse-to-fine の全段階を teacher forcing (正解を入力として与えて学ぶ方式) で 1 回の forward pass にまとめて supervise する。さらに length-aware global batching と cross-GPU load balancing で学習 throughput を元の batching 比 30.8% 向上。
- Qwen3.5-4B を土台に、既存の空間系データセットから変換した 12.3M 件の QA pair で学習。abstract は "achieves the highest" で途切れており、比較対象と指標は未確認。

## 適用可能性と実験アイデア

- **P3 (次世代アーキテクチャ)**: VLA (Vision-Language-Action; 画像と指示から行動を出すモデル) の action head を「生成」でなく「候補の scoring」にする発想の参考になる。運転の離散化した行動 (車線変更 / 停止 / 速度 bin など) なら、同じ枠組みで token を生成せずに決定できる可能性がある。
- 実験案 1 (P3): 既存の VLM/VLA の最終層の Q/K をそのまま使い、軌道を k-means で離散化した N 本の trajectory anchor を候補として scoring し、自由生成した軌道を出す場合と latency・精度を比較する (まず toy 規模で)。
- 実験案 2 (P1 周辺): planner が出す複数の候補軌道を、追加 head なしで VLM の attention で再ランクする使い方も試せる。planner evaluation の軽量 scorer になるかを見る。
- 注意: 評価は空間理解の QA で、閉ループ運転での有効性は未検証。classification 化は候補集合の外を答えられない制約があり、連続値は bin の粒度に精度が縛られる。本文で bin 数と誤差の関係を確認したい。
