# JEPAhead: From Inpainting to Causal Forecasting for Urban Driving (2611.08657)

- URL: https://arxiv.org/abs/2611.08657

## 何を解決する論文か

world model (環境の将来を予測する model) を、画素ではなく latent (特徴空間) で作りたい。V-JEPA (Joint-Embedding Predictive Architecture; 画素を再構成せず、隠した部分の特徴を予測する自己教師あり学習) の predictor は、もともと欠けた部分を埋める bidirectional な inpainting 用で、未来を予測する causal な用途には作られていない。この論文は、事前学習済みの V-JEPA1 predictor を、action を使わない causal な未来予測に fine-tuning する。

## 手法の核心

- **encoder は凍結**し、predictor だけを bidirectional inpainting から causal forecasting へ fine-tuning する。
- 連続した過去の観測、horizon に揃えた target、group 単位の causal attention (未来の group が過去の group だけを見る) を使う。
- 1 回の forward pass で 8 つの未来 token group (16 frame 相当) を予測する。
- CARLA Town12 で、591 個の候補から正しい未来を当てる retrieval が 69.0% (persistence、つまり「直前と同じ」と予測する baseline は 55.3%)。horizon が長く、変化の大きい token ほど差が大きい。パラメータが 6 分の 1 の predictor を scratch で学習した版より良い。
- 固定した linear probe (encoder の token で学習した線形 classifier) で、semantic class が変わる patch の mIoU (領域の重なり度) は 0.16 (persistence 0.13)。
- 画素空間では L1 は少し改善するが、LPIPS (人の知覚に近い画像距離) はほぼ改善しない。そのため latent と semantic の評価を並べる、と主張。

## 適用可能性 (P3)

- 凍結した encoder の上に小さい predictor を載せて将来の latent を作る構成は、学習コストが小さく、world model の最小実験として扱いやすい。
- 評価が retrieval と linear probe に留まるため、planner の性能や安全性に効くかは未検証。P3 では「latent の未来予測が運転の判断に使える水準か」を自分で確かめる必要がある。
- 注意: 絶対値は小さい (mIoU 0.16 対 0.13)。実際の運転 data ではなく CARLA。

## 試すべき実験アイデア

1. 手元の driving 動画で、凍結 encoder + causal predictor を作り、persistence との retrieval 差を horizon 別に出す (最小の実験)。差が出る horizon が planning に使える範囲か確認する。
2. predictor の出力を、planner の入力 (予測 feature) として足したときに、閉ループ / 開ループの指標が変わるか確認する。この論文が未検証のまさにその部分。
3. ego の action を条件に足した版 (action-conditioned) と比べ、action-free の限界がどこにあるか見る。
