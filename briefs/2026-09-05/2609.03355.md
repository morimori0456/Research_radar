# ALRA — 語彙全体を合わせるのをやめ、「迷っている数語」の順序を合わせる

**topic:** fm_distill_finetune / **project:** P2 / **hf_upvotes:** 0
**スコア:** P1 1.5 / P2 **4.0** / P3 2.0
**著者:** Quang Hoang Trung, Quang Huu Hieu, Nguyen Van Hoang Phuc, Vo Nguyen Le Duy / 2026-09-03 公開

## 何を解決する論文か

言語モデルの **logit-based knowledge distillation (教師モデルの出力分布そのものを生徒に合わせさせる蒸留)** は、通常**語彙全体 (数万次元) にわたって次 token 分布を一致させる。**この大域的な目的関数は、**「ありうる数語のうち、どれをどの順で好むか」という相対的な選好を無視する。**

局所的に候補語を絞る先行手法はあるが、**候補の選び方が教師側だけ、または生徒側だけに偏っていた。**教師だけだと生徒が本当に迷っている語を見落とし、生徒だけだと学習初期の当てにならない順位に頼ることになる。ALRA は**両方から候補を出し合う。**

## 手法の核心

- **候補集合を位置ごとに作る:** **生徒が「ありうる」と考える語を提案させ、そこに教師の最尤語を必ず anchor として混ぜる。**片側依存の失敗を構造で潰している。
- **候補数を適応的に決める:** 教師がその候補集合内にどれだけ広く確率を配っているかを**バッチ内の相対量として測り**、広く迷っている位置では候補を増やす。**固定 top-k ではない。**
- **Adaptive Local Divergence:** 全体の確率質量を合わせる項 (mass-matching) は残し、**選ばれた領域と残りの領域それぞれで相対分布を別々に合わせる。**厳密な full-vocabulary 分解では各条件付き項に教師の質量が係数として掛かるが、**ALRA はこれを 1 に置き換える。**狙いは明確で、**「教師の確率が低い領域だ」という理由だけでその項が軽視されるのを防ぐ。**
- **Student-Weighted Pairwise Relational Alignment:** 語のペアのうち、**生徒の確率差が小さい (= 迷っている) 高確率ペアを重く**、明らかに離れているペアや低確率ペアを軽くする。**「判断が割れている境界に教師信号を集める」**という発想。
- **結果: The Pile で 200M / 500M の生徒を random init から事前学習し、9 つの zero-shot benchmark 平均で 36.62% / 37.40%。**最強の蒸留 baseline に **+0.94 / +0.83 ポイント**、蒸留なしの事前学習に **+2.31 / +2.91 ポイント。**

## P1 / P2 / P3 への適用可能性

**P2 の「新しい loss」枠に真正面から入る 1 本である。**そして R2 にとっての意味は、**性能値ではなく「どこに監督を集めるか」という設計思想の側にある。**

**R2 の候補軸を並べ直すと、共通の形が出る。**① CLL 集中度 (少数の token に損失が集中している)、② clipping で切り捨てられる推論 token (重要な token が更新から落ちている)、④ 圧縮による適合余地の消失 (09-05 の [Compression×TTA](2609.03604.md))。**いずれも「監督が届く場所と、届いてほしい場所がずれている」という話である。****ALRA は、そのずれを是正する側から同じ問題に触れている。**

**とりわけ ① との関係が鋭い。**R2 の候補①は「損失が少数 token に集中すると蒸留が壊れる」という仮説である。**ALRA の Adaptive Local Divergence は、教師の質量係数を 1 に置き換えることで、まさに「低確率領域の項が軽視される」ことを防いでいる。****つまり ALRA は、R2 の候補①が想定する病理に対する「治療」を、独立に提案している。**

**これは R2 の対照群設計に直接効く。**09-04 時点で R2 の対照群は 3 群 (CLL / clipping / 長期結合) に増えていた。**ALRA を入れると 4 群目ではなく、「① の治療あり/なし」という対照が 1 組できる。**群を増やすより、**既存の仮説に治療をぶつけて確かめる**方が実験は速く終わる。**R2 が確かめたいのは「CLL 集中が原因か」であって、「何種類の説明があるか」ではない。**

> **ただし規模の注意。**実験は **200M / 500M の生徒を random init から事前学習**したもので、**大きな教師から実務規模の生徒へ蒸留する設定とは違う。**改善幅も **+0.94 / +0.83 ポイント**であり、**09-04 の PDT が「判定不能」と分類した桁に近い。****ALRA を R2 で使うなら「手法として採用する」のではなく「① の病理を確かめるための操作」として使うこと。**そうすれば改善幅の小ささは問題にならない —— 見たいのは順位や到達点ではなく、**CLL 占有率が実際に動くかどうか**だからである。

### 試すべき実験アイデア

1. **【半日・R2 の中心仮説の直接検証】既存の蒸留設定に「候補集合内の相対分布を別項として合わせる」だけを足し、CLL 占有率がどう動くかを測る。**ALRA の全部を実装する必要はない。**Adaptive Local Divergence の 1 項だけでよい。****占有率が下がって性能が変わらないなら、R2 の候補①は棄却に近づく。下がって性能も上がるなら、①が主因である証拠になる。****どちらに転んでも結論が出る形になっている。**
2. **【30 分】候補集合のサイズを固定 top-k にした版と、ALRA の適応版を比べる。**「適応であること」が効いているのか、単に局所化が効いているのかを切り分ける。**論文の ablation にあれば読むだけで済む。まず読む。**
3. **【メモ】pairwise で「生徒が迷っているペアを重く」という発想は、09-04 の Versatile Samples (判断が割れる境界にサンプルを作る) と同じ形である。**蒸留と planner という無関係な領域で、**「境界に教師信号を集める」**という同じ処方が独立に出ている。**R1 の introduction で使っている「同型の指摘が別領域で独立に出る」という論法が、P2 側でも成立している。**
