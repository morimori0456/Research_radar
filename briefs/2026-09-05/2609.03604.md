# Compression × TTA — 圧縮したモデルは「精度」を保っても「適合する力」を失う

**topic:** fm_distill_finetune / **project:** P2 / **hf_upvotes:** 0
**スコア:** P1 2.0 / P2 **4.5** / P3 2.5
**著者:** Francesco Corti, Dong Wang, Young D. Kwon, Cecilia Mascolo, Olga Saukh / 2026-09-03 公開

## 何を解決する論文か

実運用のモデルには 2 つの要求が同時にかかる: **軽いこと (model compression) と、現場のずれに合わせられること (test-time adaptation)。**両者は個別には研究され尽くしているが、**組み合わせたときに何が起きるかは調べられていなかった。**

本論文の結論は端的である。**圧縮したモデルは、教師ラベルありの適合なら精度を保てる。だがラベルなしの TTA では、圧縮率が上がるほど適合性能がはっきり落ちる。**しかも落ち方は圧縮手法によって大きく違う。

**TTA (Test-Time Adaptation; 配備先でラベルなしの入力だけを見てモデルを適合させる手法。BatchNorm 統計の更新やエントロピー最小化が代表例)** を前提にした軽量化は、**「精度が落ちていないから大丈夫」では判断できない**、というのが本論文の警告である。

## 手法の核心

- **ResNet-18 と ViT-Base を、CIFAR-10-C / ImageNet-C (元データにノイズ・ぼけ・天候などの破損を人工的に加えた分布シフト評価用データセット) で評価。**複数の structured compression (構造単位で削る圧縮) × 標準的な TTA 手法の組み合わせを網羅的に測る。
- **診断の枠組みを 2 つの量で立てている:**
  - **representational expressivity** —— 圧縮後の表現がどれだけ多様性を保っているか
  - **adaptation subspace compatibility** —— TTA が動かそうとする方向が、圧縮後のモデルに残っているか
- **見つかった因果:** 圧縮は表現の多様性を削り、**TTA が更新に使う部分空間そのものを構造的に潰してしまう。**その結果 **「回復可能性 (recoverability)」が失われる。**精度が残っていても、動かす余地が残っていない。
- **効果の大きさは圧縮手法に強く依存する** = **「適合性を保つ圧縮」を設計する余地がある**という前向きな含意で結んでいる。

## P1 / P2 / P3 への適用可能性

**R2 (蒸留の破綻境界) にとって、これは 4 本目の説明候補であり、しかも既存 3 本と因果の向きが違う。**

現在の R2 の候補は、① CLL 集中度、② clipping で切り捨てられる推論 token、③ 教師と生徒の長期結合 (09-04 の Intransigent Teacher)。**この 3 本はいずれも「蒸留の最中に何が壊れるか」を見ている。****本論文が持ち込むのは「蒸留した後、そのモデルが何をできなくなっているか」である。**

**そして R2 にとって決定的なのは、これが P2 の定義そのものと重なる点である。**P2 は「蒸留 + 適合 (他機種・他ドメインへの転用)」の 2 段構えであり、**本論文はまさに「1 段目が 2 段目を壊す」と言っている。**もしこれが自分の蒸留ログでも再現するなら、**R2 の問いは「蒸留はどこで壊れるか」から「蒸留は適合の余地をどれだけ食うか」に変わる。**問いの立て方が変わるので、**R2 の位置づけを見直す価値がある。**

**測り方も具体的に書ける。**本論文の adaptation subspace compatibility は、**「TTA が動かす方向」と「圧縮後に残っている表現の張る空間」の重なりで定義される。**R2 の既存の宿題 (過去の蒸留ログに CLL を後付けする) と**同じログで計算できる**: 蒸留後モデルの表現の特異値分布 (= 多様性の代理) を、容量比・蒸留の長さと並べてプロットする。**新しいデータ収集が要らない。**

> **注意点を 1 つ。**本論文は分類 (CIFAR/ImageNet) の実験であり、**言語モデルの蒸留に直接は移らない。**「表現の多様性が落ちる」は移りそうだが、**「TTA の部分空間」に対応する概念が LLM 側で何かは自明でない** (in-context 適合か、LoRA の更新方向か)。**R2 で使うなら、この対応付けを先に 1 段落で決めること。**曖昧なまま持ち込むと、実験してから意味が定まらなくなる。

### 試すべき実験アイデア

1. **【30〜60 分・既存ログのみ・R2 の宿題と同時にできる】過去の蒸留ログで、生徒モデルの中間表現の特異値分布を取り、上位成分の占有率を「容量比」「蒸留の長さ」の 2 軸に対してプロットする。**CLL 占有率の宿題と**同じ図の 2 枚目**として出せる。**容量比では動かず長さで動く、が既に R2 の仮説なので、多様性の指標が同じ挙動をするかは直接の検証になる。**
2. **【半日・R2 の問いを更新するなら】蒸留済みモデルと非蒸留モデルを同じ小データで LoRA 適合させ、到達点でなく「適合の効き方」(必要ステップ数・学習率感度) を比べる。**精度が同じでも適合しにくいなら、本論文の主張が言語側でも成立する。
3. **【メモ・P2 の実務向け】「圧縮手法によって効果が大きく違う」が本当なら、実務の判断基準が 1 つ増える:蒸留手法を選ぶときに、到達精度だけでなく**適合余地**でも比べるべきである。**ML_report の蒸留 7 本の再読時に、この観点で分類し直す価値がある。**
