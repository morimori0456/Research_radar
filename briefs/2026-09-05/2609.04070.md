# LaPla — 行動を「離散の符号」ではなく「連続の潜在」で受け渡す

**topic:** next_arch / **project:** P3 (P1 にも直結) / **hf_upvotes:** 0
**スコア:** P1 4.0 / P2 2.0 / P3 **4.5**
**著者:** Ruoyu Yao, Yusen Xie, Qingzhao Liu, Pei Liu, Zewei Yang ほか / 2026-09-03 公開

## 何を解決する論文か

VLM (Vision-Language Model; 画像と言語をまとめて扱うモデル) を運転に使うときの根本的なずれは、**VLM は離散の token を 1 個ずつ吐くのに、車の制御は連続で物理制約に従う**という点にある。よくある解法は行動を離散 token に量子化することだが、**量子化した瞬間に誤差が入り、しかも 1 token ずつ自己回帰で吐くので遅い。**

LaPla は「離散 codebook を引く」段階を捨てる。**行動の潜在空間だけを事前学習で作っておき、VLM の hidden state をその潜在空間に直接射影して、凍結した decoder に軌跡へ戻させる。**量子化誤差はゼロ、生成は 1 回の forward で済む。

## 手法の核心

- **residual VQ-VAE (Vector Quantized Variational AutoEncoder; 連続量を離散符号帳に量子化して学習する自己符号化器。residual 版は「残差をさらに符号化する」多段構成で表現力を上げる) を action tokenizer として学習し、車両の運動学 (kinematics) を潜在空間に埋め込む。**
- **推論時は codebook lookup をしない。****学習した潜在空間を「物理的にありうる軌跡だけが住む場所」= physical prior として使い、VLM の hidden state をそこへ射影するだけ。**量子化誤差が原理的に発生しない。
- **concurrent action queries:** 複数視点画像 + 過去の行動 + テキスト指示という multimodal 文脈に対し、**行動クエリを並列に attend させて 1 回の forward で全ステップ分を得る。**自己回帰の逐次生成を回避 = 遅延が小さい。
- **frozen decoder** が潜在を実際の軌跡に戻す。**decoder が凍結されているので、出てくる軌跡は常に学習済み分布の内側 = 物理的に妥当。**
- **結果: open-loop の nuScenes で長期 L2 誤差を SOTA の VLA 手法比 15.52% 削減。閉ループの NVIDIA AlpaSim で success rate +33.34 ポイント、かつ推論遅延は大幅減。**

## P1 / P2 / P3 への適用可能性

**R3 (VLA × world model 統合アーキテクチャ) の分類マップにとって、これは軸②(未来を 1 本返すか分布か) の周辺にある「受け渡しの型」という新しい観点を持ち込む。**

これまで軸②は出力の形 (点推定か分布か) で切っていた。**LaPla が示したのは、その前段 —— 意味を扱う部分と行動を扱う部分の「接続面をどこに置くか」で性能も遅延も決まる、ということである。**接続面の選択肢は少なくとも 3 つある: **(a) 離散 token を渡す (量子化誤差あり・遅い)、(b) 連続潜在を渡す (LaPla)、(c) 潜在すら介さず行動を直接回帰する。****R3 のマップに軸④「semantic と action の接続面」を立てる価値がある。**10 月に R3 へ戻ったとき、この論文が軸④の代表例になる。

**P1 側にも、見逃せない使い道が 1 つある。**LaPla の潜在空間は「物理的にありうる軌跡だけが住む場所」として学習されている。**R1 の solvability は候補軌跡を摂動で張るが、摂動が大きいと物理的にありえない軌跡まで数えてしまう危険がある。**09-04 の Versatile Samples は横/縦の 2 軸摂動でこれを避けたが、**LaPla の潜在空間は「ありうる軌跡の集合」そのものを与える。****潜在空間内で摂動すれば、候補が自動的に運動学的に妥当になる。**

> **ただし 09-06 gate の作業には使わない。**理由は明快で、**RVQ-VAE の事前学習が要るため「今日から計算できる」定義にならない。**明日の図 1 は Versatile Samples の 2 軸摂動 (追加学習ゼロ) で出す。**LaPla の潜在摂動は 10 月の実データ実験で「候補の張り方 v2」として比較対象に置く。**この順序を守ること。

### 試すべき実験アイデア

1. **【10 月・候補の張り方の頑健性チェック】solvability を (a) 幾何摂動 (横/縦 2 軸) と (b) 行動潜在空間内の摂動の 2 通りで計算し、順位が保たれるか見る。**保たれれば「候補の張り方に依存しない量」という強い主張が立つ。**壊れれば、R1 は張り方を定義の一部として固定して書く必要がある —— どちらの結果でも論文の書き方が決まる。**
2. **【1 時間・R3 のメモ】接続面 (a)/(b)/(c) の 3 分類で、手元にある VLA 論文を並べ直す。**軸④の値域が実際に埋まるかの確認。埋まらなければ軸として立てない。
3. **【メモ】「1 回の forward で全ステップ」は、R1 の指標計算にとって朗報である。**候補を K 本張って各々を評価する計算量が、自己回帰生成に比べて桁で軽い。**10 月の実験の計算予算見積もりに反映する。**
