# DreamX-Phi 1.0: Action-Conditioned Video World Model for Robotic Manipulation

> **主張を一行で:** action-conditioned world model は **「もっともらしい動画」を作れても「命じた通りの動き」を作れるとは限らない。** 忠実性は、**生成の綺麗さではなく、幾何と同一性の制約で担保する。**

## 何を解決する論文か

observed frame + language instruction + **action sequence (end-effector すなわちロボットの手先の姿勢と、グリッパの開閉状態の列)** を与えて、**その行動を取った場合の未来観測**を予測する world model である。

論文の出発点は **realism ≠ faithfulness** という指摘にある。**見た目が説得力のある rollout でも、間違ったほうの腕が動いていたり、掴んでいたはずの物体が消えていたりする。** 動画としての品質指標はこれを罰しない —— **滑らかで自然な嘘は、指標上は高得点になる。**

**この問題設定は運転にそのまま移る。** 「操舵を右に切った場合の未来」を生成させて、**もっともらしいが操舵量に対応していない映像**が出てきたら、その world model は planner の反実仮想 (もし別の行動を取っていたら何が起きたか) には使えない。**08-14 の 2608.11601 が「予測のもっともらしさは反実仮想の正しさを意味しない」と言ったのと同じ穴を、本論文は生成側から塞ぎにいっている。**

## 手法の核心 —— 部品表として読む

- **[部品 1] 腕ごとの SE(3) 変換を attention に注入する (PRoPE-style geometric encoding)。** **SE(3)** は 3 次元の回転 + 並進、つまり剛体の姿勢そのものを表す群。**PRoPE** は位置エンコーディングを相対的な幾何変換として attention に入れる系統の手法 (RoPE の姿勢版と読めばよい)。狙いは **arm identity の保存** —— **どちらの腕の指令なのかがモデル内部で混ざらないようにする。** **輸入価値が最も高い部品。** 運転では「自車の ego-motion (自車の並進・回転)」がちょうど SE(3) であり、**「操舵・加速の指令を、絵に対する幾何変換として attention に入れる」**という形にそのまま置き換わる。**指令をトークンとして横に並べるだけの実装より、行動への追従が構造的に強制される。**

- **[部品 2] lightweight depth branch —— 幾何を明示的に持たせる。** 行動条件付けだけでは **scene geometry が拘束されない。** 深度を副次的な出力として予測させ、シーンの構造が保たれるよう圧力をかける。**運転では深度・占有 (occupancy) の補助ヘッドに対応し、これは既に定番。目新しさはないが、「行動忠実性のために幾何を足す」という動機づけは記録に値する。**

- **[部品 3] SAM3 マスク + 凍結 V-JEPA teacher で物体一貫性を保つ。** **SAM3** は Segment Anything 系のセグメンテーションモデル、**V-JEPA** は動画の潜在空間で未来を予測する自己教師あり表現学習モデル (Joint-Embedding Predictive Architecture; 画素ではなく埋め込みを予測する)。**凍結した V-JEPA を teacher として使い、SAM3 が切り出した物体領域の表現が時間方向でぶれないよう縛る。** 狙いは **把持中に小さな物体が消えたり形が変わったりするのを防ぐこと。** 運転では **「遠方の歩行者やコーンが生成中に消えない」**という、まさに困っている失敗モードに対応する。**ただし依存が重い (SAM3 + V-JEPA を推論時系列に噛ませる)。**

- **[部品 4] DMD で少ステップ student へ。** **DMD (Distribution Matching Distillation; 出力分布ごと teacher に合わせる蒸留)** で多ステップ生成器を few-step 化。**本日の Alaya-EVOKE (2608.13546) と同一の技法であり、2 本が独立に同じ選択をしている。** **少ステップ化の既定手段が DMD に収束しつつある、という読み方をしてよい。**

- **成績:** WorldArena 2.0 Challenge の **Track 1 で 1 位、Track 2 で 2 位。** コード・モデルは公開予定。**チャレンジ上位という事実は「部品の組み合わせが実際に噛み合う」ことの弱い証拠**であり、個々の部品の因果的な寄与は abstract からは分からない。**ablation を本文で確認すること —— 部品表として使う以上、ここが最重要である。**

## 追っているプロジェクトへの適用可能性

- **P3 / R3 —— 「行動忠実性をどう担保するか」という列を、マップに足す。** R3 の分類マップは融合の高さ・planner コスト適性・反実仮想適性の 3 軸で組んでいる。**本論文が要求するのは 4 本目ではなく、3 本目 (反実仮想に使えるか) の測り方である:** 反実仮想として使えるかは **「行動を変えたとき、生成が指令どおりに変わるか」**で測るしかない。**本論文の部品 1 は、それを損失ではなくアーキテクチャで強制する解答になっている。**

- **P3 —— ego-motion を SE(3) として attention に入れる、が本日の最大の持ち帰り。** 我々の E2E / world model 系で行動条件付けをどう入れているかを確認し、**「トークン連結」で済ませているなら、幾何変換としての注入に置き換える実験の価値が高い。**

- **P2 —— DMD の 2 例目としての価値。** Alaya-EVOKE と本論文で **DMD が異なるドメイン・異なる teacher 設計で機能している。** R2 が扱う capacity gap の議論において、**DMD は「分布を合わせる」ぶん、点ごとの模倣より gap に強い可能性がある。** 2 本が同じ選択をしている事実を、**R2 の手法選択の根拠として引ける。**

- **P1 —— 直接の適用は薄い。** 操作系のベンチであり、planner 評価には届かない。

- **留保 (08-15 の判断を維持する):** (1) **部品はいずれも既知技術の組み合わせであり、新規性は統合と工学にある。** 論文としての引用価値は低く、**実装の参考としての価値が高い。** (2) **ablation を見るまで、どの部品が効いたかは不明。** (3) ドメインが操作系。**運転への移植は「アナロジーが成立する」以上の保証がない。**

### 試すべき実験

1. **ego-motion を SE(3) 変換として attention に注入する版を作り、トークン連結版と比較する (最優先)。** 評価は動画品質ではなく **action fidelity** で行う —— **操舵指令を意図的に変えて生成させ、生成された軌跡が指令にどれだけ追従したかを測る。** 「絵の綺麗さ」で測ると差が出ないので、**指標の設計のほうが実装より重要である。**

2. **action fidelity 指標そのものを定義する。** 本論文の問題提起 (realism ≠ faithfulness) を我々のドメインで測る指標が、**そもそも手元にない。** 「指令された ego 軌跡と、生成映像から推定した ego 軌跡の差」を測る形が最も素直。**これは R1 (保証つき評価指標) の材料にもなる —— 生成モデルの評価に conformal prediction (予測の外れ率を分布仮定なしに有限標本で保証する統計手法) をかける対象として、動画品質より遥かに筋が良い。**

3. **物体一貫性の縛りは、まず軽量版で試す。** SAM3 + V-JEPA をそのまま噛ませるのは重い。**既存の検出器のマスクと、凍結した任意の視覚 encoder で代替して、「小物体が生成中に消えるか」だけを測る。** 効果が見えてから重い構成に上げる。
