# AgentGarten: simulator の状態と neural renderer の見た目を組み合わせた、real-time の学習用 world

- 対象: P3 (world model) 寄り、P2 (蒸留) にも関係。sns_wildcard (HF upvotes 142) からの採用枠。2026-10-10 は「agent 向け環境生成で分野外」として見送ったが、中核が video model の蒸留 + 自己回帰 rollout の学習法であり、再評価して採用
- 元論文: https://arxiv.org/abs/2610.12374
- 根拠: abstract のみ (candidates.json 上の abstract は末尾が途切れており、実験の数値は未確認。本文・コード未確認)

## 何を解決する論文か
agent が探索して学ぶ仮想環境は、状態・ルール・dynamics が一貫している (faithful) ことと、観測画像が実世界の分布に近い (realistic) ことの両方が要るが、多様な環境で両立させるのが難しい。AgentGarten は simulator / game engine が持つ「状態とルール」と、共通の neural renderer が作る「見た目」を分離して組み合わせることで、real-time で対話できる環境を作る。

## 手法の核心
- 役割分担: simulation backend が persistent な world state とプログラム定義のルールを持ち、neural renderer が構造化された条件 (geometry など) から画像観測を生成する。状態の一貫性を renderer に背負わせない。
- renderer の作り方: 事前学習済み video model を geometry 条件に適応 (fine-tuning) し、蒸留して real-time 推論に最適化する。
- Adversarial Forcing (本論文の提案する蒸留法): 履歴の prefilling (過去フレームを文脈として先に流し込む処理) を exact replay で微分可能にし、後段の予測に対する loss が「過去の観測の encode の仕方」まで更新できるようにする。さらに実データに対する adversarial supervision (discriminator で本物らしさを学習) で画質を上げる。
- agent 側: 各 round の経験を playbook (再利用できる手順書) に蒸留し、次の agent が引き継いで改良する。abstract では 4 round で学習効率が大きく上がると主張 (比較対象の数値は途切れていて未確認)。

## 適用可能性と実験アイデア
- **P3 (world model)**: 自己回帰の video world model は、rollout 中に自分の出力を履歴として使うため誤差が積もる。Adversarial Forcing の「履歴 encode まで後段の loss で更新する」発想は、運転の world model の長期 rollout 安定化に試せる。実験案: 既存の小さな action-conditioned video/latent world model で、履歴の扱いだけ (通常の teacher forcing vs 履歴を通した backprop) を変えて、20〜50 step 先の予測誤差を比べる。
- **P2 (蒸留)**: 大きな video model を real-time 化する蒸留の recipe として読める。capacity gap の観点で、何 step 蒸留・どの loss 構成かを本文で確認する価値がある。
- **P1 (評価)**: 「状態は simulator、見た目は neural renderer」という分離は、closed-loop simulation (プランナーの出力を環境に返して走らせる評価) の sensor 観測生成に応用できる可能性がある。ただし本論文は game/agent 環境が対象で、運転での faithful さは未検証。
- 注意: 主眼は agent の学習効率で、renderer 単体の品質評価の詳細は abstract からは分からない。まず本文で、蒸留後の fps・画質・長期 rollout の drift を確認する。
