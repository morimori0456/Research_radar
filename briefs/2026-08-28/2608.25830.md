- topic: **planner_ai** (P1) / hf_upvotes **0**
- 公開日: 2026-08-26 (Wed)
- relevance: P1 **3.5** / P2 **0.5** / P3 **1.5**
- 著者: Sai Coumar, An T. Le, Zachary Kingston

## 何を解決する論文か

**motion planning は普通「1 本の良い経路を返す」問題として解かれる。だが、障害物のどちら側を通るかが違えば、それは本質的に別の解である。**この「本質的に別かどうか」を扱う概念が **homotopy class (ホモトピー類; 障害物にぶつからずに連続変形するだけで互いに移り合える経路をひとまとめにした同値類。要するに「柱の右を通るか左を通るか」の区別)** である。**既存の高性能な planner の多くは、探索を有望な領域に絞り込む (informed) 仕組みを持つがゆえに、1〜2 個の類に解が集中してしまう。**

GTMP (Global Tensor Motion Planning) は、**層状の多部グラフ (layered multipartite graph; 経路を時間的な層に切り、各層のノードから次の層のノードへだけ辺を張るグラフ) 上での計画を、まとめてテンソル演算として解く**枠組みで、GPU で一括に処理できるのが持ち味である。本論文はこれを 2 方向に拡張する。**層と層の間をつなぐ辺を任意の局所 planner に差し替えられるようにし、そのうえで anytime (いつ打ち切っても、その時点で使える解が手に入る) な 2 つの方針を載せる。**

## 手法の核心

- **層間の辺を black-box の局所 planner にする。**直線補間、スプライン、サンプリングベース計画、軌道最適化、生成モデルによるサンプリング — **どれを差しても枠組みが成立する。**局所的な繋ぎ方と、大域的な探索構造が分離されている。

- **Anytime GTMP — 固定予算でランダムに再スタートを繰り返す。**保証は **「ほとんど確実に (almost surely) すべての homotopy class を覆う」。**多様性の側の保証である。

- **AO-GTMP — 予算を増やしながら informed に展開し、最適コストに収束する。**asymptotically optimal (漸近最適; 計算資源を無限に注げば最適解に収束する性質) の側。**2 つの方針が、多様性と最適性という別々の目的に対応している。**

- **理論の中身が実用的である。1 つのサンプルグラフが、δ-clear (障害物から距離 δ 以上離れた代表経路を持つ) かつ長さが有界な homotopy class をすべて覆う、と証明している。**要するに **「極端に細い隙間を通る類だけは取り逃すが、それ以外は覆える」**という形の保証。

- **そして本論文で最も持ち帰る価値の高い定理はここである — 各層のサンプル数を増やすと、その層で解を取り逃す確率は指数的に下がる。一方、局所 planner を強くしても、必要な層数は sublinear にしか減らない。**
  **平たく言えば「計算資源は、賢い局所 planner を作ることよりも、幅を広く取ることに使え」ということである。**しかも**片方が指数、片方が sublinear という、比較にならないほどの差がついている。**

- **実験は 2 面。マニピュレーションのベンチマークでは既存最高水準と同等。2 次元ナビゲーションでは、位相的に多様な解の束を返す — informed な既存手法が 1〜2 の類に集中するのに対して。**

## 読むときの但し書き

- **評価が自動運転ではない。**マニピュレーションと 2 次元ナビゲーションであり、**車両の運動学的制約 (非ホロノミック拘束; 車は横に平行移動できない、という類の制約) の下で同じ結論が成り立つかは検証されていない。**AD へ持ち込むなら、ここは自分で確かめる範囲になる。
- **「最高水準と同等」であって上回ってはいない。**この論文の売りは性能ではなく **多様性の保証と、資源配分に関する理論**である。**性能目当てで読むと空振りする。**
- **多様な解を返した後、どれを選ぶかは扱っていない。**AD の planner にとっては**むしろそちらが本番である** — 位相的に異なる複数の候補が出たとして、選択の基準を与えるのは別の問題。
- **時間軸の扱いが見えない。**層状グラフは経路の空間的な離散化だが、**動的な障害物 (他車) が絡むと層は時空間で切る必要がある。**AD への移植では、ここが最大の設計上の分岐になる。

## P1/P2/P3 への適用可能性

### P1 (Planner AI + 評価) — 本日唯一の P1。評価の軸として使う方が、planner として使うより価値が高い

**この論文を「速い planner」として読むと AD には遠い。「planner を評価する軸を 1 つ増やすもの」として読むと、直接効く。**

**その軸とは、mode coverage — planner が本質的に異なる何通りの解を出せているか、である。**

**AD の planner の評価は、ほぼ常に「出した 1 本がどれだけ良かったか」で測られる。**軌跡誤差、衝突率、快適性。**だがこれらは全部、単一の出力に対する指標である。**
**前方の停止車両に対して「左から抜く」「右から抜く」「後ろで待つ」という 3 つの本質的に異なる選択肢のうち、planner が構造的に 1 つしか生成できていないとしたら、その事実は既存のどの指標にも現れない。**たまたまその 1 つが正解だった場面では、満点が出る。

**そしてこれは R1 (HIL 評価 × conformal 安全指標) が測ろうとしている「過保守」と、直接つながる。**
**過保守な planner の多くは、選択肢を 1 つしか持っていない planner である。**待つ以外の類を生成していないから待つ。**この見方に立つと、過保守は「重みの設定が保守的すぎる」という連続的な問題ではなく、「候補の集合が構造的に痩せている」という離散的な問題として捉え直せる。**
**R1 の指標に "mode coverage" を 1 本足す価値がここにある。**08-27 の RoG-DAgger から取った solvability (残っている逃げ道の本数) と近いが、**あちらは「何本残っているか」、こちらは「残っている中に本質的に違う選択肢が何種類あるか」。**10 本の逃げ道が全部「少し右にずれる」なら、それは 1 種類である。**solvability を homotopy class で数え直したものが mode coverage だと言える。**

**理論の含意も、そのまま AD の設計判断に読み替えられる。**「幅を広げる方が指数的に効き、局所の質を上げても sublinear にしか効かない」は、**サンプリングベースの候補生成を持つ AD planner の予算配分に対する直接の指針である。**候補生成の質を上げる工数と、候補数を増やす工数のどちらに投じるべきかについて、**理論的な根拠を持った回答が 1 つある**という状態は、それ自体が有用。

### P3 (次世代アーキテクチャ) — 弱いが 1 点

**end-to-end な driving policy が本質的に単一の mode しか出せない**という批判は以前からあるもので、**この論文は「多様性を保証付きで担保する」側の到達点を示している。**学習ベースの方策の多様性を評価するときの上限の目安として使える。それ以上ではない。

### P2 (FM 蒸留 + 適合) — 該当なし

無理に繋げない。

## 試すべき実験アイデア

1. **既存の走行ログに mode coverage を後付けで計算する (半日、学習ゼロ)。**
   厳密な homotopy class の判定は面倒だが、**AD の実用範囲では近似で足りる。**前方の障害物に対して**「左を通ったか / 右を通ったか / 通らずに止まったか」**という 3 値のラベルを、軌跡と障害物の位置関係から機械的に付ける。**そのうえで、planner が生成した候補集合の中に、何種類のラベルが含まれていたかを数える。**
   **出てくる分布が本命である。**「ほとんどの場面で候補が 1 種類しかない」なら、**それは過保守の構造的な原因を特定したことになり、R1 の主張の核になる。**
   **08-27 に挙げた solvability の後付け計算と同じログ・同じ運動モデル積分を使うので、同じ半日枠に相乗りできる。**むしろ **solvability を計算するときに、候補軌跡を homotopy ラベルで分類しておくだけで、両方が同時に手に入る。**

2. **R1 の最初の図に、軸をもう 1 本足すかを決める (2 時間、実装ゼロ)。**
   08-27 の DIGEST で決めた R1 の最初の図は「横軸 solvability、縦軸に衝突率と走行時間」だった。**上の 1 を済ませると、solvability を mode 数で置き換えた版が同じコストで引ける。**
   **どちらの軸で過保守と危険がきれいに分かれるかを見て、R1 の主指標を決める。**これは**選定作業であって実験ではないので、90 分ブロックを要求しない。**

3. **層のサンプル数と局所 planner の質の資源配分を、自分の設定で 2 点だけ確認する (1 日)。**
   理論の主張 (幅は指数、局所の質は sublinear) が**車両ダイナミクスの下でも成り立つか**を、粗く確かめる。**候補数を 2 倍にした腕と、候補生成の精度を上げた腕を 1 つずつ。**成り立てば planner 側の工数配分の根拠になり、成り立たなければ**「非ホロノミック拘束下では結論が反転する」という報告価値のある観測になる。**
   **ただし優先度は 1・2 より下。**これは planner を作る側の作業で、**P1 の当面の焦点は評価の側にある。**
