# Learning New Facts with QLoRA: An Acquisition-Retention Frontier

- arXiv: https://arxiv.org/abs/2608.25677
- topic: **fm_distill_finetune** (P2) / hf_upvotes **0**
- 公開日: 2026-08-26 (Wed)
- relevance: P1 **0.5** / P2 **4.5** / P3 **1.5**

## 何を解決する論文か

**PEFT (Parameter-Efficient Fine-Tuning; 基盤モデルのごく一部のパラメータだけを更新する適合手法の総称) は「更新する重みが少ないから、元の能力は壊れない」と広く信じられている。**この論文はその前提を統制実験で崩す。**壊れるかどうかは「PEFT かどうか」ではなく「adapter の容量」で決まる。**

著者は **OpenStreetMap 由来の匿名化された地理的な対応関係**を新しい事実として与え、**Qwen3-4B がそれを覚えられるか (acquisition) と、無関係な能力を保てるか (retention) を同時に測る**ベンチマークを組んだ。**FFT (Full Fine-Tuning; 全パラメータ更新) と、QLoRA (基盤モデルの重みを 4bit に量子化して凍結し、小さな低ランク行列だけを学習する省メモリな適合手法) の rank 8 / 16 / 32 / 64 を比較する。**結果は明確な**トレードオフ曲線 (acquisition–retention frontier)** であり、**rank がその曲線上の位置を決めるつまみになっている。**

## 手法の核心

- **rank が低いと覚えないが忘れない。** 低 rank の QLoRA は **OOD (out-of-distribution; 学習させた対象とは無関係な、元からできていたタスク) の性能をよく保つが、獲得できる事実の数が少ない。**

- **rank を上げると「言い換えても答えられる」ようになるが、代償が増える。**高 rank は **same-fact paraphrase generalization (同じ事実を別の言い回しで訊いても答えられること) を改善する。**丸暗記ではなく本当に取り込めている、ということ。**だがその改善に比例して、無関係なベンチマークの性能が落ちる。**

- **最も意外な点 — FFT の方が「保守的」だった。**全パラメータを更新する FFT は、**一般能力の保持は良い一方で、事実獲得の最高域には届かない。**つまり **「更新するパラメータ数が多いほど忘れる」という素朴な直感は成り立っていない。**支配しているのは更新の総量ではなく、**低ランク部分空間に押し込められた更新の集中度**の方だと読める。

- **挙動が重みの側の診断とも一致している。**分布 (出力分布の変化)、重み空間 (元の重みからの距離)、スペクトル (特異値分布の変化) の 3 系統の診断を取り、**高 rank の QLoRA ほど事前学習済みモデルから遠くへ動いている**ことを示している。**振る舞いの観察と内部の観察が同じ結論を指している**という構成。

- **効果が出る条件を切り分けている。**別途行った数学への適合実験では**このトレードオフが弱い。**著者の解釈は、**「事前学習で既に支えられている技能を強化する」場合よりも「新しい事実の対応関係を植え付ける」場合に、この現象が強く出る**というもの。

## 読むときの但し書き

- **モデルが Qwen3-4B の 1 系統である。**frontier の形が model scale とともにどう動くかは分からない。**「rank 32 で折れる」といった具体的な数字を他モデルに持ち込んではいけない。**持ち込めるのは**「rank を振ると曲線が出るので、自分の設定で自分の曲線を引け」**という手続きの方。
- **ベンチマークが人工的である。**匿名化された地理対応は統制のために良い設計だが、**実務の適合対象 (別機種のセンサ特性、別ドメインの語彙) が「新しい事実」と「既存技能の強化」のどちらに近いかは自明でない。**著者自身が両者で結果が違うと言っている以上、**自分の対象がどちら寄りかを先に判定する必要がある。**
- **量子化と低ランクが分離されていない。**比較されているのは FFT と QLoRA であり、**4bit 量子化しない LoRA が入っていれば、「rank の効果」と「量子化の効果」を分けられた。**本文に無ければ、これは自分で埋められる隙間である。
- **retention の測り方に依存する。**「無関係なベンチマーク」の選び方次第で、忘却の見え方は大きく変わる。**どのベンチマークを OOD としたかを確認する。**

## P1/P2/P3 への適用可能性

### P2 (FM 蒸留 + 適合) — 本日の P2 の 2 本柱の一方。topics.yaml の「少データでの適合」「PEFT/LoRA 等の効率的適合」に直撃

**この論文が P2 に与えるものは、手法ではなく設計変数の格上げである。**

これまで LoRA の rank は「メモリと計算量の都合で決める数字」として扱われがちだった。**この論文はそれを「獲得と保持のどちらを買うかを決めるつまみ」として位置づけ直している。**そして**そのつまみには最適値がない — 目的次第で位置が変わる、という形の結論**になっている。

**実務上の含意ははっきりしている。**基盤モデルを別機種・別ドメインへ適合させるとき、**「元の汎用性能をどこまで捨てて良いか」を先に決めないと rank を選べない。**逆に言えば、**適合の要求仕様に「保持すべき能力の下限」が書かれていないなら、それは仕様が不完全だということである。**

**FFT が保持で有利という結果は、実務的な選択肢の順序を変える。**メモリが許すなら、**「まず FFT を基準線として置き、QLoRA はそれに対する省メモリ近似として評価する」**のが正しい順序になる。**「PEFT だから安全」という理由で QLoRA を選ぶのは、この論文の後では根拠を失っている。**

### R2 (蒸留の capacity gap の系統則) との関係 — 同じ形をした第 3 の曲線

**R2 が探しているのは「teacher/student の容量比と、蒸留が破綻する境界のスケーリング則」である。この論文は、それと構造的に同じ形の曲線を、別の軸で引いている。**

- R2: **student の容量**を振ると、teacher を真似られる限界が動く。
- 本論文: **adapter の rank (= 更新の容量)** を振ると、獲得できる量と保持できる量の境界が動く。

**どちらも「容量を振ると、2 つの望ましい性質のトレードオフ曲線が現れる」という同じ骨格である。**そして**本論文の方が実験が圧倒的に安い** — 4B のモデルに rank を 4 点振るだけで曲線が出ている。

**したがって R2 の予備実験の入口として、この設定を借りるのが合理的である。**「小規模で予備実験、法則が見えるか」という R2 の次のアクションに対し、**曲線が出ることが既に確認済みの設定を出発点にできる。**

**さらに、08-27 に採用した PROOF-Gen との交絡整理にも効く。**あちらから出た問いは「capacity gap とされてきた現象の一部は、teacher データの穴ではないか」だった。**本論文の設定は teacher を介さない (直接の教師データで学習する) ので、データの穴の効果を持ち込まずに容量だけの効果を見られる。**つまり **R2 の交絡を切り分ける対照条件として、この設定はそのまま使える。**

### P3 / P1 — 該当薄

VLA を別の身体・別のセンサ構成へ適合させるときにも同じ frontier が出るはずだが、本論文はそこを扱っていない。無理に繋げない。

## 試すべき実験アイデア

1. **自分の適合対象が「新しい事実」型か「既存技能の強化」型かを判定する (2 時間、学習ゼロ)。**
   本論文が最も強く主張しているのは**条件付きの結論**である — 効果は前者で強く、後者で弱い。**判定は学習を回さずにできる。**適合させたいデータの中身を見て、**「事前学習済みモデルが素で何割正解するか」を測るだけ。**素で全く解けないなら「新しい事実」型で、この論文の frontier が効く。**そこそこ解けるなら rank の選択はもっと自由でよい。**この判定が済めば、次の実験の設計が決まる。

2. **rank を 4 点振って、自分の frontier を 1 枚の図にする (半日〜1 日、QLoRA が既に動いていれば実装ゼロ)。**
   **横軸に獲得性能、縦軸に保持性能、点は rank。**論文と同じ図を自分のデータで引く。**公開コード (github.com/zhngstl/new_facts_forgetting) があるので、ベンチマーク側の実装コストは低い可能性が高い。**
   得られるのは自分の設定での rank 選択根拠であり、**同時に R2 の「容量を振ると曲線が出る」という骨格の予備確認にもなる。**1 つの実験で 2 つの目的を満たす。

3. **論文に無い対照条件を 1 つ足す — 量子化なしの LoRA (追加半日)。**
   FFT と QLoRA の間には **rank の違いと 4bit 量子化の違いが同居している。**同じ rank で量子化だけを外した腕を 1 本足せば、**frontier のどれだけが量子化由来かが分かる。**論文の隙間をそのまま埋める作業なので、**結果が出れば単独で報告価値がある。**規模も小さい。
