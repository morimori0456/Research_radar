# MiniWAM: 世界モデルの予測 target を compact な表現に替え、World Action Model の学習を効率化

- 対象: P3 (次世代アーキテクチャ)。P2 (蒸留的な target 設計) にも関連
- 元論文: http://arxiv.org/abs/2610.12194v1 (project page: https://j1dan.github.io/MiniWAM)
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
WAM (World Action Model; 行動と将来状態を同時に予測する policy) は world model の予測を共同学習の目的に使うが、多くは事前学習済み視覚 backbone の native な特徴空間で未来を予測するため、target が高次元で学習が重い。本論文は、制御に関係する遷移情報だけを残した compact な target を作ってそれを予測させる。

## 手法の核心
- PRISM (Predictive Representations via Inverse Spatiotemporal Modeling): 現在と未来の遷移 (privileged な情報) から compact な表現を学ぶ。inverse-dynamics supervision (前後の状態から行動を当てる) と feature reconstruction を併用し、制御関連の遷移情報と未来状態の情報を両立させる。
- PRISM encoder を凍結し、MiniWAM は現在の観測から「その compact target と action」を共同予測する。
- native な未来 feature token より 65 倍少ない target で、DINOv3 / WAN2.1 VAE の両特徴での native 予測を上回り、WAM の学習が最大 8 倍速い。
- 0.25B パラメータで、LIBERO・LIBERO-Plus・RoboTwin 2.0 (ロボット操作 simulation benchmark) で大型 WAM と競合。
- 表現解析で、PRISM が reconstruction だけの場合より behavioral な構造を持つことを示す。

## 適用可能性 (P3)
- 運転 world model でも「ピクセル/高次元特徴の未来予測」より「制御に効く compact 表現の未来予測」の方が学習効率が良い可能性を示す。E2E driving の auxiliary world loss の設計に直結。
- 注意: manipulation の simulation 結果のみ。運転は multi-agent で遷移の分布が違う。

## 試すべき実験
1. 手元の E2E planner の補助 loss で、native 特徴の未来予測と、inverse-dynamics+reconstruction で作った低次元 target の予測を比較する (target 次元と学習時間、planning 指標)。
2. 低次元 target の次元数を振り、性能が落ちる境界を測る。
3. inverse-dynamics 項の有無を ablation し、ego の行動情報がどれだけ寄与するか見る。
