# Self-Retrospection Distillation (SRD): 結果を見た後の hindsight を、結果を知らない前の foresight に蒸留する

- 対象: P2 (Foundation Model 蒸留 + 適合)。sns_wildcard (HF upvotes 126) だが keyword (distillation) が P2 に一致するため P2 枠で採用
- 元論文: https://arxiv.org/abs/2610.08077
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
RLVR (Reinforcement Learning with Verifiable Rewards; 正誤が機械的に判定できるタスクで outcome reward を使う RL) は、group-relative な目的 (同じ問題の複数 rollout の報酬差で学習する GRPO 系) では、全 rollout が同じ報酬だと学習信号が 0 になる。軌跡自体には「何が必要か・どこで失敗したか」の情報があるのに捨てられる。この信号を取り出す。

## 手法の核心
- prospective learning: 事後 (post-hoc) の経験を使い、行動前の視点からの foresight 予測を教師する枠組み。
- SRD: 完了した軌跡から得られる privileged hindsight (有用だった知識・避けるべき落とし穴) を、同じ policy の trajectory-blind な foresight へ self-distillation する。teacher と student は同一モデルで、見える情報だけが違う。
- foresight は学習時の target にのみ使い、推論時に明示的に生成する必要はない。
- 10 の tool-integrated reasoning / long-horizon agentic タスクで、RLVR と self-distillation の baseline を補完し最大 +24.2pp。
- reward-uniform な group が 37〜98% の状況でも信号が取れる。2B 設定で全失敗 group が 98% のとき、RLVR 単独は成功率 0.0% で止まるが SRD 追加で 60.6%。

## 適用可能性 (P2)
- 蒸留 recipe の観点: 「privileged information を持つ同一モデルを teacher にする」形は、外部の大 teacher が使えない / capacity gap が大きい場合の代替になりうる。
- 注意: LLM agent の RL が対象で、perception や driving の蒸留に直接は載らない。abstract の数値は著者設定内。

## 試すべき実験
1. 手元の RL 学習で reward-uniform な group の比率をまず計測し、SRD が効く領域かを判断する。
2. 小型 student で、成功/失敗軌跡の要約 (hindsight) を条件に入れた同一モデルの出力を teacher として、hindsight なしの出力へ蒸留する最小実装を作る。
3. 外部 teacher からの蒸留と比べ、capacity gap が大きい設定でどちらが安定するか見る。
