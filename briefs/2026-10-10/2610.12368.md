# LiteNWM: 候補軌跡を共有 encoding で一括評価する軽量な latent navigation world model

- 対象: P3 (次世代アーキテクチャ)。P1 (候補軌跡の評価) にも関連
- 元論文: http://arxiv.org/abs/2610.12368v1
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
direct な visual navigation policy は軌跡を速く出せるが、その未来の帰結を評価しない。generative な navigation world model (映像を生成して先を見る) は foresight を与えるが、複数候補を rollout するとコストが大きい。本論文は latent 空間で候補を一括評価し、onboard で動かせる速度にする。

## 手法の核心
- 視覚 encoding を全候補軌跡で共有し、各候補の action-conditioned な未来表現を複数 horizon で同時に予測する (映像は生成しない)。
- learned scorer が予測表現から軌跡を選ぶ。
- RECON・SCAND・SACSoN (ロボット navigation データセット) の offline 評価で、NoMaD+NWM-XL (NoMaD は拡散型 navigation policy、NWM は navigation world model) に対し軌跡誤差を macro 平均で 17.56% 削減、RTX 5090 で end-to-end 128 倍高速。
- evaluator は NoMaD から MBRA へ proposer ごとの再学習なしで転用でき、MBRA の誤差を 16.2% 削減。
- 実機の未見の屋内外で、navigation 成功率を NoMaD の 43.3% から 83.3% へ。

## 適用可能性 (P3 / P1)
- 「proposer が複数候補を出し、world model が scorer で選ぶ」構造は、運転の multi-modal 軌跡候補の reranking に当てはまる。proposer 非依存で再学習不要という点は、既存 planner に後付けしやすい。
- 注意: 低速のロボット navigation で、運転のような高速・多主体のダイナミクスは未検証。

## 試すべき実験
1. 手元 planner の出す K 本の候補に対し、latent world model + scorer で rerank し、closed-loop simulation の指標変化を見る。
2. 候補数 K と horizon 数を振り、レイテンシと精度のトレードオフを測る。
3. 別 planner の候補に scorer を再学習なしで使い、転用性を確認する。
