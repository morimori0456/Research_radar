# SFT を long-tail 視点で見直す: prior barrier を測り、足りない concept に instruction 予算を寄せる PASS

- 対象: P2 (Foundation Model 蒸留 + 適合)
- 元論文: http://arxiv.org/abs/2610.12345v1
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
SFT (Supervised Fine-Tuning; 教師データで事前学習済み LLM を下流タスクに合わせる) では、必要な concept が事前学習でどれだけ支持されているかに大きな差がある。頻出 concept は既に学習済みだが、稀な concept は表現が弱く、同じ instruction 数では足りない。この差を定量化し、限られた予算で instruction をどう選ぶかを扱う。

## 手法の核心
- prior barrier: 事前学習済みモデルが、目標 concept より競合 concept をどれだけ強く支持しているかの指標。分布は long-tail で、tail concept ほど barrier が高く多くの SFT evidence が必要。
- 理論面: SFT 後の予測リスクの上界を、prior barrier と蓄積した SFT evidence の関数として導出。
- PASS: 参照データから concept を作り、各 instruction が concept の区別にどれだけ evidence を与えるかを推定し、まだ足りていない concept へ選択予算を adaptive に配分する instruction selection 手法。
- 7 つの SOTA の instruction selection 手法を 4 つの backbone×予算設定で一貫して上回り、ablation では uniform 配分より adaptive 配分が効く。

## 適用可能性 (P2)
- 少データでの適合: 「他ドメインへ適合するときに、どのデータを優先して使うか」の根拠を与える。新ドメインの稀な概念 (専門用語、特殊な操作など) ほど不足しやすい、という診断に使える。
- 注意: LLM の instruction tuning が対象で、vision や蒸留の設定への移植は自明でない。

## 試すべき実験
1. 手元の適合対象ドメインで、base model の concept ごとの prior barrier 相当 (正解 vs 競合の log-prob 差) を測り、long-tail になっているか確認する。
2. 予算固定で random 選択 / uniform 配分 / PASS 風の adaptive 配分を比較し、tail concept の精度差を見る。
3. 蒸留データ (teacher 出力) の選別にも同じ配分を使い、student の tail 性能が上がるか試す。
