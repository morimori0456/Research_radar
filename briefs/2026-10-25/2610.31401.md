# HERD: Harness-Evolving Recursive Distillation for Continual Learning (2610.31401)

- トピック: fm_distill_finetune (P2) / スコア 3.0 (arXiv RSS cs.CL から回収・candidates.json には無い)
- URL: https://arxiv.org/abs/2610.31401

## 何を解決する論文か

continual learning (新しい skill を覚えつつ、既存の能力を失わないようにする学習) では、重みを更新する parametric な方法は catastrophic forgetting (新しい学習で古い能力が消える現象) や plasticity loss (学習を重ねると新しいことを覚えにくくなる現象) に悩む。一方、prompt や skill・harness (LLM を包む手順書や補助 script) に経験を溜める non-parametric な方法は、context 長と文章への圧縮による情報の欠落に縛られる。HERD (Harness-Evolving Recursive Distillation) は、この 2 つを組み合わせ、経験をまず harness に溜め、それを蒸留で重みに取り込む。

## 手法の核心

- **harness 側**: skill を継続的に更新して再利用できるパターンを捉え、skill が捉えきれなかった「残差の大きい例」を bounded memory (容量上限付きの記憶) に残す。
- **parameter 側**: drift-constrained distillation (元の model から離れすぎないよう制約を付けた蒸留)。anchor を 2 つ (dual anchors) 置いて、再帰的 (recursive) に何度も蒸留しても forgetting が積み上がらないようにする。
- 評価は 25 stage の task stream (TRACE+17)。memory と compute の予算を固定した条件で、新 task の獲得は最強の parametric baseline と同等、forgetting は最小、汎用能力の保持は最強。

## P2 への適用可能性

- 蒸留を何度も回す運用 (teacher を更新して再蒸留、新ドメインのたびに student を更新) では、世代が進むほど元の能力から drift する。dual anchors と drift 制約は、その drift を抑える loss 設計の例として参照できる。
- 「skill が捉えきれなかった高 residual の例だけを memory に残す」は、再学習用データの選別基準として、運転ログの稀な場面を残す replay buffer にも読み替えられる。
- ただし対象は LLM agent の harness で、蒸留の対象は言語 model。anchor の 2 つが何か (元の model と直前の世代か) は abstract からは分からない。

## 試すべき実験アイデア

1. 手元の student を新しいドメインに 2〜3 回続けて蒸留で更新し、各回の後に元ドメインの性能を測って、世代ごとの forgetting の積み上がりを可視化する (HERD の問題設定の縮小版)。
2. 蒸留 loss に「初期 student との出力 KL」と「直前の世代との出力 KL」の 2 つの anchor を加え、片方だけ・両方・なしで forgetting を比べる。
3. replay に残すデータを「現在の student の loss が高いもの」だけにする版と、ランダム版を同じ容量で比べる。

## 注意

abstract のみに基づく。2 つの anchor の定義、memory の容量、forgetting の定量値は未確認。harness 側の寄与は agent 向けで、視覚・運転の蒸留には移しにくい。
