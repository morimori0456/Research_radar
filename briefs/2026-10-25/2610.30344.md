# AQL-Lite: Enabling Efficient Knowledge Acquisition for Arabic LLMs via Data-Centric Continual Pretraining (2610.30344)

- トピック: fm_distill_finetune (P2) / スコア 3.5 (arXiv RSS cs.CL から回収・candidates.json には無い)
- URL: https://arxiv.org/abs/2610.30344

## 何を解決する論文か

多言語 LLM を新しい言語 (ここでは Modern Standard Arabic; MSA) に適合させる continual pretraining (CPT; 既に学習済みの model に、新しい分野のデータで事前学習を続ける) は、ノイズの多い web データと計算コストが重い。この論文は、データの選別を最優先にし、更新するパラメータも一部に絞った「軽い CPT の recipe」を出し、full-parameter CPT (全パラメータを更新する CPT) の効果の 94% を 52% の時間で得たと報告する。「基盤モデルを別ドメインに転用する recipe」の実測例として読める。

## 手法の核心

- **quality-first curation**: 構造的な cleaning、heuristic と model ベースの filtering、MSA の選択、deduplication の pipeline。matched 1B-token では、curation 済みデータの CPT は raw web text の CPT より 4 benchmark 平均で +3.51 点。raw web text の CPT は base model から全く改善しない。
- **partial-parameter CPT**: RS-LoRA (rank-stabilized LoRA; rank を大きくしても学習が安定するよう scale を直した LoRA) の adapter を network 全体に付け、さらに最後の 8 transformer block と embedding matrix も unfreeze する。layer ごとに learning rate を変える。
- 5B-token の統制比較で、full-parameter CPT の gain の 94% (平均 73.19 vs 73.58) を wall-clock 52% で達成し、adapter だけの baseline には全 benchmark で勝つ。
- component ablation: adapter・unfreeze した block・embedding の学習が、それぞれ寄与している。
- 40B token まで scale し、100 万件で instruction-tuning した 12B model が OALL v2 (Open Arabic LLM Leaderboard v2) の 7 benchmark で平均 75.3。

## P2 への適用可能性

- 「adapter だけでは足りず、末尾の block と入出力側 (embedding) も開ける」という中間点は、LoRA だけで他ドメインに適合しきれないときの具体的な設計になる。蒸留後の student を別機種・別ドメインに合わせる fine-tuning でも、同じ 3 点セット (LoRA + 末尾 block + 入力側) が試せる。
- データの curation が効果の大半を作るという結果 (raw のままだと gain ゼロ) は、少データ適合でデータ選別に先に時間をかける根拠になる。
- 対象は言語であって、視覚や運転には直接移せない。「末尾 block を開ける」効果が encoder 側 (視覚 backbone) でも出るかは別問題。

## 試すべき実験アイデア

1. 手元の適合タスクで、(a) LoRA のみ、(b) LoRA + 末尾 N block の unfreeze、(c) full fine-tuning を、同じデータ量・同じ wall-clock 条件で比べ、(b) が (c) のどれだけを回収するかを測る。
2. (b) の unfreeze する block 数 (2 / 4 / 8) と layer-wise learning rate (下の層ほど小さく) の有無を ablation し、費用対効果の良い点を探す。
3. 適合データに filtering を掛ける前後で同じ recipe を回し、「データ選別だけでどれだけ改善するか」を分離して見る。

## 注意

abstract のみに基づく。layer-wise learning rate の具体値、adapter の rank、統制比較の seed 数・信頼区間は未確認。対象は言語の適合で、視覚・運転ドメインでの再現は未検証。
