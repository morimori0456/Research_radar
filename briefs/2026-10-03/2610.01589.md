# PAGER: Partial-to-global Alignment via Geometric and Relational Distillation

- arXiv: `2610.01589` / https://arxiv.org/abs/2610.01589
- 配属: fm_distill_finetune (P2) ・ candidates.json 内
- スコア: **P2 4.0** ・ hf_upvotes 0

## 何を解決する論文か

事前学習済みの 3D encoder (点群から特徴を出すモデル。Sonata・Concerto など) は、部屋全体を再構成した「全体の点群」を、共通の world 座標系で学習している。一方、ロボットや車が実際に見るのは、その時点の視点から見えた「部分的な点群」で、座標はカメラ基準。この差だけで性能が崩れる。frozen の Sonata は、全体の点群では 72.47 mIoU (mean Intersection over Union; 領域分割の精度) なのに、1 フレームのカメラ座標の入力では 2.57 mIoU になる。PAGER は、部分観測のラベル無しで、この表現のずれを埋める適合手法。

## 手法の核心

- **ずれの切り分け:** 学習なしで重力方向をそろえるだけで 41.64 mIoU まで戻る。つまり、座標系の違いが劣化の大部分だが、正規化 (canonicalization) だけでは埋まらない。
- **凍結した global の特徴空間に合わせる:** 事前学習済みの encoder と、全体の点群で作った分割 head は凍結する。軽量の adaptation module だけを学習し、部分観測の特徴を global の特徴に合わせる。
- **2 種類の蒸留 loss:** (1) matched-point の特徴の一致 (同じ 3D 点について、部分観測から出した特徴を、全体の点群から出した特徴に近づける)。(2) relational supervision (特徴同士の類似度の構造を global 側と同じに保つ。点ごとの一致だけでは崩れる「関係」を保つ)。
- **教師は幾何だけ:** 学習時に必要なのは、部分観測と全体の点群のペアの幾何情報だけで、ラベルは要らない。推論時は部分観測だけで動く。
- **結果:** 部分観測のラベル無しで、ラベルを使った PEFT (Parameter-Efficient Fine-Tuning; 一部のパラメータだけ学習する適合手法) を Sonata・Concerto の両方で上回る。ScanNet → ScanNet++ の zero-shot 転移では、全パラメータを fine-tuning した Sonata を上回る (53.93 vs 48.09 mIoU)。

## P2 への適用可能性

- **「基盤モデルを別の入力条件に転用する recipe」として P2 の高優先に当たる。**凍結した基盤モデルの特徴空間を「teacher」とみなし、入力条件が違う側 (部分観測) をそこに合わせる。自動運転では、例えば「蓄積した地図の点群で学習した encoder」を「1 フレームの LiDAR」に使う、「他車種のセンサ配置」に移す、といった状況に同じ形で当てはまる。
- **fine-tuning すると転移性能が落ちる、という比較が有用。**全パラメータの fine-tuning が、別データセットへの転移で凍結 + 軽量 module に負けた。P2 で「他ドメインに適合させるとき、どこまで凍結するか」を決める根拠の 1 つになる。
- **relational loss は他の蒸留にも流用できる。**点ごとの特徴の一致に「類似度の構造を保つ」項を足す設計は、teacher と student の構造が違う蒸留でも使える (relational KD の系統)。
- **限界:** 屋内のシーン (ScanNet) だけ。屋外の LiDAR は点の密度の分布が大きく違う。部分観測と全体の点群のペアが必要で、それを作るには位置合わせされた蓄積の点群が要る。

## 試すべき実験アイデア

1. **(2D toy) 部分観測のずれを再現:** 2D の点群の形状分類で、全体の形で encoder を学習して凍結し、「一方向から見えた点だけ」を入力したときの精度の落ち方を測る。(a) 正規化だけ、(b) matched-point の一致のみ、(c) relational loss も追加、で adapter を学習して比べる。relational 項がどれだけ効くかを見る。
2. **(同じ toy) 凍結 vs 全体の fine-tuning の転移:** 少し違う形状分布 (別データセット役) への zero-shot 転移で、(c) と全パラメータの fine-tuning を比べ、論文の「凍結の方が転移で強い」が toy でも出るかを確かめる。
