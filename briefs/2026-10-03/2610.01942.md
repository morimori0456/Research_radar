# Latent-Foresight: End-to-End Learning Predictable Representations for Latent World Models

- arXiv: `2610.01942` / https://arxiv.org/abs/2610.01942
- 配属: next_arch (P3) ・ candidates.json 内

## 何を解決する論文か

最近の world model (現在の観測から未来の状態を予測するモデル) では、VFM (Vision Foundation Model; DINOv2 のような大規模事前学習済みの画像 encoder) の特徴空間の中で未来を予測するやり方が有力になっている。ただし既存手法は 2 段構成で、まず VFM の特徴を PCA や別に学習した autoencoder で圧縮し、その固定された latent 空間の上で予測器を学習する。表現の学習と時間方向の予測が切り離されているので、latent 空間が「予測しやすい」形になっている保証がない。Latent-Foresight は、latent tokenizer (特徴を圧縮した token にする部分) と予測器を end-to-end で同時に学習し、予測しやすい表現そのものを作る。

## 手法の核心

- **tokenizer と動力学モデルの同時学習:** VFM の特徴を圧縮する latent tokenizer と、flow-based の生成的な動力学モデル (flow matching で次の latent を生成する予測器) を、1 つの学習で同時に最適化する。
- **latent collapse を防ぐ工夫:** 同時に学習すると、「何も情報を持たない定数の latent」にすれば予測が簡単になってしまう (latent collapse)。これを防ぐ設計と、再構成の目的と生成の目的の向きをそろえる設計を入れている (詳細は本文)。
- **段階の削減:** 2 段構成で必要だった別々の学習段階 (高解像度への適合時も含む) が不要になる。
- **結果:** 複数の「未来のシーン理解」タスク (未来の分割・深度などを VFM の特徴から予測するタスク) と複数の予測 horizon で、2 段構成の baseline を一貫して上回る。時間方向に一貫した latent が得られる。コードと重みが公開されている。

## P3 への適用可能性

- **運転の world model の「どの空間で予測するか」の設計に直結する。**画素を予測する video world model は重い。VFM の特徴空間で予測する方式は車載向きだが、圧縮を固定すると予測に要らない情報が残り、必要な情報が落ちる。end-to-end にすると、予測のために必要な情報を表現が自分で残すようになる。
- **10-02 の Planning Limits (`2609.39235`) と同じ問いの別の面。**あちらは「予測が正確でも planning が上手くなるとは限らない」、こちらは「表現を予測しやすくすると予測が上手くなる」。今日の次点の Criterion-aligned loss (`2610.01224`; 成否を決める物理量を latent に残させる) と合わせると、「latent に何を残すか」を決める 3 つの方法 (予測しやすさ / 成否の基準 / 何もしない) を比べられる。
- **限界:** 評価は「未来のシーン理解」で、world model を planning や制御に使った評価ではない。collapse を防ぐ工夫は abstract では具体的に分からない。end-to-end 学習は、2 段構成より不安定になりやすい。

## 試すべき実験アイデア

1. **(2D toy) 固定圧縮 vs end-to-end:** 2D で複数の物体が動く画像列を用意し、固定の encoder (ランダム重みで代用) の特徴を、(a) PCA で圧縮 → 予測器、(b) tokenizer と予測器を同時学習、で 5 ステップ先の物体位置を線形 probe で読み出す。(b) で collapse が起きる条件 (collapse を防ぐ項なし) も確認する。
2. **(同じ toy) 予測しやすさと planning の関係:** (a) と (b) の latent で CEM planning を回し、予測誤差が下がった分だけ planning の成功率が上がるかを見る。上がらなければ、10-02 の Planning Limits の結論と一致する。
