# RoboJEPA: latent world model の scaling law を 12 embodiment の実ロボットデータで測る

- 対象: P3 (world model)
- 元論文: http://arxiv.org/abs/2610.10515v1 (checkpoint とコードは公開と記載)
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
latent world model (画像そのものでなく圧縮した表現空間で将来を予測するモデル) は未来予測と planning に有望だが、モデルサイズ・データ・計算量に応じて能力がどう伸びるかの原則的な見積りがなかった。RoboJEPA は JEPA (Joint Embedding Predictive Architecture; 表現空間で masked / 将来部分を予測する自己教師あり構造) を 12 種のロボットの大規模データで学習し、scaling law を示す。

## 手法の核心
- 8B parameter の JEPA predictor (報告時点で最大) を 12 embodiment のデータで学習。
- imagination error (latent rollout の誤差) が compute に対して second-order power law (対数軸で 2 次式) に従い、fit した範囲を超えて予測できる。
- 下流の robotic planning 性能も compute で予測可能に改善し、imagination error と強く相関する。
- よって imagination error は実機評価の proxy (代理指標) になりうる。
- goal image 1 枚を指定するだけで、zero-shot に長期 planning をこなす。

## 適用可能性 (P3 / P1)
- P3: world model 開発で、小規模 run から大規模の品質を外挿する設計の根拠になる。
- P1: 「rollout 誤差が下流の planning 性能の代理になる」は、closed-loop 実走が高コストな planner 評価に応用できる仮説。
- 注意: ロボット操作のデータであり、運転ドメインで同じ law が出る保証は無い。

## 試すべき実験
1. 手元の driving world model で、3〜4 段階の compute で imagination error を測り、power law が当てはまるか見る。
2. imagination error と、その world model を使った planner の closed-loop 指標の順位相関を取る。
3. 学習 embodiment の数を変え、law の係数が変わるかを見る。
