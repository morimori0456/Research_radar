# Juno: JEPA の予測 latent を VLA の teacher として蒸留し、deployment 時に LoRA で適合する

- 対象: P2 (蒸留 + 適合) / P3 (VLA + world model)
- 元論文: http://arxiv.org/abs/2610.09940v1
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
JEPA (Joint Embedding Predictive Architecture; 表現空間で将来を予測する構造) の予測 latent は VLA (Vision-Language-Action; 画像と言語から行動を出すモデル) の材料として有望だが、実際には (1) embodiment 固有の制御とのずれ、(2) action 学習への干渉、(3) distribution shift 下で teacher の予測が狂う、という 3 つの失敗がある。Juno は 1 つの action-conditioned JEPA を、表現 backbone・予測 teacher・適応可能な dynamics model の 3 役に使う枠組み。

## 手法の核心
- 事前学習: embodiment に合う軌道で学習し、dynamic CLS loss で動き重み付きの patch dynamics をコンパクトな全体 state へ移す。
- 方策学習: 現フレームの JEPA patch を VLA の知覚に fuse し、別パラメータの reasoning branch に「将来 latent」を distill して行動生成を助ける。
- 展開時: 失敗 rollout を含む全遷移で world model を適応 → teacher を freeze → 検証済みの成功実行で LoRA adapter と action head だけを再 alignment。expert の修正も task reward も不要。
- SimplerEnv で平均成功率 60.9% → 68.5% (強い baseline の Qwen3GR00T 比)、test-time adaptation で 72.7%。実機は背景・高さ・物体の変化で base policy が 0% に崩れる条件でも 70〜75% を維持。

## 適用可能性 (P2 / P3)
- P2: 「teacher を domain shift 後に自分で再適応して固定し、student を LoRA で合わせ直す」流れは、蒸留した student を別環境へ適合させる recipe として直接参考になる。
- P3: VLA に world model の予測 latent を入れる構造の 1 例。
- 注意: ロボット操作が対象。運転で同様の効果が出るかは未検証。

## 試すべき実験
1. 手元の蒸留 pipeline で、teacher を新ドメインの失敗を含むデータで先に適応・凍結してから student を LoRA で合わせ、teacher を固定のままにする場合と比較する。
2. 将来 latent の distill を別 branch と同一 branch で行い、action 学習への干渉を測る。
3. 適応データに失敗 rollout を含める / 含めない ablation。
