# ViRA: Visual Foundation Model の表現を E2E planner に「推論コスト不変」で揃える study

- 対象: P1 (Planner AI + 評価) / P3 (E2E 自動運転)。P1 枠で採用
- 元論文: http://arxiv.org/abs/2610.09695v1 (コード: https://github.com/OpenDriveLab/ViRA)
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
VFM (Visual Foundation Model; 大規模事前学習された画像表現モデル) を E2E (End-to-End; センサ入力から計画まで一気通貫) 自動運転に使う例が増えたが、いつ運転性能が上がるのかは不明だった。本論文は、planner の構造と推論コストを変えずに VFM の表現へ揃える ViRA (visual representation alignment) を作り、どの VFM を target にすべきかを系統的に調べる。

## 手法の核心
- planner の中間特徴を、frozen な VFM の特徴へ合わせる補助 loss (representation alignment) として入れる。推論時は VFM を使わない。
- 発見1: 様々な E2E planner で一貫して改善し、zero-shot closed-loop 評価にも波及。
- 発見2: target VFM の選択は性能に効き、事前学習済み VFM encoder を持つ planner でも別 VFM への alignment が効く。
- 発見3: 補助の perception supervision (検出・地図など) を足すと target 選択への感度が下がる (5 つの target 間の EPDMS の幅が 2.7 → 0.5)。EPDMS (Extended PDM Score; NAVSIM v2 の運転品質を総合する指標) 。
- ViRA-Diffusion (diffusion planner) が NAVSIM v2 navtest で EPDMS 92.3、比較手法を 1.9 点以上上回る。

## 適用可能性 (P1 / P3)
- P1: planner 評価の観点で、「指標の幅 (2.7 vs 0.5) が補助 supervision で変わる」点は、ablation の読み方 (target 選択ノイズ) として使える。NAVSIM v2 / EPDMS は評価基盤の候補。
- P3: 推論コスト不変なので、手元の E2E planner に後付けしやすい。
- 注意: abstract の比較は著者設定内。

## 試すべき実験
1. 手元の planner に、DINO 系など 2〜3 種の VFM target で alignment loss を足し、EPDMS の幅を測る。
2. 補助 perception supervision の有無で幅が縮むかを再現する。
3. alignment 層の位置 (浅い / 深い) を変え、効く層を探す。
