# Closed-Loop Aware Planning via Imitation-Free Speed Scoring for End-to-End Autonomous Driving (2610.36079)

- トピック: next_arch (P3) / スコア 4.5
- URL: https://arxiv.org/abs/2610.36079

## 何を解決する論文か

end-to-end driving (画像から軌道まで 1 つの network で出す運転 model) は、人間の運転 log を真似る imitation learning (模倣学習) で学習することが多い。この方式には 2 つの弱点がある。(1) 1 つの場面に対して demonstration は 1 通りの運転しか見せないので、他にも正しい運転があることを学べず、「もっとゆっくり」のような好みを test 時に指定できない。(2) demonstration のノイズや曖昧さが、そのまま不安定な教師信号になる。論文は、正しい運転の多様性は経路よりも **速度** から生じる、と見て、経路は模倣で学び、速度は別の仕組みで選ぶ planning の分け方を提案する。

## 手法の核心

- **経路と速度の分離**: 経路 (どこを通るか) は imitation で学習する。速度は候補を複数用意し、learned scoring function (複数の基準で候補に点を付ける学習済みの関数) で選ぶ。
- scoring function の教師は、模倣データではなく **物理的に根拠のある安全制約** (衝突までの余裕など) から作る (imitation-free)。
- **CLAP-AD (Closed-Loop Aware Planning for Autonomous Driving)**: 既存の end-to-end model に後付けする plug-in の planning head。speed-conditioned training (速度を条件にして再学習すること) なしに、test 時の速度選択を明示的に制御できるのは初、と著者は主張する。
- 評価: Bench2Drive-Speed (速度の指定に従うかを測る benchmark) で Speed-Adherence Score が 82.53 (最強 baseline の TFv6 を 12.9 点上回る)。Bench2Drive (CARLA の closed-loop 運転 benchmark) の driving score は UniAD に +28.5、VAD に +32.7。NAVSIM v2 (実走行 log を使う評価) の EPDMS (Extended Predictive Driver Model Score; planning の総合点) は backbone に対して +6.1。

## P3 への適用可能性

- P3 の評価軸「最新の end-to-end 自動運転アーキテクチャ」に直接当たる。model 全体を作り直さず planning head を差し替える形なので、既存の構成に組み込みやすい。
- 「学習は模倣、選択は安全制約で採点」という分離は、P1 の planner 評価の考え方 (候補軌道を複数基準で採点) とも接続する。P1 の評価指標の定義を、そのまま scoring function の基準に使える可能性がある。
- 注意点: 数値の比較対象には、closed-loop benchmark 上で弱い旧 baseline (UniAD、VAD) が含まれる。「+28.5 / +32.7」は最強 baseline 比ではないことに注意。Bench2Drive-Speed は速度制御に特化した新しい benchmark で、著者らが設計したものとみられる (未確認)。

## 試すべき実験アイデア

1. 手元の end-to-end model の出力する経路を固定し、速度の候補を 5〜10 通り作って、衝突までの余裕 (TTC; Time-to-Collision, 衝突までの残り時間) のような単純な安全基準で選ぶ non-learned な baseline を作る。論文の learned scoring が、この単純な baseline からどれだけ上積みするかが、最初の確認点。
2. 速度の候補 × 複数基準 (安全、快適性、進捗) の点数表を closed-loop log から作り、基準の重みを変えたときに運転の「性格」がどう変わるかを見る (test 時制御の感触をつかむ)。
3. NAVSIM v2 で backbone のみ / CLAP-AD 付きを比べ、改善が EPDMS のどの下位指標 (衝突、進捗、快適性など) から来るかを分解する。
