# Vision-Language-Action or World-Action? Just Action Models (2610.37219)

- トピック: next_arch (P3) / スコア 4.5
- URL: https://arxiv.org/abs/2610.37219

## 何を解決する論文か

robot の control policy には、大きく 2 系統ある。VLA (Vision-Language-Action; 画像と言語から行動を出す model) は、vision-language model (VLM) の事前学習済み知識を引き継ぐ。WAM (World-Action Model; 将来の観測の予測と行動を同じ model で扱う) は、動画生成 model の知識を引き継ぐ。どちらが良いかは議論になっているが、論文は、この比較には 3 つの別々の選択が混ざっていると指摘する: (1) backbone の初期化、(2) 将来の観測に課す目的関数、(3) その将来予測の仕組みを推論時にも残すか。これでは VLA と WAM の性能差がどの選択の効果なのか分からない。3 つを切り分けて比べるための共通の枠組みを示す。

## 手法の核心

- **JAM (Just Action Model)**: 事前学習済みの visual backbone と action expert (行動を出す小さな head) に、action loss と **foresight loss** (将来の予測の loss) を足したもの。
- foresight loss は、現在の観測の特徴から、**凍結した encoder で符号化した将来の観測**を予測させる。予測用の head は学習後に捨てるので、推論時の構成は VLA と同じ。**映像の生成は学習にも推論にも使わない**。
- backbone は自由に選べる。論文は、固定した policy 構成の中で目的関数を比べ、次に backbone の系統 (生成 model 由来 / VLM 由来) を変えて foresight の recipe を比べる。
- 結果: LIBERO (robot manipulation の標準 benchmark)、LIBERO-Plus (摂動に対する頑健性を測る拡張版)、RoboTwin (両腕操作の benchmark) で、FastWAM と ImageWAM (WAM 系の比較手法) に並ぶか上回る。FastWAM の 97.0 / 55.3 / 91.2 が JAM で 98.2 / 64.5 / 91.4 (順に 3 benchmark)。LIBERO-Plus で約 9 点の差が最も大きい。
- foresight target をキャッシュすると、online 学習の FLOPs (計算量) が FastWAM 比で推定 73% 減る。
- 主張は「将来の supervision は、映像生成や推論時の追加機構なしでも制御を改善する。生成 model 由来でも VLM 由来でも backbone は使える」。

## P3 への適用可能性

- P3 の「VLA と world model のどちらに寄せるか」という構造選択を、実験で整理する材料になる。結論が「将来予測は loss として使い、推論には持ち込まない」なら、車載の latency 予算の中で world model の恩恵を取る形になる。
- 運転の VLA / end-to-end model に、「将来のフレーム (または BEV 特徴) を凍結 encoder で符号化したものを予測する補助 loss」を足す、という小さな変更で試せる。
- 注意点: 評価は robot manipulation の simulation benchmark のみ。運転では将来の分布がはるかに多様で、他車の行動も効くので、利得が出るかは未確認。LIBERO は上限近くで差が詰まるので、LIBERO-Plus や RoboTwin の方が差を見やすい。

## 試すべき実験アイデア

1. 手元の end-to-end driving model に、foresight loss だけを足す (予測 head は学習後に捨てる)。固定した encoder で符号化した n 秒後の特徴を予測させ、planning 指標 (NAVSIM や Bench2Drive) への効きを見る最小版。
2. foresight target を、(a) 画像 encoder の特徴、(b) BEV 表現、のどちらにするかで比べる。凍結 encoder の選び方が効くかを論文と同じ形で切り分ける。
3. target のキャッシュで学習コストがどれだけ減るかを手元の構成で実測する (論文は FastWAM 比 73% 減と推定)。

## 注意

abstract のみに基づく。foresight の予測先の具体的な表現、各 backbone の大きさ、LIBERO-Plus での差の統計的な信頼性は未確認。
