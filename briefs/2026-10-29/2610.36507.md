# GRAFT: Geometry-Aware Residual Adaptation for Foundation Trackers (2610.36507)

- トピック: next_arch として届いたが、内容は凍結した foundation model を別の環境へ軽量に適合させる recipe なので P2 として採用 / スコア 4.0
- URL: https://arxiv.org/abs/2610.36507

## 何を解決する論文か

humanoid robot 向けの BFM (Behavior Foundation Model; 参照の動きを入れると、全身の関節指令を出す事前学習済み model) は、主に平地の動きで学習されている。そのため、階段・段差・隙間では、足の置き場所、足を上げる高さ、接地のタイミングを地形に合わせられない。地形に対応させる従来法は、tracker を perception と一緒に再学習・fine-tuning するので、データと計算が重く、通常の追従と perception が結合してしまう。論文は「基盤 model は凍結したまま、地形への適合だけを小さな部品で足す」方法を示す。

## 手法の核心

- **凍結した BFM と、その参照インターフェースを変えない**。足すのは軽量な adapter (residual; 元の出力に足す補正) だけで、補正は **下半身の実行目標にのみ** 加える。
- adapter は task reward と **foot-geometry reward (足と地形の幾何に関する報酬)** で学習する。平地では補正が出ないように regularization (抑制) をかけ、不要な補正で元の性能を壊さない。
- **privileged observation からの distillation**: 学習時は正確な地形情報 (privileged; 実機では得られない情報) を使い、それを搭載 depth camera の入力に蒸留する。teacher-student の構成。
- 凍結 BFM が全身追従と通常の歩行をすでに持っているので、地形への学習は「実行の適合」という狭い問題に絞られる。
- 4 種の凍結 tracker に適用し、階段・隙間・台を simulation で評価。さらに Unitree G1 の実機で、適合した SONIC tracker が搭載 depth と無改変の参照で地形を越える。

## P2 への適用可能性

- P2 の適合の観点 (基盤 model を別ドメインに転用する recipe、PEFT 的な効率的適合) にかなり近い。核心は「凍結した foundation model の性能を保ったまま、残差だけを学ぶ」+「ドメイン固有の不要な補正を抑える regularization」+「privileged 情報から実機の入力への distillation」の 3 点で、運転 model の他機種 (別の camera 配置・別の車両) への適合に読み替えやすい。
- 特に「元のドメインで補正が出ないようにする regularization」は、LoRA などの fine-tuning で元ドメインの性能が落ちる問題への対策として、そのまま試せる。
- 注意点: 対象は humanoid の locomotion で、適合先が地形という物理的に明確な軸。運転の「他機種」は camera の内外部パラメータ・車両動力学の違いで、補正の置き場所の選び方 (下半身のみ、のような) が自明ではない。論文の数値 (成功率など) は abstract に無い。

## 試すべき実験アイデア

1. 凍結した driving backbone の出力に小さな residual adapter を足し、新しい camera 配置への適合を、元の配置では補正がゼロになる regularization つきで学習する。同じ parameter 数の LoRA と、新旧両方のドメインでの性能で比べる最小版。
2. adapter の補正を「出力の一部の次元だけ」に限定する (論文は下半身のみ) 版と、全次元に補正を許す版を比べ、元ドメインの性能低下がどれだけ違うかを見る。
3. 学習時だけ使える情報 (高精度 map、他車の真の位置など) を privileged teacher として、実機の入力だけを見る student に蒸留する構成を試す。

## 注意

abstract のみに基づく。adapter の構造と大きさ、4 種の tracker の中身、simulation での成功率の数値は未確認。
