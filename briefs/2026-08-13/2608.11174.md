# VIScore: Diagnosing Planning-Relevant Quality in Latent World Models

**topic:** next_arch (P3) ・ **arXiv:** 2608.11174 ・ **published:** 2026-08-11 ・ **hf_upvotes: 0**

> **本日の最有力。** P3 (次世代アーキテクチャ) と P1 (planner 評価) の交点に正面から座っている唯一の論文であり、追っているアイデア **R3 (VLA × world model 統合アーキテクチャ)** の「そもそも出来た world model の良し悪しをどう測るのか」という前提部分に答えている。
>
> **主張を一行で言うと「world model の表現の綺麗さを測っても planning の成功率は予測できない。encoder・predictor・planner の 3 つを跨いで測れ」。** しかも同じ日に別の論文 (落選した 2608.10145) が独立に同じ結論を出している。

## 何を解決する論文か

**latent world model (観測画像を低次元の latent 表現に潰し、その latent 空間の中で「次に何が起きるか」を予測するモデル。予測した未来の中で行動を探索することで planning に使う)** の研究では、latent 空間を **isotropic Gaussian (どの方向にも等方な正規分布)** に正則化するのが定石になっている。潰れ (collapse) を防ぎ、情報量が最大化された安定した landscape が得られるからだ。

ところが著者はまず、**「latent 空間が綺麗であること」と「planning が成功すること」が繋がっていない**という事実を突きつける。同じ分布 (isotropic Gaussian) を目標にする 2 つの正則化 loss、**SIGReg** と **VISReg** を比較すると、**SSL (self-supervised learning; ラベル無しで良い表現を学ぶ枠組み) では有益とされる SIGReg の方は planning をまったく助けない**。一方 VISReg —— 中心・スケール・形状それぞれの重みを個別に制御でき、batch size を大きくするほど分布近似が細かくなる —— は **OOD (out-of-distribution; 学習データの分布から外れた場面) データセットでの planning 成功率を改善する**。

つまり「良い表現の指標」として広く使われているものが、**planning という下流タスクの成功をまったく説明していない**。この観察から著者は、**planning 成功率を実際に説明できる指標** VIScore (Veracity-Influence-Sobriety score) を提案する。

## 手法の核心

- **測る対象を「latent だけ」から「3 段全部」に広げたのが本体。** 従来の指標 (straightness / physical-state probing / empowerment、後述) は **encoder が吐いた latent だけ**を見ていた。VIScore は **encoder・predictor・planner の 3 つそれぞれに 1 つずつ量を割り当てる**。名前の V/I/S がそれに対応する。

- **Veracity・Influence —— predictor 側の 2 つの量。** 与えられた encoded feature に対して predictor の **reachability (到達可能性: その表現から本当に正しい未来に辿り着けるか)** と **capacity (容量: どれだけ多様な未来を表現し分けられるか)** を測る。**encoder がどれだけ綺麗な latent を出しても、predictor がそこから未来に届かなければ planning は失敗する** —— この当たり前の経路が従来指標では抜けていた。

- **Sobriety —— planner 側の hallucination を測る。** 探索ベースの planner が **「実際には到達できない未来を、到達できると信じ込んで選んでしまう」度合い**。world model が甘い予測を返すと planner はそれを掴んでしまうので、**planner が掴んだ幻の量そのものを指標にする**という発想。名前の通り「素面さ」。

- **比較対象を明示していて、そこが読み所。** 既存の 3 指標を並べて負かしている —— **straightness (latent の軌跡がどれだけ真っ直ぐか)**、**physical-state probing (latent から位置や速度などの物理量を線形に読み出せるか)**、**empowerment (その状態から行動によって到達できる未来の多様さ)**。**このうち physical-state probing は我々が世界モデルの品質確認に真っ先に使う手口**であり、それが planning 成功を説明しないと言われているのは痛い指摘。

- **数字の出し方が指標論文として正しい。** 単に「相関があった」ではなく、**Spearman correlation (順位相関; 値そのものではなく順位の一致度を測るので、指標のスケールに依らず「良い順に並べられるか」を見られる) が seen / unseen のモデル・データセット双方で一貫して 0.75 超**。さらに **calibration error (指標値から予測した成功率と実際の成功率のズレ) が、全テスト条件で「定数を当てはめただけのモデル」を下回った唯一の指標**。**後者が効いていて、「順位は当たるが値は無意味」という指標の逃げ道を塞いでいる。**

## 追っているプロジェクトへの適用可能性

- **P3 / アイデア R3 —— ここが本命。** R3 は「VLA と world model の統合手法を分類マップにする」だった。**分類する前に、比較の物差しが要る。** 現状 world model の論文は「予測画像が綺麗」「表現から物理量が読める」で良し悪しを主張しているが、本論文はその両方が **planning 成功と繋がっていない**と言っている。**R3 のマップを作るなら、縦軸を VIScore 系の「planning に効く量」に取るべき**であり、これは調査を進めるうえでの座標系そのものを与えてくれる。

- **P1 / 評価の作法。** 我々が planner を評価するとき、**上流の予測モジュールの精度 (ADE/FDE など) を代理指標にして「予測が良くなったから planner も良くなるはず」と論じる**場面がある。本論文の主張はこれを直接否定する形に読める —— **モジュール単体の品質は下流の成功を説明しない**。**R1 (保証付き安全指標) を評価手法として提案するなら、「その指標が下流の成功をどれだけ説明するか」を Spearman と calibration error で示すのが作法**であり、**本論文はその作法のテンプレートとして使える。**

- **P1+P3 / 本日もう 1 本と噛み合っている。** 落選した **2608.10145 (LeWorldModel の独立再現)** が、**「1 ステップ予測精度は長期 planning の成功をまったく順位付けできない」**という同じ結論を、まったく別の方法 (再現実験) で出している。**同じ日に 2 本が独立に同じことを言っているのは、方向として無視できない信号。**

- **P2 への波及 (間接的)。** 蒸留した student の品質を「teacher との表現の近さ」で測るのも、本論文が否定した「表現だけを見る」型の指標である。**「student の表現は teacher に近いのに下流タスクで負ける」を説明する枠組み**として、V/I/S の分解は蒸留側にも移植できる可能性がある。ただし planner に相当する段が蒸留には無いので、**S に当たる項をどう定義するかは自明ではない。**

- **注意点:** (1) **検証環境の規模と種類が abstract からは読めない。** 「cross-task success rate pool」としか書かれておらず、**実写の運転データが入っているとは考えにくい**。我々のドメインでそのまま成立するかは本文の実験設定を見ないと判断できない。(2) **VIScore 自体の計算コストが不明。** planner を実際に走らせる必要があるなら、「学習中に安く監視できる指標」ではなく「学習後に評価する指標」であり、使いどころが変わる。**ここは本文で最初に確認すべき点。** (3) SIGReg vs VISReg の比較は **2 つの loss しか見ていない**ので、「表現指標は一般に planning を説明しない」まで一般化するのは著者の主張より一歩踏み込みすぎ。

### 試すべき実験

1. **手持ちの world model 系チェックポイントを並べて、既存指標の無力さを自分で確認する (最優先)。** 新しい指標を実装する前に、**「1 ステップ予測誤差」「probing の R^2」と「closed-loop の成功率」を散布図にするだけ**。**相関が出てしまえば我々のドメインでは問題が存在しないので、以降は不要。** 出なければ本論文が我々に効く。処方より先に診断。

2. **Spearman と calibration error を評価の標準出力に入れる。** 指標の良し悪しを議論するときの共通言語として、この 2 つを出す習慣にする。**特に「定数当てはめ」を baseline に置く作法は安価で強力** —— これを下回る指標は情報を持っていない。

3. **Influence (predictor の capacity) だけを先に測る。** V/I/S のうち最も実装が軽そうなのがここ。**同じ encoder 出力から predictor がどれだけ異なる未来を出し分けられるか**を測り、closed-loop 成功率との相関を見る。**1 項だけで相関が出るなら、3 項全部を実装する必要はない。**

4. **R3 のマップの縦軸に採用する。** 収集済みの VLA × world model 統合手法について、**各論文が「planning 成功と繋がる証拠」を出しているか / 表現の綺麗さだけで主張しているか**で分類する。**これは論文を読むだけで作れて、しかも R3 の新規性の議論に直結する。**

5. **2608.10145 と突き合わせる。** あちらの「1 ステップ予測誤差は短期の成功は順位付けできるが長期は全く順位付けできない」という所見と、VIScore の V (reachability) が捉えているものが同じか違うかを整理する。**同じなら、指標を新規に作らずとも「長期成功で評価しろ」で足りることになる。**
