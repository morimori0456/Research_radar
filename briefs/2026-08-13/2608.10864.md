# MVRD: Multi-View Relational Distillation for Spatial Reasoning with Vision-Language Models

**topic:** fm_distill_finetune (P2) ・ **arXiv:** 2608.10864 ・ **published:** 2026-08-11 ・ **hf_upvotes: 0**

> **P2 の 2 本目。採った理由は「蒸留で壊れるものを壊さずに済ませる」という一点に尽きる。** 論文自身が挙げる応用先に **autonomous driving が明示**されており、P2 (蒸留・適合) と P3 (VLA) の両方に橋が掛かる。
>
> **一行で言うと「teacher の特徴そのものを真似させると student の元の能力が壊れるので、特徴ではなく特徴どうしの関係だけを渡す」。** 4D-WAM (2608.10107) の「幾何知識を loss 経由でだけ入れる」と同じ思想が、蒸留の側から出てきている。

## 何を解決する論文か

**VLM (Vision-Language Model; 画像と言語を同じ空間で扱うモデル)** は画像や動画の理解では強いのに、**幾何的にもろい** —— 物の前後関係、距離、向きといった **spatial reasoning (空間推論)** で失敗する。これは embodied AI・ロボティクス・**自動運転**で直接効いてくる弱点である。

既存の処方は 2 つあり、どちらにも代償がある。**(a) 空間 QA データで fine-tuning する**: 表面的な相関を覚えるだけで、幾何的に誤った視覚表現はそのまま残りうる。**(b) 幾何に強い専用 vision model の特徴を融合する**: 効くが**推論時のモデルサイズが大きく増える**。

第 3 の道が蒸留 —— **geometry-grounded vision model (多視点画像から 3D 構造を捉えるよう学習された視覚モデル) を teacher にして VLM に幾何を教える** —— だが、ここに本論文の中心的な指摘がある。**teacher の特徴を直接合わせにいくと、student が事前学習で獲得していた「視覚と言語の対応関係」が壊れる。** 幾何は手に入るが、**物体の意味や言語との結び付きを失う。** 蒸留が別の能力を破壊するという、実務で最も痛い形の副作用である。

MVRD はこれを、**渡す物を「特徴」から「関係」に変える**ことで回避する。

## 手法の核心

- **patch 間の cosine similarity を、視点をまたいで蒸留する。** teacher の特徴ベクトルそのものではなく、**「視点 A の patch i と視点 B の patch j がどれだけ似ているか」という類似度の構造だけ**を student に合わせさせる。**多視点間の対応関係 (どの画素とどの画素が同じ 3D 点か) は、この類似度の中に十分入っている。**

- **効く理由が明快で、そこが本論文の芯。** 特徴を直接合わせると student の表現は **1 点に固定される** —— 事前学習で獲得した言語との対応を捨てて teacher の空間に移らざるを得ない。一方**関係だけを合わせると student の表現は underdetermined (一意に決まらない) なまま**になる。**制約が緩いので、student は「関係を満たす」かつ「元の vision-language 空間に近い」解を選べる。** **「弱い制約の方が良い」という主張が、機序として説明されている**のが良い。

- **推論時のコストが小さい。** feature fusion 系に**性能で肉薄しつつ、追加パラメータと latency は大幅に少ない**。**車載を前提にする我々にはこの軸が本質。**

- **主張を「幾何が入った」だけで終わらせていない。** **視覚表現がより幾何的になったこと**と、**言語との整合が保たれたこと**を**両方**示している。**副作用が無いことを明示的に測っている**のは、蒸留論文としては誠実な作り。

- **3D シーン理解へ般化する。** object grounding (言語で指した物体を 3D 空間で特定)、dense captioning、QA まで効果が伸びる。**単一タスクの調整ではないことの傍証。**

## 追っているプロジェクトへの適用可能性

- **P2 / 「蒸留が別の能力を壊す」問題への一般解として。** これは我々が実務で繰り返し踏む形である —— **ある能力を蒸留で足すと、別の能力が落ちる。** 本論文の処方は具体的な手法である以前に **原則**として持ち帰れる: **teacher から渡すのは、teacher の出力そのものではなく、teacher が満たしている性質にせよ。** **4D-WAM が「幾何の整合性だけを loss で渡す」と言っているのと完全に同型**で、本日 2 本が別分野から同じ原則に到達している。

- **P2 / アイデア R2 との関係。** R2 の破綻の話に、**「破綻」の 3 つ目の顔**を足す。昨日の TIDE は excess (発散) と deficit (伝わらない) に分けた。本論文が言っているのはそのどちらでもなく、**「伝わりすぎて、元々あった物を上書きする」**という破綻である。**R2 の枠組みが catastrophic forgetting 側まで面倒を見るべきかは設計判断だが、少なくとも「蒸留の強さを上げると何が壊れるか」は測る価値がある。**

- **P3 / VLA の空間理解に直結。** VLA が「右の車線の前方の車」のような空間参照を扱えないのは実際の弱点で、しかも**落選した 2608.08904 (08-12 の候補) が「action post-training をすると VLM の深度推定能力が全層で劣化する」と報告していた**。**VLA 化で幾何が削れるなら、MVRD 型の関係蒸留で削れた分を戻せる可能性がある** —— これは本日拾える中で最も面白い組み合わせ仮説。

- **P1 への間接的な効き。** planner の上流が空間関係を誤ると planner は救えない。**幾何的にもろい VLM を推論経路に置くこと自体のリスク**を、コストを増やさず下げられるなら価値がある。

- **注意点:** (1) **teacher に geometry-grounded model が要る**という前提。我々のカメラ構成・ドメインで妥当な teacher が用意できるかが第一の関門。(2) **「多視点」が前提**である。我々は複数カメラを持つので条件は良いが、**論文の多視点 (同一シーンを大きく異なる角度から) と、車載の多視点 (向きが違う周囲カメラで重なりが少ない) は別物**であり、**patch 間対応がそもそも成立するかは要検証。ここが最大の不確実性。** (3) 「feature fusion に approaching」であって**上回ってはいない**。性能の上限は融合系より低いという読み方が正しい。(4) 効果の測定が **spatial reasoning ベンチ**であり、**closed-loop の運転性能まで効くかは何も言っていない。**

### 試すべき実験

1. **蒸留の副作用を測る習慣を先に作る (最優先・安い)。** 手法の導入より前に、**現行の蒸留 run の前後で「狙った能力」と「壊れうる能力」の両方を測る**。我々の場合は「幾何・空間理解」と「言語/意味の理解」。**副作用が観測されなければ、本論文の問題は我々に存在しない。** ここでも処方より先に診断。

2. **特徴蒸留 vs 関係蒸留を、同じ teacher・同じ予算で直接比較する。** MVRD の全実装は要らない。**「特徴の L2 を合わせる」を「patch 間 cosine 類似度行列を合わせる」に置き換えるだけ**で中心的な主張は検証できる。**副作用の差が出るかが見どころ。**

3. **車載の多視点で patch 対応が成立するか確認する (この論文を使えるかの門番)。** 隣接カメラの重なり領域で、**teacher の patch 間類似度が実際に幾何的対応を反映しているか**を可視化する。**していなければ、我々のカメラ構成にはこの手法は乗らない** —— 実装投資の前に必ずここを通すこと。

4. **VLA 化で削れた幾何を戻せるか (最も面白い仮説)。** action post-training の前後で深度 probing の精度を測り、**落ちた分を MVRD 型の関係蒸留で回復できるか**を見る。**「行動を学ぶと空間が削れる」という既知の観察に対する初めての処方候補**になりうる。

5. **制約の強さを振る。** 特徴蒸留 (強い制約) と関係蒸留 (弱い制約) の間には連続的な中間がある。**制約の強さを軸に「獲得した幾何」と「保たれた言語整合」をプロットすれば、トレードオフ曲線が 1 枚で出る。** 本論文自身はこの曲線を出していないので、そこは空いている。
