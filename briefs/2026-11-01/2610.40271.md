# Gaussian Distillation of Flow Policies (2610.40271)

- トピック: fm_distill_finetune (P2) / スコア 4.0 / 10-31 の次点を繰り越し (candidates.json に無く、arXiv API で abstract を取得)
- URL: https://arxiv.org/abs/2610.40271

## 何を解決する論文か

flow policy (flow matching で行動の分布を生成する robot controller; 複数の行動候補 = multimodal な分布を扱える) は強力だが、行動を 1 つ出すのに network を何回も回す必要がある。この論文は、調べた flow policy の連続行動の分布が Gaussian でよく近似できることを示し、最終層だけを Gaussian の出力に置き換えて高速化する。

## 手法の核心

- **GAR (Gaussian Action Readout)**: flow policy の最後の層を Gaussian の readout に差し替える。残りの network は凍結し、読み出しの部分だけ学習する。
- 学習に使うのは対象となる state のわずか 0.02%。
- 推論は action network の 1 pass で済み、反復が要らない。最大 2 倍の高速化を報告している。
- likelihood (行動の確率) を closed-form で計算できる。flow policy のままでは likelihood の計算が重く、RL の fine-tuning などで困る点を解消する。
- task 成功率は teacher (元の flow policy) に近いとしている (「near-teacher」。具体的な数値は abstract に無い)。

## P2 への適用可能性

- 蒸留を「大きい teacher を小さい student に」ではなく、**「出力の形を単純化して推論を安くする」方向**で実務に落とした例である。学習量が極小なので、recipe として回しやすい。
- 運転の planner が diffusion や flow で複数の軌道候補を出す設計なら、推論 latency の削減に使える。closed-form の likelihood は、軌道の評価や RL による後調整にも使える。
- 注意点: 「Gaussian でよく近似できる」は、検証した policy の分布の性質である。運転の分岐 (左右どちらに避けるか等、本当に multimodal な場面) では成り立たない可能性が高い。ここが最大の未確認点。

## 試すべき実験アイデア

1. 公開 code があれば、手元の flow / diffusion policy で出力分布の Gaussian 近似の誤差を state ごとに測る。誤差が大きい state の割合が、そのまま適用可能性の指標になる。
2. 運転の closed-loop simulator で、分岐が必要な場面 (障害物の左右どちらを避けるか) だけ成功率を分けて比較する。
3. Gaussian の代わりに 2〜3 成分の混合 (mixture) にして、multimodal な場面で劣化が止まるかを見る。
