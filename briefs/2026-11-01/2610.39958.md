# Observability-Aligned Evidential Masked Pretraining for Reliable VRU Motion Prediction (2610.39958)

- トピック: planner_ai (P1) / スコア 3.5 / 10-31 の次点を繰り越し。P1 の枠が空いたため採用
- URL: https://arxiv.org/abs/2610.39958

## 何を解決する論文か

VRU (Vulnerable Road User; 歩行者や自転車など交通弱者) の行動予測は、一部しか観測できず、環境が変わる (天候など) ことにも耐えなければならない。そのため精度と並んで、予測の確信度が信頼できることが要る。masked pretraining (入力の一部を隠して復元させる自己教師あり学習) は欠損への耐性に向くが、既存の時系列版は決定論的で、観測が少ないとき確信度を下げる制約がない。

## 手法の核心

- **eCoMAE**: evidential (予測値と一緒に「どれだけ証拠があるか」を出力する不確実性推定) な masked pretraining。多変量の時系列向け。
- block 単位で時刻を隠し、decoder は Normal-Inverse-Gamma 分布 (平均と不確実性の両方を表すパラメータ) を出力する。
- 3 つの仕組みで confidence を観測量に揃える:
  1. 隠した view と参照 pass の両方で見える位置の平均を、不確実性で重みづけして一致させる。
  2. 隠した位置の evidence を抑える。
  3. 異なるマスク間で表現を一致させる。
- IMPTC (VRU の意図予測 benchmark) の leave-one-environment-out (ある環境を丸ごと学習から外す) 設定で、OOD accuracy は 0.7971 → 0.8068、OOD AURC (Area Under the Risk-Coverage curve; 自信のある予測だけ使ったときの誤り率の指標、低いほど良い) は 0.0718 → 0.0648。
- 歩行者の軌道予測で IMPTC、Waymo、nuScenes、inD の 4 dataset すべてで fine-tuning MSE が最良と報告。

## P1 への適用可能性

- planner の評価では、予測が外れた場面で planner がどう振る舞うかが見たい。**予測の確信度が観測の量と整合しているか**は、評価指標として切り出せる。
- 他ドメイン (天候・場所) への pretrain → fine-tune で効く点は、P2 の適合の関心にも重なる。
- 注意点: 改善幅は小さい (accuracy で +0.01 程度)。単一のベースライン比で、seed の分散は abstract に無い。planner の閉ループ性能に効くかは示されていない。

## 試すべき実験アイデア

1. 手元の予測 model の出力で、観測フレームを削ったときに confidence が下がるかを測る (AURC と、観測量 vs 確信度の相関)。論文の手法を使わなくても、planner 評価の診断として使える。
2. eCoMAE の 3 つの仕組みを 1 つずつ外した ablation を、公開コードがあれば再現する。どれが効いているかを確かめる。
3. 予測の不確実性を planner のマージン (安全距離) に渡す最小の実験。下流の効果は論文が示していない部分である。
