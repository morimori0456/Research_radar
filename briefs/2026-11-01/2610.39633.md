# Intrinsic Distribution Matching (2610.39633)

## 何を解決する論文か

1〜2 step で画像を生成する text-to-image model では、少ない refinement の機会で prompt の細部 (文字など) を正確に描く必要がある。DMD (Distribution Matching Distillation; 多 step の diffusion model の出力分布に、1〜数 step の generator の分布を寄せる蒸留) は、score の差 (2 つの分布の勾配の差) を使うが、この差を明示的な統計量の制約で補強できるかを調べている。

## 手法の核心

- DMD の補正項 (reverse-KL の field) を、Gaussian な moment 成分と、非 Gaussian の残差に分解する。moment 成分は特徴の平均と標準偏差で制御できる。
- **IDM (Intrinsic Distribution Matching)**: DMD の補正はそのまま残し、特徴の平均と per-coordinate の標準偏差を追加の loss で合わせる。
- 特徴は **generator 自身の EMA (Exponential Moving Average; 重みの指数移動平均) コピー**から取る。外部の特徴 encoder が要らない。
- Z-Image-Turbo (6B) と Qwen-Image (20B) で、full fine-tuning と LoRA の両方で実験。2 network evaluation で LongText-Bench の中国語 94.25%、英語 90.20%、比較した手法の中で最高と報告。
- ablation では moment loss の追加に gain があり、EMA の特徴は外部の DINOv2 encoder と 5 指標でほぼ同等とする。

## 適用可能性 (P2 蒸留・適合)

- 運転とは直接関係しない分野外の論文だが、P2 の「新しい loss を追加する蒸留 recipe」の事例として読める。**外部 encoder を使わず、自分の EMA を物差しにする**のが特に取り入れやすい。teacher と student の特徴空間を揃えない RPKD (10-31) と問題意識が近い。
- 蒸留済みの student に LoRA でも効く点は、軽量適合の recipe として使える。
- 注意点: 画像生成の text rendering が評価の主で、認識や planner の model にそのまま効く保証はない。hf_upvotes は話題性であり、この論文の価値は ablation の 1 点 (EMA 特徴 ≈ 外部 encoder) に絞って読むのがよい。

## 試すべき実験アイデア

1. 小さい蒸留 (分類でも可) で、student の EMA コピーの特徴の平均・標準偏差を合わせる補助 loss を足し、外部 encoder を使う同等の loss と比較する。
2. moment 成分だけでなく、分散の大きい特徴次元に限って合わせる版を作り、安定性の差を見る。
3. 2610.37937 RPKD の feature branch と併用できるかを検討する。
