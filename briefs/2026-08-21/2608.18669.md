# Reinforced Planning with Latent World Models (RP1)

**topic:** next_arch (P3) ・ **arXiv:** 2608.18669 ・ **published:** 2026-08-19 ・ **hf_upvotes: 0** ・ **relevance 4.5 / 5**

> **主張を一行で:** **探索アルゴリズムそのものを学習する。plan を評価する critic と、plan を改善する optimizer を、world model の想像ロールアウトだけから完全 offline で学習し、任意の事前学習済み latent world model に後付けする。**
>
> **なぜ重要か:** **world model rollout を 1,000 分の 1、推論を最大 67 倍速にした。** **これは性能の話であると同時に、評価の話である —— R1 が回したい閉ループ評価の本数は、1 本あたりのロールアウト計算量で決まる。** **同時に、R1 の設計方針にとっては最も危険な方向の論文でもある: 学習の担当範囲が「評価」から「探索規則」まで広がると、保証の議論ができる場所がさらに減る。**

## 何を解決する論文か

**world model は「行動列を入れると結果を返す」ところまで来たが、では良い行動列をどう見つけるかは、いまだに人が設計した探索 (CEM や MPPI といったサンプリング最適化) に任されている。** 学習されている場合も、**手設計の最適化器を蒸留したもの**か、**amortized policy (探索結果を吸収して一発で行動を出す方策) を作るための情報源**として使われるだけで、**「plan そのものを改善する手続き」を学習した例はない**、というのが本論文の位置づけである。

**RP1 は「探索は学習できる。良い探索規則を強化学習で neural planner に焼き付ければよい」という主張を実装した。** 視覚ナビゲーション、アーム到達、ロボット操作の 3 系統、world model backbone 2 種で、手設計探索を大きく上回ると報告している。

## 手法の核心

- **学習するものが 2 つある。** ① **critic —— 想像された結果の良さを評価する。** ② **optimizer —— 多段の plan を受け取って、より良い plan に書き換える。** **既存研究との差は ② で、abstract は「多段 plan の改善の仕方を完全に学習した最初の手法」と自称している。**

- **学習は完全に offline、かつ world model の想像ロールアウトのみから行う。** **実環境とのやり取りも、実データも要らない。** **world model を「学習環境」として使い切る構成であり、world model があれば探索器がタダで生えるという主張になる。**

- **backbone に依存しない後付け。** **事前学習済みの latent world model があれば、それとは独立に学習して、後から接続できる。** **2 種類の backbone で検証しているのは、この非依存性の主張を支えるため。**

- **効率の数字が本論文の売り。** **同等以上の性能を、world model rollout **1,000 分の 1** で達成。** **planner の推論を並行して走らせる条件下で、最強の対抗手法に対し最大 67 倍高速。** **いくつかの設定では成功率がほぼ 100% に到達。**

- **手設計探索を「上回る」形で示している点に注意。** **CEM/MPPI は分布を仮定した汎用最適化であり、タスク固有の構造を使えない。学習された optimizer はそれを使える。** **裏返せば、性能差の出どころはタスク固有性であり、汎用性は手設計側にある。**

## 追っているプロジェクトへの適用可能性

- **P1 / R1 —— まず良い面。評価スループットの制約が 3 桁動く。** **R1 は「N 本のシナリオを走らせて事故が無かったとき、何を保証したことになるか」を扱っている (08-20 の [Sampling-Verification Danger Law](../2026-08-20/2608.17956.md))。** **そこでの結論は身も蓋もなく、保証される量は N と共にしか上がらない。** **つまり R1 の主張の強さは、実際に回せる N で決まる。** **rollout を 1,000 分の 1 にできるなら、同じ計算予算で N を大きく取れる。** **これは手法の話ではなく、R1 の実験計画を書き換える数字である。**

- **P1 / R1 —— 次に危険な面。ここが本論文を読む本当の理由。** **R1 は 08-20 に「学習モデルは並べ替えに、保証は決定論に」という配置を主張の骨格にした。** **RP1 は探索規則そのものを学習する。すると失敗の原因が world model の誤りと探索器の誤りに分散し、どちらが効いたのかを事後に切り分けられなくなる。** **さらに悪いことに、探索器は world model の想像だけで学習されているので、world model の誤差が大きい領域を積極的に突きに行く動機を構造的に持つ (model exploitation; 学習された最適化器がモデルの穴を利用してしまう現象)。** **R1 はこれを「学習の担当範囲を広げると保証が言えなくなる」ことの最も鮮明な例として引くべきである。** **本日の [DA-WAM](2608.19085.md) が「選択を学習に任せる」例なら、RP1 は「探索そのものを任せる」例で、両者は同じ方向の 2 段階目にあたる。**

- **P3 / R3 —— 分類マップの「推論時」の内訳が、3 つ目を得た。** **08-20 時点の内訳は「探索の審判」「フィルタ後の順位付け」の 2 つだった。本日 RP1 が加えるのは「探索規則の生成器」である。** **3 つは保証との相性の順に並ぶ: 順位付け (許容集合あり) → 審判 → 探索規則。** **後ろに行くほど world model の誤りが決定に直接効き、事後の切り分けが難しくなる。** **この 1 次元の順序が引けたことは、R3 のマップにとって本日いちばんの収穫である。**

- **P2 —— backbone 凍結 + 小さなモジュール後付け、という構成自体は PEFT (Parameter-Efficient Fine-Tuning; 大部分を凍結して少数パラメータだけ適応させる手法群) と同じ形。** **注目すべきは「後付けするものが表現ではなく手続き (探索規則) である」点。** **P2 の適合の議論を「重みの適合 / 表現の適合」から「手続きの適合」に拡げる材料になる。** **新しい機体に移すとき、world model は共有して探索器だけ差し替える、という設計が成り立つか —— 本日の [GS-VLA](2608.19066.md) の「観測空間で適合する」と並べると、適合を行える層が 3 つ (観測 / 表現 / 手続き) 揃う。**

- **留保:** (1) **model exploitation の分析が abstract に無い。** **完全 offline で想像ロールアウトのみから学習した以上、これは最初に問われる論点であり、扱っていなければ主張の穴。本文の最優先確認箇所。** (2) **「1,000 倍少ない rollout」の比較条件が読めない。** 同一成功率での比較か、同一予算での比較かで意味が変わる。(3) **評価タスクにナビ・到達・操作しかない。** **運転のように「失敗の代償が非対称」な領域では、学習された探索器の外れ方が問題になる。** (4) **critic を学習で持つ以上、08-18 に R1 が採用した「審判に学習モデルを使わない」に真っ向から反する。** **本論文を採用したのは同意したからではなく、反対側の最良例だからである。**

### 試すべき実験

1. **RP1 の探索器に、本日 2 位の [Decision-Metric Alignment](2608.18746.md) の CEM-stage Spearman を当てる (最優先・本日の 3 本が 1 本の線になる)。** **問いは 1 つ: 学習された探索器は、world model の潜在コストと実コストの順位が一致しない領域に、手設計探索より高い頻度で入り込むか。** **入り込むなら model exploitation が測れたことになり、しかも「探索を学習すると alignment の悪い場所を突く」という一般的な命題として書ける。** **これは 3 本のうち 2 本が今日出たばかりの論文であり、誰も繋いでいない。R1 にとって最短の新規性である。**

2. **rollout 1,000 分の 1 を、性能ではなく評価本数に振る (優先度高・R1 の実験計画に直結)。** **同一計算予算で、① 高精度な探索で少数シナリオ、② RP1 で大量シナリオ、の 2 条件を比べ、得られる保証 (信頼区間の幅) がどちらで狭くなるかを計算する。** **08-20 の (1-r)^N の式にそのまま代入できる。** **「評価の計算予算をどこに配分すべきか」は、R1 が答えられて他が答えていない問いになりうる。**

3. **学習探索器と手設計探索器の失敗モードを分類する (優先度中・所要 2〜3 日)。** **成功率で比べるのではなく、失敗した事例を「world model が間違えた / 探索が間違えた / 両方」に分類する。** **切り分けができない事例の比率そのものが、R1 の「保証が言えなくなる」という主張の定量化になる。**

4. **critic を決定論的な shield に差し替えた劣化版を作る (優先度中・R1 の主張の対照実験)。** **08-20 の [Calibrated Predictive Safety](../2026-08-20/2608.17496.md) 型に倣い、RP1 の critic を「許容判定は決定論、順位付けだけ学習」に落とす。** **性能がどれだけ落ちるかが、R1 が主張する分業の価格である。** **その価格を自分で測って提示できれば、R1 は「安全のためにこれだけ払え」ではなく「価格はこれだけだ」と言える。**
