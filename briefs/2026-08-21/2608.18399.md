# What Does Attention Transfer Transfer? Attention Structure and Robustness in Vision Transformers

**topic:** fm_distill_finetune (P2) ・ **arXiv:** 2608.18399 ・ **published:** 2026-08-19 ・ **hf_upvotes: 0** ・ **relevance 4.0 / 5**

> **主張を一行で:** **teacher の attention map を student に写す蒸留は、分布内の精度をほぼ回復するのに分布シフト下では劣る —— この既知の差の中身を attention 構造の側で直接測り、差の相当部分が「学習を途中で打ち切っていただけ」だったことを示した。**
>
> **なぜ重要か:** **R2 (蒸留の capacity gap 系統則) は予備実験の着手直前にある。本論文は、その予備実験で守るべき作法を 3 つ、実例付きで与える。** **事前登録した閾値、複数 seed、学習予算を揃えた比較。** **08-20 に「着手前に seed のノイズ床を測れ」と書いたが、本論文は 3 seed 中 2 seed で結論が変わるという、まさにその実例を報告している。**

## 何を解決する論文か

**attention transfer (teacher の attention map —— 各トークンが他のどのトークンをどれだけ見ているかの重み —— を student に模倣させる蒸留) について、先行研究が報告していた事実がある: 分布内の精度は fine-tuning とほぼ同等まで回復するのに、分布シフト下では測定可能な差が残る。**

**本論文が問うのは「では何が写っていて、何が写っていないのか」である。** **これまでこの差は精度の差としてしか観測されておらず、attention 構造の側で直接測られたことがなかった。** ImageNet-100 上で、自己教師あり学習で作った teacher に対する ViT-S (小型 Vision Transformer) の student を使い、計測系を組んで 3 つの知見を出す。

## 手法の核心

- **転写は「ほぼ完全」かつ「恒久的」。** **蒸留された student の attention は、fine-tuning した場合と比べて teacher に約 2 桁近い。** **しかも追加学習を続けても離れていかない (drift しない)。** **写す対象としての attention は、疑いなく写っている。** **したがって残る差は「attention 以外の何か」か「学習の進み方」に帰着する。**

- **差はスケールに依存しない。** **先行研究より 14 倍少ないパラメータ・10 倍少ないデータでも、同じ差が再現する。** **小さくすれば消える類の現象ではないことが確定した。**

- **しかし差には時間軸がある。ここが本論文の核心。** **差の大きさは学習の成熟度に追随する。** **先行研究では停止規則によって学習 schedule が途中で打ち切られていた。それを最後まで回すと、3 seed 中 2 seed で、事前登録した閾値を下回るところまで差が縮む。** **精度を揃えた条件で比較しても同じ結論が出る。**

- **pre-registered threshold (実験前に「どれだけ縮んだら差が無いと見なすか」を宣言しておく作法) を使っている。** **後付けで基準を動かせないようにした上で、「2/3 seed で下回った」と報告している。** **1/3 seed では下回らなかったことも同時に読める書き方であり、都合の良い側だけを書いていない。**

- **とはいえ差はゼロではない。** **abstract は「この規模での終端の差は substantial」と書き始めており (引用の途中で切れている)、主張は「差は無い」ではなく「差の相当部分は学習予算の関数である」という限定付きのものになっている。**

## 追っているプロジェクトへの適用可能性

- **P2 / R2 —— 予備実験の設計が、本論文で確定する。ここが本日の P2 の要点。** **R2 の狙いは「teacher/student 比を振ると、どこで破綻するか」の系統則を引くことである。** **本論文が示したのは、その種の実験で最も起きやすい事故だ —— 学習を打ち切ったまま比較すると、予算の差を容量の差と読み違える。** **capacity gap を測っているつもりで budget gap を測ってしまう。** **R2 は最初からこれを分離した設計で入るべきで、幸いコストは大きくない (下の実験 2)。**

- **P2 / R2 —— 「3 seed 中 2 seed」は、R2 が引こうとしている曲線の分解能への警告である。** **系統則とは「student 幅を振ったら滑らかな曲線が出る」という主張である。** **だが同一設定の 3 seed で結論の向きが割れるなら、曲線の 1 点あたりのばらつきは、隣の点との差より大きいかもしれない。** **08-20 に書いた「着手前に seed のノイズ床を測れ」は、本論文で実例を得た。** **測らずに引いた曲線はノイズの上の模様である可能性が現実にある。**

- **P2 / R2 —— 「表現一致では測らない」を宣言する根拠が、本日 2 本揃った。** **本論文: attention は約 2 桁の精度で写っているのに、分布シフト下では劣る。** **本日 2 位の [Decision-Metric Alignment](2608.18746.md): probe のスコアは同等なのに、意思決定に使える幾何だけが違う。** **分野も対象も違う 2 本が、同じ構造の結論に独立に到達している。** **R2 は破綻を中間表現の一致度で定義してはならない。下流タスクの性能、それも分布シフト下の性能で定義する。** **この宣言は 2 本の引用で支えられる。**

- **P1 / R1 —— 作法として直接効く。** **R1 が提案しようとしているのは評価プロトコルである。** **プロトコルを提案する論文が pre-registered threshold を使っていないのは弱い。** **本論文は「事前に閾値を決めて、割れた結果をそのまま書く」を実演している。** **08-20 の [Calibrated Predictive Safety](../2026-08-20/2608.17496.md) も pre-registered protocol を使っており、この作法は R1 の投稿先で既に期待水準になりつつあると見てよい (推測)。**

- **P3 —— attention 構造の転写が「完全だが不十分」であることは、VLA の蒸留にも同じ形で来るはずである。** **本日の [RoleSub](rejected.md) (quota 落ち) が VLA の KV を 9〜11% まで削っている。** **削った後に残る性能差を、表現の一致度で確認して満足するのは危険だ、という読み方ができる。**

- **留保:** (1) **1 組の設定 (ImageNet-100 / ViT-S / 自己教師 teacher) での結論であり、外挿は保証されない。** (2) **seed が 3 本しかない。** **「2/3 で閾値を下回った」を系統的な主張とするには少ない —— ただし本論文はそれを系統的な主張として書いていない。** (3) **終端の差がゼロになっていない以上、「打ち切りが原因のすべて」ではない。残差の正体は未解明のまま。** (4) **分布シフトの種類が abstract から読めない** (合成汚損か、自然分布シフトか)。R2 が測定軸として採るなら、ここは合わせる必要がある。

### 試すべき実験

1. **R2 の予備実験を、本論文の作法で書き直してから着手する (最優先・所要は追加で学習 3〜5 本ぶん)。** **手順は 3 つ。** ① **同一設定を 3〜5 seed 回し、分布内と分布シフト下の両方でノイズ床を測る。** ② **「capacity gap がある」と言うための閾値を、実験前に文書に書く (この repo の decisions/ に置けばよい)。** ③ **すべての条件で学習 schedule を最後まで回す。** **これを省くと、R2 の系統則は「ノイズと打ち切りの模様」になりうる。** **08-20 に書いた宿題が、本論文で具体的な手順になった。**

2. **capacity と budget を分離する 2 次元グリッドを、R2 の主実験の骨格にする (最優先・R2 の主張を守る)。** **student の幅 (容量) × 学習 epoch (予算) の格子で破綻境界を描く。** **境界が縦線なら破綻は容量の関数、斜めなら容量と予算は交換可能。** **本論文が示唆するのは後者であり、もしそうなら R2 の主張は「capacity gap の系統則」ではなく「capacity と budget の交換率」になる。** **これは弱くなるのではなく、むしろ実務的に有用な形である —— 「student をこれだけ小さくするなら、学習をこれだけ延ばせ」という運用の指針になる。**

3. **attention 距離を capacity gap の予測子として使えるか検証する (優先度中)。** **本論文は attention 距離と分布シフト性能が乖離することを示した。だが乖離の仕方に構造があるかは別問題である。** **「attention 距離は小さいのに shift 精度が落ちる」領域が、まさに破綻境界の手前だとしたら、attention 距離は安価な早期警告になる。** **実験 2 の格子の各点で両方を測るだけなので、追加コストはほぼゼロ。**

4. **「打ち切り効果」が蒸留固有かを確認する (優先度低・ただし安い)。** **fine-tuning 側も同じだけ延長したときに差がどう動くか。** 本論文は蒸留側の延長を報告しているが、両側を揃えて延ばした条件が abstract から読めない。**R2 が比較の公平性を主張するなら、ここは自分で押さえておく必要がある。**
