# SD-OPD: Teacher-Guided On-Policy Distillation (2611.07722)

- トピック: fm_distill_finetune / プロジェクト: P2 / スコア 4.5
- URL: https://arxiv.org/abs/2611.07722
- コード: https://github.com/aim-uofa/sd-opd

## 何を解決する論文か

OPD (On-Policy Distillation; student 自身が生成した応答に対し、teacher が token ごとに密な feedback を返す蒸留) は、LLM の reasoning を伸ばす手法として使われている。しかし feedback の大きさが不均一で、数学の応答では、**言い回し (style) の位置の teacher–student の log-probability 差は、数学的内容の位置の 3.5 倍**になる。差に比例して更新すると、更新の力が teacher の表現を真似ることに多く使われてしまう。

## 手法の核心

- 参照に、student 自身の pretrained base model を使う。student と base の差は、post-training で獲得した token の選好を表し、**teacher からの距離に依存しない**教師になる。
- SD-OPD (Student-Delta OPD) は、中心化 (平均を引く) した student–base の差を更新の係数として使う。
- 係数は、中心化した teacher–student feedback と符号が一致する token だけ残す。
- student の信号は、毎 training round で計算し直す。
- Qwen3 の 1.7B〜8B の student を使う 5 つの teacher–student 構成で、6 つの数学 task の平均 pass@1 (avg@16) が OPD より 7.76〜10.37 pp 上がる。

## 適用可能性 (P2)

- P2 の「蒸留プロセスを実務で回す recipe」にそのまま当たる。追加の teacher 呼び出しは不要で、**base model の log-prob を 1 回余分に取るだけ**で試せる軽い変更。
- capacity gap (teacher が student に比べて大きすぎ、真似できない問題) への一つの対策にもなる。teacher との距離ではなく student の自分の変化量を基準にするため。
- 注意: 評価は数学の reasoning (Qwen3 同士) に限られる。VLM や運転 model の蒸留で「style 位置」に相当する位置が何かは自明でない。

## 試すべき実験アイデア

1. 公開コードを使い、手元の小さな teacher–student の組で OPD と SD-OPD を同じ予算で比べる (最小の実験)。
2. 「符号が一致した token だけ残す」処理を外した ablation で、改善のどれだけが符号フィルタによるかを分ける。
3. 数学以外 (code や指示追従) で style 位置の差が実際に大きいかを、teacher–student の log-prob 差を位置別に集計して先に確認する。
