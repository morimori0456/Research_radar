# NegWAM: Negative-Aware Planning for a Unified World-Action Model (2611.08111)

- トピック: next_arch / プロジェクト: P1 (候補では next_arch に分類) / スコア 4.5
- URL: https://arxiv.org/abs/2611.08111
- コード: https://github.com/Zizizi-hao/NegWAM

## 何を解決する論文か

WAM (World-Action Model; 将来の交通状態と自車の行動を 1 つの生成 model で同時に予測する end-to-end 運転 model) は、行動の学習がほぼ expert trajectory の模倣 (imitation) だけで行われる。そのため、**expert に幾何的には近いが安全でない trajectory** を明示的に抑える信号がない。この論文は、そうした near-expert な失敗を負例として使う post-training (事後学習) で、安全が問われる場面の頑健性を上げる。

## 手法の核心

- NegWAM は、expert trajectory に幾何的に近いが安全上の危険を持つ negative trajectory (負例) を作り、予測をそこから遠ざける repulsive anchor (反発する基準点) として使う。
- 負例は scene 条件つきの rider token (負例を model に渡すための補助 token) としても encode し、「この scene でこの trajectory が成り立つか」という scene-trajectory の整合性を学習させる。
- 学習は flow-matching (ノイズから trajectory へ連続的に変換する生成学習) の目的と、near-expert negative の目的を同時に最適化する。
- rider の枝は推論時に捨てるので、**推論の追加コストはゼロ**。
- NAVSIM v2 (実走行ログに基づく planner 評価 benchmark) の navhard split で 40.4 EPDMS (Extended PDM Score; 衝突・走行可能領域・快適性などを合成した score)。scorer-free な最強 WAM baseline より相対 +4.1%。navtest は 93.3 EPDMS。HUGSIM (閉ループ simulator) での zero-shot 評価でも汎化を確認。

## 適用可能性 (P1)

- P1 の「プランナー実装」に直接入る。imitation で学習した planner に、**near-miss な負例を作って反発させる**という追加 loss は、model 構造を変えずに足せる。
- 負例の作り方 (expert からどれだけ離すか、どう危険にするか) が評価指標と密接なので、P1 の評価側で使っている安全指標をそのまま負例の定義に流用できるかを見る価値がある。
- 注意: 効果は navhard (難しい場面) で大きく、navtest ではほぼ頭打ち。手元の planner が日常場面で既に十分なら、改善幅は小さい可能性がある。

## 試すべき実験アイデア

1. 手元の planner で、expert trajectory に小さな横ずれ・減速遅れを加えた負例を作り、repulsive な追加 loss だけを足して navhard 相当の難しい split で差を見る (最小の実験)。
2. 負例の距離 (expert からの離し幅) を 3 段階に振り、近すぎ/遠すぎで効果がどう変わるかを測る。
3. 公開コードで NAVSIM v2 の再現を取り、EPDMS の内訳 (衝突 / drivable area / comfort) のどれが改善したかを分解する。
