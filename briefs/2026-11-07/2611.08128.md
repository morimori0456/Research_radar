# FreeOcc: Decoupling Ego-Motion for Efficient 4D Occupancy Forecasting (2611.08128)

- トピック: next_arch / プロジェクト: P3 / スコア 4.0
- URL: https://arxiv.org/abs/2611.08128

## 何を解決する論文か

4D occupancy forecasting (周囲の 3D 空間を voxel の占有で表し、その未来を時間方向に予測するタスク) の world model は、自車の動きと周囲の物体の動きを切り分けるのに、重い cross-attention や深い recurrence (再帰構造) を使う。しかし自車の将来の動きは、下流の motion planner がすでに出している。**自車の動きを model 内で推定し直すのは冗長**、というのがこの論文の出発点で、軽量化を狙う。

## 手法の核心

- SE(2) (平面上の位置と向きの剛体変換) で自車の動きを数学的に取り除き、周囲の動的な成分だけの feature 空間を作る (explicit geometric decoupling)。
- この空間では attention なしの temporal fusion が使え、物理制約つきの ODE (常微分方程式) を、他車などの残差の運動にだけ適用できる。
- 生成には conditional flow matching (ノイズから目的の分布へ連続的に変換する生成学習) を使う。
- uncertainty-aware blending: 観測が十分な voxel は single-pass の decoder に回し、不確かな領域にだけ ODE solver を使う。
- 28.3M parameters (同等 model の約 40%)、ensemble 版 FreeOcc-E は 27 FPS。nuScenes で NFCD (Near Field Chamfer Distance; 近傍領域の形状誤差) 0.47 m、mIoU 32.1% で state-of-the-art。SemanticKITTI に zero-shot で転移し、sensor の packet loss や timestamp jitter 下でも理想時 mIoU の 92.8% を保つ。

## 適用可能性 (P3)

- P3 の world model 設計に対し、「**planner の出力を world model の条件に使って、冗長な推定を省く**」という構造上の分担を示す。planner と world model を分離したまま、計算を減らす方針の一例。
- 不確かな領域だけ重い solver を使う仕組みは、edge (車載) での推論予算の配り方として一般化できる。
- 注意: 自車の将来経路を入力に使うため、planner の出力が悪いと world model の予測も歪む。planner が複数候補を出す場合の扱い (候補ごとに再予測か) は abstract では不明。

## 試すべき実験アイデア

1. 既存の occupancy forecaster に、自車座標への変換 (ego-motion の除去) だけを前処理として足し、attention を減らした構成との精度・FPS の差を見る (最小の実験)。
2. planner の出力を意図的に壊した (ずらした) 場合に、予測 mIoU がどれだけ落ちるかを測り、planner への依存度を数値で出す。
3. uncertainty の閾値を振って、single-pass と ODE の割合と精度のトレードオフ曲線を描く。

## 注意

abstract のみに基づく。「state-of-the-art」の比較対象と、uncertainty の算出方法は未確認。
