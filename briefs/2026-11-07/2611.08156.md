# La-JEPA: Compact Robot Policies with Latent World Modeling (2611.08156)

- トピック: next_arch / プロジェクト: P3 / スコア 4.0
- URL: https://arxiv.org/abs/2611.08156

## 何を解決する論文か

最近の robot policy は、動画生成 model を流用した WAM (World-Action Model; 将来の観測と行動を一緒に生成する policy) か、vision-language model を土台にした VLA (Vision-Language-Action; 画像と言語から行動を出す model) に分かれる。どちらも、**生成や言語のために設計された大きな transformer** に policy が縛られ、推論コストが大きい。それが制御にどれだけ効いているかは不明だった。La-JEPA は、policy transformer を最初から小さく学習しても足りるかを検証する。

## 手法の核心

- JEPA (Joint-Embedding Predictive Architecture; 画像を再構成せず latent 空間で次の状態を予測する world model) の encoder である V-JEPA 2.1 を凍結し、その feature 空間で policy transformer を **from scratch** で学習する。
- Fast-WAM に倣い、学習時は将来の feature と action を同時に予測し、推論時は action だけを出す。
- design study (設計の切り分け実験) の結論は 2 つ: (a) JEPA feature は video VAE latent より良く、特に OOD (学習分布外) で差が出る、(b) 推論時に使わなくても、学習時の将来予測の設計が policy を大きく左右する。
- embodied pretraining (ロボットデータでの事前学習) なしの policy の中で、RoboTwin 2.0 (clean/randomized) と LIBERO-Plus で最高。実機 4 タスクの平均成功率は pi0.5 と同程度。Fast-WAM より大幅に速い。
- LIBERO-Plus の公式 evaluator が instruction を壊していることを見つけ、修正して強い open baseline を再評価した。

## 適用可能性 (P3)

- P3 が「次世代アーキテクチャ」を決めるとき、**policy を大きい生成 model から切り離して小さく作る**選択肢の根拠になる。車載での推論コスト制約に近い。
- 「推論で使わない補助予測が学習に効く」点は、運転 E2E でも、将来 BEV (鳥瞰図) や occupancy の補助予測を学習時だけ足す設計に直接つなげられる。
- 注意: 評価は manipulation (RoboTwin / LIBERO) で、運転のような長い時間スケール・高速移動では未検証。評価が最近修正された benchmark なので、数値の比較は再評価分を使う必要がある。

## 試すべき実験アイデア

1. 手元の運転 policy で、凍結した JEPA 系 encoder の feature の上に小さな transformer を from scratch で学習し、現在の backbone との精度・latency を比べる (最小の実験)。
2. 学習時のみの将来 feature 予測を on/off して、閉ループ指標の差を見る。予測の horizon (何 step 先か) も振る。
3. JEPA feature と VAE latent を OOD 条件 (天候・場所) で比べ、論文の「OOD で差が出る」が運転 data でも出るか確認する。
