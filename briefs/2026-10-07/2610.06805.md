# H-JEPA: 時間スケール別に階層化した latent world model で長期 planning

- 対象: P3 (world model)
- 元論文: http://arxiv.org/abs/2610.06805v1 (Wancong Zhang, Basile Terver, Michael Rabbat ほか)
- 根拠: abstract のみ

## 何を解決する論文か
JEPA (Joint-Embedding Predictive Architecture; 画素ではなく latent 表現の未来を予測する自己教師あり手法) の world model は、単一の時間スケールで予測・planning するため、長期の planning で抽象度の異なる推論ができない。H-JEPA は action-conditioned な JEPA を階層化し、上位ほど遠い未来を、その層独自の latent で予測する。

## 手法の核心
- 各レベルが独自の latent 空間で、より先の未来を予測する階層を end-to-end で学習する recipe。
- Planning は top-down: 最上位がゴールへの進捗を最適化し、各レベルの予測が下位 planner の subgoal (途中目標) になる。
- 時間スケールが分かれた要因を持つデータでは、上位が速くて予測不能な細部を捨て、遅くて task に関係する状態だけを保つ。
- 結果: 4 つの simulation 環境 (navigation/manipulation) で flat な JEPA を上回る。Visual AntMaze では 3 レベルで成功率 18% → 73%、planner の計算量はむしろ減る。ablation で時間分解と上位の goal 表現の両方が寄与。
- inverse-dynamics supervision (前後の状態から行動を推定する教師) を足すと DROID (実ロボット映像) にも拡張でき、offline の planning 精度が少ない計算量で上がる。

## 適用可能性 (P3)
- 運転は「車線変更・経路 (遅い)」と「操舵・周辺車両 (速い)」が分かれた階層構造を持つので、設計の着想として自然。
- 注意: 実証は小さな simulation と少量の実ロボット映像。運転の高次元・多主体環境への一般化は未確認で、planner 計算量の削減は報告されているものの、学習コストは別。

## 試すべき実験
1. 運転 log の latent で、2 レベルの H-JEPA (短期: 0.5 秒、長期: 5 秒など) を小さく学習し、上位 latent が route/車線レベルの情報を持つかを probing で確認する。
2. flat な JEPA と同じ planner 予算で、長期の goal 到達 (経路追従) を比較する。
3. ablation を再現: 上位の goal 表現を外した時に何が落ちるか。
