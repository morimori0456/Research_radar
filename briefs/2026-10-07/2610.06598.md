# SimForcing: simulation の motion 知識を real-domain の world model に蒸留する

- 対象: P2 (蒸留 + ドメイン適合) と P3 (world model) の両方
- 元論文: http://arxiv.org/abs/2610.06598v1 (Xiaodong Wang ほか)。コード: https://github.com/Wang-Xiaodong1899/SimForcing
- 根拠: abstract のみ

## 何を解決する論文か
Action-conditioned world model (ロボットの行動を入力に、その結果の映像を予測するモデル) は、行動に正確に反応することと、見た目が現実的であることを両立させたい。simulation は構造化された motion の教師信号を安価に出せるが、見た目が現実と違うため直接転用しにくく、simulation の予測が不正確だと real 映像の生成を誤誘導する。

## 手法の核心
- Latent-motion distillation: simulation 教師から、latent 空間での「時間変化」だけを揃えて motion の prior を取り込む。見た目の差は揃えない。
- Multi-block simulation conditioning + condition dropout: simulation の予測軌跡を条件に使うが、dropout で「simulation が正しい前提」に依存しすぎないようにする。
- Simulation-conditioning CFG (classifier-free guidance; 条件あり/なしの予測を混ぜて条件への従い具合を調整する手法): 蒸留で内在化した motion 知識と、simulation latent による追加誘導のバランスを取る。
- student が simulation 条件と real 映像の両方を生成するので、推論時に追加の world model は不要。
- 結果: Bridge で PSNR/SSIM/LPIPS/FVD が比較手法中最良 (外部の embodied pretraining なし)。InternData-A1 でも評価。この world model で VLA を初期化すると LIBERO の成功率が上がる。

## 適用可能性
- P2: 「sim 教師 → real 生徒」で、見た目の gap を避けて motion だけを蒸留する設計が、domain gap 対策の具体例になる。
- P3: world model の学習に sim を使う際の、sim の誤りに引きずられない conditioning の作法。
- 運転では、sim (CARLA 等) の trajectory 情報を real 動画の world model に入れる構図に対応する。

## 試すべき実験
1. 運転 world model で、sim 教師との latent 差分 (時間方向の変化) だけを揃える loss を小さな video 予測モデルに足し、action 応答性 (行動を変えた時の予測の変化) が上がるか見る。
2. condition dropout 率を振り、sim 条件への過依存がどこで出るかを調べる。
3. 本文で、教師と student の構造・latent の取り方・計算量を確認する (abstract では不明)。
