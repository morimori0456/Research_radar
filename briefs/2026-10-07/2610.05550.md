# Low prediction error が planning を誤らせる: latent world model の誤差を 3 段で診断

- 対象: P3 (world model) / 副次的に P1 (評価の考え方)
- 元論文: http://arxiv.org/abs/2610.05550v1 (Rui Min, Xianyao Li, Fang Xu ほか)
- 根拠: abstract のみ。結果は小規模な control task 上 (PushT, Reacher, Cube など)

## 何を解決する論文か
Latent world model (観測を潜在表現に変換し、その空間で未来を予測するモデル) は、予測誤差 (MSE) の小ささで評価されがちだが、予測誤差の大半を占める成分が、行動選択の質に最も効く成分とは限らない。この論文は、誤差の中のどこを直せば planning が良くなるかを分けて測る。

## 手法の核心
- 同じ物理的な開始状態から複数の候補 action 列を比較し、終端の誤差を 2 つに分ける: candidate pool の center error (全候補に共通する偏り) と action-relative response (行動ごとの違いへの反応の誤差)。
- 4 つのモデル系統 × 4 task、各 task 256 開始状態 × 300 候補で検証。16 セル中 14 で center error が MSE を支配する。
- ところが 6 セルでは、action-relative response だけを oracle で直した方が、物理的な順位相関 (Spearman) と top-30 エリート候補の質が良い。MSE は center だけ直した方が小さいにもかかわらず。
- ただし LeWorldModel (LeWM) で oracle 選択の action を実行すると、PushT や Reacher では center の修正が有利で、設定によって結論が変わる。
- LeWM では、実際の終端を encoder に通すと順位相関が 0.464 → 0.975 (Reacher)、0.193 → 0.631 (PushT) に上がる = 順位が落ちる場所を特定できる。
- 72 run の objective 実験は診断指標を改善したが、closed-loop の planning 改善は未確認。結論は「representation / prediction / planning を別の段として評価せよ」。

## 適用可能性
- P3: world model を作るとき、MSE や FVD だけで model を選ばない理由と、その代替の診断手順 (候補 action の順位相関) が手に入る。
- P1: planner 評価でも「平均誤差の小ささ」と「候補の順位付けの正しさ」は別物、という観点が使える。
- 限界: 小さな control task での診断で、結論は設定依存と著者自身が述べている。運転にそのまま当てはまる証拠は無い。

## 試すべき実験
1. 手元の world model で、同一開始状態・複数候補 action 列について、予測 vs 実際の終端の Spearman 順位相関を、MSE と並べて報告する診断を作る。
2. 誤差を center と action-relative に分解し、どちらが大きいかを見る (center が大きくても順位には効かない場合がある)。
3. 順位相関が低い場合、encoder (representation) のせいか dynamics のせいかを、実際の終端の再 encode で切り分ける。
