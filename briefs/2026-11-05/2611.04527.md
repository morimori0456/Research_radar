# Future Representation Distillation for Imagination-Free World Action Models (2611.04527)

- トピック: next_arch / プロジェクト: P3 (P2 の distillation 手法にも関連) / スコア 4.0
- URL: https://arxiv.org/abs/2611.04527

## 何を解決する論文か

WAM (World Action Model; 将来の動画を予測する能力を借りて行動を決める policy) は、事前学習済みの video diffusion model (ノイズから動画を生成する model) の予測の知識を robot 制御に使う。ただし未来の動画を毎回 diffusion で生成すると遅く、予測が外れると行動も悪くなる。DreamFree は、**未来の動画を作らずに、予測の知識だけを現在の観測から取り出す**ことで、これを避ける。

## 手法の核心

- representation distillation (大きな model の中間表現を、小さな model に再現させる蒸留): visual encoder が、凍結した video diffusion model の表現を、現在の観測だけから予測するよう学習する。
- その後、action module が、この visual encoder から行動に効く情報を取り出して行動を予測する。推論時に動画を生成しない (imagination-free)。
- 14B (140 億 parameter) の video diffusion backbone を使いながら、11 Hz の real-time closed-loop 制御ができる。
- 実機と simulation の task で、state-of-the-art の VLA (Vision-Language-Action; 画像と言語から行動を出す model) と WAM より高い成功率。
- backbone の video prior が強くなる、あるいは video data が増えると、制御も良くなる。新しい task を、**行動注釈なし**の動画 (別の embodiment の動画を含む) から学べる。

## 適用可能性 (P3 / P2)

- P3: world model を推論時の生成から切り離し、「表現の蒸留」として使う設計の実例。運転でも、将来予測 model の知識を現在フレームから読める encoder に移せれば、推論コストを抑えられる可能性がある。
- P2: distillation の対象を、出力 (logit や動画) でなく **将来を予測する表現**に取る、という選び方が参考になる。student の capacity が足りない場合の挙動は abstract から分からない。
- 注意: 対象は manipulation。運転は画面の変化が大きく、現在フレームだけから将来表現を予測する難しさが違うはず。14B の teacher を Thor のような車載級の計算機でどこまで回せるかは別問題である (11 Hz の hardware は abstract に無い)。

## 試すべき実験アイデア

1. 手元の動画予測 model (または公開された video diffusion model) を teacher として凍結し、現在フレームから teacher の中間表現を回帰する encoder を作る。回帰誤差と、下流の軌道予測の誤差の相関を見る。
2. 運転で、この encoder を凍結して planner に載せ、行動注釈のない動画だけで追加の事前学習をした場合の効果を、データ量を変えて見る。
3. teacher の表現を取る層 (浅い・深い) を変えて、行動に効く層を探す。

## 注意

abstract のみに基づく。teacher の元の名前、蒸留 loss の形、real-time の測定 hardware は未確認。
