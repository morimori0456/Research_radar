# RAFT: Reasoning-Aligned Fine-Tuning Improves Robustness of VLA Post-Training (2611.04368)

- トピック: next_arch → fine-tuning による適合の観点で P2 に配置 (P3 の VLA にも関連) / スコア 4.5
- URL: https://arxiv.org/abs/2611.04368

## 何を解決する論文か

汎用の VLA (Vision-Language-Action; 画像と言語から行動を出す policy) を、少ない demonstration で目的の task に fine-tuning すると、その task の成功率は上がるが、見た目・物体・指示が少し変わると壊れやすくなる。つまり**少データ適合で robustness が落ちる**。RAFT (reasoning-aligned fine-tuning) は、行動を学ぶ前に task に関する reasoning (推論) の注釈で adapter だけを先に学習し、その後に凍結して行動を学ぶ 2 段階で、この劣化を抑える。

## 手法の核心

- 段階 1: 低ランクの adapter (LoRA のように、重みの差分を小さな行列で表したもの) を、task に関係する reasoning の注釈で学習する。
- 段階 2: その adapter を凍結したまま、行動の demonstration で policy を fine-tuning する。
- 実機 (DROID robot) の out-of-distribution (学習時と違う条件) 成功率は 75.0%、plain fine-tuning は 27.9%。2 本腕の多段階 task (YAM) では 70.0% 対、最良の baseline 36.0%。
- simulation の pick-and-place と引き出しを開ける task でも、見た目・物体・指示の変化に強くなる。
- 解析: plain fine-tuning より注釈された領域に attention を多く向け、後半の層で物体の identity を linear probe (単純な線形 model での読み出し検査) で高精度に読める。reasoning data を広く混ぜると、demonstration の量が違っても下流の成功率がさらに上がる。

## 適用可能性 (P2 / P3)

- P2: 「基盤モデルを別ドメインに少データで転用する recipe」にそのまま当たる。特徴は、**行動データが少なくても、安価な reasoning 注釈を先に入れる**ことで、ドメインギャップに対する頑健性を稼ぐ点である。
- P3: VLA の学習手順の一部として、段階を分ける設計を採るかの判断材料になる。
- 注意: 対象は manipulation の VLA。運転の VLA で reasoning 注釈 (例: 注目すべき物体・領域の指定) の作成コストと効果が同じかは分からない。数字は設定固有で、baseline の強さは abstract からは評価できない。

## 試すべき実験アイデア

1. 手元の fine-tuning で、「adapter を reasoning 注釈で先に学習して凍結 → 行動を学習」と plain fine-tuning を、同じ demonstration 数で比べる。評価は nominal の条件と、見た目・指示を変えた条件の両方で行う。
2. reasoning 注釈の質を段階的に落として (粗い領域指定のみ、等) 効果が残る下限を見る。注釈コストの見積もりになる。
3. 凍結した adapter の有無で、物体 identity の linear probe 精度と attention の位置がどう変わるかを可視化し、効いた理由の再現確認にする。

## 注意

abstract のみに基づく。adapter の rank、reasoning 注釈の作り方、baseline の詳細は未確認。
