# Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs (2611.05249)

- トピック: planner_ai / プロジェクト: P1 (P3 の VLA 構造にも関連) / スコア 4.5
- URL: https://arxiv.org/abs/2611.05249

## 何を解決する論文か

VLA (Vision-Language-Action; 画像と言語の入力から行動を出す大きな model) の最近の構成は、事前学習済みの VLM (Vision-Language Model; 画像と文章を扱う model) に、flow-matching (ノイズから行動の系列を少しずつ生成する生成手法) で行動を出す小さな action expert を付ける形である。この expert は VLM の key-value 表現 (attention が参照する中間特徴) を読んで行動を作る。主流の学習 recipe は、expert の loss の勾配を VLM に流さない (論文の用語で insulation; VLM の既存能力を守るため) 運用をとる。この論文は、**その遮断が本当に必要か**を、運転と manipulation の両方で切り分ける。

## 手法の核心

- 2 つの要因を独立に動かす。(1) expert の loss の勾配を VLM に流すか (coupling) 遮断するか (insulation)。(2) VLM 自身に、同じ target 行動を離散化した action token を予測させる supervision を付けるか。
- open-loop (記録済みのログに対する軌道誤差) の運転評価では、action token の supervision があれば insulation は coupling と同程度。無ければ coupling が trajectory-prediction error を約 25% 減らす。
- 両方の要素を最初から joint に学習した場合、coupling は closed-loop (出した行動が次の入力に返る閉ループ) 運転の route progress (経路を進めた割合) を、action token ありで約 17%、無しで約 40% 上げる。manipulation でも同様に改善する。
- 結論: insulation の価値は、VLM が action 側の supervision を別に受けているか、評価が open-loop か closed-loop かに依存する。**insulation を default の recipe とする根拠は弱い。**

## 適用可能性 (P1 / P3)

- P1: 同じ論文の中で open-loop と closed-loop の結論が食い違う点が使える。open-loop の誤差だけで recipe を選ぶと、closed-loop での差を見逃す。planner の評価には closed-loop を必ず入れる根拠になる。
- P3: VLA 型の planner を学習するとき、勾配の遮断・action token・co-training の 3 つが絡み合っている。手元の recipe がどの組み合わせかを棚卸しできる。
- 注意: どの運転 benchmark・どの VLM かは abstract に無い。数字は論文の設定での値で、規模が違うと再現しない可能性がある。

## 試すべき実験アイデア

1. 手元の VLA 型 planner で、「勾配を流す / 遮断」×「action token supervision の有無」の 2×2 を同じ budget で回し、open-loop 誤差と closed-loop の進捗の両方を並べる。
2. 遮断した運用で、VLM の key-value 表現から軌道を読み出す probe (凍結した表現に単純な model を載せて情報量を測る検査) を作り、coupling の有無で行動に関する情報量がどう変わるかを見る。
3. 勾配を流す場合に、VLM の言語・画像の能力が落ちるかを、既存の VQA 系の小さな評価で確認する (insulation の本来の目的の検証)。
