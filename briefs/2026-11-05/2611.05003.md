# Unifying and Beyond the Theory of Pervasive Capability Degradation in LLM Post-training SFT from Feature Interference (2611.05003)

- トピック: fm_distill_finetune / プロジェクト: P2 / スコア 4.0
- URL: https://arxiv.org/abs/2611.05003

## 何を解決する論文か

LLM を SFT (Supervised Fine-Tuning; 正解データで追加学習する) で特定の task に適合させると、事前学習で身につけた一般的な能力が落ちる。論文はこれを PCD (Pervasive Capability Degradation) と呼ぶ。従来の説明は「分布が変わったから」という大づかみなもので、どこを触れば直るかが分からず、対策手法は理論の裏付けが弱かった。この論文は、**特徴どうしの干渉 (feature interference)** という細かい機構で PCD を説明し、その理論から新しい loss を導く。

## 手法の核心

- 理論: model は少ない次元に多くの特徴をほぼ直交に詰め込んでいる (superposition; 重ね合わせ)。narrow な domain の SFT データがこの直交構造を乱し、その干渉で活性化が出力側の決定境界 (decision hyperplane) を越え、一般 task の予測が反転する、という説明。
- この理論で既存の対策手法を 6 つの paradigm に整理し、それぞれが効く理由と限界を示す。
- one-hot の教師ラベルに対する cross-entropy だけでは PCD を解けないことを証明する。
- 提案 AEGIS loss: 競合する全 token の方向に対する activation margin (正解と他候補の差) のずれを直接制約する。**干渉の抑制と task への適合を分離**する。
- 3 つの model family・14 の SFT task で、各 paradigm の代表手法より target task と一般能力の両方で良い。計算コストは標準 SFT の約 1.3 倍。

## 適用可能性 (P2)

- P2 の「他機種・他ドメインへの適合」で最も困る問題 (適合すると元の能力が落ちる) に、理論付きの loss を出している。LoRA などの PEFT (Parameter-Efficient Fine-Tuning; 一部の重みだけ学習する) と併用できるかは abstract から分からないが、loss なので組み込みは軽い。
- 蒸留でも、student を特定 task に寄せると一般能力が落ちる場面で、同じ考え方が使える可能性がある。
- 注意: 対象は LLM の SFT。視覚や VLA の fine-tuning で同じ干渉が起きるかは別に確認が要る。「約 1.3 倍」の内訳 (margin の計算に全 token を見る費用) は abstract に無い。

## 試すべき実験アイデア

1. 手元の fine-tuning で、適合前後に一般能力の小さな評価 (元 domain の held-out と汎用 benchmark) を固定して回し、PCD の大きさを数字にする。
2. AEGIS の考え方である「正解 logit と競合 logit の margin を、適合前の model の値から離れすぎないよう抑える」項を、既存の loss に足して差を見る。実装は論文のコードが出ていれば優先して使う。
3. 同じ設定で、LoRA の rank を変えたときと AEGIS 項を足したときで、target task の精度と一般能力のトレードオフ曲線を比べる。

## 注意

abstract のみに基づく。3 つの model family の名前、14 task の内訳、既存手法に対する改善幅の具体値は未確認。
