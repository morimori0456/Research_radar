# AquaProbe: Efficient Adaptation of Frozen Vision Models for Underwater Images (2610.40900)

- トピック: fm_distill_finetune (P2、ドメインギャップの測定 + PEFT) / スコア 4.0 / RSS 回収分 (月曜 announce)
- URL: https://arxiv.org/abs/2610.40900

## 何を解決する論文か

地上の画像で事前学習した vision model は、水中では信頼性が落ちる (濁り・後方散乱・波長ごとの減衰で見た目が変わる)。既存の適合手法は、adapter を encoder の全深さに均等にばらまくか、固定した 2 domain の差で層を選ぶ。しかし**ギャップがどの層に出るかは、水の種類や撮影距離で変わる**。この論文は、ギャップの位置をまず測り、LoRA (Low-Rank Adaptation; 低ランクの差分だけを学習する軽量 fine-tuning) の予算をそこに配分する。

## 手法の核心

- **AquaProbe**: 同じ場面の clean な画像と、物理的に水中の劣化をかけた画像の**対**を作る。
- encoder に通したときの差を、**その層で新しく加わった差**と**前の層から持ち越した差**に分ける。これで「どの層でギャップが生まれるか」の profile が取れる。
- 固定した LoRA の予算 (adapter の parameter 数 0.59M) を、測った profile に比例して層ごとの rank に割り当てる。
- 結果 (segmentation の mIoU; 予測と正解の重なり具合): 比例配分は 70.1 で、同じ予算の一様配分より 1.9 point 良い。
- さらに、推定した条件の cluster ごとに adapter を選ぶ **3-way router** (3 つのうち 1 つを入力に応じて選ぶ仕組み) で、標準の SUIM split で 70.6 mIoU、未知の劣化に対する AUDRC (selective prediction の指標; 自信のない予測を棄却したときの性能) が 63.4。

## 適用可能性 (P2: FM 蒸留 + 他機種・他ドメインへの適合)

- 他機種 (別 camera・別 sensor) への適合で、**どの層に LoRA を置くかを実験で当てずに測って決める**手順になる。層ごとの rank を総当たりで探すより安い。
- 「paired な clean / 劣化画像」は、他機種への適合では「同じ場面を機種 A と機種 B で撮ったデータ」か、「機種 A の画像に機種 B の特性をかけた合成」で代替できる。ギャップの原因を物理で再現できる場合に効く。
- 条件の cluster で adapter を切り替える router は、天候・時間帯・機種など、複数の domain を 1 つの基盤 model で扱う場合の型になる。
- 注意点: 改善幅は 1.9 mIoU と小さく、単一の dataset (SUIM) での結果。物理的な劣化のかけ方が実際の機種差に合っているか (sim-to-real の差) が前提になる。

## 試すべき実験アイデア

1. 手元の基盤 model で、機種 A の画像に機種 B の特性 (解像度・ノイズ・色) をかけた対を作り、層ごとの特徴の差を「新しく加わった差」と「持ち越し」に分けて可視化する。ギャップが出る層が浅いか深いかで、LoRA の置き場が変わる。
2. その profile に比例した rank 配分と、一様配分を同じ parameter 数で fine-tuning して比べる。差が出なければ、手元のギャップは層に偏っていない。
3. 少データ (機種 B の画像 100 / 1000 枚) で上の比較を繰り返し、データが少ないほど配分の効果が大きいかを見る。
