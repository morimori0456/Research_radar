# Frozen in Time: How a Physics Foundation Model Forgets Under Sim-to-Real Adaptation (2610.40857)

- トピック: fm_distill_finetune (P2、sim-to-real 適合での忘却対策) / スコア 4.0 / RSS 回収分 (月曜 announce)
- URL: https://arxiv.org/abs/2610.40857

## 何を解決する論文か

基盤 model を新しいデータで fine-tuning すると、元の知識が壊れる (catastrophic forgetting; 破滅的忘却)。この論文は、PDE (偏微分方程式; 流体などの物理現象を表す式) 向けの基盤 model である Walrus-1.3B で、simulation → 実験データの 2 段階の適合 (sim-to-real) の間に何が起きるかを測る。対象は円柱まわりの流れ。

## 手法の核心

- 段階 1: simulation の流れで fine-tuning する。**20 epoch で元の事前学習データの 1 step 予測誤差が最大 35 倍**に悪化する。
- 段階 2: 実験データで続けて fine-tuning すると、直前に学んだ simulation の性能もさらに落ちる。
- 忘却の要因を調べる: dataset への依存、task 表現の類似度。
- 対策は **replay** (過去の task のデータを少量混ぜて学習する) で、**実験データの学習中に simulation データを 1% 混ぜるだけで、失った simulation の性能の大部分が戻り**、実験への適合も保たれる。
- 結論として、忘却は sim-to-real 適合の実務上の障害で、軽い replay で保持が大きく改善する。

## 適用可能性 (P2: FM 蒸留 + 他機種・他ドメインへの適合)

- 「simulation で適合 → 実データで適合」は、P2 の他機種・他ドメイン適合そのものの形で、段階を重ねるごとに前の段階が壊れるという警告になる。基盤 model の元の能力を保ちたいなら、適合のたびに保持の指標を測る必要がある。
- 1% の replay という安いコストで大半が戻るのは、実務の recipe として使える。replay の割合を決める 1 本の曲線を引けばよい。
- 前日までのブリーフ (2610.38001: 逐次 fine-tuning で distillation が元の能力を守る) と対になる。あちらは元の model を教師にした distillation、こちらは過去データの replay。2 つを同じ設定で比べる動機になる。
- 注意点: 対象は物理の基盤 model で、vision や言語の model とは忘却の出方が違いうる。replay には過去データが手元に必要で、基盤 model の事前学習データが非公開だと使えない。

## 試すべき実験アイデア

1. 手元の基盤 model を機種 A → 機種 B の順に fine-tuning し、各段階の後に、元の事前学習 task と機種 A の性能を測る。まず「どれだけ忘れるか」の基線を取る。
2. 段階 2 で機種 A のデータを 0.1% / 1% / 10% 混ぜ、保持と機種 B への適合の曲線を描く。論文の「1% で大半が戻る」が再現するかを見る。
3. 同じ設定で replay と、元の model を教師にした KL 項 (distillation) を比べ、データ量が少ないときにどちらが効くかを調べる。

## 注意

abstract のみに基づく。「大部分が戻る」の具体的な割合、replay データの選び方、他の model での再現は未確認。
