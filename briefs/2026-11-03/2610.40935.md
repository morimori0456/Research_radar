# Let LiDAR Decide Where to Look: Geometry-Measured Token Selection for Efficient Sparse Latent World Models (2610.40935)

- トピック: next_arch (P3、E2E 運転 + world model) / スコア 4.5 / RSS 回収分 (月曜 announce)
- URL: https://arxiv.org/abs/2610.40935

## 何を解決する論文か

camera だけで走る E2E (end-to-end; 画像から直接軌道を出す) 運転 model は、1 frame あたり数千の image token を encoder に通すが、大半は空・建物・何もない路面で、planning に要らない。さらに、これらの token は planner の attention を薄めるので、**ランダムに 75% 捨てるだけで dense (全 token を使う) model より良くなる**、という観察が出発点。この観察を使って、何を残すかを賢く選び、計算量も減らす。

## 手法の核心

- **GATS (Geometry-Aware Token Selection)**: LiDAR と radar の点を image 平面に投影し、点が落ちた patch だけを残す。選択は視覚特徴でなく**測定した 3D 形状**で決まる。
- 選択は vision backbone を**走らせる前**に行う。backbone は残った patch だけを encode するので、end-to-end の FLOPs (浮動小数点演算量) が最大 18 倍減る。
- 残した token には LiDAR の点から 3D anchor (3 次元の位置) を付ける。
- 後段は self-supervised な latent world model (将来の特徴と 3D 変位を予測する model; box の annotation は不要) で、予測を通じて planner の表現を学ぶ。
- 結果: token を 25% に絞ると nuScenes の 3 秒 L2 誤差 0.520 m (dense は 0.573 m)、NAVSIM の EPDMS (Extended Predictive Driver Model Score; 衝突や走行可能領域の遵守などを合成した planner の評価 score) が 88.9 (dense は 85.9)。FLOPs は 6.6 倍少ない。10% でも dense を上回る。739 の intent-critical な場面 (他車の意図が安全に効く場面) では、危険な車両の 95.8% を網羅し、衝突率は 0.09% (dense は 0.34%)。

## 適用可能性 (P3: 次世代アーキテクチャ)

- 「token を減らすと良くなる」は、E2E の入力側の設計を見直す直接の根拠になる。計算を減らす話と精度を上げる話が同時に成り立つ。
- latent world model を、box annotation なしの自己教師ありで学ぶ構成は、P3 の world model の方針とそのまま重なる。
- LiDAR (または radar) を持つ構成が前提。camera のみの車では、選択に使う 3D 形状を別の手段 (depth 推定など) で用意する必要があり、その誤差が選択を壊しうる。
- 注意点: 測定が手に入る点の近くだけ残すので、遠方や点が疎な対象 (小さい障害物、反射の弱い物体) が落ちる危険がある。論文は intent-critical 場面で網羅率を出しているが、abstract だけでは落ちる条件が分からない。

## 試すべき実験アイデア

1. 手元の E2E model で、token をランダムに 25% / 10% に落とす ablation (一部を外して効果を見る実験) を先に回す。dense と比べて悪化しなければ、「token が planner の attention を薄める」が手元でも成り立つと言える。
2. 選択の基準を、LiDAR 投影 / 視覚特徴の重要度 / ランダムの 3 つで比べる。同じ budget で差が出るかを、衝突率と L2 の両方で見る。
3. 落ちた token の内訳 (遠方、小物、夜間) を数える。小さい障害物と遠方の対象で網羅率が下がるなら、budget の一部を一様な選択に回す混合を試す。

## 注意

abstract のみに基づく。選択の閾値、world model の architecture、nuScenes / NAVSIM 以外での検証、閉ループでの結果は未確認。
