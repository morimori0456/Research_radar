# RAIL: Representation-Aligned Imitation Learning for Student-Compatible Teacher Policies (2611.12251)

- トピック: fm_distill_finetune / プロジェクト: P2 / スコア 4.0 (capacity gap 対策)
- URL: https://arxiv.org/abs/2611.12251

## 何を解決する論文か

画像などの生センサ入力から RL (Reinforcement Learning; 報酬を最大化して方策を学ぶ) で直接学ぶのは難しいため、「privileged information (本番では得られない真の状態など) を見られる teacher policy を先に作り、生入力しか見ない student policy に蒸留する」やり方がよく使われる。しかし teacher が student に見えない情報に頼っていると、student はどう頑張っても真似できず、irreducible imitation gap (どうしても埋まらない模倣の差) が残る。RAIL は、この差を蒸留の後で埋めるのでなく、**teacher の訓練中に**防ぐ。

## 手法の核心

- teacher と student の観測の両方から、**contrastive learning (近いものを近く・違うものを遠くに置く表現学習) で共有の潜在表現を学ぶ**。
- teacher policy を、その共有空間の上で直接訓練する。teacher は共有空間で見える情報しか使えないので、student が再現できる行動だけを学ぶ。
- 従来の対処 (reward shaping、teacher 訓練後の student への追加 RL) を使わずに、imitation gap を縮め、課題の性能は保つと報告。
- 複数の環境で、強い baseline と、生観測から直接 RL する場合を上回る。
- 共有表現のおかげで、teacher だけを新しい課題で訓練して student に zero-shot (追加学習なし) で transfer できる、とも書かれている。

## 適用可能性 (P2)

- P2 の中心課題である **capacity gap / 再現できない teacher** への、「teacher 側を student に合わせて作る」という対策。多くの蒸留 recipe は student 側の loss や data 選別を直すが、この論文は teacher の訓練設計を直す点が違う。
- 運転への接続: privileged な情報 (他車の真の位置・意図、地図の真値) を使う teacher から camera-only の student に落とす構成で、そのまま発想を使える。
- 注意: 評価は RL の control 環境。LLM や大規模 vision model の蒸留に効くかは未検証。

## 試すべき実験アイデア

1. 手元の privileged teacher → student 蒸留で、まず teacher と student の中間表現を contrastive loss で揃える補助項を teacher の訓練に足し、student の最終性能と imitation gap (teacher と student の行動の差) を比べる。
2. 共有表現に通さない普通の teacher と通した teacher で、student が再現できる割合を測る。差が出なければ、gap の原因は表現でなく capacity と切り分けられる。
3. teacher-only の学習で新課題へ zero-shot transfer できるかを、小さな toy 課題で確かめる。
