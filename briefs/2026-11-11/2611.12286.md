# VLA-MOPD: On-Policy Distillation for Multi-Task VLA Policy Consolidation (2611.12286)

- トピック: next_arch / プロジェクト: P3 (P2 の蒸留としても読める) / スコア 4.5
- URL: https://arxiv.org/abs/2611.12286

## 何を解決する論文か

VLA (Vision-Language-Action; 画像と言語から action を出す model) を課題ごとに post-training すると、課題ごとの specialist model が増えてしまう。これを 1 つにまとめる consolidation は難しい。複数課題をまぜた RL は trajectory 単位の粗い credit しか得られず、offline distillation は student が実際に訪れる観測を見逃し、最終出力だけの distillation は action 生成の途中状態を supervise しない。VLA-MOPD は、flow-matching VLA (ODE を数 step 解いて action を生成する VLA) の specialist 群を、on-policy distillation で 1 つに統合する。

## 手法の核心

- **on-policy distillation** (student 自身が出した行動・状態に対して teacher が supervision を与える蒸留) を **multi-teacher** (課題ごとの凍結 teacher を使う) に拡張した protocol。
- student が robot の rollout を集め、**訪れた各観測と、action 生成の途中の ODE 状態**で、instruction によって選ばれた凍結 teacher に問い合わせる。
- teacher から flow の step ごとの transition target を取り、masked local matching loss で valid な action chunk (まとめて出す連続 action の塊) を supervise する。
- 任意で reference-policy 項を足し、他の課題の性能の保持 (retention) を支える。
- 結果: LIBERO (言語条件付き manipulation benchmark) で、課題あたり 1 trajectory から出発して mean success-once が 75.4% → 98.9% (endpoint action distillation は 98.15%)。RoboTwin 2.0 で 73.0% → 89.3%。Piper robot で 2 round の consolidation により 70.0% → 90.0%。Spatial への適合実験では、reference 項があると Object suite の低下が 3.0 点で、無いと 13.2 点。

## 適用可能性 (P3 / P2)

- P2: 昨日採用した P^2-MOPD (multi-teacher on-policy distillation) の flow-matching VLA 版。specialist を統合する recipe として、**途中状態まで supervise する**点と、**reference 項で retention を守る**点が使える部分。
- P3: 運転 VLA でも、domain (都市・高速・悪天候) ごとに specialist を作ってから 1 つにまとめる流れは自然で、flow-matching の action head を使うなら構造がそのまま合う。
- 注意: 最終出力だけの distillation (98.15%) との差は LIBERO では 0.75 点しかなく、利点が大きく出るのは RoboTwin や実機側。運転のような別 domain での効果は未検証。

## 試すべき実験アイデア

1. 手元の specialist 2 つを統合する最小構成で、最終出力のみの distillation と、途中 step も含める distillation の差を測る。
2. reference-policy 項の重みを振り、新課題を足したときの既存課題の低下 (retention) を測る。
3. 運転 VLA で domain 別 expert を作れるなら、DeltaForge (2611.11856; 重み空間で統合) と、この on-policy distillation 方式 (data 空間で統合) を同じ expert 群で比べる。
