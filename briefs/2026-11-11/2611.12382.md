# AutoVLA-D: Learn a Trajectory-Geometric Condition from Reasoning for Autonomous Driving VLA (2611.12382)

- トピック: planner_ai / プロジェクト: P1 (P3 にも効く) / スコア 4.0
- URL: https://arxiv.org/abs/2611.12382
- コード: https://github.com/ShivaTeam/AutoVLA-D (abstract に記載)

## 何を解決する論文か

VLA (Vision-Language-Action; 画像と言語指示から直接 action を出す model) で運転する場合、最終出力の連続 trajectory に「減速して右に寄る」のような言語指示を直接結びつけるのは難しい。指示は action の言葉で書かれているのに、出力は自車の座標列だからである。この論文は、連続 trajectory を出す前に、離散 token で表した trajectory の「形」を先に生成して条件として使う TrajCond を提案する。

## 手法の核心

- **TrajCond**: 離散化した differential action trajectory (座標でなく step ごとの変化量の列。abstract では "1D-Brohan" 表現と呼ばれるが、定義の詳細は abstract だけでは不明) を、最終 trajectory の前段の条件にする。
- 離散 trajectory と連続 trajectory を同じ autoregressive (1 token ずつ順に生成する) 過程で同時に生成する。これが名前の D (Double) の由来。
- 2-stage training で TrajCond を先に学習し、そのあと連続 trajectory 予測を学習する。
- 重要な観察: **離散 trajectory を最終出力にすると性能は落ちるが、条件として使うと連続出力が一貫して良くなる**。
- 評価は NAVSIM navtest (実データ由来の open-loop 寄りの運転 benchmark)、nuScenes (運転 data set; 開ループの軌道予測)、NeuroNCAP (衝突しやすい危険場面を neural rendering で再現する closed-loop の安全評価)。

## 適用可能性 (P1 / P3)

- **P1**: planner の出力形式を「離散の粗い軌道 → 連続の精密な軌道」の 2 段にする設計は、学習ベース planner にそのまま試せる。NeuroNCAP のように危険場面の closed-loop 評価で効果を確かめている点が、評価重視の P1 と相性が良い。
- **P3**: VLA 型 E2E (end-to-end; 画像から直接運転出力を得る) の出力設計の一例。言語 reasoning と数値 trajectory の橋渡しを何で行うか、という設計上の選択肢が増える。
- 注意: abstract では改善幅の数値が書かれていない。VLA 前提なので、小さな planner にそのまま移せるかは未確認。

## 試すべき実験アイデア

1. 手元の planner に補助 head として「K 個に量子化した粗い action 列」の予測を足し、その出力を連続 head の入力に渡す。最終出力は連続のまま、条件を付けた場合と付けない場合を比べる (最小の実験)。
2. 離散 trajectory を最終出力にした場合と条件にした場合の差を、NAVSIM の sub-score ごとに分解し、どの指標 (衝突・進行・快適性など) に効くかを見る。
3. 公開コードがあるので、NeuroNCAP の危険場面だけで再評価し、衝突率が下がるかを確認する。
