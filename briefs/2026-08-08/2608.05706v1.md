# LAWM-3D: Learning 3D-Aware Latent Actions from Human Videos for Generalizable Robot World Models

**topic:** fm_distill_finetune (P2) ・ **arXiv:** 2608.05706v1 ・ **published:** 2026-08-06 ・ hf_upvotes: 0

## 何を解決する論文か
world model を学習したいが、**行動ラベル付きデータは高価で、プラットフォームごとに行動空間もバラバラ**という問題がある。これに対し **LAM (Latent Action Model; ラベルなし動画から「フレーム間で何が起きたか」を潜在的な行動表現として自己教師あり学習する手法)** が有望視されてきた。本論文はまず「**multi-view 動画を LAM に食わせれば潜在行動は 3D を理解するようになるか?**」を検証し、**答えは No** と示す。原因は (a) 未来フレームの見た目が漏れてショートカット学習になる、(b) カメラ間の見た目差と視点変化が邪魔をする、の2点。LAWM-3D はこの2つを潰す設計を提案する。

## 手法の核心
- **multi-view invariant unified action tokenization:** 視点が変わっても同じ行動が同じ token になるよう、**行動の tokenize(離散/圧縮表現化)を視点不変に統一**する。カメラごとに別々の潜在行動を作らせない。
- **3D foundation model への geometric alignment:** encoder の中間特徴を、**事前学習済み 3D foundation model の特徴に固定(anchor)する制約**を入れる。視点間の幾何対応を「学習で当てさせる」のではなく**外部の基盤モデルから明示的に与える**——ここが P2 的に一番おいしい部分。
- **non-injective RGB-D joint reconstruction:** 再構成目標を **RGB + depth の同時再構成、かつ非単射(non-injective; 出力から入力を一意に復元できない)**に設計。これで **「未来フレームの見た目をそのまま覗いて当てる」ショートカット**を封じ、幾何的に意味のある motion cue に supervision を集中させる。
- **設計の一貫性:** 上記3つは寄せ集めではなく、**「見た目ではなく幾何と運動を潜在行動に載せる」**という単一の動機で結合していると著者は強調。
- **二段パラダイム:** **大規模な人間動画で pretrain → ロボットデータで fine-tuning**。生成品質・物理整合性・汎化のすべてで SOTA。

## 追っているプロジェクトへの適用可能性
- **P2(本命):** 「**ラベルの豊富な他ドメイン(人間動画)で事前学習し、ラベルの乏しい自ドメイン(ロボット)へ適合させる**」という P2 の中核テーマの、今日いちばん綺麗な実例。特に **既存の 3D foundation model を教師/アンカーとして中間特徴に効かせる**のは、フル蒸留よりずっと軽い「部分蒸留」であり、我々の蒸留パイプにそのまま追加できるレバー。
- **P2(negative transfer 対策):** 「multi-view を足しただけでは 3D 理解は出ない」という**明示的な負の結果**が価値。データを増やす前に**何が supervision を汚しているか(ここでは appearance leakage)**を疑え、という指針。
- **P3(直結):** 運転動画は行動ラベル(ステア・アクセル)が付く場合もあるが、**大量の車載/ドラレコ動画は無ラベル**。latent action を挟めば、これらを world model の学習に取り込める。**RGB-D 同時再構成で見た目ショートカットを封じる**発想は、driving world model が「背景の見た目を覚えるだけ」に陥る問題への直接的な処方。
- **P3(XEWorld との対:** 同日の [XEWorld](2608.05799v1.md) が「既存 world model は 2D パターンマッチャに過ぎず、視覚的類似度で汎化が決まる」と診断した問題に対し、LAWM-3D は**「幾何で接地する」という具体的処方**を出している。**診断(XEWorld)と処方(LAWM-3D)をセットで読む**のが今日の最大の収穫。

### 試すべき実験
1. **appearance leakage の存在確認:** 我々の world model / latent action 学習で、**未来フレームを入力から遮断した ablation** を走らせ、性能低下がどれだけ小さいかを測る。低下が小さければ「見た目を覗いていた」証拠で、非単射再構成の導入価値が確定する。
2. **3D foundation model アンカーの追加:** 既存 encoder の中間層に、市販の 3D/depth foundation model 特徴への alignment loss を1本足すだけの最小変更で、**視点変化・カメラ位置変更に対する頑健性**がどれだけ上がるか測る。コストが軽いので最初に試すべき。
3. **RGB-D 同時再構成:** LiDAR/stereo depth を持つ運転データで、RGB 単独再構成 vs RGB-D 同時再構成を比較。**遠方車両・遮蔽復帰時の予測誤差**で差が出るはず。
4. **無ラベル車載動画の取り込み:** latent action で無ラベル運転動画を pretrain に混ぜ、少量の行動ラベル付きデータで fine-tuning。**ラベル量を 1/2, 1/5, 1/10 に落としたときの性能曲線**を引き、latent action pretrain が何倍のラベル削減に相当するかを実測する。
