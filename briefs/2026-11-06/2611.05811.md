# ReTailor: A Residual Feature Tailoring Framework for Real-Time Cross-Sensor Pansharpening Adaptation (2611.05811)

- トピック: fm_distill_finetune / プロジェクト: P2 / スコア 4.0 (対象は remote sensing だが、適合の設計が転用しやすい)
- URL: https://arxiv.org/abs/2611.05811

## 何を解決する論文か

pansharpening (低解像度のマルチスペクトル画像と高解像度のパンクロ画像を融合して高解像度のカラー画像を作る衛星画像処理) の model は、学習した sensor では強いが、**未知の sensor では急に劣化する**。従来の対処は、target sensor の学習 pair を集めて再学習するか、画像 1 枚ごとに network 全体を最適化する (zero-shot 適応) かで、前者は pair とコスト、後者は推論時間が重い。「他機種への適合」を軽く素早く行う問題と読める。

## 手法の核心

- 学習済みの融合 network は凍結し、**軽量な residual Feature Tailor だけ**を self-supervised (正解ラベル無し) かつ physics-aware な制約 (sensor の物理特性と整合する制約) で素早く最適化して、sensor 間のずれを補正する。
- content-aware patch selection: 画像全体でなく情報量の多い少数の patch だけで最適化し、品質と効率を両立する。
- rolling residual bootstrap: 画像の流れ (stream) の中で、直前までに得た sensor 固有の知識を次の画像に引き継ぐ。
- LoRA との比較で優位性を示し、同じ原理を super-resolution pansharpening と image segmentation にも適用して改善。code 公開予定。

## 適用可能性 (P2)

- 「基盤 model は凍結し、機種差だけを小さな residual で補正する」構造は、カメラ・センサが変わったときの perception 側の適合に近い。target 側のラベル無しで回せる点が使える。
- 少数 patch の選択で最適化コストを抑える発想は、車載・Thor 上でのオンライン適合の計算予算にも合う。
- 注意: 数値の改善幅は abstract に無い。物理制約は pansharpening 固有で、汎用の画像 model では別の自己教師 loss が要る。

## 試すべき実験アイデア

1. 手元の perception model を凍結し、特徴の後段に小さな residual 層を挿して、カメラ違いの少量 unlabeled データで自己教師 loss だけで最適化する。LoRA との比較を同じ最適化 budget で行う。
2. 最適化に使う画像の部分 (patch) を、ランダムと「予測の不確実性が大きい領域」で選び分け、適合後の精度を見る。
3. 画像を順に流すとき、前の画像の residual を初期値に引き継ぐ (rolling) と、毎回リセットする場合で収束速度を比べる。
