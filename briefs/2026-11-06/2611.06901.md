# Motion-guided Contrastive Regularization For Latent World Models (2611.06901)

- トピック: next_arch / プロジェクト: P3 / スコア 4.5
- URL: https://arxiv.org/abs/2611.06901

## 何を解決する論文か

JEPA (Joint-Embedding Predictive Architecture; 観測を再構成せず、latent 空間で次の状態を予測する world model の型) 系の world model は、action で条件づけた latent dynamics を学ぶ。分布の正則化だけでは、**control に必要な情報が表現に残る保証がない**。論文は static collapse という失敗を特定する。encoder が episode ごとに違う静的な内容 (背景など) を保存し、操作に関係する状態の変化を抑えてしまう。静的内容は時間的に予測しやすく episode 間で多様なので、正則化があっても残る。

## 手法の核心

- OGBench-Cube (cube 操作の benchmark) で背景をランダム化すると、タスクは同じなのに planning 性能が大きく落ちることを統制実験で示す。
- motion-guided contrastive regularization: 予測した latent の遷移を、同じ episode 内の候補観測への遷移と比べる。背景の identity では action の結果を区別できなくなる。
- optical flow (画像間の画素の動き) の類似度を soft contrastive target (似た動きに似た教師を与える) として使う。
- latent prediction と SIGReg (latent 分布を等方 Gaussian に近づける正則化) と併用する。
- 結果: LeWorldModel (LeWM) から planning 成功率が OGBench-Cube の背景ランダム化で 52% → 78%、LIBERO-Object で 14% → 54%。他の 4 つの視覚制御 benchmark では同程度を維持。

## 適用可能性 (P3)

- 運転では背景 (建物、天候、道路の見た目) が場所ごとに多様で、動くものは少ない。**static collapse は運転の world model で起きやすい構造**であり、表現の診断に使える。
- optical flow は動画から自動で得られるので、行動注釈が無い運転ログにも適用しやすい。
- 注意: 評価は小規模な制御 benchmark で、運転規模・多視点・自車運動のある設定は未確認。自車が動くと optical flow が背景も動かし、前提が崩れる。

## 試すべき実験アイデア

1. 手元の latent world model で、同じ動作の背景だけを入れ替えた対 (augmentation) を作り、latent の距離が背景で決まっていないかを測る (static collapse の診断)。
2. 自車運動を補正した optical flow (ego-motion を除いた残差の flow) を contrastive の target にした場合の効果を、小さなデータで確かめる。
3. LeWM の公開 code が使えるなら、LIBERO-Object の 14% → 54% を再現し、規模を落とした運転ログ (単眼カメラの短い clip) へ拡張する。
