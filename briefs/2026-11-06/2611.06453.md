# Beyond Infraction Scores: Failure-Boundary Profiles for Closed-Loop Evaluation of Driving and Robot Navigation Agents (2611.06453)

- トピック: fm_distill_finetune に分類 → planner_ai として採用 / プロジェクト: P1 / スコア 5.0
- URL: https://arxiv.org/abs/2611.06453

## 何を解決する論文か

CARLA (オープンソースの運転シミュレータ) の closed-loop (出した行動が次の入力に返る閉ループ) benchmark は、route completion (経路をどれだけ進めたか) に infraction penalty (違反による減点) を掛けた driving score で agent を順位づける。この score では、障害物の前で止まる agent と、障害物に接触しながら押し通る agent を区別できない。論文は **「進むべき場面で進めたか」「止まるべき場面で止まれたか」を測る評価** を提案する。

## 手法の核心

- failure-boundary profile: 1 つの scenario family で 1 つの測定可能な因子だけを動かす (例: 駐車車両 2 台で塞がれた通路の幅、対向車との time gap)。各 variant は測定により「通れる (proceed)」か「止まるべき (stop)」に certify (正解ラベルを付与) される。
- agent ごとに 2 本の曲線を推定する。commitment (通過を試みる確率) と competence (接触なく通れる確率)。それぞれが 0.5 を横切る位置を境界として求め、simulator の run-to-run のばらつきを入れた区間推定を付ける。
- 要約指標 decision accuracy: 通れる variant でのきれいな通過と、塞がれた variant での停止に点を与える。
- 結果: 7 つの driving agent を CARLA の 7 family で評価。rule-based expert の decision accuracy は 0.74、学習 agent で最高の TFv6 は 0.60。driving score が近い agent でも失敗の仕方が違う。塞がれた通路で止まる agent でも、対向車の gap を待つことはほとんどしない。
- 同じ方法を変更せずに Isaac Sim の warehouse robot に適用し、fine-tuning した 2 版は「より多くの gap をきれいに通るが、まったく止まらなくなった」ことを検出。

## 適用可能性 (P1)

- P1 の評価指標そのものに直結する。**driving score が同じでも「押し通る」型と「止まる」型が混ざる**ことを示す例で、planner の改良が closed-loop score を上げても、止まる能力を失っていないかを別軸で見る根拠になる。
- 末尾の fine-tuning 版が「止まらなくなった」結果は P2 (適合) の副作用検知にも使える。
- 注意: 7 family は CARLA の合成シナリオで、実走行ログ (NAVSIM 等) への持ち込み方は abstract に無い。certify に使う測定の詳細も未確認。

## 試すべき実験アイデア

1. 手元の planner を、通路幅と対向車 gap の 2 family だけ再現して commitment / competence の曲線を描く。driving score が同じ 2 つの checkpoint で曲線が分かれるかを見る。
2. 既存の評価ログから「接触ありで完走」したエピソードを抽出し、塞がれた条件がどれだけ混ざっているかを数える (新規実装なしでできる確認)。
3. fine-tuning 前後の planner で decision accuracy を比べ、「停止能力の退化」が出るか確認する。
