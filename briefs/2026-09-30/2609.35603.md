# Control-Geometry Straightening for Sampling-Based Latent Planning

- arXiv: `2609.35603` / https://arxiv.org/abs/2609.35603
- 配属: next_arch (P3)
- スコア: **P3 4.0** (P1 3.0) ・ hf_upvotes 0

## 何を解決する論文か

JEPA (Joint-Embedding Predictive Architecture; 画素を復元せず、潜在表現の空間で次の状態を予測する自己教師あり学習の枠組み) で学んだ latent world model (観測を圧縮した潜在空間の中で、行動に応じた次状態を予測するモデル) を使って planning するとき、遷移の予測が正確でも、planning の目的関数が最適化しにくい形をしていることがある。この論文は、**行動の空間での幾何 (行動どうしの向きの関係) と、潜在空間での状態の変化の幾何を揃える補助 loss を 1 つ足すだけ**で、少ないサンプル数でも良い行動列を見つけやすくなることを示した。

## 手法の核心

- **CGS (Control-Geometry Straightening) loss:** 行動のペア間の cosine 類似度と、それぞれの行動で起きた潜在状態の変化 (latent difference) のペア間の cosine 類似度を一致させる。必要なのは (画像, 行動, 次の画像) という局所遷移だけ。
- **直感:** 「似た向きの行動は、潜在空間でも似た向きに状態を動かす」ように表現を整える。そうすると planning の目的関数 (目標の潜在状態までの距離) が行動に対して素直な形になり、ランダムサンプリング型の planner が少ない候補で当たりを引ける。
- **理論:** 線形ダイナミクスの下で、temporal straightening (潜在軌跡を直線に近づける既存の正則化) と、planning horizon 全体での終端コストの曲率の均一化につながることを示す。MPPI (Model Predictive Path Integral; 行動列をランダムにたくさん試して、良かったものほど重く平均する planner) には有限予算での保証、CEM (Cross-Entropy Method; 良かった上位の行動列に分布を寄せていく planner) には局所収束、勾配降下には収束の上界を与える。
- **結果:** 4 つの制御環境で、1 更新あたり 128 候補のサンプリング planner のとき、LeWM (LeWorldModel) より成功率 +20 pt、その temporal straightening 版より +12.6 pt。end-to-end に学んだ表現にも、事前学習済みの表現 (DINO-WM 型) にも適用できる。

## P3 への適用可能性

- **world model の評価軸を 1 つ増やす:** 「予測が正確か」とは別に「その潜在空間で planning しやすいか」を測るべき、という主張。P3 で world model を作るとき、予測誤差だけで checkpoint を選ぶと planning に向かない表現を選ぶ可能性がある。
- **追加コストが小さい:** 既存の world model の学習に loss を 1 項足すだけで、構造の変更は要らない。事前学習済み encoder の上でも使える。
- 08-28 に繰り越した RDR (`2608.25017`; latent world model の学習と評価のずれを loss 1 項で閉じる) と同じ系統の「loss 1 項で planning 側の性質を直す」論文で、並べて読むと比較対象になる。

## P1 への波及

- 運転の planner の多くは MPPI や CEM 型のサンプリングを使う。サンプル数を減らしても成功率が落ちないなら、車載の計算予算に直結する。ただしこの論文の環境は小さな制御タスクで、運転規模での効果は未知。

## 試すべき実験アイデア

1. **(半日・2D toy) 最小再現:** 2D の点質量 (位置と速度、行動は加速度) の環境で、画像 (または状態) → 潜在の encoder と、潜在の遷移モデルを学ぶ。CGS loss あり/なしで 2 つ学習し、MPPI の候補数を 16/32/64/128 と振って到達成功率を比べる。**W39 で決めた「2D toy の初 commit」の候補として、loss 1 項・環境 1 つで完結する。**
2. **(同じ toy) 行動と潜在変化の cosine 類似度の散布図:** 学習後に、行動ペアの cosine と潜在変化ペアの cosine を散布図にする。CGS なしでどれだけ崩れているかが目で見える (実験 1 の結果の説明図になる)。
3. **(P3 の本番前) checkpoint 選択基準の比較:** 予測誤差最小の checkpoint と、少候補 MPPI の成功率最大の checkpoint が一致するかを見る。一致しなければ、評価に planning 指標を足す根拠になる。
