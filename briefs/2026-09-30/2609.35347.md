# Beyond Teacher Assignment: Domain-Normalized Multi-Teacher On-Policy Distillation

- arXiv: `2609.35347` / https://arxiv.org/abs/2609.35347
- 配属: **sns_wildcard 枠 (探索枠 1/1)**。中身は P2 そのものだが fm_distill の keyword に 1 語も当たらず wildcard 経路で届いた (`distillation` 単独は keyword に無い)。**真に分野外の wildcard は YuE2 (音楽生成) だけで、そちらより学びの価値が高いと判断して枠を使った** (判断の分岐点は rejected.md に記載)
- スコア: **P2 4.5** ・ hf_upvotes 138

## 何を解決する論文か

RL で 1 つの言語モデルから数学・コード・指示追従などの専門家 (specialist) を複数作れるが、使う側は全部できる 1 つのモデルが欲しい。MOPD (Multi-teacher On-Policy Distillation; student が答え、その問題の分野の specialist が token ごとに指導する蒸留) は「誰が教えるか」は決めるが、「その指導が student をどれだけ強く動かすか」は決めていない。この論文は、MOPD の student が最良の単一 specialist から学んだ student にすら勝てないことを示し、原因を**分野ごとの指導信号の大きさの不均衡**と特定して、それを正規化するだけの DN-MOPD で解消した。

## 手法の核心

- **観察:** Qwen3.5 の 3 サイズで、MOPD の student は数学 specialist の利得をほとんど受け取れない。指示追従の teacher の信号は数学の teacher の信号より**数倍ばらつきが大きく** (spread が大きい)、共有 student の更新を支配している。
- **DN-MOPD:** 分野ごとのルーティング (どの specialist が教えるか) はそのまま。各分野の指導信号を、**実測したばらつきで割って**スケールを揃える。
- **結果:** 6 つの公開ベンチマークの平均で、3 サイズすべて・3 seed・2 つの回答長上限で MOPD を上回り、失った数学の利得の大部分を取り戻す。
- **統制実験が効いている:** 分野の重みを固定値にした対照で、利得は主に「数学を上げる」ではなく**「指示追従を下げる」**ことから来ると分かった。さらに、DN-MOPD が測った値に近い固定重みでもほぼ同じ性能 → **本質は正規化の仕組みではなく「分野間の信号の大きさを揃えること」**。

## P2 への適用可能性

- **「他機種・他ドメインへの適合」を 1 つのモデルに統合する場面に直結する。**機種 A 向け・機種 B 向けに別々に適合させたモデル (または分野別の teacher) を 1 つの student にまとめるとき、各 teacher の loss/勾配の大きさが揃っていないと、ばらつきの大きい 1 分野が学習を独占する。
- **実務で最初にやるべき診断が明確:** 蒸留を回す前に、分野 (機種・ドメイン) ごとに蒸留 loss の token 単位 (画像なら画素・特徴単位) の分散を測る。桁が違えばこの論文の状況にある。
- **固定重みでほぼ同等という結果は実務には朗報。**動的な正規化を実装しなくても、事前に 1 回ばらつきを測って固定重みを決めれば足りる可能性が高い。
- 同日の `2609.35259` (KL の向きと学習率が支配的) と併せると、蒸留 recipe で振るべき変数は「KL の向き・学習率・分野間の信号スケール」の 3 つで、rollout の取り方はその後、という優先順位になる。

## P3 への波及

- VLA の多タスク学習 (把持・移動・言語応答など) でも、タスクごとの loss スケールがずれていれば同じ独占が起きる。多タスクの VLA で「特定タスクだけ伸びない」ときの最初の確認項目になる。

## 試すべき実験アイデア

1. **(半日) 分野別の信号分散を測るだけ:** 既存の蒸留 (または多タスク fine-tuning) で、1 バッチごとに分野別の loss と勾配ノルムを記録し、分野ごとの分散を並べる。まず不均衡が存在するかだけ確かめる。コードは logging 数行。
2. **(1 日) 2 teacher の toy:** 2 つの教師 (例: 2D 平面の異なる領域に特化した回帰器) から 1 つの student へ蒸留し、片方の teacher の出力を 5 倍スケールにした条件で student の各領域の誤差を比べる。分散で正規化すると回復するかを見る。
3. **(本番) 固定重みの事前推定:** 本番の多ドメイン蒸留の最初の 1% の step で分野別の分散を測り、その逆数を固定重みとして残りを回す。動的正規化との差を 1 回だけ確認する。
