# WorldPlay2: Extending Real-Time Interactive World Models in Control and Horizon

- arXiv: `2609.35560` / https://arxiv.org/abs/2609.35560
- 配属: next_arch (P3)
- スコア: **P3 4.0** (P2 3.0) ・ hf_upvotes 23 (next_arch の同点 4.0 は CGS と本論文のみ。FlexiWorld / CATok / OPIS は 3.5)

## 何を解決する論文か

interactive world model (ユーザーやエージェントの操作に応じて、次の映像をリアルタイムに生成し続けるモデル) には、多様な操作への即応と、長時間にわたる一貫性の両立が求められる。しかし、種類の違う操作をまとめて扱うのは難しく、長い履歴を全部入れると文脈が爆発し、高速化のための蒸留は不安定になる。WorldPlay2 は、操作の入力方法・履歴の圧縮・蒸留の安定化の 3 つを同時に設計し直して、この両立を狙った。

## 手法の核心

- **factorized hybrid control interface:** フレーム単位の行動入力 (移動・視点操作など) と、構造化された意味的な操作 (シーンの見た目・キャラクターの同一性・動的なイベント) を分けて入れる。操作の種類ごとに経路を分けることで、それぞれの制御を学びやすくする。
- **圧縮メモリの共有:** 過去の文脈を少数の memory token に圧縮し、それを **autoregressive (1 フレームずつ順に生成する) student** と **bidirectional (前後を同時に見て生成する高品質な) teacher** の両方で共有する。これにより、長い rollout 全体を一度に処理せず、区切り (clip) ごとにメモリを条件にした score evaluation (teacher が student の出力の良し悪しを評価する蒸留の信号) ができ、蒸留の計算量が大きく下がる。
- **Stable Forcing:** student を少数ステップ生成の戦略で初期化し、rollout 全体を再生 (full-rollout replay) して学習することで、長時間生成での品質劣化 (誤差の蓄積) を抑える。
- abstract には具体的な数値が無く、「既存手法を上回る」とだけある。**性能の大きさは原論文で確認が必要。**

## P3 への適用可能性

- **運転の world model (カメラ映像を行動条件付きで先読みするモデル) の設計にそのまま対応する:** 「自車の操作 (フレーム単位)」と「シーンの条件 (天候・他車の挙動などの意味的な条件)」を別経路で入れる、という分け方は、運転 simulator としての world model の入力設計の参考になる。
- **長時間 rollout の誤差蓄積は closed-loop 評価用の world model で最大の問題**で、メモリ圧縮 + full-rollout replay はその対策の 1 つの型。
- 09-29 の FuseReg (凍結 encoder のどの層を latent に使うか) と合わせ、world model の「何を覚えておくか・何を latent にするか」の設計選択肢が揃ってきた。

## P2 への波及

- **双方向 teacher → 逐次 student の蒸留で、teacher と student が同じ圧縮メモリを共有する**、という設計は、系列モデルの蒸留一般に使える。teacher と student の入力文脈を揃えることで、蒸留信号が文脈の違いで汚れない。

## 試すべき実験アイデア

1. **(半日・2D toy) 長時間 rollout の誤差蓄積を測る:** 2D の点質量の遷移モデルで、(a) 1 step 先予測だけで学習、(b) 自分の予測を入力に戻して長い rollout 全体で学習 (full-rollout replay 相当)、の 2 つを作り、50 step 先までの位置誤差を horizon ごとに描く。誤差曲線の立ち上がり方が変わるかを見る。
2. **(1 日) 履歴の圧縮の効き目:** 同じ toy で、過去 k フレームをそのまま入れる版と、k フレームを小さなベクトル 1 本に圧縮して入れる版を比べる。k を増やしたときの計算量と精度の関係を 1 枚の図にする。
3. **(原論文を読むときの確認項目)** 定量結果の大きさ、特に「Stable Forcing なし」の ablation で長時間品質がどれだけ落ちるか。これが小さければ、1 の実験の優先度は下がる。
