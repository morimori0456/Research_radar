# Teacher-Student Gaps Are Not Enough: Outcome-Guided On-Policy Distillation for Multi-Turn Autonomous Agents

- arXiv: `2609.35319` / https://arxiv.org/abs/2609.35319
- 配属: fm_distill_finetune (P2)
- スコア: **P2 4.0** (同点 4.0 が 3 本: 本論文 / R²-OPD `2609.35517` / UNI2-h 蒸留 `2609.35203`。hf は全て 0。複数ターンで環境とやり取りする設定が運転の closed-loop に最も近いので本論文を採った) ・ hf_upvotes 0

## 何を解決する論文か

on-policy distillation (OPD; student が自分で生成した行動列に対して、teacher がステップごとに「自分ならこうする」という密な信号を与える蒸留) を、複数ターンで環境とやり取りする agent に使うとき、これまでは「teacher と student の出力分布の差が大きいステップほど直すべき」と扱われてきた。この論文は、差が大きくても結果に無害なステップと、差が小さくても結果を決定づけるステップがあることを実測し、**teacher の指導が最終的なタスク成功に効いたかどうか**で監督の重みを付け直す OG-OPD を提案した。

## 手法の核心

- **supervision-benefit mismatch (監督の量と利益のずれ) の指摘:** 分布の差は「今のターン」の違いしか見ていない。一方、teacher の指導が役に立つかは、**その後 student 自身が環境の中でどう続けるか**で決まる。student が teacher と違う行動を選んでも成功することはあるし、teacher が好む行動が「student には続きをこなせない状態」に導くこともある。
- **OG-OPD:** 各ターンで、student の元の続きと、teacher の指導を入れた場合の続き (paired student continuations) を実際に走らせ、最終タスクの成否を比べる。その差で teacher の監督の重みを較正する。
- **trajectory-relative weighting:** 重みは軌跡内での相対値として付けるので、軌跡全体の難易度の違いに引きずられない。
- 監督を強めるのは **student の元の軌跡の上**で、「teacher に従うと student が最後まで成功できる」ターンだけ。
- 結果: ALFWorld / ScienceWorld / WebShop (いずれも言語で行動する agent の環境) で vanilla OPD より成功率 +3.6〜17.7 pt、最強 baseline より最大 +7.0 pt。

## P2 への適用可能性

- **「どこに監督を当てるか」が支配変数、という P2 の読み (R2) の新しい実例。**DART-SD (09-01; 復帰ステップにだけ loss を当てる) と同じ方向で、今回は「当てる場所を結果で決める」。同日の R²-OPD (`2609.35517`) も、数学推論で「結果と一致する修正に重みを寄せる」同型の提案で、**独立な 2 グループが同じ週に同じ結論**を出している。
- ただし同日の `2609.35259` は「on-policy かどうかより KL の向きと学習率が効く」と示しており、OG-OPD の利得が KL の向きを揃えた比較かは確認が要る。
- **運転の蒸留への移し方:** 大きな運転 policy (teacher) から小さな policy (student) へ蒸留するとき、全時刻に均等に模倣 loss を掛けるのではなく、「teacher の行動に切り替えると closed-loop で最後まで走り切れる時刻」だけ重みを上げる。closed-loop simulator があれば paired continuation は計算できる。

## P1 への波及

- 「teacher (expert) との差が大きい時刻 ≠ 結果に効く時刻」は、**planner の評価で open-loop の誤差 (人間軌跡との距離) と closed-loop の成績がずれる**理由の言い換えになっている。P1 の評価で「open-loop 誤差が大きいが closed-loop では無害な場面」を数えると、同じずれが出るはず。

## 試すべき実験アイデア

1. **(半日・2D toy) 差の大きさと結果への影響の相関を測る:** 2D の到達タスクで teacher policy と弱い student policy を用意し、student の軌跡の各時刻で (a) teacher との行動差、(b) その時刻だけ teacher の行動に差し替えて最後まで走らせたときの成功率の変化、を記録する。(a) と (b) の相関が弱ければ、本論文の主張が toy でも再現する。
2. **(1 日) 重み付け蒸留:** 上の (b) を重みにして模倣 loss を掛けた student と、均等重みの student を比べる。
3. **(P1 評価) open-loop 誤差と closed-loop 結果の散布図:** 既存の評価ログで、場面ごとに open-loop の誤差と closed-loop の失敗有無を並べる。これは 1 の実験の「運転版」で、学習なしで今ある記録からできる。
