# Right On Q (OnQ): Recovering Reasoning under Quantization via Self-Generated Trajectories (2610.29378)

- トピック: fm_distill_finetune (P2) / スコア 4.5
- URL: https://arxiv.org/abs/2610.29378

## 何を解決する論文か

QAT (Quantization-Aware Training; 低 bit 化した model を、量子化の誤差込みで再学習して性能を戻す) で LLM を 2〜3 bit にすると、長い reasoning で崩れ、元の model なら収まる token 数の中で終われなくなる。既存の recipe は、量子化した student を、元の full-precision model (teacher) が出した固定の応答の上で教える。この論文は、ずれの原因を 2 つ特定し、on-policy distillation と新しい KL の重み付けで回復させる。

## 手法の核心

- 原因 1: **固定応答での教師あり**だと、学習時の prefix (それまでの生成文) と student が実際に生成する prefix がずれ、応答が長いほど開く (exposure bias と同型)。
- 原因 2: student 自身の prefix 上では、ある token 候補は確率を低く、別の候補は高く出しすぎる。この不一致は entropy の高い (次の token が割れている) 位置で多い。
- **on-policy distillation**: block 単位の calibration (量子化の初期調整) から始め、student 自身に応答を生成させ、その prefix 上で teacher が各 token の分布を教える。
- **candidate-wise Dynamic KL**: forward KL (teacher の高確率候補を student が取りこぼすと罰する; 過小予測の修正) と reverse KL (student が teacher の低確率候補に確率を置くと罰する; 過大予測の修正) を、候補ごとの teacher/student 確率比で重み付けして混ぜる。
- 結果: Qwen3 1.7B/4B/8B の 2/3 bit で 9 benchmark 平均が最良。2 bit では全サイズ・全 benchmark で全 baseline を上回り、8B は最強 baseline より平均 +10.26。応答が短くなり、打ち切りと繰り返しも減る。

## P2 への適用可能性

- 量子化は model compression の一形態で、「teacher = 元の model、student = 圧縮版」の蒸留として読める。Dynamic KL は量子化に限らず、通常の蒸留の loss として差し替えられる (候補ごとに forward/reverse の重みを変えるだけ)。
- 10-22 の OPTD (2610.28048; on-policy distillation に層間の動きを足す) と同じく、on-policy distillation を基盤に「何を合わせるか」を変える系統。並べると、OPD の改善が loss 側 (OnQ) と表現側 (OPTD) に分かれている。
- capacity gap (teacher と student の能力差が大きいと蒸留が効きにくい問題) への対策として、2 bit という極端な gap で効いている点が評価できる。

## 試すべき実験アイデア

1. 手元の蒸留 run で、student の生成上で teacher/student の確率比を token 候補ごとに集計し、過小予測と過大予測がどちらが多いか、entropy の高い位置に偏るかを測る (OnQ の診断の再現。学習不要)。
2. 既存の KD loss (forward KL) を Dynamic KL に差し替え、同じ step 数で比較する。分類や軌道予測の model なら「候補」= クラスや離散化した軌道 mode として同じ重み付けができる。
3. 量子化を伴う onboard 配備 (INT4 等) を予定している model で、固定データでの QAT と on-policy な QAT を比べ、長い出力 (長い軌道や長い reasoning) ほど差が開くかを確かめる。
