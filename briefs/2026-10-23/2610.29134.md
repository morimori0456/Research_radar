# NormTune: Norm-Guided Parameter-Efficient Fine-Tuning for Reasoning-Intensive Tasks (2610.29134)

- トピック: fm_distill_finetune (P2) / スコア 4.0 (arXiv RSS から回収・candidates.json には無い)
- URL: https://arxiv.org/abs/2610.29134

## 何を解決する論文か

PEFT (Parameter-Efficient Fine-Tuning; 重みの一部や小さな追加 module だけを学習する適合法) は full fine-tuning より安いが、reasoning が重い task では大きく負ける。この論文は、その差の原因を「PEFT の重み更新の norm (大きさ) が full fine-tuning よりずっと小さい = 更新が足りない層がある」(norm-related under-adaptation) と特定し、更新が足りない層を自動で強める方法を提案する。

## 手法の核心

- 観察: PEFT で学習した重みの更新量 (ΔW の norm) は full fine-tuning より明確に小さく、それが reasoning task での性能差と結びつく、という 3 つの観察を示す。
- **NormTune**: 学習中に層ごとの weight-update norm を見て、更新が小さすぎる層を適応的に強める。LoRA (Low-Rank Adaptation; 重み更新を 2 つの細い行列の積で表す PEFT) に限らず、Bone や MoRA (他の PEFT 方式) にも後付けできる。
- 結果: S1K-1.1 (少数の高品質 reasoning データ) で学習し、rank-8 の LoRA / Bone / MoRA に足すと、AIME 2024・MATH 500・GPQA・AIME 2025 の平均がそれぞれ +24.24 / +11.33 / +16.21 % 上がる。
- rank-256 に足すと full fine-tuning (S1) と同等か上回る (+2.17 / +0.93 / +3.00 %)。

## P2 への適用可能性

- 「他機種・他ドメインへの適合」を LoRA で回すときに、少データ (S1K は約 1000 例) で full fine-tuning との差を詰める手段として直接当てはまる。追加データも追加 module も要らず、学習中の重み付けを変えるだけ。
- 診断が安い: 手元の LoRA run と full fine-tuning run の層ごとの更新 norm を比べるだけで、under-adaptation が起きているかが分かる。
- 対象は LLM の reasoning task。視覚や運転の model で同じ現象 (特定の層で LoRA の更新が足りない) が起きるかは未確認。

## 試すべき実験アイデア

1. 既存の LoRA 適合 run と、同じデータでの full fine-tuning (またはその短い run) の層ごとの ΔW の norm を並べ、比が小さい層がどこか (浅い層か深い層か、attention か MLP か) を可視化する。
2. 少データの別ドメイン適合 (例: 他機種のセンサ構成への適合) で、rank-8 LoRA ± NormTune を比べ、full fine-tuning との差がどれだけ縮むかを測る。
3. rank を上げる (8 → 64 → 256) のと NormTune を足すのとで、同じ性能に届くまでの学習パラメータ数を比べる。どちらが安く gap を詰めるかが実務の判断材料になる。

## 注意

abstract のみに基づく。「強める」の具体的な方法 (学習率のスケーリングか、更新の再スケールか) と、汎用性能 (元の task) の劣化は未確認。
