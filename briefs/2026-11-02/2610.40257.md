# Learned Terminal Costs for Short-Horizon MPC of Autonomous Trucks (2610.40257)

- トピック: planner_ai (P1) / スコア 3.5 / 10-31 の次点を繰り越し
- URL: https://arxiv.org/abs/2610.40257
- 著者: Hooman Hamze, Benjamin Houshmand, Deepthi Pathare, Erik Börve

## 何を解決する論文か

大型トラックの高速道路走行では、質量が大きく、周囲の車の協力が要る場面が多いので、安全制約を守りながら先まで見て判断する必要がある。MPC (Model Predictive Control; 短い先の未来の軌道を最適化して、最初の 1 手だけ実行し、毎ステップ解き直す制御) は制約を守れるが、計算できる短い horizon (先読みの長さ) では、その先の良し悪しを知らない。RL (Reinforcement Learning; 試行から方策を学ぶ学習) は長期の振る舞いを学べるが、制約を保証せず、衝突の罰則が疎だと保守的になりすぎる。この論文は両者を組む。

## 手法の核心

- finite-horizon の MPC を dynamic programming (状態空間を離散化し、後ろから最適値を埋めていく解き方) で解く。
- horizon の終端に付ける **terminal cost** (終端状態の良し悪しの見積もり。horizon より先の cost の代理) を、事前に学習した RL model から取る。
- 周囲の車が反応する simulation で、次の 4 つを比べる: terminal cost をゼロにした MPC、base policy を rollout して terminal cost を見積もる方式、RL 単独、提案の hybrid。
- 報告: hybrid は衝突ゼロで、比べた構成の中で cost が最小。

## 適用可能性 (P1: Planner AI + 評価)

- planner の実装として、「制約を守る部分は MPC に残し、先の見積もりだけを学習に任せる」分担は、既存の最適化ベース planner に後から足しやすい。学習側の失敗が制約違反に直接つながらない。
- 評価の面では、比較構成の切り方 (terminal cost ゼロ、base policy rollout、RL 単独、hybrid) が、planner の部品の効果を分離する手本になる。
- 注意点: 評価は simulation のみで、数値は abstract に無い。対象はトラックの高速道路で、都市の相互作用には未検証。反応する周囲の車の model が評価結果を左右するので、その model の作りに注意して読む。

## 試すべき実験アイデア

1. 手元の MPC 型 planner の horizon を 3 通りに短くし、terminal cost をゼロにした場合と、学習した value を使った場合で、衝突率と cost がどう変わるかを測る。horizon が短いほど差が開くなら、計算量の節約として使える。
2. RL の value の誤差を意図的に増やし (noise を足す)、hybrid が制約を守り続けるかを測る。terminal cost が外れても安全が保たれることが、この方式の売りになる。
3. 周囲の車が反応しない設定と、反応する設定で差が出るかを見る。評価の closed-loop 化が結論に与える影響の確認になる。
