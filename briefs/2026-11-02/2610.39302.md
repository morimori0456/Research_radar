# Proving and Improving the Platonic Representation Hypothesis with JEPAs (2610.39302)

- トピック: sns_wildcard (探索枠、関連は P3 の world model と P2 の表現転用) / スコア 3.5 / hf_upvotes 62
- URL: https://arxiv.org/abs/2610.39302
- 著者: Randall Balestriero, Yann LeCun

## 何を解決する論文か

PRH (Platonic Representation Hypothesis; 別々の modality で学習した model も、scale が大きくなると同じ世界の表現に収束するという仮説) は、証明が無いので「いつ成り立つか」「どう作ればよいか」の指針を与えなかった。この論文は PRH を定理にし、JEPA (Joint-Embedding Predictive Architecture; 同じ場面の 2 つの view の一方から他方の embedding を予測する自己教師あり学習。画素や token の再構成はしない) で学習した encoder は、positive pair が「同じ場面の 2 つの観測」(good views) なら、modality が違っても回転 1 つの違いを除いて同じ表現になる、と主張する。

## 手法の核心

- **Platonic Representation Theorem**: JEPA を複数の modality で別々に学習したとき、positive pair が good views で、それ以外の misalignment に上限があれば、表現は 1 つの回転を除いて一致する。
- next-token prediction (次の token を当てる学習) は、1 つの文書の別の部分を positive pair にする JEPA と見なせる。同じ場面の観測ではない (bad views) ので、vision との alignment は scale を上げて初めて現れる、と説明する。
- 145k 件の caption から 9.4 億枚の web 画像の text まで検証し、alignment の scaling law (規模と alignment の関係式) が未見の run を seed のばらつき内で予測すると報告する。
- 同じ corpus で同じ alignment に届くのに、good views は next-token prediction の 42 分の 1 の sample で足りる。109M parameter の text JEPA が、72B までの language model や CLIP の text encoder より、DINOv2 と CLIP の image encoder によく揃う。
- 回転 1 つで別々に学習した encoder を image captioner にできる (COCO で CIDEr .838)。ペアを使わない benchmark でも、text JEPA が 8B までの language model の zero-shot を上回る (ImageNet-100 の top-5 で 64% 対 56%)。

## 適用可能性

- **P3 (world model / 表現学習)**: 「どの 2 つの観測を positive pair にするか」が表現の質を決める、という主張は、運転の世界表現にそのまま問いとして使える。同じ時刻の複数 camera、camera と LiDAR は good views の候補で、過去と未来のフレームは良い pair か怪しい pair かを実測で分けられる。
- **P2 (基盤モデルの転用)**: 別々に学習した encoder が回転 1 つで揃うなら、encoder 間の接続 (adapter の学習量) を極小にできる可能性がある。他機種・他 modality への適合を、回転 1 つの推定として試せる。
- 注意点: 定理の前提は good views と有界な misalignment で、実データで成り立つ程度は検証の範囲に依存する。検証は画像と text が中心で、運転の multi-sensor では未確認。hf_upvotes (62) は話題性であり、主張の強さの証拠ではない。

## 試すべき実験アイデア

1. 手元の別々に学習した 2 つの encoder (例: 2 つの camera の encoder、または camera と LiDAR) に、同じ場面の同期データを通し、直交 Procrustes (2 つの点群を回転だけで最もよく重ねる手法) で回転を推定する。残差が小さいかを、alignment の指標 (例: 近傍の一致率) で測る。
2. 同じ encoder 構造で positive pair の取り方 (同時刻の別 camera か、同じ camera の連続フレームか) だけを変え、同じ量の sample で alignment がどれだけ違うかを測る。42 倍という差が運転のデータでも出るかの目安になる。
3. 2 を world model の latent に使い、下流の予測精度と alignment の相関を見る。相関が無ければ、運転では alignment の指標が実用にならないと分かる。
