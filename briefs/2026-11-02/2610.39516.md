# Robust LiDAR Sensor-to-Sensor Domain Generalization via Accumulated-Point Scene Completion (2610.39516)

- トピック: fm_distill_finetune (P2、他機種適合の面) / スコア 3.5 / 10-31 の次点を繰り越し
- URL: https://arxiv.org/abs/2610.39516
- 著者: Christoph B Rist, Larissa T Triess, Markus Enzweiler, Dariu M Gavrila

## 何を解決する論文か

LiDAR の点群は sensor ごとにサンプリングのパターンが違うので、ある dataset で学習した semantic segmentation (点ごとにクラスを付ける課題) の model は、別の sensor で性能が落ちる。target 側のデータもラベルも使えない状況で、未知の sensor に効く model を作る **domain generalization** (学習時に見ていない domain で動くようにする学習) の論文である。

## 手法の核心

- source-only (target のデータを一切使わない) の学習で、segmentation に **occupancy prediction** (空間のどこに物があるかを当てる課題) の補助 loss を足す。
- source domain の複数の scan を重ねて「簡単な world model」を作り、その occupancy を supervision (教師) にする。単一 scan の segmentation だけの学習を置き換える。
- **入力は変えない**。学習時も推論時も同じ 1 frame の LiDAR を入れ、enrich するのは教師の側だけ。
- 推論時の overhead は無い。補助 head を外せば segmentation だけ、残せば scene completion (欠けた場面の補完) が付いてくる。
- 結果: 「certain setups」で未知の domain の性能が上がり、source domain の性能は保つ。「教師の与え方が汎化を大きく左右する」ことが主な知見。

## 適用可能性 (P2: 基盤モデルの他機種・他ドメイン適合)

- 他機種適合の recipe として、**target を見ずに、教師を豊かにするだけ**で効くなら、sensor の仕様が変わるたびに fine-tuning する運用を減らせる。推論 cost が増えないのも実務向き。
- 同じ発想は LiDAR に限らない。camera の機種違い (画角・解像度) でも、複数 frame を重ねた密な教師を補助 loss にする形に移せるかが問いになる。
- 注意点: 効果は「certain setups」に限られ、abstract に数値が無い。効く条件が分からないと、運用に入れる判断ができない。

## 試すべき実験アイデア

1. 公開の LiDAR dataset を 2 つ選び (sensor が違うもの)、一方で学習して他方で評価する。通常の segmentation と、ego-pose で重ねた複数 scan の occupancy を補助 loss にした版を比べる。
2. 重ねる scan の枚数を 1・5・20 に変え、汎化の変化を見る。重ねる枚数が教師の質を決めるはずなので、効く条件の一部が分かる。
3. 手元の model で、補助 head を外した推論の速度が変わらないことを確認する (論文の主張の検算)。
