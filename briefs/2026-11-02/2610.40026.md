# RoboSeed: Multidimensional Evaluation of VLA and World-Action Models (2610.40026)

- トピック: next_arch (P3、評価設計の面で P1 にも関係) / スコア 3.5 / 10-31 の次点を繰り越し
- URL: https://arxiv.org/abs/2610.40026
- 著者: Xin Ma, Furong Chen, Xinlong Man, Bo Zhang

## 何を解決する論文か

robot の action model を選ぶとき、成功率だけでは、手元の計算予算や目的が違う人に判断材料を与えない。RoboSeed は VLA (Vision-Language-Action; 画像と言語から行動を出す model) と WAM (World-Action Model; world model と行動出力を組み合わせた model) を、複数の観点で並べて評価する枠組みである。成功率の 1 位探しでなく、「自分の予算でどれを選ぶか」と「結論がどこまで信頼できるか」に答えることを狙う。

## 手法の核心

- 5 つの dimension を定義する: capability (できること)、downstream training affordability (下流で学習し直す cost)、deployment affordability (動かす cost)、locally verified research value (手元で確かめた価値)、reproduction evidence (再現の証拠)。
- 実測値と監査の基準を、固定の normalization anchor (0 点と 100 点にあたる基準値) で 0-100 の profile に写す。balanced、training-constrained、deployment-constrained の 3 つの重み設定を持つ。
- interface と protocol の確認を先に行い、比べてよい組かどうかを決める。
- 測れていない項目は欠測として明示し、欠測のある総合点は出さない。weighted input coverage (重みで数えた入力の充足率) で、証拠の足りない場所を示す。
- 代表的な VLA と WAM に適用し、予算で最適な backbone が変わること、adaptation recipe への感度が大きいこと、language と visual の task interface で差が出ることを報告する。総合順位は、serving trace が不完全で protocol も不揃いなので出していない。

## 適用可能性

- **P3**: 次世代 architecture の候補 (VLA、world model) を選ぶ基準として、「適合に必要な学習 cost」と「推論の cost」を最初から軸に入れる発想が使える。成功率の差が小さい候補の比較で効く。
- **P1 (評価)**: planner の評価でも、閉ループの score 1 つでなく、複数の dimension の profile を出し、欠測を隠さないという設計は、そのまま真似られる。特に「総合点は欠測があれば出さない」は、比較の誤読を減らす規則として安い。
- 注意点: 対象は robot manipulation の model で、運転の model には評価していない。anchor の値は robot の task に合わせたもので、運転では作り直しになる。

## 試すべき実験アイデア

1. 手元の planner 候補 2-3 個について、5 dimension の運転版 (閉ループの安全・快適性、他 domain へ適合する学習 cost、目標 hardware での latency と memory、手元での再現) を表にし、欠測を空欄のまま残す。成功率だけの順位と並べ、順位が変わるかを見る。
2. 重みを balanced と deployment-constrained に変えて順位が入れ替わるかを測る。入れ替わらなければ、その dimension は判断に効いていない。
3. 公開の scoring code を読み、anchor の決め方を調べる。運転で anchor を決める場合に、何を基準に固定するかを決める。
