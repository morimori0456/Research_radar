# Preserving Safety During Sequential Fine-Tuning: A Factorial and Geometric Analysis of Replay (2610.38001)

- トピック: fm_distill_finetune (P2、逐次適合での忘却対策) / スコア 3.5 / 10-31 の次点を繰り越し
- URL: https://arxiv.org/abs/2610.38001
- 著者: George Ruellan, Diana Benavides-Prado

## 何を解決する論文か

LLM は、無害なデータで fine-tuning しただけでも safety alignment (有害な依頼を断る性質) が劣化し、タスクを順に適合していく sequential adaptation ではさらに悪化する。従来の対策は 2 つあり、有害依頼の拒否例と無害依頼の応答例を混ぜる **replay** (過去の振る舞いの例を再度学習に混ぜる) と、base model の logit に近づける **distillation** (元の model の出力分布を教師にする) である。両者を混ぜて報告されてきたため、どちらが効いているかが不明だった。この論文は 2 つを切り分ける。

## 手法の核心

- Mistral-7B と Llama-3-8B に、code 生成、ドイツ語の要約、科学 QA の 3 タスクを順に **LoRA** (低ランクの差分だけを学習する軽量 fine-tuning) で学習させる。
- 比較の軸は 2 つ: 拒否例を見せる supervised replay と、base model の logit への distillation。両方を使う条件も置く。
- 指標: HarmBench の ASR (Attack Success Rate; 有害な依頼に応じてしまう率)、OR-Bench-hard の over-refusal (安全な依頼まで断る率)、下流タスクの score。
- 結果 (Mistral): replay は ASR を base より平均 51.1 point 下げるが、over-refusal が 53.4 point 上がる。distillation だけだと ASR が 5.4 point 下がり、over-refusal は 5.1 point の上昇にとどまる。Llama も同じ傾向。両方を併用すると over-refusal が和らぎ、下流の score はほぼ保つ。
- 幾何の分析: 拒否の方向 (activation 空間で拒否を担う方向) は、Mistral では distillation の方がよく保つが、Llama では replay 後に方向を ablation (取り除く) しても拒否が残る。方向が保たれていることは、振る舞いの安全の代理にならない。

## 適用可能性 (P2)

- 適合を何段階も重ねる運用では、**元の model の出力への distillation を正則化に使う**と、元の能力を保ちながら新しい domain に適合できる、という recipe の根拠になる。replay のようにデータを集める必要がなく、元の model さえあればよい。
- 同じ構図は、基盤モデルを運転の別機種・別 domain に順に適合する場面にも対応する。「元の機種の性能を落とさない」ことを、distillation の loss で守る形にできる。
- 注意点: 対象は LLM の safety で、perception や planner の model への転用は検証されていない。内部表現の指標 (refusal direction) が振る舞いの代理にならないという結果は、適合後に内部の特徴の類似度だけで健全性を判定してはいけない、という教訓として効く。

## 試すべき実験アイデア

1. 手元の model に、domain A、domain B の順で LoRA 適合を行う。domain B の学習中に、凍結した domain A 後の model の出力への KL 項を足す版と足さない版で、domain A の性能の落ち幅を比べる。
2. KL の重みを 3 通りに振り、新 domain の伸びと旧 domain の保持のトレードオフ曲線を描く。
3. 適合後の健全性の判定を、内部の特徴の類似度と、出力の指標の両方で行い、2 つが食い違う例があるかを見る。
