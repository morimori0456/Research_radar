## 何を解決する論文か

RAE (Representation Autoencoder; 凍結した事前学習済み画像 encoder (ここでは DINOv3-L) の特徴を、そのまま diffusion 生成の latent (生成モデルが扱う圧縮表現) として使い、別途 pixel decoder で画像に戻す方式) では、「encoder のどの層の特徴を混ぜて latent にするか」を決める必要がある。浅い層は画素の細部を残し、深い層は生成品質を上げるので、固定の混ぜ方では再構成と生成のどちらかが犠牲になる。この論文は、層の選び方を決め打ちせず、**学習中に層の部分集合をランダムに選んで混ぜる**だけで、この板挟みを緩めた。

---

## 手法の核心

- **層の dropout。**学習サンプルごとに、K 層それぞれを確率 p で落とす Bernoulli mask (各層を独立に残す/落とすコイン投げ) を引く (全部落ちた場合は引き直す)。残った層の特徴を**残った層数で割って平均**する: `z = Σ m_k h_k / Σ m_k`。推論時は全層平均でも、少数の層でも、1 層だけでも同じ decoder が使える。
- **理論: 層間の不一致への感度を罰している。**この平均化は期待値では全層平均と一致し、ばらつきは「層同士の特徴の食い違い」だけから生じる (Lemma 1)。そのため decoder の loss は「通常の再構成 loss + 層間の食い違いに対する decoder の感度の罰則」に分解できる (Proposition 1)。ただし線形モデル + 二乗誤差を仮定した解析である。
- **decoder の loss は標準的。**ViT decoder を pixel の L2 + LPIPS (人の知覚に近い画像の類似度) + GAN loss で学習する。構造も計算量も変えず、変わるのは入力の作り方だけ。
- **数字 (ImageNet-256)。**固定の混ぜ方に特化した既存 decoder は、学習時と違う混ぜ方で使うと PSNR が 12.51 dB まで崩れる。FuseReg の 1 本の decoder は 23 層混合で 27.52 dB / rFID (再構成画像の分布のずれ、低いほど良い) 0.42。**生成器 (RAEv2 DiT-XL) を触らず decoder を差し替えるだけで、guidance なしの gFID (生成画像の品質指標、低いほど良い) が 3.01 → 2.21。**
- **diffusion 側にも同じ原理を適用。**DiT (Diffusion Transformer) には「ランダムな層部分集合の平均にノイズを載せた入力」を与え、正解は全層平均にする。DiT-Base で gFID 13.96 → 9.93 (decoder の落とし率 0.9、DiT の落とし率 0.7 のとき)。**落とし率は段ごと・スケールごとに別に選び直す必要がある**、と著者自身が書いている。

## プロジェクトへの適用可能性

分野は画像生成で、自動運転ではない。探索枠で採用したのは、「凍結した基盤 encoder の特徴を下流で使う」という P2/P3 に共通する構図に対して、**学習コストゼロで足せる regularizer** だからである。

### P3 (次世代アーキテクチャ) —— world model の latent をどの層から取るか

DINO 系 encoder の特徴空間で未来を予測する world model (DINO-WM や JEPA (Joint-Embedding Predictive Architecture; 画素でなく特徴空間で予測する自己教師あり学習) 系) でも、同じ「どの層を使うか」の決め打ちがある。予測に効く層と、planning や画像への復元に効く層は一致しないかもしれない。

**実験アイデア 1 (1〜2 日):** 手元の特徴空間 world model で、latent を (a) 最終層のみ (b) 固定の数層平均 (c) FuseReg 式のランダム層部分集合平均 (p = 0.5〜0.9) の 3 通りで学習する。評価は (i) k ステップ先の特徴予測誤差 (ii) その latent から軌跡を出す head の ADE (Average Displacement Error; 予測軌跡と正解軌跡の平均距離) の 2 つ。(c) が (ii) を改善すれば、「予測の目標は深い層、行動は浅い層も」という今日の論文の図式が運転でも成り立つ根拠になる。

### P2 (蒸留) —— feature distillation の「どの層を合わせるか」を決め打ちしない

teacher の中間特徴に student を合わせる feature distillation (出力だけでなく中間層の特徴も真似させる蒸留) では、合わせる teacher の層を手で選ぶのが普通である。FuseReg の考え方をそのまま移すと、**teacher 側の層をランダムな部分集合で平均した特徴を目標にする**ことになる。

**実験アイデア 2 (半日):** 既存の feature-KD recipe で、目標を (a) 固定の 1 層 (b) ランダム層部分集合平均 にして比較する。見るべきは平均精度より、**teacher を別の基盤モデルに差し替えたときや、student の層構成を変えたときの劣化の小ささ**。層の決め打ちへの依存が減るなら、他機種への適合 (P2 の fine-tuning 観点) で recipe を使い回しやすくなる。

## 注意点

- 実験は ImageNet-256 と凍結 DINOv3-L の 1 組み合わせだけ。動画・時系列・運転データでは未検証。
- 理論は線形 decoder と二乗誤差を仮定しており、非線形の実モデルでは経験的な裏付けのみ。
- 落とし率 p は decoder と DiT で最適値が違い (0.9 と 0.7)、スケールでも変わる。「足すだけ」ではなく p の探索が 1 軸増える。
