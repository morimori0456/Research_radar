# GIFT: Representation Geometry Matters for Single-Domain Generalized Object Detection (2610.35374)

- トピック: fm_distill_finetune (P2) / スコア 4.0
- URL: https://arxiv.org/abs/2610.35374

## 何を解決する論文か

物体検出 model を 1 つの domain (たとえば晴れの昼) で学習し、見たことの無い domain (霧、夜、雨) にそのまま使いたい。これが Single-Domain Generalized Object Detection (S-DGOD) で、従来は未知の domain を模擬するか、domain 固有の要素を抑えるアプローチが主流だった。GIFT は、Vision Foundation Model (VFM; 大規模に事前学習された画像 model) がもともと持っている汎化力に注目する。普通の fine-tuning は事前学習で得た表現の幾何構造 (特徴同士の角度や距離の関係) を壊してしまい、その構造に domain に依らない意味が入っている、というのが著者らの主張。

## 手法の核心

- **幾何構造を保つ fine-tuning**: 事前学習した weight に、学習可能な **Householder reflection** (ベクトルを鏡映する直交変換; 長さと角度を保つ) を掛ける。直交変換なので、表現の内積の関係が崩れにくい。
- **channel-wise scaling**: チャネルごとの軽い倍率を足して、task 固有の適応の自由度を補う。
- backbone は凍結し、追加の学習 parameter は 1% 未満 (PEFT; Parameter-Efficient Fine-Tuning の一種)。
- 結果は、未知 domain 上の性能を表す mPC (mean Performance under Corruption; 劣化した画像での平均性能) で、Cityscapes-C が前 SOTA 比 +7.9%、Diverse Weather Dataset が +2.9%。
- 主張としては「幾何構造の保存が cross-domain 汎化の鍵」。

## P2 への適用可能性

- P2 の評価軸「他ドメインへの適合」「ドメインギャップの克服」「効率的な PEFT」に直接当たる。対象が運転画像 (Cityscapes、天候) なので、運転向け perception に移しやすい。
- LoRA (低ランク行列を足して適合する PEFT) と違って、直交変換で表現の関係を壊さない形にする点が新しい。abstract は LoRA との比較に触れていないので、LoRA より良いかは未確認 (下の実験 1 で確かめる)。
- 蒸留 (P2 の前半) とは別軸だが、蒸留後の小さい student を別 domain に適合させるときの手段としても考えられる。student でも幾何構造が効くかは未確認。
- 未確認点: どの VFM、どの検出 head を使ったか、parameter 数、学習コスト、baseline と同じ backbone で比べたかは abstract に無い。mPC の絶対値も不明で、+7.9% が相対か絶対かも分からない。

## 試すべき実験アイデア

1. 手元の VFM backbone の attention の q / v projection に Householder reflection (少数のベクトルから作る直交行列) を足し、同じ parameter 数の LoRA と比較する。source domain と、天候を変えた held-out domain の両方で評価する。
2. fine-tuning 前後の表現の幾何構造がどれだけ変わったかを測る (たとえば固定した画像集合の特徴 Gram 行列の差)。「普通の fine-tuning が幾何を壊す」を自分の model で確認し、domain gap が大きいほど壊れ方が大きいかを見る。
3. 反射の数 (表現力) と held-out domain の性能の関係を測り、増やす価値がある範囲を決める。
