# Video World Models Need Predictable Latents (2610.34663)

- トピック: next_arch (P3) / スコア 4.0
- URL: https://arxiv.org/abs/2610.34663

## 何を解決する論文か

video world model (動画で将来を予測する model) は、通常 autoencoder (画像を小さい latent に圧縮し、復元する network) の latent 空間で予測する。この autoencoder は「元の画像を復元できること」だけを目的に学習されているので、latent が「次に何が起きるかを予測しやすい形」になっているとは限らない。結果として、長い時間の rollout と未知の状況に弱く、推論も重い。一方、latent planning 向けの world model は予測しやすい latent を学ぶが、画素の予測を捨てている。この論文は、両方を満たす latent を作る方法を示す。

## 手法の核心

- **temporal objective (時間方向の目的関数)** を autoencoder の学習に足し、時間的に予測しやすい latent の幾何にする。
- **past-conditioned decoder (過去の情報を条件に復元する decoder)** と組み合わせる。latent だけに復元の全責任を負わせず、過去の画像を decoder 側で補うことで、latent は予測しやすさに集中できる。
- 同じ学習予算で、推論が最大 5 倍安く、学習が 7 倍以上速く、pixel と perceptual (知覚的な) 誤差が、未知の状況と長い horizon で 15-24% 下がる。
- 実世界の policy 評価との一致も上がる: VLM に world model が生成した画素の予測を見せて task の成否を判定させたとき、実世界での評価に近づく。
- 主張は「latent の temporal predictability は、video world model の latent 空間の設計基準として重要」。

## P3 への適用可能性

- P3 の評価軸「world model の表現学習」に当たる。autoencoder の学習を変えるだけなので、既存の world model の pipeline に差し込める。DriveUniTok (今日のもう 1 本) のような tokenizer の学習にも、この temporal objective を足すという接続が考えられる。
- 「world model で policy を評価する」という使い方は、P1 の closed-loop 評価 (simulation に代わるもの) と接する。world model の評価と実世界の評価の一致を VLM の判定で測る方法は、運転にも移せそう。
- 対象は robot data の video world model で、運転 (高速、多数の動く物体) で同じ利得が出るかは未確認。「5 倍安い推論」の基準が何かも abstract にはない。

## 試すべき実験アイデア

1. 既存 autoencoder の学習に「隣接フレームの latent 差が小さい / 線形に外挿しやすい」ような単純な temporal loss を足し、固定した世界モデルで未来予測誤差と rollout の発散度合いを比べる最小版。
2. past-conditioned decoder の有無だけを切り替える ablation。latent の質への効き方を分離できる。
3. 運転 log で、world model の rollout を VLM に判定させた成否と、実際の結果 (衝突の有無など) の一致率を測る。P1 の評価の代理として使えるかの判断になる。

## 注意

abstract のみに基づく。temporal objective の具体的な形、autoencoder の大きさ、比較対象は未確認。
