# RSKD: Grounding Semantic Consistency in Driving VLMs via Distillation (2610.34689)

- トピック: fm_distill_finetune (P2) / スコア 4.5
- URL: https://arxiv.org/abs/2610.34689

## 何を解決する論文か

大きな multimodal model (画像と言語を扱う VLM) の知識を、車載向けの小さい model に knowledge distillation (大きな teacher の出力を小さな student に真似させて学習する手法) で移したい。ただし、全 token を一様に teacher に合わせると、planning に効く語 (たとえば「左折」「歩行者」) が、どうでもよい語の中で薄まる。さらに teacher が間違っているときは、その間違いまで student に写してしまう。RSKD は、答えの中の語句ごとに「どれだけ重要か」と「teacher の予測が正解と意味的に一致しているか」を見て、teacher と正解のどちらにどれだけ頼るかを振り分ける。

## 手法の核心

- **task-critical な語句の局所化**: ground-truth の答えから、planning に重要な semantic phrase を取り出す。
- **phrase-level consistency score**: 各語句について、teacher の予測が ground truth と意味的に整合している度合いを score にする。
- **JSD と ground-truth の loss の混合**: JSD (Jensen–Shannon divergence; 2 つの確率分布の違いを測る対称な距離) による distillation loss と、正解ラベルに対する教師あり loss の重みを、語句ごとに consistency score で切り替える。
- teacher が整合している語句では teacher の情報を強め、不整合な語句では ground truth の supervision を強める。teacher の誤りの増幅を避ける設計。
- 評価は DrivingVQA、LingoQA (運転場面の質問応答)、MapLMv2 (地図・車線の理解)。student ベースの比較手法には DrivingVQA と LingoQA で勝ち、MapLMv2 では competitive (勝ちきっていない)。

## P2 への適用可能性

- P2 の評価軸「蒸留を実務で回せるか」に対し、loss が既存の要素 (JSD と CE) の重みの切り替えだけで、設計が単純で試しやすい。teacher の誤りに対する対策は、自前の teacher を使う場合にも効く (teacher が常に正しいとは限らない)。
- capacity gap (teacher と student の大きさの差が大きいと蒸留がうまくいかない問題) への直接の対策ではないが、「teacher を信じる度合いを場所ごとに変える」という発想は、gap が大きいときの補助手段になり得る。
- 運転ドメインの VLM を対象にしており、P2 の「基盤 model を運転に使う」という文脈に合う。ただし評価は VQA で、closed-loop の運転性能 (P1 の評価軸) との関係は未確認。
- 未確認点: 提案手法の改善幅の数値と、student の大きさ、teacher の種類、どれだけ小さくなったかは abstract に無い。MapLMv2 で勝てていない理由も不明。

## 試すべき実験アイデア

1. 既存の蒸留 script の token-level loss を 2 つの mask に分ける最小版。「語句の重要度 mask」(最初は手作業の keyword list でよい) で重要語に重みを付け、効果を見る。consistency score は後から足す。
2. teacher の出力と正解の一致度 (embedding の cosine 類似など単純なもの) で JSD と CE の重みを切り替える版を、重要度 mask 無しで試す。2 つの要素のどちらが効いているかを切り分ける ablation になる。
3. teacher に意図的に間違った答えを混ぜたデータで、一様な蒸留 (baseline) と RSKD 型の差を見る。「teacher の誤りを増幅しない」が再現できるかを安く確認できる。

## 注意

abstract のみに基づく。数値と ablation は未確認。student ベースの baseline との比較が中心で、teacher 自身や強い大型 model との差は不明。
