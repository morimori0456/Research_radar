# Benchmarking Obstacle-Conditioned Safety in Household Robot Navigation (OSMA-Bench) (2610.34674)

- トピック: next_arch として届いたが、内容は P1 (評価指標) なので planner_ai の quota で採用 / スコア 3.5
- URL: https://arxiv.org/abs/2610.34674

## 何を解決する論文か

家庭用ロボットの navigation では、障害物が何であるか (花瓶か、人か、ペットか) と、どれだけ近いかによって、余白と速度を変えるべきである。しかし既存の評価は、この「意味の違いが連続的な動きの違いとして出るか」を測っていない。OSMA-Bench (Obstacle-Conditioned Safe Motion Adaptation Benchmark) は、障害物の種類だけが違う、空間配置を揃えた scenario の組を作り、VLM と VLA が意味の違いを動きに反映できているかを測る。結果は、どちらも一貫しては反映できていない。

## 手法の核心

- **spatially matched scenario sets**: 障害物の種類以外 (配置、距離) を揃えた scenario 群。差が出れば原因は障害物の意味だけ、と言える対照実験の形。
- **Semantic Sensitivity Index (SSI)**: 障害物ごとの「注意すべき順序」に対し、clearance (余白)、距離に応じた速度、動きの滑らかさがその順序に従っているかを測る指標。
- 評価対象は VLM-based policy (障害物を認識して navigation program を生成する型) と VLA policy。safety を明示した prompt を与えても一貫して適応しない。
- 診断: policy は障害物を安全性の観点で正しく区別できているのに、出力する motion parameter や action に反映できない。この欠落を **semantic-to-motion grounding の gap** と呼ぶ。
- VLM-based policy には、認識と program 生成の間に **明示的な parameter 推論の step** を入れると適応が改善する。

## P1 への適用可能性

- 運転 planner の評価は collision rate と route completion が中心で、「相手が歩行者なら大きく避け、段ボールなら小さく避ける」ようなふるまいの差を測る指標は少ない。SSI の考え方 (種類だけを変えた対の scenario で、余白や速度が注意の順序に従うか) は、運転にそのまま移せる評価の形。
- 「認識は正しいのに動きに出ない」という診断は、VLM や VLA を planner に使うときの失敗の種類として押さえておく価値がある。認識の精度が上がっても planner の挙動は自動では良くならない。
- 対象が家庭内の低速 navigation で、車の力学、速度域、交通ルールとは遠い。運転で同じ gap が出るかは未確認。

## 試すべき実験アイデア

1. CARLA などで、「同じ配置で、前方の物体だけを歩行者 / 自転車 / 車 / 段ボールに差し替えた」対の scenario を作り、planner の最小余白と接近時の速度を測る。caution の順序 (歩行者 > 自転車 > 車 > 段ボール) との順位相関を、SSI の簡易版にする。
2. VLM を使う planner があれば、物体の種類の認識と軌道生成の間に「余白と速度の目標値を明示的に出させる step」を挟み、SSI が改善するかを見る (論文の parameter 推論 step の移植)。
3. 余白が増えた分だけ route completion や所要時間が悪化していないか (unnecessary conservatism) を同時に測る。論文の趣旨は慎重すぎないことも含むため、片側の指標だけにしない。
