# Thinking at the Right Size: Amortized Distillation Across Post-Trained LLMs (ADAPT)

- arXiv: https://arxiv.org/abs/2608.22854
- topic: **fm_distill_finetune** (P2) / hf_upvotes **0**
- 公開日: 2026-08-24 (Mon)
- relevance: P2 **4.5** / P3 **1.5** / P1 **0**
- 著者: Yan Zhou, Sara Kangaslahti, Jonathan Geuter, Nihal V. Nayak, Marco Fumero

## 何を解決する論文か

実運用では、1 つのモデルを作れば済むということがない。**post-trained variant (事前学習後に用途別に追加学習した版 — instruction-tuned / reasoning-tuned / chat 用)** が複数あり、そのそれぞれについて **latency と memory の予算に応じた複数のサイズ**が要る。**この (variant, size) の組を 1 つずつ独立に作るのは計算コスト的に無理**なので、実際のモデルファミリは各 variant につき数個の粗いサイズしか用意していない。

**先行の boomerang distillation (Kangaslahti et al., 2026) は size 軸だけを解いた** — teacher-student ペアが 1 組あれば、追加学習なしに **model size interpolation (2 つのモデルの間の「中間サイズ」を構成する操作)** で任意の中間サイズを作れる。ただし **base model 限定**で、post-trained variant ごとにやり直す必要が残っていた。

**ADAPT は size 軸と variant 軸の両方を一度に amortize (1 回のコストで多数を賄う) する。**1 回の蒸留実行から **L 個の補間サイズ × K 個の post-trained variant = L×K 個のモデル**を出す。

## 手法の核心

- **貢献は 2 つの部品の組み合わせで、片方だけでは成立しない。**

- **部品 1: two-phase distillation。**student を **pre-training alignment (事前学習相当の表現を teacher に揃える段) → supervised fine-tuning distillation (指示追従・推論の振る舞いを蒸留する段)** の 2 段で作る。**この 2 段構成が「サイズを滑らかに補間しても性能が滑らかに変わる」性質を担保している**というのが論文の主張で、単に精度を上げるための工夫ではない。**補間可能性そのものを設計目標にしている**点が読みどころ。

- **部品 2: weight-delta initialization。**base model に対する蒸留で生じた **weight change (重みの差分 Δ)** を取り出し、**別の post-trained variant から初期化した student にそれを転写する。**これで variant 軸のコストが消える。**「蒸留という操作の効果は、post-training の違いをまたいでほぼ同じ方向のベクトルである」という仮定**に乗っており、ここが本論文で最も検証すべき前提である。

- **副産物として adaptive model-size selection が得られる。**サイズが離散的な数点ではなく**連続体**になるため、**推論時に問題の難しさに応じてサイズを選べる。**long-form reasoning (長い推論を要するタスク) で compute-accuracy trade-off が改善したと報告している。タイトルの "Thinking at the Right Size" はこれを指す。

## 読むときの但し書き

- **weight-delta の転写可能性は経験的主張である。**variant 間の距離が大きいとき (例えば chat 用と強い reasoning-tuned) に崩れないかは、本文の実験範囲を確認する必要がある。**この仮定が本論文の acceptance risk の中心。**
- **「単一の蒸留実行」の実際のコストが abstract にない。**L×K 個を得るための 1 回が、独立に作る場合の 1 回より遥かに重ければ主張は薄まる。
- **boomerang distillation 前提なので、そちらを先に読まないと機構が理解できない。**本論文単体では自己完結していない。
- **capacity gap への言及がない。**teacher と student の容量比が開いたときに補間が破綻する点があるはずだが、abstract には現れない。**P2 の関心からは、そこが最も知りたい箇所である。**

## P1/P2/P3 への適用可能性

### P2 (FM 蒸留 + 適合) — 本日の P2 本命。「recipe」として最も直接使える 1 本

topics.yaml の P2 は「**再現可能な recipe / 新しい loss / capacity gap 対策は高優先**」と明記しており、本論文は **recipe の側で真正面から当たる。**

**実務上の意味は「蒸留の単位を 1 モデルから 1 ファミリに変える」ことである。**現状の蒸留運用は「teacher を決め、student のサイズを決め、回す」の繰り返しで、サイズを変えたければもう一度回す。**ADAPT はこの繰り返しを 1 回に畳む。**もし成立するなら、**「student のサイズをいくつにするか」という設計判断を、学習の前ではなく学習の後 (さらには推論時) に先送りできる。**これは判断の遅延ができるという意味で、実験計画上かなり大きい。

**もう一つの持ち帰りは weight-delta initialization という発想そのもの。**「**適合の効果を差分ベクトルとして取り出し、別の出発点に足す**」という操作は、P2 のもう一つの軸である **fine-tuning による他ドメイン適合**にもそのまま形が移る。**あるドメインへの適合 Δ を、別の base から始めた student に転写できるか** — これは本論文が主張していない領域だが、機構としては同じ問いである。

### P3 (次世代アーキテクチャ) — 弱いが無関係ではない

**adaptive model-size selection は、VLA (Vision-Language-Action) の実機運用に効く可能性がある。**制御周期の余裕がある局面では大きいサイズ、詰まった局面では小さいサイズ、という切り替えは実機側の要求そのものである。ただし本論文は言語タスクでの報告であり、**latency が hard constraint になる制御ループで同じ枠組みが使えるかは全く別問題。**着想として記録するに留める。

## 試すべき実験アイデア

1. **weight-delta 転写だけを最小構成で検証する (1 日)。**
   小さい teacher-student ペアを 1 組用意し、base model で蒸留して Δ を取り出す。それを **2 つの異なる post-trained variant から初期化した student に転写**し、**「転写した student」対「その variant で蒸留し直した student」**を比べる。**論文の 2 部品のうち、崩れるとしたらこちらなので、ここだけを先に叩く。**部品 1 (two-phase distillation) の実装は不要で、既存の蒸留パイプラインに差分の足し引きを加えるだけで済む。

2. **補間の滑らかさを、性能ではなく分散で測る (半日、1 の後)。**
   補間で作った中間サイズ列に対し、性能曲線が**単調かつ滑らか**かを見る。**折れ曲がりや谷が出る位置があれば、そこが実質的な capacity gap の境界**である。論文が触れていない capacity gap の話を、この枠組みで観測できる可能性がある。**R2 (蒸留の capacity gap 系統則) の測定手段として使える**のが狙い。

3. **domain 適合 Δ の転写に発想を移す (2〜3 日、本論文の主張の外)。**
   variant 軸ではなく **domain 軸**で同じことを試す。ドメイン A への適合 Δ を取り出し、別 base の student に足して、**A への再学習なしにどこまで届くか**を測る。**成立すれば P2 の「他機種・他ドメインへの適合」に直接効く。**成立しなくても、Δ の転写がどの軸で成り立ちどの軸で壊れるかの境界が分かる。

**優先は 1 → 2 → 3。**1 は本論文を採るか捨てるかを決める判定で、しかも 1 日で済む。
