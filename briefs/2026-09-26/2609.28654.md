## 何を解決する論文か

video generation model (動画の続きを生成するモデル) は、最近 world model (環境が次にどうなるかを予測・シミュレートするモデル) として扱われることが増えた。しかし、物体が遮蔽物の陰に入ると消えたり、あり得ない位置から再び現れたり、固い壁をすり抜けたりする。この論文は、**object permanence (見えなくなった物体も存在し続けるという認識。人間の乳児は生後 3.5 か月頃に獲得する) と object solidity (固い物体同士はすり抜けないという認識) を、専用の合成データで測り、学習させる**ことを狙った。

## 手法の核心

- **課題の構造と見た目を分けて乱数化する。**Blender (3D CG ソフト) で 150 種の課題 generator を手作業で作った。各 generator には 2 種類の parameter がある。物体の数・軌道・遮蔽の配置・接触のタイミングは「課題の構造」として系統的に変える。色・材質・照明・カメラ角度は「見た目」として乱数で変える。こうして 1 課題あたり 1 万件、合計 1.5M 件の学習データを作る。
- **認知科学の実験を 6 系統に整理した。**object permanence (以下 OP) が 3 系統 (遮蔽物の陰を通る物体、静止物体の遮蔽、容器に入った物体) で 90 generator。object solidity (以下 OS) が 3 系統 (障害物による遮り、物体の落下、衝突) で 60 generator。
- **「事象の直前」で動画を 2 つに割る。**どの課題も、鍵になる物理事象 (遮蔽からの再出現、衝突など) が動画の後半で起きるように作ってある。モデルには前半だけを渡し、事象を含む後半を生成させる。学習と評価で同じ形式を使う。
- **16B の world model を fine-tuning した。**NVIDIA の Cosmos3-Nano (公開 world model) を土台に、構造は変えず学習データだけを WROP に替えて 1 epoch 学習した (PWM-WROP)。
- **採点は人間の盲検の一対比較。**14 モデルの出力を 20 人が 2 つずつ見比べ、Bradley–Terry model (一対比較の勝敗から各選手の強さを推定する統計モデル。Elo レーティングと同じ考え方) で順位を付けた。PWM-WROP は Elo 1679.5 で、true continuation (入力動画の続きをそのまま生成する方式) の 4 モデル中 1 位、全体でも 3 位だった。

## 結果で目を引く点

- **OP と OS で効き方が違う。**PWM-WROP の系統内順位は、OP 側が 1 位・3 位・3 位だった。一方 OS 側は 2 位・5 位・**8 位 (衝突)** だった。著者は「遮蔽の追跡には効くが、接触の力学には効きにくい」と解釈し、2 つの能力には別の内部表現が要るのではと書いている。
- **Elo は解像度差を抱えたまま比べている。**PWM-WROP の出力は 320×192 で、競合は 720p〜1080p である。解像度を揃えると、LPIPS と MS-SSIM (どちらも正解動画との画像の近さを測る指標) で最良だった。

## プロジェクトへの適用可能性

### P3 (次世代アーキテクチャ) — 3.0: 運転 world model の「遮蔽」を点検する物差し

運転の world model で一番困る失敗は、この論文の OP の失敗と同じ形をしている。**駐車車両の陰に入った歩行者が、生成された未来の中で消える**失敗である。今の運転 world model の評価は、FVD (生成動画の分布が本物にどれだけ近いかを測る指標) のような画質の指標が中心で、この失敗を直接には測れない。

この論文から持ち帰れるのは 3 点である。

1. **事象の直前で切る評価形式。**入力を「遮蔽の直前まで」にすると、モデルが遮蔽中の物体を覚えているかを 1 問ずつ判定できる。
2. **構造と見た目を分けた合成。**見た目だけ乱数化すれば、モデルが見た目で正解を覚えられなくなる。
3. **OP と OS は別々に測るべきという結果。**「遮蔽物の陰の追跡」と「接触・衝突の力学」は別の能力として扱う。

**実験アイデア (半日〜1 日、GPU 1 枚):**
1. 手元の運転ログ (または nuScenes などの公開データ) から、「歩行者または車両が他の車両に 1 秒以上隠れて、再び現れる」場面を 50 件抜き出す。3D box の追跡 ID があれば、遮蔽の開始と終了は自動で取れる。
2. 遮蔽開始の直前までを入力にして、使っている world model (または公開の運転 world model) に続きを生成させる。
3. 生成した動画に既製の detector をかける。「再出現すべき時刻の前後 0.5 秒に、正しい位置 ±2 m に物体が出たか」を数える (再出現率)。
4. **判定:** 再出現率が 80% を下回るなら、その world model を closed-loop simulation (planner の出力で次の場面が変わる形のシミュレーション) に使うと、隠れた歩行者を planner が見落とす場面が作られない。この指標を world model 選定の必須項目にする。

### P1 (Planner AI + 評価) — 2.0

上の再出現率は、P1 で生成シミュレーションを planner の評価に使うときの前提条件の点検にもなる。world model が遮蔽中の物体を消すなら、「隠れた歩行者への対応」は評価できない。評価シナリオ集に「遮蔽からの再出現」の項を足す根拠になる。

### P2 (蒸留 + fine-tuning) — 1.5

「構造は変えず学習データだけを替えた fine-tuning で、特定の物理能力を足せるか」という問いは、P2 のドメイン適合と同じ形である。ただし下の但し書きのとおり、fine-tuning 前後の比較が無いので、この論文から recipe の効果は読み取れない。

## 読むときの但し書き

- **タイトルの主張 (学習で身に付く) を示す比較が無い。**土台の Cosmos3-Nano そのもの (fine-tuning 前) は、評価した 14 モデルに入っていない。そのため PWM-WROP の順位が WROP データのおかげなのか、土台が元々強いのかを切り分けられない。
- **学習データと試験が同じ generator から出ている。**学習データは「同じ 150 generator の、試験とは別の描画」である。試験の成績は分布内の汎化であり、実写や別種の場面に移るかは測られていない。
- **採点は 20 人の人手で、試合数は系統あたり 36〜96 回。**系統別の順位の信頼区間は広いと思われる。
