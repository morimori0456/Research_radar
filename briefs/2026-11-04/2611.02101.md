# When Delay Meets Drift: Physical Safety of Robot Foundation Models Is a Cross-Layer Problem (2611.02101)

- トピック: next_arch → 評価の観点で P1 に配置 (P1、closed-loop の安全評価の設計。P3 の VLA にも関連) / スコア 3.5
- URL: https://arxiv.org/abs/2611.02101

## 何を解決する論文か

robot foundation model (多様な task に使い回す大きな policy) は closed loop (出した行動が次の観測に返る閉ループ) で動くが、安全性の評価は「1 つの変化だけ」を入れて行われがちである。robustness benchmark は景色などを変えるが推論は瞬時と仮定し、推論遅延の研究は通常の場面しか見ない。この論文は、**遅延と環境の変化が同時に起きると、単独の影響の合計より大きなリスクになる** ことを測り、安全は model 単体の性質でなく system 全体 (環境・model・計算機・実行) の相互作用で決まると主張する。

## 手法の核心

- **cross-layer variation propagation**: 環境・model・計算 platform・実行の各層の変動が、層をまたいで伝わるという定式化。
- **interaction contrast (交互作用の差)**: 2 つの変動を同時に入れたときのリスクから、それぞれ単独のリスクの和を引いた量。正なら「合わせると足し算以上に危ない」。
- 実験: pi0.5 (VLA; 画像と言語から action を出す policy) を LIBERO (robot 操作の simulation benchmark) で動かし、4,000 の paired closed-loop episode を比べた。
- 結果: 400 ms の推論遅延は、学習時と同じ視点では safety-violation rate を 3.5 percentage point (pp) 上げるだけだが、60 度の camera ずれがあると 37 pp 上がる。合計より **33.5 pp (95% CI: 25-43) 大きい**。
- 最後に、変動がいつリスクに変わるかを予測し、それに応じて compute・電力・制御を調整する研究課題を示す。

## 適用可能性 (P1: 評価 / P3: VLA)

- P1 では、planner の評価を「遅延 × センサのずれ (camera の取り付け角、較正誤差)」の格子で回し、interaction contrast を出す設計がそのまま使える。単独の robustness 試験で合格した planner が、組み合わせで崩れるかを見られる。
- P3 では、VLA や E2E model を車載の計算機で動かすときの遅延が、分布のずれと重なって効くことの警告になる。
- 注意点: 対象は manipulation (LIBERO) で、運転ではない。violation の定義や、遅延が車速と共に効く運転での大きさは別に測る必要がある。この論文の位置づけは position paper (主張と研究課題の提示) の性格が強く、手法の一般性は abstract から判断できない。

## 試すべき実験アイデア

1. 手元の planner で、推論遅延 (0 / 100 / 200 / 400 ms) × camera の取り付け角のずれ (0 / 数度 / 大きなずれ) の格子を closed-loop で回し、衝突率の interaction contrast を出す。
2. 単独要因の試験で合格した planner の順位と、組み合わせでの順位が入れ替わるかを見る。入れ替わるなら、評価は単独要因の試験だけでは足りない。
3. 遅延を「入力が古い」形 (観測の遅れ) と「出力が遅れる」形 (action の遅れ) に分けて、どちらがずれと強く交互作用するかを見る。

## 注意

abstract のみに基づく。「safety violation」の具体的な定義、pi0.5 以外の model での再現、運転 simulator での結果は未確認。
