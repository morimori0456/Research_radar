# Contrastive Adapter Training and Consensus Knowledge Distillation for Multi-Source-Free Domain Adaptation in Skin Cancer Diagnosis (2611.03528)

- トピック: fm_distill_finetune (P2、source-free な domain adaptation と distillation の組み合わせ) / スコア 4.0
- URL: https://arxiv.org/abs/2611.03528

## 何を解決する論文か

皮膚がんの診断 (メラノーマと良性の母斑の判別) では、病院や撮影機器ごとにデータの性質が違い、学習済み model が別の施設のデータで精度を落とす。通常の domain adaptation (学習時と違う分布への適合) は source data (元の学習データ) を要するが、プライバシー規制で使えないことが多い。そこで **multi-source-free unsupervised domain adaptation (MSFDA; 複数の元 domain で学習済みの model だけを使い、元データなしでラベル無しの target domain に適合する設定)** を扱う。既存手法は backbone 全体を fine-tuning するため、小さな医療データで catastrophic forgetting (前に学んだことが壊れる) や過学習が起き、hard pseudo-label (確信度の高い予測を正解とみなす) も domain shift の下ではノイズが多い。

## 手法の核心

- **CAT (Contrastive Adapter Training)**: 凍結した ViT (Vision Transformer) の backbone に、軽量な **ConvPass adapter** (畳み込みで特徴を足す小さな追加層) だけを入れ、supervised contrastive learning (同じ class を近く、違う class を遠くに寄せる学習) で学習する。source ごとの model を作る**前に**、全 source に共通の domain-invariant (domain によらない) な特徴空間を作る。
- **CKD (Consensus Knowledge Distillation)**: 複数の source model の logit を集めて 1 つの consensus (合意) の教師信号にし、ラベル無しの target データ上で student を KL divergence (2 つの確率分布の差を測る量) で適合させる。hard pseudo-label も confidence による重み付けもしない。
- 5 つの公開皮膚病変データセットで、平均 AUROC (判別性能の指標) 86.1%、既存の MSFDA 手法を上回る。学習する parameter は 4.3M だけ。code は公開されている (https://github.com/A-Abedi/CAT_CKD)。

## 適用可能性 (P2: FM 蒸留 + 他機種・他ドメインへの適合)

- P2 の適合の基準 (少データ、ドメインギャップ、PEFT 系の効率的適合) に直接重なる。「adapter だけを学習して共有空間を先に作り、次に複数の教師から 1 つの student に蒸留する」という 2 段の recipe として読める。
- 「機種 A 用・機種 B 用の fine-tuning 済み model が既にあり、機種 C のデータは unlabeled で、A・B の元データは使えない」という状況に、構造がそのまま対応する。
- 注意点: 医療画像の分類 (2 値に近い) で、検出や planner 出力のような構造化された出力には未検証。consensus の作り方 (単純平均か重み付けか) は abstract に書かれていない。データが 5 つと少ない。

## 試すべき実験アイデア

1. 既存の機種別 fine-tuning 済み model が 2〜3 個あるとき、新機種の unlabeled データで、(a) logit の単純平均を教師にした distillation、(b) hard pseudo-label、(c) 手元の最良の単独 model、を比べる。差が出れば consensus の教師信号が効いている。
2. 全層 fine-tuning と adapter だけの学習で、前の機種での性能の落ち (forgetting) を測る。
3. adapter を入れる前の共有特徴空間の学習 (CAT) を外して、CKD 単体との差を見る。共有空間が効いているかを分離できる。
