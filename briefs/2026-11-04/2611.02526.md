# INTERACT: Learning Interaction-Aware World Dynamics from Driving Videos for Autonomous Driving (2611.02526)

- トピック: next_arch (P3、object-centric な world model + E2E 運転。P1 の衝突評価にも関連) / スコア 4.5
- URL: https://arxiv.org/abs/2611.02526

## 何を解決する論文か

安全な運転には、今の場面を認識するだけでなく、**自車が動いたとき周囲の交通参加者がどう変わるか**を予測する必要がある。ところが既存の E2E (end-to-end; 画像から直接軌道を出す) 運転 model は、場面を密な視覚特徴や BEV (Bird's-Eye View; 真上から見た地図状の特徴) にまとめ、物体どうしの相互作用を暗黙のままにしている。この論文は、物体単位の表現で相互作用を明示的に予測する world model (将来の状態を予測する model) を、注釈なしの運転動画から学び、planner に渡す。

## 手法の核心

3 段階の枠組み (**INTERACT**: INTERaction-aware Action-Conditioned Trajectory learning)。

- 段階 1: **slot-based** な表現を学ぶ。slot は「物体 1 つに対応する特徴ベクトル」で、recurrent (時間方向に更新する) な slot が、密な視覚特徴を時間的に構造化された場面内の実体にまとめる。物体の annotation は不要。
- 段階 2: slot の文脈と動画の遷移から **latent ego action** (自車の操作を、ラベル無しで推定した潜在変数) を推定し、それを条件に未来の slot を予測する。自車の動きと周囲の実体が互いにどう変わるかを捉える。
- 段階 3: 学んだ slot・latent action・未来の slot の予測を、**distillation で trajectory planner に渡し**、軌道の生成と選択を導く。
- 結果: NAVSIM (実走行ログを元にした planner 評価 benchmark) で state-of-the-art。特に safety-critical な衝突系の指標が改善する。nuScenes でも検証している。

## 適用可能性 (P3: 次世代アーキテクチャ / P1: 評価)

- 「注釈なし動画 → 物体単位の world model → planner に蒸留」という流れは、P3 の world model 方針に沿う。蒸留で渡すので、推論時に world model を動かすコストを planner 側に持ち込まない設計である点も実務的。
- 衝突指標が伸びる点は、interaction を明示した効果の候補。P1 では、planner が他車の反応を考慮しているかを測る評価の材料になる。
- 注意点: 段階 1〜3 を別々に学習するため、どの段階が効いたかは abstract から分からない。改善幅の数値もない。slot の数や追跡の安定性 (物体の分裂・合体) は運転の混雑した場面で問題になりうる。

## 試すべき実験アイデア

1. 段階ごとの ablation を回す: (a) slot のみ、(b) slot + latent ego action、(c) + 未来 slot の予測の蒸留。衝突指標が (c) で初めて動くなら、interaction の予測が効いていると言える。
2. 本日の ScaleDrive (2611.02853) と比べる。同じ planner に、dense な latent 表現 (ScaleDrive 型) と slot 表現 (INTERACT 型) を載せ、衝突率と L2 誤差を比べる。注釈なし動画から作る 2 つの流儀の優劣になる。
3. latent ego action を、実際の ego の軌道と照合する。操作ラベル無しでどこまで復元できるかが分かり、world model の条件付けの信頼性を測れる。
