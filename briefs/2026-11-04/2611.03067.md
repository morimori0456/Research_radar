# PlanContext: Benchmarking In-Context Driving Decision-Making (2611.03067)

- トピック: planner_ai (P1、planner 評価 benchmark。candidates.json では next_arch に分類されていたが、内容は P1 の評価) / スコア 4.5
- URL: https://arxiv.org/abs/2611.03067

## 何を解決する論文か

E2E (end-to-end; 画像から直接軌道を出す) 運転 model の既存 benchmark は、軌道の安全性・規則の遵守・快適性・進行度といった「軌道の質」を測る。だが実際の運転では、「同じ場面でも、今から左折するのか直進するのか」のような文脈で正しい判断が変わる。この論文は、**場面を固定したまま高位の運転意図 (high-level driving intention) だけを変えた対で評価する** PlanContext を提案し、既存の score ではこの文脈依存の判断力が測れていないことを示す。

## 手法の核心

- **paired evaluation (対評価)**: 観測する場面は同一にして意図だけを変える。意図以外の要因が混ざらないので、「意図に応じて判断を変えられたか」が制御された形で測れる。
- 代表的な運転 context を 6 種類定義している (6 種類の中身は abstract からは分からない)。
- 3 つを合わせて評価する: contextual decision correctness (その意図に対する判断が正しいか)、road compliance (道路規則の遵守)、dynamic safety (動的な安全性)。class-balanced metrics (少数の context にも同じ重みを置く集計) を使う。
- データは NAVSIM (実走行ログを元にした planner 評価 benchmark) 由来の 9,561 の scene-condition instance。公開されている 23 個の E2E model を評価した。
- 結果: 従来の運転の質の score が高い model が、route-level (進路を選ぶ水準) の in-context 判断でも強いとは限らない。判断の質は、判断のタイミング・道路構造・交通の相互作用によっても変わる。

## 適用可能性 (P1: Planner AI + 評価)

- 「閉ループの score が同じでも、意図に応じた判断ができているかは別」という評価軸の追加として、そのまま P1 の評価指標の候補になる。同点の planner を区別する材料になる。
- 対評価は、場面を作り直さずに既存の log から作れるので、手元の評価基盤に足しやすい (意図の条件だけを差し替える)。
- 注意点: 6 つの context の定義、判断が「正しい」とする基準、23 model のうち上位がどれかは abstract から読めない。NAVSIM は log を再生する形式なので、閉ループで意図を変えたときの挙動までは測れない可能性がある。

## 試すべき実験アイデア

1. 手元の planner に、同じ場面で route command (左・右・直進) だけを入れ替えて入力し、軌道が意図に沿って変わるかを測る。まず「command を変えても軌道がほぼ同じ」場面の割合を数える。
2. 手元で使っている既存の運転の質の score (PDMS 系) と、意図に対する判断の正しさの順位相関を、複数の checkpoint で取る。相関が低ければ、この論文の主張が手元でも成り立つ。
3. 判断のタイミング (交差点の手前・直前) で層別して、どの段階で意図が反映されなくなるかを見る。

## 注意

abstract のみに基づく。benchmark の公開有無、6 context の詳細、各 model の個別結果は未確認。
