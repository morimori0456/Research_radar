# Reuse, Don't Retrain: Efficient, Modality-Versatile Geospatial Foundation Models through Feature Distillation (2610.32566)

- トピック: fm_distill_finetune (P2) / スコア 4.0 / 出所: RSS (cs.CV の new、candidates.json には無し)
- URL: https://arxiv.org/abs/2610.32566

## 何を解決する論文か

地理空間 foundation model (GeoFM; 衛星画像などを入力にする事前学習 model) は、事前学習のコストが高いのに、backbone の大きさや sensing modality (センサの種類) ごとに同じ事前学習が繰り返されている。この論文は、既存の model の表現を再利用するために feature distillation (teacher の中間特徴を student に合わせる蒸留) を使う。小さい model を一から学習し直す代わりに、凍結した大きな teacher から蒸留する。

## 手法の核心

- **patch-level feature matching**: 凍結した teacher (CROMA、TerraMind) の patch ごとの特徴を、より小さい ViT (Vision Transformer) の student が出力するように合わせる。
- **結果 1 (サイズ違いへの蒸留)**: PANGAEA (地理空間 model 用の downstream benchmark) の 9 task で、蒸留した TerraMind の Tiny / Small / Base が、同じサイズで公開されている model を mIoU (mean Intersection over Union; segmentation の重なり率の平均) で 2.76 / 3.02 / 1.87 点上回る。さらに各蒸留 model は、1 つ上のサイズの公開 model と同等かそれ以上。CROMA-Base も +2.05 点。
- **コスト**: TerraMind-Base の蒸留は A6000 GPU で 43 時間。独立に事前学習した場合の報告コストの約 0.5%。
- **結果 2 (TEDI)**: unpaired (対応するペアデータが無い) な multi-expert 蒸留。multispectral 画像用の TerraMind と、高解像度 RGB 用の DINOv3 の 2 つを teacher にする。modality ごとに別の patch embedding を持たせ、共通の Transformer trunk に流し込むので、位置合わせ済みの co-registered なデータが要らない。TEDI-Large は PANGAEA-9 の単一 model 比較で最高の 62.51 mIoU で、2 つの teacher の両方を総合で上回る。TEDI-Base は 61.75 mIoU を、パラメータ 72% 減で達成。

## P2 への適用可能性

- P2 (FM 蒸留) の「実務で回せる recipe」にそのまま近い。loss は patch-level の特徴合わせという単純なもので、凍結 teacher + 小さい student という構成が明快で、**コストを teacher の事前学習比で示している**ので、手元で回すかの判断材料になる。
- 「student が teacher を上回る」(TEDI) 条件は、capacity gap (teacher と student の大きさの差で蒸留がうまく行かなくなる問題) への対処の観点でも見る価値がある。ここでは teacher を複数にして補い合わせている。
- 運転の文脈なら、大きな vision encoder を Jetson に載る大きさへ蒸留する、また camera と LiDAR のようにペアが揃わない modality を 1 つの trunk に集める、という 2 つの読み替えができる。
- 地理空間 (衛星画像) の結果であり、運転画像で同じ程度の利得が出るかは未確認。

## 試すべき実験アイデア

1. 手元の vision encoder (例: DINOv3 系) を teacher に凍結し、1/4〜1/8 のサイズの ViT を patch-level の特徴合わせだけで蒸留する最小実験を行う。公開されている同サイズの model との downstream 比較と、GPU 時間を記録する。
2. 蒸留した student が「1 つ上のサイズの公開 model」に並ぶ条件 (論文の主張) が、運転 domain の downstream task (segmentation や物体検出の head を凍結特徴の上に載せる) でも再現するか見る。
3. TEDI の構成を縮小して、2 つの異なる teacher (RGB 向けと別 modality 向け) を、modality ごとの patch embedding + 共通 trunk の student に蒸留してみる。

## 注意

abstract のみに基づく。loss の重み、特徴を揃える層の選び方、学習 schedule、teacher の画像サイズの扱いは未確認。比較対象の「公開された同サイズ model」の学習条件が揃っているかも、本文で確認が要る。
