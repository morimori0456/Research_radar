# See What I Need, Dream What I Want: A Navigation Foundation Model on a Self-Constructed Representation Space (2610.31762)

- トピック: next_arch (P3) / スコア 3.5 / 出所: RSS (cs.CV の cross、candidates.json には無し)
- URL: https://arxiv.org/abs/2610.31762

## 何を解決する論文か

vision foundation model (大規模データで事前学習した画像 encoder) の上に作る navigation policy は、どの視覚表現を使うかを encoder の事前学習 objective に任せがちで、policy 自身の目的に合わせた表現にはなっていない。RepresentNav は、policy の目的で作られる「自前の表現空間」を持ち、その中で少し先の場面を予測する (dream) navigation foundation model を提案する。

## 手法の核心

- **Representation Residuals**: 3 層の小さな transformer。複数の vision foundation model の、最終層だけでなく**全層の特徴**に attention をかけ、navigation に要るものを policy が選んで取り出す。
- **dream (latent chain-of-thought)**: 各 action の前に、少し先の場面の表現を latent 空間で予測する。これは JEPA (Joint-Embedding Predictive Architecture; 画素を再構成せず、未来の表現を表現空間で予測する自己教師あり学習) として policy と end-to-end で学習する。損失は next-representation prediction loss と、その target への正則化項。
- **結果**: VLNVerse、VLN-CE R2R (言語指示で目的地へ行く navigation benchmark)、EVT-Bench、2 つの point-goal benchmark で state of the art。VLNVerse の fine-grained で成功率 83.80% (従来の最高から +20.05 点)、EVT-Bench の distracted tracking で単眼 camera のまま 85.5% (+10.1)。実機でも、散らかった場所や動く人の中で効果が出る。
- **ablation**: 同じ encoder 群で、出力を単純に concat するより自前の表現空間が明確に良く、層の重みを不均等に学ぶ。dream を入れると衝突が 4 分の 1 減る。
- **観察**: dream した latent 1 つから、少し先の depth、semantics、3D occupancy が復元でき、しかも occupancy は supervise していないのに、実際の未来 frame に事前学習 encoder をかけた場合より正確。abstract は、これを「dream が compact な latent world model として現れた」としている。

## P3 への適用可能性

- P3 の関心である world model (予測・表現学習) を、**policy の内側の補助予測**として持つ設計の例になっている。別の world model を作らず、policy が自分の目的の表現を作り、その上で未来の表現を予測するだけで、衝突が減り、副産物として depth / occupancy も出る。
- 全層の特徴に attention をかけて層を選ぶ小さな module は、既存の driving encoder に後付けしやすい。
- navigation (室内外の移動) の結果であり、高速の運転で同じ効果が出るかは未確認。

## 試すべき実験アイデア

1. 手元の driving policy (または模倣学習の小さな baseline) の最終層特徴を使う部分を、複数層に attention をかける小さな module に置き換え、層ごとの学習済み重みを可視化する。
2. 次の frame の表現を予測する補助 loss (JEPA 型; target 側に正則化) を追加し、衝突率 / 違反率の変化を見る。
3. dream した latent に、depth や occupancy を読み出す線形 probe をかけ、supervise していない情報が入っているかを確かめる。

## 注意

abstract のみに基づく。Representation Residuals の入力層数、target への正則化の具体形、dream の予測先 (何 step 先か) は未確認。比較は navigation benchmark の範囲。
