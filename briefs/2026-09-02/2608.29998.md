# The Intervention Gap in Latent World Models — 報酬の当てはまりは、その世界モデルが介入を正しく動かすかを何も保証しない

**topic:** next_arch / **project:** P1 (主) · P3 (主) / **hf_upvotes:** 0
**スコア:** P1 **4.5** / P2 1.5 / P3 **4.5**

## 何を解決する論文か

著者は **intervention fidelity (介入忠実度)** を、world model の**独立に測れる性質**として立てる。定義は明快である —— **モデル自身の open-loop な遷移予測** (自分の予測を入力に戻しながら、環境に触れずに数ステップ先まで想像すること) **が、タスク変数を、環境側で同じ介入を行ったときと同じように動かすか。**

**そしてこれは、報酬の当てはまり (reward fit) からは見えず、タスク信号で学習させても保証されない。**

TD-MPC2 (潜在空間で価値と遷移を同時に学ぶ、model-based RL の代表的手法) の公開チェックポイントをサイズ違いで並べると、**タスク観測量に対する「作用素の誤差」が大きくなるほど episode return は下がる。一方で reward 予測誤差は小さいまま、ほぼ平坦である。**さらに、**タスク信号を一切使わない自己教師あり world model のほうが、同じタスクにおいてこの作用素をよく保存していた。**

## 手法の核心

- **capture-gated matched-intervention audit (捕捉判定つき・条件を揃えた介入監査)。**手順は 2 段階で、**まず「モデルがそもそもその問い合わせを内部に表現しているか (capture)」を判定し、表現している事例だけを対象に、次の測定へ進む。**表現していないものを混ぜて平均すると、**「表現していない」と「表現しているが間違っている」が混ざって何も分からなくなる。**
- **この capture ゲートが、R1 の言う「分母の健全性」そのものである。**測定対象として数える資格のある事例を先に選別してから割り算する、という発想。
- **失敗の中身が特定されている。**Cheetah (連続制御の標準タスク) では、LeWorldModel の 3 つのチェックポイントが**現在のタスク問い合わせを捕捉しており、実際の介入効果も表現から復号できる。**にもかかわらず、**想像した 5 ステップ先の効果は「効果ゼロと予測する」より悪く、環境側の終点オラクル (正解を知っている参照) より悪い。**
- **診断名まで付いている: task-direction rotation with excess gain (タスク方向の回転と、過大なゲイン)。feature collapse (表現が潰れて情報を失う現象) ではない。**つまり**情報は残っているのに、動かす向きと量が狂っている。**表現の質の問題ではなく作用素の問題である、という切り分け。
- **重症度は条件依存で、そこも正直に報告されている。**PreJEPA の 5 seed は、この激しい形にはならないが**オラクル比の不足は残る。**Finger Spin では移動系以外にも不足が及び、**seed 間で重症度がばらつく。**
- **実務側の付随知見が 3 つ。**(a) DreamerV3 では**事後分布そのもの**が現在の問い合わせを担っており、そこからのサンプルではない。(b) **ensemble disagreement** (複数モデルの予測のばらつき。不確実性の代理指標として広く使われる) **は学習データの近傍でしか誤差を順序付けられない。**(c) 凍結した support-aware スコアは、転移させると誤差の順序付けをむしろ悪化させる一方、**その場で計算した disagreement は両方向で有効なままだった。**
- 結論: **intervention fidelity は間接的に推定するのではなく、モデルの native interface 上で、捕捉判定を先に置いて、直接監査せよ。**

## P1 / P2 / P3 への適用可能性

**R1 にとって、これは方法論の完成した先例である。**R1 が主張しようとしている構造を並べると、ほぼ一対一で対応する:

| 本論文 | R1 |
|---|---|
| episode return / reward fit (既存の集約指標) | 衝突率 |
| intervention fidelity (隣に置く新しい量) | **solvability / mode coverage** |
| 「reward fit は intervention fidelity を明かさない」 | **「衝突率は逃げ道の残数を明かさない」** |
| capture-gated (資格のある事例だけ数える) | **抜け穴監査 (分母の健全性)** |
| task-anchored 学習は保証しない | (未検証) |

**特に capture ゲートの位置付けが重要である。**R1 の 3 本柱のうち「分母の健全性」は、これまで**抜け穴を潰す守りの作業**として書かれていた。**本論文はそれを、測定手続きの一部として前段に組み込んでいる。**「まず測る資格のある事例を選別し、その上で新しい量を測る」という 2 段構成は、**R1 の図 1 の構造としてそのまま使える。**

**そして最も刺さる 1 行は、reward 予測誤差が「小さいまま、ほぼ平坦」だったことである。**指標が飽和していて差を作らない一方、実際の性能は落ちている。**これは「既存指標が測れていない」の最も説得力のある示し方**であり、**本日の [Driving on Memory](2608.31029.md) の「記憶だけでスコアが落ちない」と、証拠の型が同じである。**2 本合わせると、R1 の主張は **「そういう例がある」から「異なる 2 分野で独立に同じ形で起きている」**に上がる。

**P3 (R3) には、W35 以降の議論に対する追加の材料が入る。**W35 の収束点「画素は world model の言語として粗すぎる」に対して、本論文は**潜在空間の world model でも同じ穴が空く**ことを示している。**つまり問題は表現の媒体 (画素か潜在か) ではなく、何が学習信号として届いているかである。**本日の [Video World Models](2608.30692.md) が「見えていない状態には勾配が届かない」と言い、**本論文が「タスク報酬で学んでも介入の作用素は保証されない」と言う。指している場所は同じで、監督の届かない範囲である。**

**加えて R3 の設計判断に効く反直観な結果が 1 つ: タスク信号なしの自己教師あり world model のほうが、作用素をよく保存していた。**「下流タスクに合わせて学習させたほうが良い」という標準的な直観と逆である。**R3 が VLA × world model の統合を考えるとき、「どこまでタスクに寄せるか」の線引きに直接影響する。ただし R3 は今月着手しない方針なので、軸への記録に留める。**

**P2 は 1.5。**接点は薄い。

### 試すべき実験アイデア

1. **【最優先・半日・09-06 の gate 用】走行ログで「介入残差」を測る。**手順は本論文の 2 段構成をそのまま移す —— **(a) capture: そのシーンで、比較したい介入 (例: 自車が減速する / しない) の効果がログから復号できるか判定し、できる区間だけを残す。(b) 測定: モデル (または simulator) が想像した数秒先の効果と、実際に起きた効果の差を取る。**そして **「効果ゼロと予測する」ベースラインより良いか**を確認する。**本論文の最も強い数字はここ (想像した効果が、効果ゼロ予測より悪かった) なので、同じベースラインを置くこと。**08-31 以降ずっと未着手の作業と、必要なログが同一である。
2. **【1 時間・紙のみ】R1 の図 1 を、本論文の対応表の形で下書きする。**左に「既存指標 (衝突率)」、右に「隣に置く量 (solvability)」、上に capture ゲート。**本論文が既にこの構造で通っているので、構成を考える時間はゼロで済む。**RoboPAD 09-10 の投稿判断 (09-06 gate) に必要なのは、実質この 1 枚である。
3. **【中期・R2 とも共有】ensemble disagreement の射程の主張を、自分の設定で確認する。**本論文の (b)(c) —— **不確実性の代理指標は学習データ近傍でしか誤差を順序付けられず、転移すると凍結スコアはむしろ悪化する** —— は、R1 が「保証付き」を名乗るなら踏まなければならない地雷である。**conformal prediction (予測の外れ率を分布仮定なしで保証する統計手法) を被せられる範囲の切り分け**は R1 のアイデア在庫にすでに書かれており、**「近傍でしか効かない」という本論文の結果は、その切り分けの外側の境界を 1 本与える。**
