# Stick to What You Know — 生徒が知らないことを教師にさせると、幻覚が生まれる

**topic:** fm_distill_finetune / **project:** P2 (主) / **hf_upvotes:** 0
**スコア:** P1 2.0 / P2 **4.5** / P3 1.5

## 何を解決する論文か

SFT (Supervised Fine-Tuning; 目標となる応答を用意して、それを模倣するように base model を学習させる標準的な適合手法) では、**目標応答が、base model がまだ確実に内在化していない知識を要求していることがある。**base model はその事実を持っていないのに、「持っているかのように流暢に答える」という振る舞いだけを学ぶ。**著者はこれを hallucination (モデルが事実でないことを自信を持って生成する現象) の発生源の 1 つとして扱う。**

そして既存の緩和手法群を **knowledge-aligned SFT (知識整合 SFT)** という 1 つの枠組みに整理する。定義は一行 —— **SFT の学習目標を、base model の parametric knowledge (追加の検索なしに、重みの中だけで想起できる知識) の範囲に制限する。**

## 手法の核心

- **既存手法を 2 系統に整理して、統一された設定で比較する。**(a) **generation-based** —— base model 自身に生成させたものを目標にする。(b) **estimation-based** —— 目標が base model の知識内かを推定してフィルタする。**バラバラに提案されてきたものを同条件で並べた点が、まず地味に効く貢献である。**
- **新手法 1: Evidence Rewrite。**base model の生成を**外部の証拠と照合して検証**し、通ったものを目標にする。**「base が言えること」と「事実であること」の両方を要求する。**
- **新手法 2: Recall Rewrite。**主張を**「base model が一貫して想起できるか」だけで残す。**一度言えたかではなく、**繰り返し安定して出てくるか**を条件にしている。**この「一貫して (consistently)」が効きどころで、たまたま出た知識を知識として数えない。**
- **結果: Qwen 3 4B と OLMo 3 7B、WildHalu と Biography (いずれも事実性の評価ベンチマーク) で、事実性の幻覚が減り、一般的な能力はおおむね保たれた。**
- **最も強いのは Recall Rewrite。**事実性の改善が最大で、加えて **UnknownBench での refusal (答えられない問いに対して「分からない」と答える振る舞い) も改善した。**幻覚を減らすと単に無口になっただけ、という失敗を避けられている。
- **結論: base model の知識を超えた SFT 目標が、幻覚を駆動している。**手法の勝敗より、**この因果の確認が本論文の主題である。**

## P1 / P2 / P3 への適用可能性

**R2 にとって、これは capacity gap の SFT 版であり、しかも治療の向きが逆である。**

蒸留の標準的な発想は **「生徒を教師に近づける」**である。capacity gap の議論も、生徒の表現力が足りないから追いつけない、という形で書かれてきた。**本論文の処方は反対で、教師 (= 学習目標) を生徒の届く範囲まで下げる。**そして下げたほうが良くなった。

**ここが本日の [OPD の論文](2608.31046.md) と組になる。**

| | 教師の扱い | 主張 |
|---|---|---|
| **Knowledge-Aligned SFT (本論文)** | 生徒の知識範囲まで**下げる** | 範囲外の目標が幻覚を作る |
| **OPD の分解 ([2608.31046](2608.31046.md))** | そもそも教師の内容を**使わない** | 利得は確率整形であり、教師由来ではない |

**方向は違うが、両方とも独立変数が同じである —— 教師の内容と、生徒がすでに持っているものとの関係。****R2 の系統則を、この 1 本の軸の上に書ける。**「容量比」という当初の独立変数が棄却された ([RESEARCH_PIPELINE.md](../../RESEARCH_PIPELINE.md) の R2 欄) あと、**代わりに何を置くかが 9 週間空いていた。本日、両端から挟む形で候補が 1 本立った。**

**そして R2 の次のアクションとして書かれている作業と、道具が完全に共通する。**R2 の欄には「過去の蒸留ログに CLL を後付けし、上位 1% 占有率が容量比とともに単調に動くか」とある。**Recall Rewrite の判定 —— 目標中の各主張を base model が一貫して想起できるか —— は、同じログに対して、同じ base model の logprob を使って、後付けで計算できる。****つまり共変量を 1 本増やすコストが、ほぼゼロである。**

**W35 の P2 の結論との整合も取れている。**「支配変数は loss ではなく周辺工程」であり、本論文の介入は**loss にも architecture にも触れず、学習目標のテキストだけを書き換えている。**5 例目にあたる。

**P1 は 2.0。**直接の接点はないが、**refusal の改善**は 1 点だけ引っかかる。「答えられない問いに答えない」ことは、**「実行可能な行動が無い状態を、無いと認識する」**ことの言語版であり、**R1 の solvability がゼロになった状態の検出と同型である。**幻覚を減らす処置が同時に refusal を改善した、という結果は、**「知らないことを知る」能力が副産物ではなく同じ機構であることを示唆する。**ただし本論文にその測り方は無い。

**P3 は 1.5。**

### 試すべき実験アイデア

1. **【R2・半日・既存ログのみ】過去の蒸留/SFT ログに「目標の想起可能性」を後付けで計算し、共変量として追加する。**各学習目標について、**base model が同じ主張を一貫して生成するか**を数回のサンプリングで判定し、スコア化する。**R2 の既存の作業 (CLL の後付け計算) と同じログ・同じモデル呼び出しで済むので、追加コストはほぼゼロ。****仮説は「想起可能性の低い目標の割合が高い設定ほど、蒸留の効きが悪い」。**これが成り立てば、棄却された「容量比」の代替独立変数になる。**ただし 09 月は R1 に絞る方針なので、実行は 10 月以降。**
2. **【1 時間・机上】自分の適合対象について「base が持っている / 持っていない」の線を引く。**09-01 の [VLAct](../2026-09-01/2608.27550.md) の実験 1 で書くことになっていた **「どこまで共有し、どこから専用にするか」の表**に、**列を 1 本足すだけで済む** —— 各項目について、**base model がすでに持っているか。**持っていないものを SFT の目標に混ぜている箇所が、本論文の言う幻覚の発生源である。**前提条件ゼロ・紙のみ。**
3. **【原論文の確認・30 分】「一般能力がおおむね保たれた」の "largely" がどれだけかを確認する。**知識を base の範囲に制限するということは、**base が知らない新しい知識を SFT で入れることを諦めるということでもある。**適合 (他機種・他ドメインへの転用) が主目的である P2 にとって、**この副作用の大きさは手法の採否を決める。**abstract では分からない。
