# Preserving General Capabilities during Domain Specialization with Uncertainty-Calibrated MOPD

**topic:** fm_distill_finetune / **project:** P2
**スコア:** P1 1.5 / P2 **4.5** / P3 1.5

## 何を解決する論文か

LLM を特定分野 (医療、ロールプレイなど) に特化させると、その分野は強くなる代わりに**推論・コーディング・指示追従・創作といった一般能力が落ちる。**著者はこの綱引きを **MOPD (Multi-Teacher On-Policy Distillation; 複数の教師を使い、student 自身が生成した軌跡の上で教師に添削させる蒸留)** の枠組みで扱う。domain teacher と general teacher の 2 人を置く構成そのものは既存だが、**素の MOPD には 2 つの穴がある** — student が自分で吐く軌跡には「教師と大きく差が出る token」がめったに現れず学習信号が薄い、そして差の符号 (教師の方が確率が高い) だけでは**その更新方向を信じてよいかが分からない。**提案手法は一般能力の平均をロールプレイで **+4.73%**、医療で **+10.84%** 改善しつつ、専門分野の性能は維持した。

## 手法の核心

- **Dual-temperature sampling** — student に軌跡を吐かせるとき、temperature (生成のばらつきを制御するつまみ。高いほど多様な出力が出る) を 2 種類使って候補の幅を広げる。**「学習の役に立つ token は、student が普段吐かない領域にある」という前提に立った、探索側の手当て。**
- **positive-advantage-density filtering** — 生成した軌跡のうち、**「教師の方が student より確率を高く付けた token」の密度が高いものだけを残す。**advantage (優位性; ここでは教師と student の食い違いの大きさと向き) が濃い軌跡に学習を集中させる。
- **CLL (Centered Log-Likelihood) filtering** — ここが本論文の中心。**advantage の符号だけでは足りないという診断に対する答えである。**教師の出力分布の entropy (不確実性の大きさ。分布が平坦なほど大きい) で較正した「教師がこの token をどれだけ本気で推しているか」のスコアを計算し、**方向と推しの強さが一致している token だけを確率的に残す。**教師自身が迷っている場所での更新を、確率的に捨てている。
- **ablation で「単に rollout を増やしただけの効果ではない」ことを確認している。**軌跡レベルと token レベルの 2 つの機構が、それぞれ狙った失敗モードに効いていることも診断実験で示している。

## P1 / P2 / P3 への適用可能性

**R2 (蒸留の capacity gap の系統則) に対して、08-28 に立てた仮説の検証手段をそのまま与える論文である。**

08-28 の DIGEST で書いた仮説はこうだった — **「student が小さいほど教師との食い違いは全体的に大きくなり、勾配は一部の token へさらに集中する。その集中度が閾値を超えたところが破綻の境界ではないか。」**この仮説は測る量が決まっていなかった。**本論文の CLL は、まさにその量の完成品である** — token ごとに「教師と student の食い違い」を教師の確信度で較正したスカラー。集中度は、この値の分布の歪みとして測れる。

**そして 08-28 の QLoRA frontier と本論文は、同じ現象を別の切り口で見ている。**QLoRA の論文は**「adapter の容量というつまみで、獲得と保持のトレードオフ曲線が引ける」**と示した。本論文は**「そのトレードオフは、どの token を更新するかを選ぶことで緩和できる」**と示している。**つまり容量は曲線の位置を決め、token 選択は曲線そのものを外側へ押す。R2 が主張したい系統則は、この 2 つの効果を分離できて初めて綺麗な形になる。**

**Echo-GRPO ([2608.26684](2608.26684.md)) と本日セットで読むべきである。**両方とも「student 自身の分布から離れた場所での更新は信用できない」という同じ命題を扱っており、**片方は教師の確信度で切り (本論文)、もう片方は教師の言葉を student の言葉に書き換える (Echo-GRPO)。**同じ病に対する、捨てる治療と直す治療。

### 試すべき実験アイデア

1. **【最優先・R2 の中間量を確定させる】過去の蒸留ログに CLL を後付けで計算する。**半日。08-28 の行動リストにある「勾配ノルムの集中度 (上位 1% の占有率) を測る」を、**勾配ノルムではなく CLL で行う。**勾配より計算が軽く、教師の出力分布さえ保存してあれば再学習が要らない。**上位 1% の CLL 占有率が、容量比とともに単調に上がるかどうか — これが R2 の予備実験の第一図になる。**
2. **【R2 の gate として書き下す】**08-28 に「これが出なければ本実験に進まない、という関門を 1 つ書く」という項目を立てた。**本日それを具体化できる: 「容量比を 3 点振ったとき、CLL の上位 1% 占有率が単調に変化しなければ、集中度仮説は捨てる。」**紙 1 枚。実装不要。**この 1 文を書くことが、今週できる最も安い前進である。**
3. **CLL filtering を「捨てる」ではなく「重みを下げる」に変えて感度を見る。**確率的に落とす設計は実装が簡単だが分散が乗る。連続的な重み付けで同じ効果が出るなら、R2 の実験系はより安定する。
