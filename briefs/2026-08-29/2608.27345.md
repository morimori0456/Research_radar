# PAWBench: How Far Are We from Probabilistically Aligned World Modeling?

**topic:** next_arch / **project:** P3 (主) · P1 (副) / **hf_upvotes:** 73 (本日最高、wildcard を除く)
**スコア:** P1 **4.0** / P2 1.5 / P3 **4.7**

## 何を解決する論文か

映像生成モデルを world model (環境の変化を予測・シミュレートするモデル) として使う流れが広がっているが、現在の評価は「生成された 1 本の動画がもっともらしいか」しか見ていない。しかし物理現象の多くは**同じ初期状態・同じ行動から複数の異なる結果があり得る** — コップを縁に押せば、落ちることも踏みとどまることもある。著者はここに **probabilistic alignment (確率的整合性; 同じ条件で何度も生成させたとき、結果の出現頻度が現実の確率分布と一致すること)** という要件を定式化し、それを測る PAWBench を作った。50 シナリオ・11 システムで測った結果、**正しい確率を再現しつつ起こりうる挙動の幅もカバーできたモデルは 1 つもなかった。**

## 手法の核心

- **評価の単位を「1 本の動画」から「同一条件での反復生成の分布」に変える。**world model を決定的な予測器ではなく **stochastic sampler (確率的サンプラー; 分布から標本を引く装置)** とみなす、という立場の宣言。
- **PAWEval** — 反復 rollout (モデルに最後まで生成させて 1 本の軌跡を得ること) を、**outcome-level (結果レベル)** の経験分布に変換するプロトコル。動画のピクセルを比べるのではなく、「落ちた/落ちなかった」といった離散的な結末に射影してから頻度を数える。**画質評価と挙動評価を切り離す設計になっている。**
- 参照確率は 50 シナリオごとに与えられ、**「正しい頻度を出せているか」と「起こりうる挙動を取りこぼしていないか」の 2 軸で採点する。**片方だけなら簡単に満たせる (常に多数派の結果を返せば頻度は近づくが幅は死ぬ) ため、2 軸同時が本質。
- **分布を後から動かせるかの介入実験も行っている** — 言語プロンプト、初期ノイズのサンプリング、追加学習の 3 つ。どれで分布が変わり、どれで変わらないかを切り分けている。

## P1 / P2 / P3 への適用可能性

**P3 (R3: VLA × world model 統合アーキテクチャ) への効き方が最も直接的である。**08-28 の 4 本で R3 の分類マップに「時間をどこに持つか」という軸が入ったが、**この論文は 2 本目の軸を与える — 「その world model は、未来を 1 本返すのか、分布を返すのか」。**統合アーキテクチャを議論するとき、下流の planner が world model に何を要求するかはここで決まる。1 本しか返せない world model の上に、複数シナリオを比較する planner は載らない。

**P1 (R1: 過保守も含めた保証付き評価) にとっては、指標設計の直接の参考になる。**trajectory prediction は本質的に multimodal (他車が右折するか直進するかは決まっていない) であり、**「1 本のもっともらしい予測」を評価する枠組みは AD でも同じ病を抱えている。**PAWEval の「結末に射影してから頻度を数える」という手続きは、そのまま **「左/右/停止のどのモードを、どの頻度で出したか」** に置き換えられる。これは 08-28 の DIGEST で「候補軌跡に左/右/停止のラベルを付けておけ」と書いた作業と、**同じ形をしている。**

### 試すべき実験アイデア

1. **【最優先・R1 に直結】走行ログの solvability 計算に、PAWEval 形式の mode coverage を同時に載せる。** 各シーンで predictor に N 回サンプリングさせ、結末 (左/右/停止/衝突) の経験分布を作る。参照分布は人間ドライバーの実測頻度。**「頻度は合っているが幅が死んでいる predictor」と「幅は出るが頻度が偏っている predictor」を分離できれば、R1 の主指標の候補が 1 つ増える。**ICRA 締切前に最初の図として使える形。
2. **過保守の定義を分布側から与えられないか試す。** 「危険側の結末に過大な確率を割り当てている」= 過保守、と定義できれば、**現在の「介入頻度」ベースの定義より測りやすい。**紙 1 枚で成立するか判定できる。
3. **【R3】手持ちの world model 候補 2〜3 本に対し、同一初期状態から 20 回 rollout して結末の分散を測るだけの小実験。**半日。**分散がほぼゼロなら、その world model は決定的予測器であり、R3 で「world model を別に立てる必然性」を主張する論拠が 1 つ消える。**逆に分散が出れば、それが必然性の証拠になる。
