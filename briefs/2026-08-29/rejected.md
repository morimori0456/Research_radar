### 惜しい不採用 4 本

- **2608.26788 (Decoupling Planning and Control for Instructable Agents) — 本日で最も惜しい 1 本であり、同時に topic 誤配の実例でもある。**
  `fm_distill_finetune` に分類されているが、**中身は VLA と world model の統合アーキテクチャそのものであり、正しくは next_arch に属する。R3 (VLA × world model 統合アーキテクチャ) の「既存統合手法の分類マップ作成」という次のアクションに、これ以上ないほど直接あたる論文である。**
  構成は **Instruct-to-Act** — **指示調整済みの VLM (Vision-Language Model) を planner として高レベルの言語指示を低頻度で出させ、world model controller をその指示で条件付けて高頻度に自律動作させる。**両者は言語だけで繋がる。**controller を言語で指示可能にするために、controller 自身の rollout を切り出して合成指示で再ラベルし、behavior cloning の目的関数を既存の報酬最大化・world modeling の目的関数と同時に最適化する。**
  **結果として最も重要なのは、事前学習済み VLM planner を fine-tuning なしで差し替えられることである。**7 環境 (うち 3 つは複数エージェントが言語で協調する設定) で、controller 単独・VLM 直接行動生成の両方を一貫して上回り、6/7 で強力な VLA・multi-agent RL の baseline に匹敵。
  **R3 の分類マップにおいて、これは「planner と controller を完全に分離し、界面を言語にする」という 1 つの極を占める。**08-28 の 4 本が埋めた「時間をどこに持つか」の軸とは直交する、**「界面を何にするか」という別軸の端点である。**08-26 の Gen2Sim、08-28 の Code World Model と並べると、**界面が「潜在 / コード / 言語」の 3 値で埋まる。**
  **落としたのは、内容で next_arch に再配置しても [PAWBench](2608.27345.md) 4.7 と [CLAP](2608.27406.md) 4.5 に quota で及ばなかったため。差は 0.1〜0.3 で、実質は同着である。R3 の分類マップを作る作業では、この 3 本を必ず同時に並べること。**
- **2608.27449 (SWE-Prime)** — **成功した agent trajectory であっても、無駄・冗長・危険な手順を含む。それをそのまま SFT (Supervised Fine-Tuning) に使うと、望ましくない解き方まで模倣させてしまう。**2 段の選別で対処する。第 1 段は軌跡単位 (過程の質・結果の質・代表性)、第 2 段は**連続するステップを意味のまとまりに区切ったセグメント単位で、最終解への寄与・学習可能性・危険性を評価する。**
  **設計として見るべきは、選ばれなかったセグメントも系列には残し、loss の計算からだけ外すこと。**文脈は保ったまま、模倣する対象だけを絞る。**選ばれた 10% の軌跡だけで学習した方が、全量で学習するより SWE-Bench Verified で相対 24.2% 良い。**
  **P2 への含意は明快である — 蒸留データの量を増やす前に、質の選別をやれ。**落としたのは検証領域がソフトウェア工学のエージェントに閉じており、[UC-MOPD](2608.26735.md) と [Echo-GRPO](2608.26684.md) が R2 の中間量に直接触れているのに対し、こちらは recipe としての一般則にとどまるため。**ただし「文脈は残して loss だけ外す」という実装上の工夫は、R2 の実験系でそのまま使える。**
- **2608.26550 (SPEAR)** — **RL ベースの蒸留は、疎な結果報酬 (最終的に正解したかだけ) では論理の導き方を教えられず、密な報酬を得ようとすると PRM (Process Reward Model; 推論の各ステップに点を付ける、別に学習したニューラルモデル) が要って高くつく、というジレンマがある。**SPEAR はこれを**学習不要**で解く。
  **自然言語の推論トレースを、分野ごとに適応した記号的な milestone (中間目標) の列に射影し、student と teacher の milestone 列を LCS (Longest Common Subsequence; 最長共通部分列。順序を保った一致部分の長さ) で照合して報酬にする。**順序を考慮した密な報酬が、外部のニューラル検証器なしで手に入る。コード公開済み。
  **落としたのは quota。**ただし **R2 が「蒸留の質を何で測るか」に踏み込む段階では、この「記号列に落として順序込みで比べる」という安い代理指標は有力候補である。**08-27 の PROOF-Gen で出た「蒸留の質は loss でなく教師の歩留まりで決まる」という論点とも接続する。
- **2608.27167 (Calibrated Enough to Know, Not Calibrated to Act)** — **P2 の枠では 3.0 だが、指摘している現象が R1 と地続きなので記録する。**
  **原理的に予測不可能な問いに対して、それらしい体裁の「市場パネル」を見せると、LLM エージェントの断定率が 6.5% → 54.0% に跳ね上がる。パネルの数値を全部でっち上げても 24.5% → 36.8% で、本物の市場データが生む 37.6% と統計的に区別できない。**行動を解禁しているのは情報ではなく、**情報の見た目の権威**である。
  **診断の切り分けが極めて丁寧で、そこが読む価値である。**能力不足ではない (答えられる問いには正確に答える)。信念のずれでもない (表明確率はほとんど動かない)。判断力の欠如でもない (事前に「これは予測不可能か」と聞けば 90% で正しく分類し、そう分類した場合は 0.4% しか断定しない)。**壊れているのは「行動するか否かの gate」だけであり、そこが分離できるから訓練で直せる。**3B モデルをサイコロ・コイン・壺・タイマーの合成事例 540 件で fine-tuning すると、断定率が 0.0% になり未見の領域にも転移する。
  **R1 との接点は「過保守」の裏返しにある。**R1 が測ろうとしているのは planner が慎重すぎることだが、**本論文が測っているのは「根拠が無いのに行動してしまう」方向の失敗である。**そして重要なのは、**その失敗が能力でも信念でもなく、行動判断の gate という分離可能な部品に局在していたという方法論。**planner の過保守も同じように分離できるなら、**「予測が不確かなときに減速する挙動」を、予測性能とは独立に測って独立に直せる。**落としたのは検証が LLM エージェントの金融質問に閉じているためだが、**方法論としての分離の作法は R1 の指標設計に移せる。**

- **2608.26771 (Cross-Architecture KD: DINOv2 → 軽量 Visual SSM)** — **落としたが、R2 に効く事実を 2 つ持ち帰る価値がある。**
  1 つ目: **intermediate feature-alignment loss (教師と student の中間層の特徴を近づける loss) を足すと精度が下がり、素朴な logit-level KD (最終出力の確率分布だけを合わせる蒸留) が最強だった。**アーキテクチャが根本的に違う (ViT の attention と SSM の selective scan) 場合、中間表現を無理に揃えるのは害になる、という実例。
  2 つ目: **22M の教師から 4.45M の student へ、容量比 5.0 倍で精度の 98.3% を保持。**R2 が引きたい「容量比 vs 破綻」の曲線上の、cross-architecture という条件での 1 点になる。
  **落としたのは検証が単一の茶葉病害データセットに閉じており、著者自身が SSM 実装の簡略化を limitation として認めているため。**ただし **3 seed・bootstrap 信頼区間・FLOPs/latency まで報告しており、小規模論文としての作法は良い。**
- **2608.26879 (Inverted Asymmetric Fusion)** — **多モーダル融合が単一モーダルの最良を下回るという現象に、「強いモーダルが融合で壊れている」(strong-modality collapse) という診断を与えた。**対称的な attention 融合で text pathway の精度が 74.9% → 56.4% に落ちる。対処は**支配的なモーダルを融合層で素通しし、弱いモーダルだけがそれを文脈として参照する非対称な構成。**P3 に 2.5 を付けたが、**VLA で視覚と言語をどう融合するかという設計判断に一般化しうる**ので、R3 の分類マップの脚注に置く。
- **2608.27266 (Naive Prompt Optimization)** — **複雑な prompt 探索は要らず、教師モデルで反復修正するだけの単線的な手法が GEPA と同等以上、しかも rollout が少ない。**「教師の推論の強さが、探索側の複雑さを部分的に代替する」という主張は蒸留の話と地続きだが、**重みを更新しないので P2 の蒸留・適合の軸から外れる。**
- **2608.26956 (RubricRM) / 2608.26585 (GRAS) / 2608.26948 (KISS-GS) / 2608.27397 (CAST) / 2608.27394 (RATIO)** — **いずれも relevance_criteria への接点が細く、quota 以前に基準に届かない。**なお 2608.26956 の rubric ベース報酬は、**08-28 に不採用とした V-Rubrics と同じ発想であり、2 日連続で同型の論文が来ている。**この系統が育つなら R2 の教師信号設計で拾う。

### 惜しい不採用 4 本

- **2608.27367 (Successive Capacity Growth) — R2 に対しては本日の採用 2 本に匹敵する価値がある。P2 に 4.3。**
  **JEPA (Joint-Embedding Predictive Architecture; 生の画素ではなく埋め込み空間で未来を予測する world model の系統) の ViT encoder は固定サイズで、簡単なタスクには過剰、難しいタスクには不足している。**SCG は**最小構成 (1 head・2 層・283K パラメータ) から始め、幅 (attention head を足す) か深さ (transformer block を足す) を段階的に伸ばす。**
  **設計の核心は「試して、駄目なら戻す」を安全に行える点にある。function-preserving expansion (拡張の前後でモデルの出力が厳密に一致するようにパラメータを初期化する手法) を使うので、拡張を試すこと自体はモデルを壊さない。**予測 loss が改善しなければ bit 単位で元に戻せる。**タスク非依存の判定機構で、誤った拡張がゼロ (false-positive 0 件) と報告している。**
  さらに **SIGReg (Sketched Isotropic Gaussian Regularizer) で学習された意味次元が統計的に独立に保たれ、拡張しても表現が collapse (全ての入力が同じ表現に潰れる現象) しない。**60 次元の多物体力学タスクでは深さ方向が選ばれ、固定小モデル比で予測 loss が 20.3% 改善、固定大モデルへスケールするより**パラメータ効率が 56 倍。**2D ナビゲーションでは幅を 1 回足すだけで固定大モデルを 23% 上回った。
  **R2 との関係は正面衝突に近い。R2 が引きたいのは「teacher/student の容量比と破綻境界のスケーリング則」で、本論文が示したのは「タスクの複雑さに対して必要な容量が決まり、それは自動探索できる」という主張である。**しかも**幅と深さのどちらが伸びるかがタスクによって違う** — つまり**容量は 1 次元のスカラーではない。R2 が「容量比」を単一の数で扱おうとしているなら、この論文はその前提に疑問を突きつけている。**
  **落としたのは next_arch の quota で PAWBench・CLAP に及ばなかったため。だが P2 の観点では本日 3 位であり、fm_distill_finetune に分類されていれば採用していた。R2 の予備実験を設計する前に必ず読むこと。**
- **2608.27328 (R2M-Bench)** — **08-28 の「記憶」の線を、評価側から直接引き継ぐ論文。**
  問題設定が鋭い。**「一度見た場所に戻ってきたとき、最初のフレームと戻ってきたフレームが似ている」ことは、モデルが覚えていた証拠にならない。**その間ほとんど何も動いていなかっただけかもしれない。**絶対的な revisit スコアは、描画の安定性・反復的な内容・動作の失敗に汚染される。**
  対処は**同一 rollout 内での相対較正である。**各 revisit について、**間隔を揃えた非 revisit の対 (一般的な時間安定性を測る) と、短区間の対 (短期の一貫性を測る) という 2 つの対照を同じ rollout から取り、その差を見る。**得られる指標が **MemoryGain (時間安定性の baseline に対する revisit の優位)** と **NMR (Normalized Memory Ratio; その優位を短期〜baseline の変動幅で正規化した値)。**
  **数字が主張を裏付けている。**NMR は人間の一貫性判断と Spearman ρ=0.547 (95% CI [0.45,0.63]) で相関し、**生成された動きの量との相関は 0.072** — 生の revisit 類似度の **0.207** に対して大幅に低い。**つまり「ゆっくり動けば高得点」という抜け穴が実際に潰れている。**
  **本日の [PDPO](2608.27158.md) と全く同じ話をしている。**PDPO は「エージェントが評価の抜け穴を突く」、R2M-Bench は「指標自体が抜け穴を含む」。**そして対処法まで同型で、どちらも「同じ条件から対照を取って差を見る」。R1 の指標設計に対して、この『同一 rollout 内対照』という手続きは直接移植できる**— 例えば「危険地点に遭遇したエピソード」と「間隔を揃えた遭遇なしエピソード」の差で過保守を測る、という形。**落としたのは quota だが、R1 の方法論としての価値は本日採用の CLAP より高い可能性がある。**
- **2608.26673 (PredVLA)** — **問いが良い。「言語条件付き制御に、本当にあれだけのモデル規模が必要なのか。」**
  **学習パラメータ 0.68M、ロボットデータでの事前学習なしの predictive-coding (予測符号化; モデルが感覚入力を予測し、その予測誤差だけで内部状態を更新する枠組み。神経科学由来) 方策で、LIBERO の短期 3 スイート平均 86.9%、長期を含めて 75.4%。**
  **主張の作り方が丁寧である。**front end・デモ・action decoder・評価手順を全て揃えた統制比較で、**パラメータ数を合わせた Transformer 方策の 3.7 倍、LSTM 方策の 7.4 倍の成功率。**「小さいモデルでも動く」ではなく「同じ大きさなら構造で 3〜7 倍違う」と言っている。
  **そして predictive-coding という定式化の副産物が測定に効く。観測が内部状態に影響するのは予測誤差による潜在推論の経路だけなので、それを切れば厳密な open-loop 制御 (観測を一切見ずに動く条件) が作れる。「観測がどれだけ効いているか」を近似なしで測れる。**
  **R2 への含意が刺さる — 「基盤モデルを蒸留して小さくする」以外に「そもそも小さい別構造を使う」という選択肢があり、しかも後者が勝つ領域がある。R2 が容量比の系統則を主張するとき、比較対象を『同じ構造での容量違い』に限ると、この事実を見落とす。**
  **落としたのは quota。R3 の分類マップには「大規模事前学習に頼らない極」として入れる。**
- **2608.27384 (FlashVLA)** — **08-28 の StreamPI の直系の続きであり、P1 の配備側に直接効く。**
  **flow-matching (ノイズから目標分布への連続的な変換を学習する生成手法。拡散モデルの親戚で、行動生成に使うと反復ステップが要る) ベースの VLA は、行動を出すのに複数回の反復が必要で遅い。**しかも**非同期実行 (推論しながら前の行動を実行し続けること) にすると、行動の繋ぎ目が滑らかでなくなる。**
  FlashVLA の設計は**「異なるノイズ水準の複数チャンクを buffer に保持し、chunk 単位の因果的 attention でまとめてデコードする」** — **1 回の推論で 1 つの実行可能チャンクが必ず出る。**そして**chunk 単位の自己回帰という定式化そのものが行動の連続性を暗黙に保証するので、未来状態を別途条件に与える必要がない。**単一 GPU で **30Hz 以上**の制御周波数。

- **2608.26645 (FLARE)** — **VLA が失敗から復帰できないのは、失敗の無い綺麗なデモだけで学習しているからだという診断。**対処は Retry (デモに摂動と橋渡し区間を注入して逸脱への対処を学ばせる) と Reset (MLLM で実行動画を解析して分布外状態を自動同定し、環境を有効な状態へ戻す小さなスキル集を集める) の 2 段。**P1 に 3.0。**「失敗データを意図的に作る」という発想は AD の評価データ生成にも移せるが、**指標の議論が無いため R1 には直接繋がらない。**
