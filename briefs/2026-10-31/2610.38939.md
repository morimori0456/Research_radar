# Optimization-based lane-changing trajectory planning in mixed traffic with embedded input convex neural networks (2610.38939)

- トピック: planner_ai (P1) / スコア 4.0
- URL: https://arxiv.org/abs/2610.38939

## 何を解決する論文か

人間の運転車が混在する交通での lane change では、周囲の挙動の予測を最適化に組み込みたいが、neural network をそのまま最適化に入れると計算が重い。通常の方法は MIP (Mixed-Integer Programming; 整数変数を含む最適化) に落とすが、binary 変数が増えて遅くなる。この論文は network を凸に制約し、LP (Linear Programming; 線形計画) で解ける形にして trajectory planner に埋め込む。

## 手法の核心

- **ICNN (Input Convex Neural Network)**: 入力に対して出力が凸になるよう構造を制約した network。凸なので最適化に組み込んでも局所解の問題が起きにくい。
- **安全 cost の surrogate (重い計算を近似する軽い model)**: 計画軌道を encode する ICRNN (入力凸の recurrent network)、lane change の所要時間を埋め込む FICNN (全入力に凸)、それらと過去の交通状態を融合する PICNN (一部の入力にだけ凸) の decoder から成る。
- **快適性 cost**: 最適な横方向の快適性 cost を、所要時間の関数として別の FICNN で近似する。
- **軌道は Bézier curve で表現**する。surrogate は LP として埋め込むので binary 変数が要らず、最適解で厳密であることも理論的に示している。
- 結果: surrogate の精度は制約なしの baseline に匹敵し、最適化効率は従来の MIP より大幅に改善。closed-loop simulation で重み付き planning cost が下がり、baseline を上回る。

## P1 への適用可能性

- 「学習した cost を、classical な最適化 planner に保証を保ったまま入れる」ための具体的な実装方法である。Learning-based な予測と rule-based な planner の接続に使える。
- 安全と快適性を別の surrogate に分ける構成は、評価指標の分解と揃えやすい。cost の項ごとに失敗を説明できる。
- 凸制約は表現力を落とすはずだが、精度が制約なしに匹敵するという主張は確認の価値がある。割り込みのように多峰的な挙動では凸性が足りない可能性がある。
- 注意点: lane change 専用で、一般の urban 走行にそのまま広がるとは書かれていない。

## 試すべき実験アイデア

1. 手元の lane change scene の安全 cost を、MLP と ICNN の 2 通りで fit し、精度差と最適化時間を比較する。凸制約の精度 cost を最初に測る。
2. ICNN の cost を sampling-based planner と LP 埋め込みの両方で使い、同じ cost での planning 品質と latency を比べる。LP にする意味の有無が分かる。
3. 周囲の車が譲る / 譲らないの 2 峰がある scene で surrogate の誤差を測り、凸性が破綻する条件を特定する。
