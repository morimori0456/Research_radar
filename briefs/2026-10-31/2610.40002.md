# How Much Should a VLA Trust Its Reasoning? Step-Level Guidance as a Measured Action-Value Function (2610.40002)

- トピック: next_arch (P3) / スコア 5.0
- URL: https://arxiv.org/abs/2610.40002

## 何を解決する論文か

reasoning VLA (vision-language-action; 画像と言語から行動を出す model のうち、推論文を書いてから行動を生成するもの) は、推論文 (reasoning trace) が誤ると行動も誤り、正しそうな文でも計画を惑わすことがある。従来は「推論が正しいか」を判定してきたが、この論文は「推論にどれだけ行動を引っ張らせるか」を問う。その強さを行動生成の step ごとに調整し、end-to-end driving の open-loop と closed-loop の両方で検証する。

## 手法の核心

- **CoC-CFG**: classifier-free guidance (条件ありと条件なしの予測の差を重みで増幅する手法) を、policy の context と、そこから推論部分だけを除いた context の間に掛ける。abstract に CoC の展開は無い (Alpamayo の Chain of Causation を指すと思われるが未確認)。
- **step ごとに重みが 1 つ**: 行動を生成する ODE を解く Euler step (連続時間の生成過程を小刻みに進める 1 回分) ごとに重み w を持つ。w=1 で元の policy に戻るので、既存 model を学習し直さずに掛けられる。
- **重みの選択を MDP (Markov Decision Process; 状態と行動の逐次意思決定の定式化) として扱う**: expert を凍結して noise も固定すると、ある step だけ重みを変え、残りを現在の controller で最後まで生成すれば、その重みの value が正確に得られる。bootstrap (value の推定値から次の推定値を作る) が要らない。
- **Q-adaptive guidance**: この測定値に小さな critic (状態と重みから value を予測する network) を fit し、controller を保守的に改善する。
- 結果: Alpasim (運転 simulator) の open-loop で全ての固定重みと online RL (SAC、GRPO [Group Relative Policy Optimization; PPO の簡略版]) を上回る。closed-loop は 300 scene 中 262 passed で、元の policy は 252。Waymo の end-to-end driving benchmark の hidden test では、凍結した Alpamayo 1.5 に rule-based な camera・車両の変換と本手法を足して rater feedback score 8.135 (既存の最良 8.079)。

## P3 への適用可能性

- reasoning 付きの運転 model を、**再学習なしで推論時の制御だけ**改善できる。推論文の質を上げるより先に試せる。
- 「推論を使うかどうか」を二択でなく step 単位の連続量にしたのが新しい。推論を言語の出力としてでなく、行動生成への条件の 1 つとして扱う設計になる。
- 生成 model の「1 step だけ変えて最後まで走らせる」で value を厳密に測る、という評価の作り方は、VLA 以外の diffusion 系 planner にも移せる。
- P1 への波及: w=0 と w=1 で軌道が大きく変わる scene は「推論が効いている scene」なので、失敗分析の切り口になる。
- 注意点: CFG は 1 step あたりの model 評価が増えるので推論 latency が上がるはず (abstract に記載なし)。8.135 には rule-based 変換の寄与も含まれ、本手法だけの gain ではない。

## 試すべき実験アイデア

1. 手元の reasoning 付き policy で w を {0, 0.5, 1, 1.5, 2} に固定し、open-loop の軌道誤差を scene ごとに測る。scene ごとの最適 w がばらつかなければ、adaptive 化は不要と分かる。
2. Euler step の前半だけ、後半だけに w を掛けて比べる。推論が粗い経路に効くのか、細かい調整に効くのかが分かる。
3. 測定 value で小さな critic を学習し、critic の入力に「言語 span の長さ」「teacher との不一致」を足す。低 cost な拡張で済むか見る。
4. 推論 span を除いた context に対する感度を、P1 の失敗予告 (SRP 2610.37299) の signal として足し、失敗の予告精度が上がるかを見る。

## 注意

abstract のみに基づく。262 と 252 の差は 300 scene で 10 scene で、信頼区間は abstract に無い。Waymo の "first three stages" が何を指すか、closed-loop で固定重みとの比較があるか、critic の学習に要する rollout 数と推論 latency は未確認。
