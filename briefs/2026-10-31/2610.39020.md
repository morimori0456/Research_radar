# Distilling the Shape of Uncertainty: What On-Policy Distillation Learns and How to Predict It (2610.39020)

- トピック: fm_distill_finetune (P2) / スコア 4.5 / arXiv RSS から回収 (fetch 天井の外)

## 何を解決する論文か

OPD (On-Policy Distillation; student が自分で生成した出力に teacher が supervision を付ける蒸留) では、強い teacher を使っても student が伸びないことがある。原因は「新しい知識が足りない」と説明されてきたが、その知識の中身は不明だった。この論文は、OPD で移るものが「どの token を候補にするか」だけでなく「どこで分岐の余地を残すか」でもあると示し、蒸留の前に最適な teacher を予測する指標を提案する。

## 手法の核心

- **how to branch と where to branch を分離**: 前者は候補 token の選び方、後者は推論の経路をどこで開いたままにするかである。従来の token-overlap metric (上位候補の重なりの指標) は前者しか見ていない。
- **entropy shape**: 次の token の entropy (分布の不確実さ) を出力の列に沿って並べた系列。
- **ESC (Entropy Shape Correlation)**: student と teacher の entropy shape の一致度を測る指標。
- **因果の検証**: 学習中の ESC を追跡し、さらに teacher の token の好みを保ったまま entropy だけを介入して変える。where to branch が how to branch と独立に OPD の gain を生むと示す。
- **teacher selection**: OPD の結果予測を teacher 選択の task として定式化し、評価 protocol を作る。蒸留前の ESC が 2 つの student のどちらでも最良の teacher を選び、既存の予測指標を上回る。

## P2 への適用可能性

- **学習を回す前に teacher を選べる**ので、蒸留の実務で最も高い cost (外れ teacher での学習) を減らせる。「一番強い model を teacher にする」という既定の判断を、測定で置き換えられる。
- 昨日の MPOPD (2610.36477) と CARD (2610.36445) は gap を埋める手法で、ESC はそもそも gap の測定にあたる。先に ESC で測り、悪いときだけ手法を足す順序にできる。
- 「teacher の予測値だけでなく、不確実さの形を移す」という見方は、soft label の temperature を調整する既存の直感を、系列に沿って測れる形にしたものと読める。
- 注意点: 対象は LLM の text 推論で、student は 2 つのみ。運転 model には「次の token」がないので、entropy shape の定義を読み替える必要がある。

## 試すべき実験アイデア

1. 公開 code で、手元の student と teacher 候補 3 体の組について、蒸留なしで ESC を計算し、実際に蒸留した gain と順位が合うかを見る。
2. 視覚 model では、pixel や patch ごとの予測 entropy の map を entropy shape の代わりにし、teacher と student の相関を取る。分類精度より良い teacher 選択の指標になるかを比べる。
3. trajectory prediction では、時刻ごとの mode の entropy (候補軌道の分散) を系列にする。teacher と student が「どの時点で迷うか」の一致度を、蒸留の事前診断に使う。

## 注意

abstract のみに基づく。teacher と student の具体的な組、ESC の相関の大きさ、entropy の介入の方法、既存の予測指標の種類は未確認。student が 2 つだけなので、teacher selection の一般性は確定していない。
