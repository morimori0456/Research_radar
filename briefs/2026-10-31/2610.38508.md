# SaiVLA-JEPA: Evaluating Future Latent Prediction in JEPA-Conditioned VLA Control (2610.38508)

- トピック: next_arch (P3) / スコア 4.0 / arXiv RSS から回収 (fetch の窓または天井の外)
- URL: https://arxiv.org/abs/2610.38508

## 何を解決する論文か

JEPA (Joint-Embedding Predictive Architecture; 画素でなく表現を予測する学習方式) の特徴量を既に使っている VLA (vision-language-action; 画像と言語から行動を出す model) に、「将来の表現を予測する補助 loss」を足すと closed-loop の制御は良くなるのか。この問いを、同じ条件を揃えた 10,030 組の paired episode で検証する。結論は「現在の特徴を入れる効果は大きいが、将来予測の supervision は検出できる gain が無い」である。

## 手法の核心

- **SaiVLA-JEPA**: vision-language model、diffusion transformer の action expert (行動を生成する専用の network)、凍結した V-JEPA encoder (JEPA の動画版) を組み合わせた flow policy (noise から行動へ流す生成 policy) の系列。
- 補助 head 2 つが学習時だけ将来の表現を予測し、推論では外すので、action sampler は変わらない。
- 3 条件を LIBERO-Plus (robot manipulation の simulation benchmark) で比較する: JEPA 特徴なし、現在の JEPA 特徴あり、さらに将来の supervision あり。
- 結果: JEPA 特徴なし 71.6% → 現在の JEPA 特徴あり 約 82.5%。将来の supervision は、評価した学習予算では aggregate で検出可能な gain なし。
- テスト時の適合も 2 種類試す。latent の context を適合させる TCA の context-retry による gain は、試行回数を増やした system レベルの結果。parameter を適合させる TPA は、凍結 policy や対照群に対して一貫した優位がない。

## P3 への適用可能性

- JAM (2610.37219; 将来予測を補助 loss にして制御を改善) と MoGAP (2610.36624; 動く領域に予測を集中) の「学習時だけ将来予測を足す」系統に対する、**直接の反証候補**である。今週の P3 の方向を決める前に読むべき。
- 効いたのは「将来を予測すること」でなく「良い視覚表現を入れること」だった。driving model でも、foresight loss の前に backbone を強い事前学習に替える効果を測るのが先になる。
- 「latent の loss が下がっても、制御が良くなるとは限らない。paired の closed-loop rollout で測れ」という教訓は、P1 の評価設計にも当てはまる。
- 注意点: "at the evaluated training budget" の限定付きで、予算を増やすと結果が変わる余地がある。JEPA 特徴が既に時間情報を持つので、将来の supervision の余地が小さかった可能性もある。JAM の結論と両立しうるので、片方だけを信じない。

## 試すべき実験アイデア

1. 手元の driving model で 3 条件 (事前学習特徴なし、あり、あり+foresight loss) を同じ seed・同じ scene の paired で比較する。差を scene ごとの対応差分で検定する。
2. 学習予算を 1 倍、2 倍、4 倍にして foresight loss の gain を測る。予算依存なら JAM との矛盾が解ける。
3. foresight loss の値と closed-loop の成績の相関を、学習の checkpoint ごとに取る。latent loss を model 選択に使ってよいかが分かる。

## 注意

abstract のみに基づく。効果量の信頼区間、学習予算の具体値、manipulation の結果が運転に移るかは未確認。"no detectable gain" は gain が無いことの証明ではない。
