# GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives

- arXiv: https://arxiv.org/abs/2609.39601
- 投稿日 (HF 記録): 2026-09-29 / hf_upvotes: 227 / 枠: sns_wildcard → P3 寄りで採用
- 評価: 3.5 / 5 (abstract のみで評価。abstract は末尾が途切れており、手法の詳細・学習 recipe は未確認)

## 何を解決する論文か

grounding (画像中で「どの物体が対象か」と「それがどこにあるか」を点や box で答えるタスク) は、ロボット制御や運転で closed-loop (出力を即座に制御へ戻す閉ループ) に使うには、散らかった場面や小さな物体でも正確で、かつ速くなければならない。ところが VLA (Vision-Language-Action; 画像と言語から行動を直接出すモデル) や WAM (world-action model; 将来予測と行動生成を一体で行うモデル) は、perception を汎用の vision-language / video-generation backbone から借りており、この条件で失敗する。GroundingPI は grounding 専用の 4B 規模の foundation model を作り、VLA/WAM の視覚 backbone として差し替えられるようにする。

## 手法の核心 (abstract から読み取れる範囲)

- 点と box を「座標を量子化した token」として通常の語彙と共通の vocabulary で生成する (別の検出 head を持たず、言語モデルの出力として扱う)。
- 学習は multimodal / spatial の pretraining → SFT (supervised fine-tuning; 教師あり微調整) → GRPO (Group Relative Policy Optimization; PPO の簡略版で LLM の RL 学習に使う) による RL の段階構成。
- 公開 dataset と専用の data engine (自動でラベルを増やす仕組み) から supervision を得る。
- 評価は 34 benchmark・11 種の perceptual capability・44 baseline。平均 73.68% で、より大きい GPT-6 Astra (71.54%) を上回ると報告。
- 下流評価: RoboTwin 2.0 (双腕ロボットの simulation benchmark) の OOD (訓練分布外) 4 設定すべてで主要 backbone を上回り (最大で相対 +24.8%)、RoboCasa-GR1 では demonstration 50% で baseline の 75% 学習を上回る。nuScenes (運転の公開 dataset) では backbone として使い open-loop L2 error (予測軌道と実軌道の距離) 平均 0.296 m。

## プロジェクトへの適用可能性

- **P3 (次世代アーキテクチャ)**: 主対象。「VLA の perception が弱点であり、grounding に特化した backbone を差し替えるだけで下流が伸びる」という主張は、E2E 運転の視覚 encoder を何で初期化するかの判断材料になる。座標を語彙 token として出す設計は、運転で「前方車両・歩行者の位置」を言語モデル側に渡す中間表現の候補。
- **P2 (蒸留 + 適合)**: 「demonstration 50% で baseline の 75% 相当」はデータ効率の主張で、他ドメインへの適合の観点で参照価値がある。4B を小型化して closed-loop で回せるか (蒸留の対象になるか) は未検証で、論文からは分からない。
- **P1 (Planner AI + 評価)**: 直接の接点は薄い。nuScenes の open-loop L2 は planner 評価としては弱い指標なので、数字の扱いには注意が要る。

## 試すべき実験アイデア

1. 公開されていれば GroundingPI の encoder / 出力を、手元の E2E 運転 baseline の視覚 backbone と差し替え、同じ学習設定で nuScenes の L2 だけでなく衝突率なども比較する (open-loop L2 だけでは差が出ても意味が薄い)。
2. 小さな物体 (遠方の歩行者・信号) に絞った grounding 精度と、planner の失敗ケースの対応を見る。「perception の失敗が planner 失敗の何割か」を切り分ける診断になる。
3. 4B を数百 M 規模に蒸留し、closed-loop に載せられる遅延で grounding 精度がどこまで残るかを測る (P2 との接続)。
