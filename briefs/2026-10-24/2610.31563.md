# When to Follow the Teacher: Advantage-Based On-Policy Distillation (2610.31563)

- トピック: fm_distill_finetune (P2) / スコア 4.5
- URL: https://arxiv.org/abs/2610.31563

## 何を解決する論文か

On-policy distillation (OPD; student 自身が生成した trajectory の上で、teacher が各 token の確率で教える蒸留) は、teacher の出力を固定で真似る SFT (supervised fine-tuning) より強いことが多い。ただし標準の OPD は「teacher の好みに合わせること」が常に student の役に立つと仮定して、全ての状態で teacher に従わせる。この論文は、teacher が好むことと、いまの student が成功するのに実際に役立つことを区別し、役立つ teacher の行動だけを強く学ばせる。

## 手法の核心

- **AOPD (Advantage-Based On-Policy Distillation)**: teacher の各行動を、student の下での counterfactual advantage (その行動を取った場合に student の期待結果がどれだけ良くなるか) で重み付けする。結果を改善する行動は強化し、そうでない行動は重みを下げる。
- 問題: advantage を正しく求めるには、各ステップで別の teacher の行動を試して rollout をやり直す必要がある。
- 解決: AOPD の目的関数は、通常の student rollout と最終 reward だけで推定できると示す。teacher の importance weight (teacher と student の確率の比) を、student が実際に選んだ行動に掛けることで、追加 rollout なしで不偏 (unbiased) な advantage 重み付き supervision が得られる。
- 結果: 数学・コード・MedQA (医療 QA) で、蒸留と RL のベースラインより良く、外部 teacher と self-distillation (自分自身を teacher にする) の両方で効く。
- 計算は標準 OPD と同じ rollout 効率のまま。

## P2 への適用可能性

- 蒸留 recipe として「全 token 一様」から「student に効く token へ」の重み付けに変える 1 ステップで、capacity gap (teacher と student の能力差が大きすぎて teacher の出力を真似しきれない問題) の緩和に直結する。teacher が強すぎる設定ほど、従わなくてよい箇所を見分ける意義が大きい。
- 必要なのは最終 reward (正誤など) だけで、追加 rollout は要らないので、既存の OPD run にそのまま足せる。
- 対象は LLM の reasoning/coding/QA。視覚や運転 model に移すには、最終 reward の定義 (例: closed-loop score) が要る。

## 試すべき実験アイデア

1. 手元の OPD (または logit distillation) run に importance weight × terminal reward による advantage 重みを足し、同じ計算予算で standard OPD と比べる。
2. 重みが小さくなる (teacher に従わない) token/状態がどこに集中するかを集計する。teacher が強すぎて真似るべきでない箇所が見えるなら、capacity gap の診断として使える。
3. 昨日の OnQ (低 bit 量子化の OPD) の student 側設定で AOPD に替えたとき、2 bit の崩れが追加で減るかを小規模で確かめる。

## 注意

abstract のみに基づく。advantage 推定の分散、reward が疎なとき (正誤だけのとき) の安定性、teacher の importance weight が極端に大きい token の扱い (clipping の有無) は未確認。
