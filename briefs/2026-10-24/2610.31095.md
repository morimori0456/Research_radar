# To Route or to Adapt? Multi-Expert Diffusion Planners in Unseen Regions (2610.31095)

- トピック: planner_ai (P1) / スコア 4.0 (arXiv RSS から回収・candidates.json には無い。P2 の「別ドメインへの適合」にも当たる)
- URL: https://arxiv.org/abs/2610.31095

## 何を解決する論文か

地域ごとの expert adapter (共通の planner に差し込む小さな追加 module) を持つ diffusion planner (軌道を noise から段階的に生成する planner) が、学習していない地域 (unseen region) に出たとき、「既存の expert から良さそうなものを選ぶ (route)」のと「planner 自体を新地域で適合させる (adapt)」のどちらが効くかを調べる。結論は、選ぶ方式は頭打ちで、新地域のわずか 20 シーンでの fine-tuning のほうがずっと効く、というもの。

## 手法の核心

- 設定: 共有 adapter と地域別 expert adapter を持つ diffusion trajectory planner。実世界の held-out の地図 3 つで、自車の横ずれ (lateral offset; planner の軌道と人間の走行軌跡の横方向の距離) を測る。
- route の限界: 8 種類のテスト時 routing 方式のどれも、全シーンで同じ expert を使う static default より fleet-mean lateral offset を改善しない。シーンごとに最良の expert を選ぶ oracle でも、平均で 0.9 m しか減らない。
- adapt の効果: 新地域 20 シーンでの reward-based fine-tuning (報酬で planner を直接最適化する fine-tuning) で大きく改善する。joint replay (元の地域の学習シーンも混ぜて再学習) だと fleet-mean offset が 6.9 m、static default は 12.4 m。replay が元の地域での忘却 (forgetting) も抑える。
- nuPlan (自動運転 planner の標準 benchmark) では、学習した都市をまたぐ fine-tuning で open-loop offset は良くなるが、closed-loop (planner の出力で自車が実際に動く評価) は悪化する。
- 診断: 2 つの test-time adaptation (推論時に model を調整する手法) のベースラインは、低い offset を「退化した軌道」で出していた。offset の数字だけでは良し悪しが判断できない例になっている。

## P1 への適用可能性

- 評価の読み方として直接使える。open-loop の offset 指標が良くなっても closed-loop が悪化する、退化した軌道でも offset が低く出る、という 2 点は、手元の planner 評価でも「指標の改善を信じてよいか」のチェック項目になる。
- 地域・車種・センサが変わる展開では、expert を増やして routing を磨くより、少数シーンでの適合に投資したほうが費用対効果が高い可能性を示す。P2 の「他機種・他ドメインへの適合」とも重なる。
- 対象は軌道の生成が diffusion の planner。手元の planner が回帰型でも同じ傾向かは未確認。

## 試すべき実験アイデア

1. 手元の planner を新しい地域/条件に出すとき、(a) 既存条件で学習した expert の選択、(b) 20〜50 シーンでの fine-tuning (+ 元データの replay) を同じ評価セットで比べ、route の oracle との差が 1 m 前後で頭打ちになるかを見る。
2. 適合後の評価では、open-loop の offset と closed-loop の score (衝突・進捗・快適性の内訳) を必ず並べ、nuPlan と同じ「open-loop は上がり closed-loop は下がる」乖離が出ないかを確認する。
3. 評価 script に「退化した軌道」の検出 (例: 軌道が静止または直線に潰れていないか、シーン間で多様性があるか) を足し、低 offset が本物かを判定できるようにする。

## 注意

abstract のみに基づく。reward の具体的な形、20 シーンの選び方、offset の絶対値の意味 (6.9 m / 12.4 m は fleet-mean で、planner の質を直接表すか) は未確認。
