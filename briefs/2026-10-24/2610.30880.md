# One Teacher, Many Views: Reducing Reference Sensitivity in On-Policy Self-Distillation (2610.30880)

- トピック: fm_distill_finetune (P2) / スコア 4.0 (arXiv RSS から回収・candidates.json には無い)
- URL: https://arxiv.org/abs/2610.30880

## 何を解決する論文か

OPSD (On-Policy Self-Distillation; 自分自身の trajectory の上で、正解の参照解 reference を見せた「特権付きの自分のコピー」が各 token の確率で教える蒸留) では、teacher は reference 全体を見て条件付けされる。reference は答えの証拠であると同時に、解き方の順序・言い回し・経路も含むので、teacher の出力が推論時には student が持たない情報に頼りすぎる。この論文は、別の正しい reference に替えただけで teacher の分布が大きく変わる (reference-induced target instability) ことを示し、その対策を提案する。

## 手法の核心

- 問題の定義: 問題文と student の状態を固定したまま reference を別の正解に替えると、teacher の next-token 分布が大きく変わる。これを reference-induced target instability と呼ぶ。
- **MCPD (Monte Carlo Privileged Distillation)**: 特権情報を「reference の部分的な view (一部だけ見せたもの) の分布」として扱い、複数の view で teacher を評価して、得られた next-token 分布を平均したものを蒸留の target にする。
- 理論: この確率空間での平均は、「view の分布の下で teacher→student の KL divergence の期待値を最小化する」解と一致する (exact target)。
- 結果: 数学・科学の reasoning benchmark で、full-reference の OPSD より一貫して良く、より reference に依存しない supervision になる。
- 追加の学習 model は不要で、teacher の forward を複数回回すだけ。

## P2 への適用可能性

- 「teacher が student に無い情報 (正解ログ、特権センサ、教師用 label) を見ている」蒸留全般の安定化に使える発想。運転の蒸留でも、teacher だけが将来の情報や GT 地図を見る設定はよくあり、そこで teacher の出力が特権情報の細部に過敏だと student が学べない。
- 診断が安い: 同じ入力で teacher の特権情報を 2 通りに替えて出力分布の KL を測れば、不安定さが分かる。
- 対象は LLM の reasoning。特権情報が連続値の情報 (点群・地図など) の場合、「部分的な view」の作り方は設計が要る。

## 試すべき実験アイデア

1. 手元の蒸留で teacher の特権入力を 2 つの等価な版 (例: 別の annotation、別の順序) に替え、teacher の出力の食い違い (KL) を集計する。大きければ MCPD 型の平均化が効く候補。
2. view の数 (2 / 4 / 8) と teacher の追加計算の増加に対する性能の伸びを測り、費用対効果が合う点を探す。
3. 特権情報を部分的に隠す方式 (ランダムに一部だけ見せる) で teacher を評価し、平均化した target で student を学習して、full 特権の teacher との差を比べる。
