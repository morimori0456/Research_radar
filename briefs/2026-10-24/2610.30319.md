# TerraTransfer++: Demonstration-Free End-to-End Planner (2610.30319)

- トピック: next_arch (P3) / スコア 4.5 (蒸留・適合の観点で P2、planner として P1 にも関係する)
- URL: https://arxiv.org/abs/2610.30319

## 何を解決する論文か

end-to-end 自動運転 (画像から直接軌道や行動を出す) の標準的な学習はどの方式も高コストである。imitation learning (人間の運転ログを真似る) は大規模な走行ログが要り、衝突寸前などの稀な状況をほとんど含まない。photorealistic な simulator での closed-loop RL (試行と報酬で学ぶ) は、描画と大きな視覚 backbone の計算が重くて sample 効率が悪い。この論文は、軽い vectorized simulator (画像でなく scene-state のベクトルで動く高速 simulator) での self-play で作った policy を teacher にして、人間の demonstration なしで画像入力の end-to-end model を作る。

## 手法の核心

- **self-play で teacher を作る**: 毎秒数百万 step の vectorized simulator で、基本的な運転品質の reward だけから自己対戦させる。ログに無い衝突・near-miss・回復の分布が自然に得られ、反応の速い policy ができる。
- この self-play policy の rollout を flow-matching (ノイズから軌道へ連続的に変換する生成手法) の trajectory teacher に蒸留する。teacher は 2 種類 (closed-loop policy と planner)。
- **student**: 凍結した事前学習済みの視覚 backbone の上に軽量な adapter だけを学習する。損失は action の KL divergence、batch 内の関係構造を揃える low-rank structural loss、planner 側は trajectory-matching loss。teacher の latent 空間を再現させる。
- 全ての target は self-play policy に由来し、ログの軌道を正解にしない。必要なのは (画像, scene-state) の対応データだけ。
- 結果: 3D Gaussian splatting による photorealistic な closed-loop benchmark HUGSim で、公開されている imitation 系 end-to-end 手法を全て上回る closed-loop policy。planner は NAVSIM (自動運転 planner の benchmark) の navhard で 59.4 EPDMS (Extended PDM Score; 衝突・進捗・快適性などを合成した score)、既存最良 DriveZero-Scale の 57.1 を上回り、navtest で 95.5 PDMS (EPDMS の元になった旧版の score)。

## 適用可能性

- P3: end-to-end 学習の「データの出どころ」を人間のログから self-play に替える設計。ログが薄い安全上の稀な状況の扱いが主な利点。
- P2: 蒸留と適合の組み合わせ。teacher の latent 空間を adapter で再現する形で、凍結 backbone + 軽量 adapter なので、別センサ/別機種への適合の recipe としても読める。
- P1: 評価側の示唆。NAVSIM navhard (難しい場面を集めた split) と HUGSim の closed-loop の両方で測っており、人間ログに近いこと以外で planner を評価する流れの具体例。
- 注意点: self-play の挙動が現実の交通 (他車の癖) と合うかが要。abstract では sim2real の検証は読み取れない。

## 試すべき実験アイデア

1. 手元の vectorized simulator (または簡易 simulator) で、基本 reward のみの self-play policy を作り、その rollout の衝突/near-miss の分布が手元の走行ログと比べてどう違うかを集計する。
2. 凍結 backbone + 小さい adapter で teacher の latent を再現する蒸留を、手元の既存 backbone で小規模に再現し、IL で学習した同サイズの student と NAVSIM の score を比べる。
3. IL で作った policy を初期値に、self-play の稀な状況だけで追加学習する混合 (IL + self-play 蒸留) を試し、demonstration なしの純粋版との差を見る。

## 注意

abstract のみに基づく。self-play の reward 設計、simulator の交通 agent の作り、sim2real での性能、adapter の規模は未確認。
