# DRILL: Training World Models to Improve Policies, Not Predict Pixels (2610.30814)

- トピック: next_arch (P3) / スコア 4.0
- URL: https://arxiv.org/abs/2610.30814

## 何を解決する論文か

world model (行動に応じて環境がどう変わるかを予測する model) は、VLA (Vision-Language-Action; 画像と言語から行動を出す model) を RL (強化学習) で後学習するとき、実環境との interaction を減らすために使われる。ところが通常は「次のフレームの pixel を当てる」ように学習され、本来の役割である「想像した rollout で policy を改善する学習信号を出す」こととずれている。この論文は、pixel の誤差が小さくても policy の勾配が悪くなる例を示し、policy の改善量で world model を学習させる。

## 手法の核心

- 観察: 次フレームの pixel MSE が 17% 高いのに、policy の改善目的で学習した world model のほうが下流の policy が良くなる。pixel の精度と policy の有用性は別物。
- **DRILL (Downstream-Return Imagination Learning Loop)**: bilevel 最適化 (内側で policy を更新し、外側でその結果の return が最大になるよう world model を更新する)。内側の更新は GRPO (Group Relative Policy Optimization; PPO の簡略版で、同じ状況の複数 rollout の相対的な良さで更新する LLM/VLA 向け RL 手法)。
- **DRILL-VWI**: closed-form の近似。追加の simulator rollout なしで、prediction error を (1) policy が訪れる状態の頻度、(2) GRPO の group-relative advantage、(3) model の自信度、で重み付けする。
- **DRILL-IMG**: 内側の更新を通して meta-gradient (更新の更新に対する勾配) を取る完全版。Hessian-vector product を切り詰めて計算する。VWI は一定の仮定の下で IMG の局所的な 1 step 成分を再現すると理論的に示す。
- 結果: 5 つの manipulation simulator と 2 つの VLA backbone で、成功率が WMPO より平均 +13.1 点、RLVR-World より +7.9 点。RLVR による事前学習とも補い合う。

## P3 への適用可能性

- world model の目的関数を「画像が綺麗か」から「下流の policy/planner が良くなるか」に替える考え方で、運転 world model でも同じ問題が起こる。地味な背景を綺麗に描くより、policy が重視する状態 (他車との相互作用など) の誤差を重く見るべき、という重み付けの根拠になる。
- 昨日の Events, Not Pixels (world model の return 誤差は少数の event step に集中する) と同じ方向の知見で、画像誤差を主指標にする評価・学習を見直す根拠が 2 本そろった。
- 対象は manipulation (物の操作) で、運転のような長い連続状態・多数の他車の設定は未検証。

## 試すべき実験アイデア

1. 手元の world model で、pixel/latent の誤差と、その world model で想像 rollout したときの policy 改善量 (成功率や score) の相関を複数 checkpoint で測る。相関が弱ければ DRILL 型の重み付けの余地がある。
2. DRILL-VWI 型の重み (policy の訪問頻度 × advantage) を既存の world model 学習の loss にだけ足す小規模実験。追加 rollout が要らないので最初に試す価値がある。
3. 計算の重い DRILL-IMG は後回しにし、VWI と IMG の改善幅の差を論文の表で確認してから判断する。

## 注意

abstract のみに基づく。VWI の重み付けの具体的な式、運転のような高次元・長期の設定での挙動、meta-gradient の計算コストは未確認。
