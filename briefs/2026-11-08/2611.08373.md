## 何を解決する論文か

VLA (Vision-Language-Action; 画像と言語から行動を直接出す model) は、視覚表現を 2D の vision-language 事前学習から受け継ぐ。3 次元空間の supervision は、個別 task への適応 (post-training) の段階で初めて足されることが多い。精密な制御に必要な「空間の理解」を、最初から転用できる foundation model の能力として育てたい、というのがこの論文の動機である。

## 手法の核心

- pi05 (Physical Intelligence の公開 VLA policy) を初期値に continual pre-training (事前学習を続ける) し、**action 予測**と、**中間の visual embedding と、凍結した 3D perception model の空間表現との alignment** を同時に最適化する。
- 異種の robot dataset (embodiment・task・scene が違う) を統一して、空間学習に使う。
- feature-dependent gate (入力に応じた重み) で、VLA の複数の層の visual embedding を適応的に集めて空間 supervision に使う。
- 空間表現の teacher (凍結した 3D perception model) は RGB に加え、一部の data にしかない depth とカメラ較正も使える。これで不均一な幾何 annotation を活かす。
- probabilistic state dropout (学習中に robot の状態入力を確率的に落とす) で、状態への過度な依存と、デモ軌跡への overfitting を抑える。
- 補助部品は**学習時のみ**で、事前学習済み VLA の構造をそのまま再利用できる (abstract の末尾が切れていて、評価結果は未確認)。

## 適用可能性 (P3)

- 「推論構造を変えず、学習時だけ補助 loss で中間表現を良くする」設計。車載の推論コスト制約と相性がよい。運転 E2E (end-to-end; 画像から直接操作量を出す構成) なら、frozen の depth / 3D 検出 model の特徴に backbone の中間層を揃える補助 loss に対応する。
- 昨日の La-JEPA (2611.08156; 凍結 encoder の上に小さい policy) や 2611.06918 (中間層の話) と並べると、「中間表現をどう育てるか」の比較軸が揃う。
- 注意: 評価は manipulation。運転では高速移動・長い時間スケールで、3D teacher の質が効き方を左右する。

## 試すべき実験アイデア

1. 手元の E2E / VLA の中間層に、凍結 depth model の特徴との alignment loss (cosine や L2) を学習時だけ足し、閉ループ指標と latency の変化を見る (最小の実験)。
2. alignment を掛ける層を固定する場合と、論文のような gate で層を混ぜる場合を比べる。
3. depth が一部の data にしかない状況を再現し、欠損時に loss をマスクして学習できるか確認する。
