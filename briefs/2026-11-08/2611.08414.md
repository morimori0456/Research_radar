# Spectral and Subspace Dynamics of LoRA in Supervised Fine-Tuning and Reinforcement Learning (2611.08414)

## 何を解決する論文か

LoRA (Low-Rank Adaptation; 重みの更新量を 2 つの低 rank 行列の積で表し、少ない parameter で fine-tuning する PEFT 手法) は、SFT (Supervised Fine-Tuning; 正解 data を真似させる学習) でも RL (Reinforcement Learning; 報酬で学習) でも、似た optimizer 設定のまま使われがちである。しかし両者で LoRA の更新量の中身がどう違って動くかは分かっていなかった。この論文は、更新量の singular spectrum (特異値の並び; 更新がどれだけ少数の方向に集中しているかを表す) と singular subspace (更新が張る方向の空間) を学習中に追跡し、違いの原因を特定したうえで、段階ごとに更新を調整する。

## 手法の核心

- 数学 reasoning の task で LoRA 更新を追跡した。RL は全 learning rate で spectrum が**集中**し、SFT は中程度の learning rate で spectrum が**広がる**。RL は小さい learning rate で subspace の**回転**も SFT よりずっと速い。
- SFT と RL の間を 1 要素ずつ補間し、両方の差の原因が **group-mean baseline subtraction** (同じ prompt から複数の応答を生成し、報酬の平均を引いて advantage にする計算; GRPO 系で使う) だと突き止めた。
- 二次の multi-index model (少数の方向だけに依存する単純な理論 model) に LoRA を適用して機構を説明する。baseline subtraction は「coherent fitting (そろった方向への fit)」と「gradient noise」の 2 つの力の釣り合いを、spectrum の集中と速い回転の側に傾け、同時に risk を最小にする learning rate を低くする。
- この知見から更新を段階別に変える。**SFT**: 完全な更新の spectrum を flatten (特異値を均す) して、適合を多くの方向に散らす。**RL**: 現在の LoRA 更新が張る span の外側にある成分を flatten し、subspace の回転を促す。
- 複数 model の数学 reasoning で、各段階の設定が比較手法の中で多くの設定で最良。

## 適用可能性 (P2)

- P2 の「少データでの適合」「PEFT/LoRA による効率的適合」に直接関わる。**同じ LoRA 設定を SFT と RL で使い回さない**という実務上の指針になる。
- 蒸留 (特に昨日の OPD = On-Policy Distillation; student が自分で生成した応答に teacher が token ごとに feedback を返す方式) の後段に RL や LoRA を重ねるとき、段階ごとに rank・learning rate の見方を変える根拠になる。
- 注意: 評価は数学 reasoning のみ。運転や視覚 model への転用は未検証。理論は単純化した model での説明で、実 model にどこまで当てはまるかは本文を読まないと分からない。

## 試すべき実験アイデア

1. 手元の LoRA 学習で、学習中に LoRA 更新 (B·A) の singular value を数 step ごとに記録し、SFT と RL (あれば) で spectrum の集中度が論文と同じ向きに動くかを確認する (最小の実験; 学習コードに SVD の logging を足すだけ)。
2. SFT 段階に「spectrum を均す正則化」を足し、同じ rank・同じ step 数で元の SFT と下流指標を比べる。
3. RL 段階では、LoRA の span 外の勾配成分を残す更新 (論文の flatten 相当) と、通常の更新を、learning rate を振って比べる。
4. 蒸留した student を別ドメインに合わせる場面で、rank を増やす手法 (2611.07349 GEAR; 昨日の次点) と組み合わせられるか検討する。
