# VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding (2611.08449)

## 何を解決する論文か

robotics や自動運転の model は、言語だけで推論する必要はなく、**visual plan** (点・bounding box・trajectory で空間的な目標と将来の動きを表す) を出力できる。しかし autoregressive な vision-language model (VLM; 1 token ずつ順に生成する) は座標を token 1 つずつ出すため、plan が豊かになるほど遅くなる。VFlash は、座標の構造が既知であることを使い、plan を速く正確に出す。

## 手法の核心

- **Flash Primitive Decoding**: visual primitive (点・box・trajectory) の座標を、軽量な drafter (本来は speculative decoding で下書きを作る小さい model) が **1 回の forward pass でまとめて**予測する。
- 出力の layout は primitive の種類・次元・長さに適応する。小さい box から、長さが可変の長い trajectory まで扱える。
- 通常の speculative decoding と違い、**autoregressive model の token 列と一致させる必要がない**。annotation 付きの primitive で直接学習し、構造として正しい予測はそのまま受け入れる。
- 2D と 3D の robot trajectory task で、autoregressive decoding より予測誤差が一貫して小さい。3D の点の運動予測では、予備的な単一 rollout の計測で**約 25 倍速**。
- plan を条件にした world action model (将来と行動を一緒に生成する policy) が、MolmoSpaces の 4 task suite 平均で成功率 70.2% (baseline は 62.6%)。

## 適用可能性 (P1 / P3)

- P1: VLM や LLM を使って trajectory を token として出す planner では、座標の token 化が推論の律速になる。座標をまとめて出す drafter は、その遅さへの直接の対策になる。
- P3: VLA / world model が中間に出す "visual plan" を、後段の policy の条件に使う設計の実例。
- 注意: 評価は robot manipulation と trajectory 予測。25 倍は「予備的な単一 rollout」の計測で、運転 trajectory の精度や安全性は未検証。

## 試すべき実験アイデア

1. 手元の trajectory を token 化して出す model があれば、waypoint を 1 forward pass でまとめて出す head と、autoregressive 版を、ADE / FDE (予測軌跡と正解の平均距離 / 最終点の距離) と latency で比べる (最小の実験)。
2. 長さ可変の trajectory (停止、右左折) で、出力長を drafter が適応して決める部分だけ再現する。
3. 計測は単一 rollout ではなく複数回の平均で取り直し、25 倍が再現するか確認する。
