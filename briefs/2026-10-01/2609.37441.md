## 何を解決する論文か

latent world model (観測を圧縮した潜在空間の中で、行動に応じた次の状態を予測するモデル) の多くは、候補の行動列を「予測した終端の潜在状態と、目標の潜在状態との Euclid 距離」で採点する。学習では表現が 1 点に潰れる collapse を防ぐため、潜在分布を isotropic Gaussian (全方向に同じ分散のガウス分布) に寄せる正則化をかけることが多い。この論文は、**その正則化が作る潜在空間の幾何では、Euclid 距離による順位がタスクの本当のコストによる順位とずれうる**ことを示した。予測が正確で、collapse していなくても起きる。対策として、正則化の目標を学習可能な対角共分散に置き換えている。

## 手法の核心

- **問題の所在:** planner は潜在空間の距離で候補を比べるので、「どの方向の誤差を重く見るか」は潜在空間の幾何で決まる。isotropic な正則化は全方向を同じ重さにするので、タスクにとって重要な方向と重要でない方向の区別が消える。
- **AnisoWM と ΛReg:** 正則化の目標を固定の isotropic Gaussian から、**学習可能な対角共分散 Λ を持つ Gaussian** に替える。trace (分散の合計) を固定する制約と、非等方性の度合いの制約をかけて、collapse と極端な偏りを防ぐ。
- **変えないもの:** 予測の目的関数、予測器の構造、Euclid 距離の planner はそのまま。Λ は学習時にだけ使う。つまり既存の LeWM (LeWorldModel; JEPA 型の小型 latent world model) の正則化項を 1 つ差し替えるだけ。
- **理論:** 予測の学習がどの方向に分散を割り振るか、それが学習データの分布にどう依存するか、どういう条件で planning の regret (最良の選択との差) が減るかを解析している。
- **結果:** 4 つの視覚制御環境すべてで LeWM より planning の成功率が高く、潜在空間での planning コストとタスクの結果の一致度も上がった。

## P3 への適用可能性

- **09-30 の CGS (`2609.35603`; 行動の向きと潜在変化の向きを揃える loss) と同じ問い、別の直し方。**CGS は「行動に対する幾何」を、AnisoWM は「目標までの距離の幾何」を直す。どちらも LeWM を baseline にしていて、比較条件が揃っている。同じ日に届いた ATLAS (`2609.36333`; 状態間の相対関係を encoder から planning 用の潜在に移す) と ALeWM (`2609.32921`; 予測に効く情報を潜在の先頭の次元に集める) も同じ LeWM の改良で、**LeWM の正則化の設計が今週の world model の主戦場になっている。**
- **P3 の world model 設計への示唆:** planning に使う潜在空間を作るなら、「collapse しない」と「planning の距離がタスクと揃う」は別の要件として扱うべき。前者だけを満たす isotropic 正則化はデフォルトにしない方がよい。
- **運転に移すときの注意:** 運転のコストは「前方の車との距離」「車線中心からのずれ」など方向ごとに重みが大きく違うので、非等方性が効きやすい領域と期待できる。ただし論文の環境は小さな視覚制御タスクで、運転規模での検証はない。

## 試すべき実験アイデア

1. **(半日・2D toy) isotropic と anisotropic の比較:** 2D の点質量環境で、タスクのコストを非等方にする (例: x 方向の誤差は 10 倍重い)。LeWM 型の world model を isotropic 正則化と ΛReg の 2 条件で学習し、Euclid 距離の planner の成功率と、学習された Λ の対角成分を見る。**Λ が x 方向に大きな分散を割り当てるかどうかが、論文の主張の最小検証。**09-30 の CGS の toy と環境を共有でき、同じ commit に並べられる。
2. **(同じ toy) CGS との併用:** CGS loss と ΛReg を 2×2 で組み合わせ、効果が足し算になるか・打ち消し合うかを見る。どちらも LeWM の学習に 1 項足すだけなので、実装コストはほぼ同じ。
3. **(同じ toy) 潜在距離とタスクコストの順位相関:** 学習後、ランダムな終端状態のペアについて、潜在距離の順位とタスクコストの順位の Spearman 相関を取る。今日の DRPE (`2609.32322`) の「意思決定に効く誤差」を、潜在空間の側から測る指標になる。
