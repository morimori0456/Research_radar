## 何を解決する論文か

E2E (end-to-end; センサー入力から走行軌跡までを 1 つのモデルで出す) 運転の policy は、多くの場合ログの模倣で学習される。自分の行動の結果を見ないまま学ぶため、closed-loop で走らせると causal confusion (原因と結果を取り違えた相関を学んでしまう現象) が起きる。video world model (行動を条件に未来の映像を生成するモデル) を環境として RL で post-training する方法はあるが、生成された映像が**与えた行動どおりに動いていない** (action-vision mismatch) ことがある。RoXDrive は、行動に忠実なロールアウトだけを選んで RL に使う枠組みを提案している。

## 手法の核心

- **Action-Vision Faithfulness Evaluator:** 生成された映像から自車の動きを逆算する inverse dynamics (観測の変化から、それを起こした行動を推定するモデル) を学習し、推定した行動と条件に与えた行動が一致しているかを長い horizon で判定する。幾何を意識した補助的な軌跡の監督を足して精度を上げている。
- **2 段階の学習:** (1) 事前学習: policy は模倣学習、評価器は上記の inverse dynamics。(2) RL post-training: policy が world model とやり取りして長いロールアウトを作り、**評価器が行動に忠実と判定したものだけ**を、安全性を考慮した密なスコアで採点して、場面単位の closed-loop RL に使う。
- **plug-and-play:** planner の種類を問わない。DiffusionDrive (拡散モデルで軌跡を生成する E2E planner) と Qwen3-VL ベースの VLM planner の両方で効果を示している。
- **結果:** nuScenes で DiffusionDrive の安全違反を 27.6% 削減、13 万場面超の社内データで Qwen3-VL の安全違反を 33.7% 削減。

## P3 への適用可能性

- **world model を「RL の環境」として使うときの品質管理の型。**生成の見た目の品質ではなく「行動を変えたら映像がそのとおり変わるか」を測る。P3 で world model を学習環境に使う場合、この判定器がないと、行動を無視して綺麗な映像を出すだけのモデルから報酬を学んでしまう。
- **判定器の作り方がシンプル:** inverse dynamics で「映像から行動を逆算して、入力した行動と比べる」だけ。world model の種類に依存しない。
- 09-30 の WorldPlay2 (`2609.35560`; 行動の制御性と長い horizon を伸ばした interactive world model) や 09-30 の上限落ち `2609.34684` (状態を当てられることと、状態の変化に予測が追従することは別) と同じく、「行動への応答性」を world model の独立した評価軸として扱う流れ。

## P1 への波及

- 評価器そのものが「world model の行動応答性」の評価指標になる。P1 で学習済みの simulator や world model を評価に使う場合、この指標で「その simulator は planner の行動の違いを反映しているか」を先に確かめられる。

## 試すべき実験アイデア

1. **(2D toy) 忠実性判定器の最小版:** 2D の点質量環境で、行動を一部無視する (例: 確率 p で行動を 0 にする) 劣化した world model を作る。生成された軌跡から inverse dynamics で行動を推定し、入力した行動との誤差で「忠実なロールアウト」を判定する。p を振って、判定器が劣化を検出できるかを見る。
2. **(同じ toy) フィルタの有無での RL:** 劣化した world model の中で policy を RL で学び、(a) 全ロールアウトを使う、(b) 忠実なものだけ使う、の 2 条件で、正しい環境に戻したときの成功率を比べる。論文の主張 (フィルタで sim-to-real ギャップが縮む) の最小検証になる。
3. **(既存 world model がある場合) 応答性の監査:** 同じ初期フレームから行動だけを変えて複数ロールアウトし、生成映像から逆算した自車の軌跡の差が、行動の差に比例しているかを見る。比例しなければ、その world model は RL の環境として使えない。
