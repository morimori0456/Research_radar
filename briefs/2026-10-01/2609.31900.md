## 何を解決する論文か

LLM の post-training (事前学習後の追加学習) は、SFT (Supervised Fine-Tuning; 正解の応答を教師にした fine-tuning)、RLVR (Reinforcement Learning with Verifiable Rewards; 正誤を自動で判定できる問題で報酬を与える RL)、OPD (On-Policy Distillation; student 自身が生成した応答に teacher が token ごとの確率で指導する蒸留) を多段に組み合わせるが、各段は別々に設計・評価されている。この論文は、**ある段で student を強くすると次の段が効きにくくなることがある**と示し、段の順序と準備が蒸留の効果を大きく左右することを定量化した。

## 手法の核心

- **teacher の大きさより相性:** Qwen3 系で、パラメータ比 2 倍〜53 倍の student-teacher の組 9 通りで OPD を比べた。効果を決めるのは teacher の大きさではなく **student-teacher の compatibility (student が teacher の分布をどれだけ追えるか)** だった。capacity gap (teacher と student の大きさの差が大きすぎると蒸留が効かなくなる問題) を「大きさ」ではなく「相性」で捉え直す結果。
- **前の段が相性を変える (3 つの効果):**
  1. **student 側:** 短い SFT で warm-up すると後の OPD が効く。一方、RLVR で先に強くした student は、同じ teacher から蒸留すると**逆に性能が下がる**。
  2. **teacher 側:** teacher を RLVR で適合させると、足した能力に比例して後の OPD の精度が上がる。
  3. **後の段への影響:** 同じ精度に揃えたとき、OPD 後のモデルは SFT 後のモデルより、後の RLVR の初期値として優れる。この差は RL の計算量を増やすほど広がる。
- **組み合わせの効果:** teacher の適合と student の warm-up だけで、同じ蒸留ステップ数での OPD の平均精度が 29.2% → 43.8% (相対 +50%) になった (準備の学習は別途必要)。
- **結論:** 各段は「足す能力」だけでなく「次の段にとっての学びやすさ」で選ぶべき。

## P2 への適用可能性

- **蒸留パイプラインの段取りの check list になる。**P2 で蒸留を回すとき、(a) student を先に RL やタスク特化で強くしてから蒸留していないか (逆効果の可能性)、(b) student に短い warm-up (teacher の出力による SFT) を入れているか、(c) teacher 側を student のタスクに寄せたか、の 3 点を確認できる。
- **capacity gap 対策の選択肢が増える:** 09-30 の上限落ち `2609.34489` (データが少ないと小さい teacher の方が良い) は「teacher を選ぶ」対策、今日の次点 TeacherGRPO (`2609.33426`) は「teacher を student に寄せて学習し直す」対策。この論文はその中間で、「teacher と student の両方を少しずつ準備する」ことで相性を上げる。コストが最も小さい。
- **09-30 の On-Policy or Off-Policy (`2609.35259`) と組み合わせる:** あちらは「loss の向きと学習率が先、on-policy かどうかは後」、こちらは「段の順序と準備が先、teacher の大きさは後」。**P2 の蒸留 recipe で先に決めるべき項目の優先順位**が 2 本で揃う。
- **注意:** 実験は LLM の数学・科学推論だけ。視覚基盤モデルの蒸留で「RL で強くした student は蒸留で下がる」が成り立つかは未検証。

## 試すべき実験アイデア

1. **(小規模 LLM) warm-up の有無:** 小さい student (0.5B 程度) を、(a) そのまま OPD、(b) teacher の出力で 100〜500 step の SFT をしてから OPD、の 2 条件で、同じ OPD ステップ数の精度を比べる。論文の効果 1 の最小再現で、半日で回る。
2. **(同じ設定) student を先に強くした場合:** student を先にタスクデータで fine-tuning してから OPD する条件を足し、「先に強くすると蒸留で下がる」が再現するかを見る。再現すれば、P2 の既存パイプラインの段の順序を見直す根拠になる。
3. **(視覚への移植) 相性の指標:** 視覚の蒸留で、蒸留前の student-teacher 間の KL (2 つの確率分布のずれ) や feature の CKA (Centered Kernel Alignment; 2 つの表現の類似度) を「相性」の代理指標として測り、蒸留後の精度と相関するかを見る。相関すれば、teacher の候補を蒸留前に絞り込める。
