# 2610.28122 — De-Diffusing WAMs: Action-Sufficient Direct Prediction for Robot Control (DirectWAM)

## 何を解決する論文か

WAM (World-Action Model; 未来の映像を予測して、それを条件に robot の行動を出す model) の cascade 構成は、映像予測と行動予測の両方が diffusion で、推論に何度も反復が要る。1 ステップに削ると成功率が大きく落ちる。この論文は「1 ステップの未来予測は、行動予測に何を残しておけばよいか」を調べ、行動の精度を直接の基準にして 1 ステップの student に蒸留する。

## 手法の核心

- **観察 1**: 評価した WAM では、映像側のノイズをサンプルし直しても下流の行動はほとんど変わらない。確率的な生成は行動には要らない。
- **観察 2**: 両方の stream を単純に 1 ステップへ切り詰めると、タスク成功率が大きく下がる。映像空間の supervision だけでは gap の一部しか埋まらない。局所感度分析では、映像予測の誤差が行動精度に与える影響は不均一で、行動に効く成分と効かない成分がある。
- **DirectWAM**: 事前学習済みの映像 expert と行動 expert を、サンプリングなしの 1 ステップ predictor に変える。future-to-action の cascade の構造は残す。
- **action-sufficient distillation**: 先に 1 ステップの行動 model を学習し、その後で future predictor を、自分の予測した未来から行動を decode し、demonstration の行動誤差を expert を通して逆伝播して学習する (任意で future-latent の再構成 loss も足す)。student が作った未来を、representation の一致ではなく**下流の制御結果**で評価する。
- **結果**: LIBERO の 4 suite で平均成功率 97.1%、RoboTwin 2.0 で 85.4%。同じ「各 stream 1 回評価」の予算の Flash-WAM を上回る。実機 3 task でも優位。反復する full teacher に対して推論 latency は 28.0 倍短い。

## 適用可能性と実験アイデア

- **P3 (次世代 architecture)**: 世界予測つきの policy は onboard 推論の latency が最大の壁で、その解として「予測した未来の質を、行動への影響で測る」蒸留は設計の方針になる。
  - 実験案 1 (最小): 手元の diffusion 系の world model / planner に対し、映像側のノイズを resample して出力軌道がどれだけ変わるかを測る。変わらなければ、確率的な生成は行動には不要で、DirectWAM の観察が当てはまる。
  - 実験案 2: 蒸留 loss を「予測した未来の特徴の一致」から「その未来から decode した行動の誤差」に替える版を比べる。
  - 実験案 3: 未来の予測誤差に対する行動の局所感度を測り、予測の精度を行動に効く成分に集中させる。
- **P2 (蒸留 + 適合)**: 蒸留の目的関数を、student の中間表現の一致ではなく**下流の目的で測る**という発想は、capability gap 対策の一般的なパターン。OPTD (2610.28048) の層間 transition と比べると、どこに supervision を置くかの別の答え。
- **P1**: 28 倍の latency 短縮は、closed-loop simulation で world model を回す評価のコストにも効く。
- 注意: 検証は LIBERO と RoboTwin の manipulation で、運転の高速・長期 rollout は未検証。cascade 構造と前提条件 (映像と行動が別の expert として事前学習済み) が必要。student が teacher の diffusion の多様性 (multi-modal な行動) を失う可能性があり、運転のように複数の妥当な軌道がある設定では要確認。
