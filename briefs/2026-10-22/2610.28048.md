# 2610.28048 — On-Policy Transition Distillation (OPTD)

- 元論文: https://arxiv.org/abs/2610.28048 (著者: Runyang You, Yongqi Li, Tiezheng Yu ほか)
- トピック: fm_distill_finetune (P2) / 評価 4.0
- 出所: candidates.json
- 根拠: abstract のみ。3 つの backbone の名前、loss の重み、計算コストは未確認

## 何を解決する論文か

OPD (On-Policy Distillation; student 自身が生成した軌跡の上で、teacher が各 token の確率分布を教える蒸留) は、複数の teacher (数学用、コード用など) の能力を 1 つの student にまとめる用途でよく使われる。ただし最終層の分布を合わせるだけでは、teacher と student の capability gap (能力差) が残る。この論文は最終層だけでなく「層から層へ予測がどう変わるか」も合わせることで、gap をさらに詰める。

## 手法の核心

- **depthwise prediction transition**: 各中間層の hidden state を語彙に射影したときの log-probability が、層を進むにつれてどう変化するか (層間の増分)。
- **診断**: 同じ問題の中で、正解した応答は不正解の応答より、teacher と student の層間 transition の KL が小さい (測った全ての中間層ペアで)。つまり中間の「考え方の動き」の一致は、正しさと相関する。
- **OPTD**: 通常の OPD の最終層の分布マッチに、teacher と student の layer-to-layer log-probability 増分のマッチングを足す。student が生成した rollout の上で行う。
- **結果**: 3 つの backbone、8 つの benchmark (数学・コード・instruction following) で、2 domain と 3 domain の蒸留の両方で best か tied-best。3 domain では teacher-student の gap の約 90% を回復する。通常の OPD は約 75%。
- **条件**: 中間層の出力を語彙に射影できる必要があるので、teacher と student が同じ語彙を共有する LLM が前提になる。

## 適用可能性と実験アイデア

- **P2 (蒸留 + 適合)**: capability gap 対策の新しい loss で、優先度の高い分類に当たる。追加の rollout も reward も要らず、既存の OPD に項を足す形なので、実装コストは低い。
  - 実験案 1 (最小): 手元の蒸留 run で、まず診断だけ再現する。正解応答と不正解応答で、teacher と student の層間 KL に差があるかを測る。差が出なければ OPTD の動機が自分の設定には当てはまらない。
  - 実験案 2: 差が出たら、最終層の loss に transition 項を小さい重みで足して、同じ step 数で通常の OPD と比較する。評価は gap の回復率 (論文と同じ定義)。
  - 実験案 3: 層数や hidden size が違う teacher-student の組でも使えるか (層の対応付けをどうするか) を先に決める。abstract に書かれていないので、ここが最大の不明点。
- **P3**: teacher が大きい VLA / E2E planner で student が小さい場合、層の対応付けと語彙射影の代わりに、行動 head の出力の変化量を合わせる形に変えられるかが論点になる。
- 注意: 評価は LLM の数学・コード・指示追従で、行動生成や視覚 model には未検証。「約 90% 対 75%」の差が seed の揺れを超えるかは abstract からは分からない。2026-10-21 に採用した SPOD (2610.25034; teacher が好まない成功を削る erosion の抑制) や Nash-MOPD (2610.26124; domain 配分) とは目的が違い、併用できる。
