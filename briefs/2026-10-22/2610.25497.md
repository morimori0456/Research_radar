## 何を解決する論文か

SFT (Supervised Fine-Tuning; 正解の例を真似させる学習) は、正解の response を one-hot の目標として扱う。そのため、model がもともと妥当と思っていた別の続き方の確率を押し下げ、新しい task を覚える代わりに汎用性能が落ちやすい。この論文は、外部の teacher を使わず、同じ model が「正解を見た状態」の自分を teacher にして学ぶ方法を提案する。

## 手法の核心

- **Gold-Conditioned Distillation (GCD)**: 1 つの model が teacher と student を兼ねる。teacher 役は prompt の中に gold response (正解の応答) を入れた状態で次 token の分布を出し、student 役は元の prompt だけ (推論時と同じ入力) で分布を出す。
- **loss**: gold response の各 token 位置で、student の分布が teacher の分布に近づくよう forward KL (teacher 側の分布を基準にした KL) を最小化する。
- **狙い**: 正しさは gold response を context に入れることで保たれ、soft target (確率分布) なので plausible な別の続き方も残る。model が持つ事前知識を使って、自分に新しい task を教えさせる。
- **結果**: Qwen と Llama で、複数の学習 task にわたって、SFT より新 task の accuracy が高く、汎用 benchmark の劣化も一般に小さい。
- **コスト**: 学習時に forward が実質 2 回になる (teacher 役の分)。推論時の追加コストはない。

## 適用可能性と実験アイデア

- **P2 (蒸留 + 適合)**: 「他ドメインへの少データ適合で、元の能力を壊さない」という P2 の fine-tuning 観点にそのまま当たる。外部 teacher が要らないので、domain 適合の recipe として試しやすい。
  - 実験案 1 (最小): 手元の少データ fine-tuning の設定で、通常の SFT と GCD を同じデータ・同じ step で比べ、新 task の accuracy と元の汎用 benchmark の落ち幅の 2 つを並べる。
  - 実験案 2: LoRA (低ランクの追加重みだけを学習する PEFT) と組み合わせ、GCD の損失で adapter を学習する版が SFT + LoRA より forgetting が少ないかを見る。
  - 実験案 3: 蒸留の本流への接続として、大きい teacher の分布を使う通常の蒸留と、GCD の self teacher を混ぜる版を比べる。
- **P3**: 行動の教師データ (expert demonstration) を one-hot の行動として扱うと、他の妥当な行動を潰す、という問題は VLA の模倣学習にも当てはまる。VLA で gold action を context に入れる形が作れるかが論点だが、abstract は LLM のみ。
- 注意: 評価は言語 task。gold response が長い場合や、gold 自体が noisy な場合に、teacher が gold を丸写しして soft target の利点が消える可能性がある (abstract に記述なし)。teacher 役が答えを見ているため、leak による過信がないかの検証も未確認。
