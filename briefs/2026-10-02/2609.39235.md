# The Planning Limits of Latent World Models

- arXiv: `2609.39235` / https://arxiv.org/abs/2609.39235
- 配属: next_arch (P3) ・ candidates.json 内
- スコア: **P3 4.5** (P1 4.0) ・ hf_upvotes 0

## 何を解決する論文か

world model (行動を条件に未来の状態を予測するモデル) で planning をする研究は、「何ができたか」を示すものが多く、「どこまで先なら planning に使えるか、どこで壊れるか」はわかっていなかった。この論文は、latent world model (画像そのものではなく、encoder の特徴空間で未来を予測する world model) が planning に使える距離を測る指標 **plannable range** を定義した。その上で、制約になっているのは予測の精度ではなく「目標が、想像した軌跡の届く範囲にあるか」だと示した。

## 手法の核心

- **評価の設定:** 凍結した自己教師あり encoder 5 種 (V-JEPA 2 / 2.1、VideoMAEv2、VideoPrism、DINOv2) の上に、行動を条件にした predictor を学習する。Meta-World (ロボットアームの操作タスク集) 16 タスクと、実ロボットのデータ BridgeData V2 (2,958 episode) で評価する。
- **plannable range の測り方:** expert の実演の途中から、expert の次の行動列と、ランダムな行動列 100 本を world model で想像させる。目標 (k ステップ先の expert の観測) に最も近づいた距離で採点し、expert の行動が何 % のランダム候補より上位に来るか (expert percentile) を見る。これを目標の距離 k を伸ばしながら測り、順位付けが信頼できる最大の k を plannable range とする。
- **主な発見 1: 範囲は想像の長さで決まる。**5 ステップ先まで想像する設定では、順位付けが信頼できるのは 5〜10 ステップ先の目標まで。実際のタスクは完了まで 16〜53 ステップかかる。**predictor を 81 倍大きくしても、長いロールアウトで学習しても範囲は伸びない。**
- **主な発見 2: 完璧な予測でも同じ壁がある。**world model を本物の simulator (予測誤差ゼロ) に置き換えても、目標が 5 ステップ先なら成功率 92%、20 ステップ先なら 41%。つまり限界は予測誤差ではなく、「想像した軌跡の終点と目標の距離で行動を採点する」という planning の構造から来ている。
- **対策の比較:** 遠い目標に対して、想像だけ 23%、MPC (Model Predictive Control; 毎ステップ観測を取り直して計画をやり直す) 30%、目標まで想像を伸ばす 47%、expert の近い subgoal (中間目標) を与える 76%。また、範囲内で使えば VLA の補助になる: VLA が出した 8 個の行動候補から world model で選ぶと、16 タスクの成功率が 65% → 77%。

## P3 への適用可能性

- **world model を planner に組み込むときの設計の制約を明示している。**「想像の horizon」と「目標の距離」が釣り合っていないと、予測がどれだけ正確でも planning は失敗する。P3 で world model ベースの planner を設計するなら、**horizon を伸ばすか、近い subgoal を出す上位の仕組みを置くか**のどちらかが必須になる。
- **「world model は候補の選別に使う」という使い方の根拠。**VLA の候補から選ぶ使い方は、想像の範囲が短くても効く。10-01 の World4Scorer (`2609.36438`; 候補の採点器を world model で学ぶ) と同じ「生成は別のモデル、world model は選別」という分業を、ロボットの設定で支持している。
- **encoder の選択が範囲と成功率の両方に効く。**V-JEPA 2.1 が最も安定。P3 で凍結 encoder の上に world model を作るなら、encoder の比較を最初にやる価値がある。

## P1 への波及

- **評価指標として使える。**plannable range (expert の行動がランダム候補の何 % より上位か、を目標の距離ごとに測る) は、P1 で学習済みの world model や予測モデルを評価するときに、予測誤差より planning の成否に近い指標になる。10-01 の DRPE (`2609.32322`; 意思決定に効く誤差だけが planning の成否を説明する) と同じ方向で、こちらは「どの距離まで」という軸を足している。

## 試すべき実験アイデア

1. **(2D toy・学習なしで半日) 完璧な予測でも壁が出るかの再現:** 2D の格子か点質量で、本物の遷移を world model として使う (予測誤差ゼロ)。想像の長さ H = 5 に固定し、目標の距離 k を 5〜40 に振って、「想像の終点と目標の距離」で採点した planning の成功率を描く。論文の Fig. 1b (92% → 41%) と同じ形が出るかを確認する。10-01 の DRPE toy と同じ環境で作れ、2D toy の初 commit の最有力候補。
2. **(同じ toy) 対策の比較:** 同じ環境で、H を k まで伸ばす / MPC / expert の subgoal を与える、の 3 つを比べる。計算量 (想像したステップの総数) あたりの成功率で並べる。
3. **(P1 の予測モデル) expert percentile の測定:** 社内の予測モデルか world model で、実際のログの自車の行動と、ランダムに摂動した行動を想像させ、ログの行動の順位を予測の長さごとに出す。順位が崩れ始める距離が、その world model を planning に使える上限の目安になる。
