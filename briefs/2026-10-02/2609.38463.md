## 何を解決する論文か

運転 planner の closed-loop 評価 (planner を simulator 内で実際に走らせ、その結果で採点する評価) は、driving score・目的地到達率・衝突率のような集計指標で行われる。これらの指標は「交通ルールを守ったか」を直接測っていないので、ルール違反をしながら高得点を取る planner を見逃す。この論文は、34 種類の交通標識それぞれに自動の違反判定器を付けた closed-loop ベンチマークを作った。既存の planner 17 種を測り、ルール遵守と目的地到達を同時に満たす率が 2.9〜9.0% しかないことを示した。

## 手法の核心

- **標識ごとの rule checker (違反判定器):** MetaDrive (強化学習向けの軽量な運転 simulator) を拡張し、34 種の標識 (一時停止・速度制限・進入禁止・一方通行・横断歩道など) にルールのロジックと、走行中に違反を検出する判定器を実装した。29 種の scenario type を、Priority (優先権)・Speed・Obstacles・Routing (経路選択) の 4 群に分けている。
- **「違反したくなる」場面を意図的に作る:** ランダムに置くだけだと、ルールが試されない (対向車が来ない、制限速度がもともとの速度と同じ、など)。そこで、自車が交差点に近づいた瞬間に優先車列を放つ、禁止された分岐を最短経路にして誘惑する、といった rule-targeted な生成をしている。背景車両は IDM (Intelligent Driver Model; 前走車との車間から加減速を決める古典的な追従モデル) で、速度・密度などの分布は nuPlan (実走行ログのデータセット) から推定した。
- **地図は実在の道路から:** OpenStreetMap のモスクワの道路断片 26,020 個に標識を後から置く。合成した道路だと「生成器の癖を覚えれば解ける」ため。train/test は地図 ID で分けて leakage を防いでいる。合計 29,000 場面 (train 23,200 / test 5,800)。
- **主指標 SCD (Sign Compliance Destination):** 「対象の標識に違反せず、かつ目的地に着いた」率。遵守だけを見ると、途中で事故って止まった場合に「守ったかどうか」が決まらないので、到達と組にしている。
- **改善の baseline:** 既存 planner にルールの制約を足した「ルール遵守版 expert」を 8 種作り、場面ごとに最良の軌跡を選んで教師データにする。PlanT-2 (物体トークンを入力にする transformer の模倣学習 planner) をこれで fine-tuning すると、SCD が 5.9% → 72.3%。入力から標識の種類だけを消すと 72.8% → 15.4% に落ちるので、改善は本当に標識を読んで起きている。

## 数字で効いている点

- **既存指標との相関が弱い。**Spearman 順位相関 (値ではなく順位の一致度) で見ると、driving score と目的地到達率は SCD と弱い負の相関で、Routing 群だけ逆に正になる。**衝突率が最も近い代理指標だが、Routing 群とはほぼ無相関。**つまり「衝突せず目的地に着く planner」が「ルールを守る planner」とは限らないことを、群ごとに示している。
- **失敗の内訳を分けている。**fine-tuning 後の PlanT-2 は標識の遵守率 96.6% だが SCD は 71.9%。**遵守したのに到達しなかった episode が 24.7%、違反した episode は 3.4%** で、残りの失敗の大半はルールの理解ではなく経路の実行 (衝突・路外逸脱) にある。

## P1 への適用可能性

- **評価指標の設計テンプレートとしてそのまま使える。**「ルール遵守 × タスク完了」の AND を主指標にし、遵守単体と到達単体も別に出す、という 3 本立ては、自社の planner 評価にも移せる。とくに「遵守したが到達しなかった」を独立したカテゴリとして数えるのが重要で、これを分けないと、止まっているだけの planner が遵守率で高く見える。
- **既存指標で見落とす失敗の、具体的な規模の根拠になる。**10-01 の DRPE (`2609.32322`; 合計の予測誤差は planning の成功を説明しない) と同じ型の主張を、評価指標の側で示している。R1 (評価手法の研究) で「集計指標は○○を見落とす」と書くときの引用先として使える。
- **限界:** 入力は構造化された標識情報で、標識の検出・認識の誤りは含まない。1 場面 1 ルールで、複数ルールの同時発生は扱っていない。標識はロシアの交通法規基準 (Vienna 条約加盟国との意味的な一致は平均 92%)。日本の標識への移植は、論文の主張どおりなら見た目の差し替えで済むはずだが、未検証。

## 試すべき実験アイデア

1. **(公開データのみ・半日) 自分の planner の SCD と既存指標の乖離を測る:** 公開の test 5,800 場面に、手元で動く planner (なければ IDM と PlanT-2 の公開 checkpoint) を走らせ、SCD・遵守率・到達率・衝突率を群ごとに出す。論文の Fig. 5 (指標間の Spearman) を自分の planner 群で再現できるかを見る。
2. **(P1 の評価パイプライン) 「遵守したが未到達」を独立カテゴリにする:** 社内の closed-loop 評価で、失敗を「ルール違反」「衝突」「停止・未到達」に排他的に分けて集計する。これまで 1 つの失敗率にまとめていた場合、どのカテゴリが支配的かを最初に確認する。
3. **(2D toy) ルール判定器付きの toy 評価:** 2D の格子道路に「進入禁止」「一時停止」の 2 ルールだけを置き、最短経路が禁止区間を通るように目的地を配置する。最短経路 planner と、ルールを制約に入れた planner で、到達率・遵守率・SCD を比べる。止まっている 2D toy の初 commit の候補として、10-01 の DRPE toy と同じ格子で作れる。
