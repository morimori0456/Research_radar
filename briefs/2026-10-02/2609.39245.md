# ReWAM: Reciprocal World Action Models for Interactive Autonomous Driving

- arXiv: `2609.39245` / https://arxiv.org/abs/2609.39245
- 配属: next_arch (P3) ・ candidates.json 内
- スコア: **P3 4.0** (P1 3.5) ・ hf_upvotes 0

## 何を解決する論文か

WAM (World Action Model; 未来のシーンの生成と自車の行動の生成を 1 つのモデルで同時に行う構造) は、E2E 運転の新しい流れになっている。ただし既存の WAM は、他車を「world の一部として予測される対象」として扱い、「自車の行動に反応して行動を決める意思決定者」としては扱っていない。そのため、合流や交差点のような相互作用の強い場面で弱い。ReWAM は、自車と他車が互いの行動に反応し合う構造を、game theory の Level-k 推論として WAM の中に組み込んだ。

## 手法の核心

- **Level-k の応答の階層:** Level-k 推論 (Level-0 は相手を考えずに動き、Level-k は相手が Level-(k-1) で動くと仮定して最適に応答する、という game theory の段階的な推論モデル) を使う。自車用と他車用の action DiT (Diffusion Transformer; transformer を骨格にした拡散モデル) を役割別に用意し、各 level で互いの戦略を小さな strategy token にまとめて cross-attention で交換する。
- **共通の未来表現に接地:** 両方の action DiT は、video DiT が生成する「未来の運転シーン」の共通の表現を参照する。相互作用の推論が、world model の予測から切り離されないようにしている。
- **学習:** expert の行動を「相手の行動に対する最適応答の分布からのサンプル」とみなし、階層全体を conditional flow matching で同時に学習する。他車の未来の軌跡は学習時の教師にだけ使い、推論時には使わない。
- **実装:** 既存の WAM である DriveLaW の上に作り、VAE・text encoder・video DiT は凍結、action DiT と相互作用のモジュールだけ学習する。
- **結果:** NAVSIM (実走行ログから作った運転 planner のベンチマーク。他車は反応しない non-reactive 設定) で PDMS (衝突・走行可能領域・進行度などをまとめた総合指標) 90.6。ベースの DriveLaW から +1.5、従来の SOTA (ReWorld) から +0.2。Level を 1 → 4 に上げると 90.03 → 90.64 で、最大の伸びは Level-2 で、Level-5 では頭打ち。相互作用の強さで場面を 5 段階に分けると、強い場面ほど改善が大きい。

## P3 への適用可能性

- **「他車をどう表現するか」の設計の選択肢として。**world model で他車を「予測対象」として扱うか、「応答する主体」として扱うか、という設計軸を明示した。P3 で WAM 型のアーキテクチャを検討するとき、他車用の action head を持つかどうかは早い段階で決める必要がある。
- **Level-k は安価に試せる構造。**strategy token を交換するだけなので、反復の回数 (level) を推論時に変えられる。Level-2 で大半の効果が出るという結果は、計算予算の見積もりに使える。
- **限界:** 評価は non-reactive の NAVSIM だけで、他車が本当に反応する closed-loop では検証されていない。相互作用のモデル化を売りにする論文としては、評価が主張と噛み合っていない。改善幅は SOTA に対し +0.2 と小さい。video DiT を含む重い構成で、車載の計算予算では現実的でない。

## P1 への波及

- **評価の弱点の例として。**「相互作用を扱う」と主張する planner を non-reactive の評価で測ると、他車が反応しないので主張を検証できない。P1 の評価設計で、reactive な closed-loop 評価を必須にする根拠として使える。

## 試すべき実験アイデア

1. **(2D toy) Level-k の最小版:** 2D の合流場面 (自車 1 台・他車 1 台) で、他車を (a) 等速で動く予測対象、(b) 自車の行動に Level-1 で応答する主体、として扱う 2 つの planner を作り、他車が実際に応答する simulator で衝突率と合流成功率を比べる。Level を 0〜3 に振って、Level-2 で頭打ちになるかを見る。
2. **(同じ toy) reactive vs non-reactive の評価の差:** 上の 2 つの planner を、他車が反応しない評価と反応する評価の両方で測る。non-reactive の評価で差が消える (= NAVSIM では Level-k の価値を測れない) かを確認する。
