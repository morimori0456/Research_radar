# 2610.19714: Uncertainty-Driven Self-Play for Robust Multi-Agent Driving Policies

- 元論文: http://arxiv.org/abs/2610.19714v1
- トピック: planner_ai (P1) / 評価: 4.0 / 著者: Sajad Marvi, Julian Schmidt, Alessandro Canevaro ほか

## 何を解決する論文か
学習ドメイン外でも壊れない driving policy を作るのが課題。標準の self-play (自分自身のコピー同士で走らせて学習する方式) は、難しいシナリオを人手で設計しないと弱点が見つからない。本論文は epistemic uncertainty (モデル自身の知識不足に由来する不確実性) を「シナリオの難しさ」の自動指標に使い、手設計なしで curriculum (易→難の学習順序) を作る。

## 手法の核心
- agent の半分を「exploring agent」とし、隣接 agent の epistemic uncertainty を上げることを報酬にする。残り半分は安全に走ることを学ぶ。
- exploring agent が policy の最も自信のない状況を継続的に探すので、難しいケースの curriculum が自動生成される。
- 結果: nuPlan Val14 で 99.12% (標準 self-play 97.97%)、Argoverse 2 で 82.39% (同 78.03%) を fine-tuning なしの zero-shot transfer で達成。Waymo でも標準 self-play を上回る。
- LSTM hidden state の coverage が baseline 比 85% 増 = 行動の多様性が高い。
- uncertainty 上位の agent は下位の 14.8 倍の失敗率 (衝突・off-road・DNF の合計) で、ラベル無しで難シナリオを優先づけできる。

## P1 への適用可能性と実験アイデア
- 評価側: uncertainty を「難シナリオの選別器」として、既存の closed-loop simulation のシナリオ集合を並べ替える。失敗率との相関が再現するか確認する (ログがあれば self-play の学習なしで試せる)。
- 学習側: 自前の planner に ensemble か MC dropout (推論時に dropout を残して不確実性を見積もる手法) を付け、uncertainty 報酬の adversarial agent を 1 体だけ混ぜた小規模 self-play を回す。
- 注意: abstract のみで確認。uncertainty の推定法の詳細と学習コストは本文で要確認。
