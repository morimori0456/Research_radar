# 2610.19601: PA1-OPD: One-Step Prefix-Augmented On-Policy Distillation for Language Model Pretraining

- 元論文: http://arxiv.org/abs/2610.19601v1
- トピック: fm_distill_finetune (P2) / 評価: 3.5 / 著者: Zhenhe Wu, Jian Yang, Yaping Jin ほか

## 何を解決する論文か
通常の knowledge distillation (KD; teacher の出力分布に student を合わせる) は、コーパス上の prefix (文頭からの途中までの系列) でしか teacher の supervision を与えない。student 自身が生成した状況では teacher の教えが無い。On-Policy Distillation (OPD; student 自身が生成した系列に対して teacher が supervision を返す蒸留) を pretraining に低コストで入れる方法を提案する。

## 手法の核心
- コーパス上の選んだ prefix に対し、student が 1 ステップだけ sampling し、その遷移先で teacher のフィードバックを受ける (one-step)。
- 元の next-token prediction と corpus-path KD は維持したまま、supervision を受ける状態を増やす。
- tree attention (分岐した系列で prefix の計算を共有する attention) を微分可能にして計算を共有。推論は変わらない。
- student の surprisal (予測の意外さ) が高い上位 10% の root だけ選ぶと、KD の cross-entropy 改善幅に 48.85% 上乗せ (Stage2)。
- C4 / PG-19 / Pile で、全 checkpoint で KD より held-out cross-entropy が良い。

## P2 への適用可能性と実験アイデア
- 蒸留 recipe に「student が間違えやすい状態を選んで teacher に聞く」を足す発想は、LLM 以外の蒸留 (系列出力を持つモデル) にも移せる。
- 実験: 手元の蒸留 pipeline で student の loss/surprisal 上位 10% のサンプルだけ 1 step on-policy 展開し、teacher loss を追加する ablation を行う。
- 注意: LM pretraining での検証のみ。fine-tuning や視覚モデルへの転用は未検証で、downstream task の改善は abstract に無い。
