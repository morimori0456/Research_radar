# 2610.20609: SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving

- 元論文: http://arxiv.org/abs/2610.20609v1
- トピック: next_arch (P3) / 評価: 4.0 / 著者: Shaoyuan Xie, Zihan Zhang, Jingxuan Wang ほか / hf_upvotes: 9

## 何を解決する論文か
VLA (Vision-Language-Action; 画像と言語から行動を直接出すモデル) の運転版は、自由文のナビ指示を受け付ける。その分、シーン的に危険な指示 (うっかり or 悪意) を実行してしまう弱点がある。ナビ追従・矛盾 (conflict) 認識・adversarial 頑健性を同時に測る初の benchmark suite を作り、それに対する VLA を提案する。

## 手法の核心
- 既存 VLA は全て不十分: SimLingo は closed loop で言語指示の車線変更を 1 回も完了できず、矛盾した指示で大きく劣化する。
- 3 段階の navigation-compliance mode (従う/注意して従う/拒否、のような段階) を明示的に予測し、conflict の判断と action 生成を分離する。
- world model dreaming: 専門家や planner の action ではなく「ナビ指示に厳密に従ったらどうなるか」を world model で想像し、従って安全かを判定する。
- Bench2Drive で Driving Score 88.16、Success Rate 68.64%。言語追従が 49.3% 向上し、危険指示での衝突は 60 → 38 (最良の SimLingo 変種比)。

## P3 への適用可能性と実験アイデア
- 「従った場合の未来を world model で想像してゲートにかける」設計は、E2E planner の安全 filter として切り出して試せる。
- P1 の評価にも有用: 言語指示を持つ planner の conflict-aware 評価 benchmark として。
- 実験: 手元の VLA/E2E モデルに対し、危険な指示を混ぜた Bench2Drive シナリオで衝突率を測るだけでも baseline になる。
- 注意: benchmark の公開状況と world model の計算コストは本文で要確認。
