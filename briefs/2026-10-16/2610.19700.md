# 2610.19700: ReGRA: Residual-Gradient Adaptation for Complementary Low-Rank Fine-Tuning

- 元論文: http://arxiv.org/abs/2610.19700v1
- コード: https://github.com/Fanyao-Li/ReGRA
- トピック: fm_distill_finetune (P2) / 評価: 3.5 / 著者: Fanyao Li, Yuxi Liu, Xiaohao Liu ほか

## 何を解決する論文か
LoRA (Low-Rank Adaptation; 重みの更新を低ランク行列の積で近似する parameter-efficient fine-tuning) は rank を上げても、追加した方向が downstream 性能に効くとは限らない。rank-16 の診断実験では、上位の特異成分だけを残した方が最良で、成分を足すと悪化した。固定 rank 予算を有効に使う方法を提案する。

## 手法の核心
- 2 段階 adapter。第 1 段で通常の LoRA 更新を学習する。
- calibration set で task gradient を推定し、第 1 段の更新が張る two-sided subspace への射影を除去する (residual gradient)。
- 残差方向を集約して第 2 段 adapter を初期化。第 1 段の更新は変えない。
- 直交性 regularizer で 2 つの更新が相補的な方向を学ぶようにする。
- 両更新は pretrained weight に merge でき、推論コストは増えない。同じ総 rank の他手法より高性能で、2 倍 rank の LoRA に並ぶと報告。

## P2 への適用可能性と実験アイデア
- 他ドメイン適合で LoRA rank を上げても伸びない場面の対策候補。merge 可能なので deploy 側を変えずに済む。
- 実験: 現行の LoRA (rank r) を ReGRA (r/2 + r/2) に置き換え、同じ総 rank で比較。calibration set は少量 (数百サンプル) で足りるかも確認する。
