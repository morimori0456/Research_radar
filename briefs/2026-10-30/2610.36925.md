# Vision-Language Agents Can Learn in Their Own Latent Worlds (2610.36925)

- トピック: next_arch (P3) / スコア 3.5
- URL: https://arxiv.org/abs/2610.36925
- コード: https://github.com/Tom111-lhx/Dwell

## 何を解決する論文か

VLM (vision-language model) は世界についての知識を持つが、その知識を、環境と対話しながら policy を改善する (online の強化学習) ために使うのは難しい。理由は、policy が変わると agent が訪れる状態の分布が変わり、world model (行動の結果を予測する model) もそれに追従して更新する必要があるのに、大きい事前学習済み model を継続して更新するのは計算が高いことにある。この論文は、VLM 自身を world model と policy の兼用にして、画像を再構成せずに潜在空間 (latent space) だけで将来を想像させる、model-based RL (環境の model を学習し、その中で想像して policy を改善する強化学習) の枠組みを示す。

## 手法の核心

- **Dwell**: VLM を **recurrent latent transition operator** (現在の潜在状態と行動から次の潜在状態を出す再帰的な遷移関数) として再定義する。VLM が潜在空間で予測し、結果を評価し、行動を選ぶ。
- world model と policy が **同じ VLM の表現を共有する**ので、別の world model を用意する必要がない。
- 学習は 2 つの経路を使う: (1) 実環境との実際のやり取りから、行動の結果を予測する能力を学ぶ、(2) 潜在空間での imagination (想像上の rollout) から policy を改善する。
- 結果: 5 つの interactive な視覚環境で、学習可能な手法の中で全体として最良。imagination に要る計算量を大きく減らせる、と報告している。
- 主張: VLM agent にとって有用な world model は、未来の画像を再構成する必要はなく、**行動に役立つ形の未来を予測できればよい**。

## P3 への適用可能性

- P3 の world model の優先観点「予測・シミュレーション・表現学習」のうち、**再構成せずに潜在空間だけで予測する**方向の事例。運転の world model は動画を生成する重い構成が多いが、planner が使うのは「その行動の結果どうなるか」の情報だけなので、latent で十分かを問う材料になる。
- VLM が policy と world model を兼ねる構成は、VLA を world model として使い回す設計の検討に繋がる。推論時に imagination を使うのか、学習時だけ使うのか (JAM / MoGAP は学習時だけ) で、車載の latency 予算への影響が変わる。
- 注意点: 評価対象は「interactive な視覚環境」5 つで、具体的な環境名 (ゲーム的な環境か robot か) は abstract から分からない。運転のように、他者の振る舞いが不確実で安全制約がある環境で、潜在空間の imagination が信頼できるかは未確認。

## 試すべき実験アイデア

1. 手元の VLA (あれば) の中間表現から次の時刻の表現を予測する head を足し、その予測を使った imagination で候補軌道を評価できるか、を closed-loop simulation の小さな環境で見る。再構成なしの world model がどこまで planner の役に立つかの下見。
2. 画像再構成を使う world model と、latent 予測だけの world model を、同じ planner の候補評価に使い、planning 指標と計算量を比べる (論文の主張「再構成は不要」の運転での検証)。
3. imagination のずれ (想像した結果と実環境の結果の差) を、policy が変わるたびに測る。論文が問題にしている分布の shift が、運転 policy でどれだけ起きるかの診断になる。

## 注意

abstract のみに基づく。5 つの環境の中身、比較した baseline、imagination の深さ、VLM の大きさ、学習全体の cost は未確認。「最良」は学習可能な手法の中での比較で、環境ごとの差の大きさは分からない。
