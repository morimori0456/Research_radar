# Adapting Video Models for Robot Control via Motion-guided Asymmetric Prediction (2610.36624)

- トピック: next_arch (P3) / スコア 4.5 (RSS 回収分: cs.RO ではなく cs.AI feed の cross-list)
- URL: https://arxiv.org/abs/2610.36624

## 何を解決する論文か

WAM (World Action Model; 動画生成 model を土台にして、将来の映像と行動を同時に予測する robot policy) は、動画生成の事前学習で得た表現を robot の制御に転用する。このとき「将来の映像を予測する」目的関数が、事前学習した表現を対象 robot の domain に適合させる役目を持つ。ところが標準の映像予測は、動画事前学習から引き継いだまま、画面のどの領域も一様に扱う。制御に効くのは物体や腕が動く領域で、背景のような静止領域は大半が無関係なので、supervision の配分が無駄になっている。この論文は、映像予測の supervision を空間的にどう配るかを調べ、動く領域に集中させると policy が大きく良くなることを示す。

## 手法の核心

- **MoGAP (Motion-Guided Asymmetric Prediction)**: WAM の通常の「映像 + 行動」予測に、動く領域に注目した映像予測を追加で足す。
- **asymmetric noise (領域ごとに非対称なノイズ)**: diffusion (ノイズを足した映像を元に戻す生成方式) の学習で、動的な領域により強いノイズを乗せ、静的な領域には弱いノイズしか乗せない。model は「ほぼ無傷の静止領域」を文脈にして、「大きく壊された動的領域」を復元する。静止領域は答えが分かっているので、勾配が動的領域の予測に集まる。
- **training-only の補助経路**: 追加の予測経路は同じ video diffusion backbone を共有し、学習中だけ使う。推論時の構成と cost は元の WAM のまま。
- 動きの手がかりは学習用の動画から直接作る (たとえばフレーム間の差分のようなもの)。外部の teacher model や、深度のような別 modality を必要としない。
- 結果: GR-1 tabletop benchmark (robot manipulation の simulation) で、Fast-WAM (Wan2.2-5B ベース) の success rate が 38.8% から 47.5%、Cosmos3-Nano ベースが 52.3% から 62.3% に上がる。複数の WAM architecture で一貫して改善する、と報告している。

## P3 への適用可能性

- 前日の JAM (2610.37219; 将来予測を推論に持ち込まない補助 loss) と同じ「学習時だけ構造を足す」系統で、こちらは「将来予測のどこに supervision を配るか」という別の軸を与える。運転の動画 world model では、画面の大半は道路や空や建物のような静止領域で、他車・歩行者・自車の動きに対応する領域は小さい。一様な予測 loss は、この小さい領域に十分な重みを与えていない可能性が高く、MoGAP の発想はそのまま当てはまる。
- 動きの手がかりを動画自身から作る点は、運転 log にそのまま使える。ego motion (自車の動き) で背景が全体に動くため、静的か動的かの判定にはフレーム間差分より ego motion を補正した残差 (他車の動き) が要る、という運転固有の工夫は必要になる。
- 注意点: 評価は robot manipulation の simulation のみ。運転での確認はない。動画 world model を policy の事前学習に使う構成が前提で、それを使わない VLA にはそのまま持ち込めない。

## 試すべき実験アイデア

1. 手元の動画予測つき driving model (あれば) の映像予測 loss に、動的領域の重み付けだけを足す最小版。重み付けは、ego motion を補正したオプティカルフローの大きさで決める。NAVSIM や Bench2Drive の planning 指標への効きを、重み付け無しと比べる。
2. 論文の asymmetric noise (動的領域に強いノイズ、静的領域に弱いノイズ) と単純な loss の重み付けを、同じ予算で比べる。利得がどちらの機構から来るかの切り分け。
3. 動的領域の定義を (a) フレーム間差分、(b) ego motion 補正後の残差、(c) 検出された他 agent の bounding box、で変え、運転では何が「動く領域」として効くかを見る。

abstract のみに基づく。動きの手がかりの具体的な作り方、補助経路の loss の重み、seed 間の分散、他の benchmark での結果は未確認。success rate の改善幅 (約 9〜10 点) は大きいが、同じ simulation 内の比較である。
