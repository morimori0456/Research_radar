# IMPACT — 平均された loss が、いちばん大事な場所を見落としていた

**topic:** next_arch / **project:** P3 (主) + P2 / **hf_upvotes:** 0
**スコア:** P1 3.5 / P2 **4.0** / P3 **4.0**
著者: Rongze Tang, Jianjie Fang, Zhaolu Wang, Ziyou Wang, Xvyuan Liu ほか

## 何を解決する論文か

**world model (行動を条件に未来の観測を予測するモデル)** は見た目の品質では進歩したが、**物理的にもっともらしい相互作用 —— 手が物に触れて物が動く、といった部分 —— が苦手なままである。**

既存の対処は、動きや幾何や意味を符号化した**外部表現**で生成を制約する方向だった。しかしその表現を得るには補助的な推定器や手動アノテーションが要り、**学習をスケールさせられない。**

**著者は制約を足すのをやめ、学習目的そのものを疑う。****そして supervision-allocation mismatch (監督の配分の不整合) を特定する —— 全体で平均を取る MSE (Mean Squared Error) の denoising objective (拡散モデルでノイズを除去する学習目標) の下では、画面の大半を占める静止した内容が最適化の信号を支配し、相互作用の生成にとって決定的な、面積の小さい動的物体の領域が不釣り合いに学習されない。**

**問題は表現の不足ではなく、loss の配り方だった。**

## 手法の核心

- **内部から prior (事前情報) を取る。**操作対象の物体に対応する token に紐づく **cross-attention (行動やテキストの条件と画像 token を対応付けるアテンション)** を、**行動によって変化する領域の時空間的な prior として使う。**外部の推定器は要らない。
- **その prior から候補領域をサンプリングする。**
- **候補を detached local prediction error (勾配を切った、その領域だけの予測誤差) で校正して interaction map (相互作用マップ) を作る。**アテンションだけだと「注目しているが実は当たっている」領域まで拾うので、**誤差で重みを補正している。**
- **この map で denoising の監督を再重み付けする。**
- **設計上の要点は、足さないものの側にある —— 外部表現が要らず、推論時の変更も要らない。****学習時の loss の重みだけが変わる。**
- **ロボットアーム操作と人間の手の操作、複数の制御様式、複数の DiT (Diffusion Transformer; 拡散モデルの backbone を transformer にしたもの) backbone にわたって、対応する MSE 学習のベースラインを一貫して上回る。**改善は相互作用の忠実度・物理的妥当性・視覚品質。

> **引用前の注意:** 比較対象は **「対応する MSE 学習ベースライン」**であり、**外部表現を使う既存手法との直接比較が abstract に書かれていない。**「外部表現なしで同等以上」なのか「MSE より良い」だけなのかで、主張の強さが大きく変わる。

## P1 / P2 / P3 への適用可能性

**この論文の一文は、そのまま R1 の主張の学習側の双子である。**

R1 が言おうとしているのは **「集約された評価指標は、稀だが決定的な部分を隠す」**である。**IMPACT が言っているのは「集約された学習目標は、稀だが決定的な部分を学ばせない」。****評価と学習で、同じ構造の同じ失敗が起きている。**

**この対応は、R1 の導入を書くときに効く。**「なぜ集約すると壊れるのか」を評価の側だけで論じると、**「指標の設計が下手だっただけでは」と読まれる余地がある。****学習の側でも同じことが独立に報告されているなら、これは設計の巧拙ではなく、平均を取るという操作そのものの性質だと言える。****引用 1 本で、主張の一般性が上がる。**

**P2 (R2) にとっては、6 例目である。**W35 の結論 **「蒸留・適合の支配変数は loss の関数形ではなく、監督を当てる範囲である」**が、**ついに言語モデルの外 —— 拡散 world model —— でも同じ形で観測された。**

| 分野 | 論文 | 監督の当て方 |
|---|---|---|
| LLM 蒸留 | UC-MOPD / Echo-GRPO / [Switch Distillation](2609.01532.md) | 更新する token を選ぶ |
| 音声/生成 | DART-SD | loss を当てる位置を選ぶ |
| RL 蒸留 | [On-Policy Distillation](../2026-09-02/2608.31046.md) | 基準そのものが不要 |
| **拡散 world model** | **本論文** | **loss を当てる空間領域を選ぶ** |

**5 例が言語モデル周辺に固まっていた間は「LLM 特有の現象」という反論があり得た。分野が離れた 6 例目が出たことで、R2 は「監督配分」を分野横断の変数として主張できる。**

**P3 (R3) には軸の外側から効く。**R3 の 3 軸はどれも**構造**の軸だが、**IMPACT は構造を一切変えずに loss の重みだけで相互作用の質を上げている。****「マップの軸が構造だけでよいのか」という問いを立てる材料である。**ただし **R3 は今月着手しない。**

**P1 は 3.5** —— 直接使う手法ではないが、上記の通り**論拠として使う。**

### 試すべき実験アイデア

1. **【最優先・09-06 gate に効く・30 分】R1 の導入に「学習側でも同じ失敗が起きている」という 1 段落を足す。****必要なのは本論文の 1 文の引用だけ。**図 1 の作業とは独立で、**待ち時間なしで今日書ける。**
2. **【1 時間・机上】「面積で重みが決まってしまう」構造が、R1 の評価対象にも無いか点検する。**走行ログで solvability を集計するとき、**大半の時間は「逃げ道が十分ある」状態のはずで、そのまま平均すれば決定的な数秒が薄まる。****IMPACT と全く同じ罠を、自分の指標の集計側で踏む可能性がある。**先に気づけば、図 1 の集計方法が変わる。**これは今週やる価値がある。**
3. **【メモのみ・R2 用】attention を「どこに監督を当てるか」の内部信号として使う設計を記録する。**本日の [Switch Distillation](2609.01532.md) は教師の entropy、[Sink Strength](2609.00746.md) は attention sink、本論文は cross-attention。**3 本とも、追加の学習なしにモデル内部から取れる信号で監督や劣化を制御している。**R2 の系統則を書くとき、**この「内部信号で決める」という共通点が軸になる。**
