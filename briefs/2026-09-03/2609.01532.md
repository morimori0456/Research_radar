# Knowledge Distillation During Mid-Training Favors Reasoning over Factual Recall — 蒸留は推論を伸ばす裏で、事実の記憶を遅らせていた

**topic:** fm_distill_finetune / **project:** P2 (主) / **hf_upvotes:** 0
**スコア:** P1 2.0 / P2 **5.0** / P3 1.5
著者: Jacqueline He, Howard Yen, Shuyue Stella Li, Margaret Li, Hanqing Zeng ほか

## 何を解決する論文か

**logit-based knowledge distillation (教師モデルが出す語彙全体の確率分布を、生徒に真似させる蒸留)** は小型言語モデルの標準手法だが、**学習のどの段階で使っても同じように効くのかは検証されていない。**

著者は **mid-training (事前学習と post-training の間に、精選したコーパスで自己教師あり学習を続ける中間段階)** に絞って統制実験を行い、**段階によって効果の符号が変わることを見つけた。**

**pre-training 中の forward KL 蒸留 (教師分布 → 生徒分布の向きに Kullback-Leibler divergence を最小化する、標準的な蒸留の定式化) は、推論も事実記憶も同時に改善する。ところが mid-training で同じことをすると、推論は伸び続けるのに事実記憶の獲得が遅くなる。**平均的な指標だけ見ていれば「蒸留は効いている」で終わっていた話である。

## 手法の核心

- **原因を 2 つの非対称性の掛け算として説明する。**
  - **教師側の非対称性: 教師は procedural data (手続き的・推論的なデータ) では自信が高く、knowledge-intensive data (事実知識が要るデータ) では自信が低い。**
  - **生徒側の非対称性: 生徒は low-entropy な事実知識を学習の**早い**段階で獲得する。**
  - **つまり mid-training の時点では、生徒がちょうど事実を覚えている最中なのに、教師はその領域で曖昧な分布を返す。**曖昧な分布を真似させれば、覚えかけの事実がぼやける。
- **対策 Switch Distillation は驚くほど単純: 教師が自信を持っている token でだけ蒸留し、それ以外は通常の cross-entropy に戻す。**
- **自信の判定に使うのは teacher predictive entropy (教師の予測分布のエントロピー。低いほど 1 つの語に確信がある) のみ。**追加のモデルもアノテーションも要らない、**軽量な routing signal (どちらの loss を使うか振り分ける信号)** である。
- **数値: NTP (Next-Token Prediction; 素の次単語予測) に対して推論性能 1.61–1.71 倍、知識・常識 1.13–1.19 倍を得ながら、事実記憶を 96.7–96.8% 保持。**
- **そして重要なのは持続性 —— post-training を通した後も効果が残る。**推論 1.25–1.32 倍・知識/常識 1.13–1.20 倍を維持したまま、**事実記憶の差は解消する。**中間段階での判断が最終製品まで効いている。

> **引用前の注意:** 「教師サイズを通して一貫して既存の蒸留 objective を上回る」とあるが、**生徒サイズを振った結果があるかは abstract からは読めない。**

## P1 / P2 / P3 への適用可能性

**R2 にとって、これは「監督を当てる範囲が支配変数である」の 5 例目であり、しかも軸が 1 本増えている。**

W35 は P2 について **「蒸留・適合の支配変数は loss の関数形ではなく、監督を当てる範囲である」**と結論し、根拠に [UC-MOPD](../2026-08-29/2608.26735.md)・[Echo-GRPO](../2026-08-29/2608.26684.md) の「更新する token の選択」、[DART-SD](../2026-09-01/2608.18524.md) の「loss を当てる位置」、[On-Policy Distillation](../2026-09-02/2608.31046.md) の「そもそも教師の内容が要らない」を並べてきた。

**本論文が足しているのは、範囲を決める基準が「教師の自信」であり、しかもその適否が学習段階に依存するという点である。**

| 例 | 監督を当てる範囲を決める基準 |
|---|---|
| UC-MOPD / Echo-GRPO | 生徒側の不確実性・clipping の境界 |
| DART-SD | loss を当てる位置 (空間的) |
| On-Policy Distillation | **基準そのものが不要** (低確率 token を抑えるだけ) |
| **本論文** | **教師側の entropy。かつ「いつ」当てるかが効果の符号を変える** |

**R2 の中心問題の読み方が、これで具体的になる。**RESEARCH_PIPELINE には **「容量比 1.0 でも蒸留が効く反例 5 本で、容量差が原因という当初の前提は棄却」**と記録されている。**本論文はその代わりの説明候補を出している —— 効くかどうかは容量比ではなく、教師の自信分布と生徒の学習段階の噛み合わせで決まる。**容量比は静的な量だが、**噛み合わせは学習の進行とともに動く量**であり、**「同じ容量比で効いたり効かなかったりする」を説明できる。**

**さらに、本日の [圧縮運転方策の閉ループ評価](2609.00718.md) と同じ形をしている。**あちらは**「集約スコアは、特定の運転能力が丸ごと落ちたことを隠す」。**こちらは**「平均性能は、事実記憶だけが遅れていることを隠す」。****分野は無関係なのに、隠れ方が同型である。**

**P1 は 2.0、P3 は 1.5。**直接の接点はない。

### 試すべき実験アイデア

1. **【最優先・R2・1 時間・机上】過去の蒸留ログを「どの段階で蒸留したか」で並べ直す。**手元に「蒸留が効かなかった」事例があるなら、**容量比ではなく段階で説明が付くかを確認する。**必要なのは既存ログの読み直しだけで、**新しい学習は要らない。**もし段階で説明が付くなら、**R2 の独立変数が容量比から段階に入れ替わる。**
2. **【R2・10 月以降・半日】teacher predictive entropy を、過去の蒸留データに後付けで計算する。**Switch Distillation を実装する前に、**「教師の entropy が data domain によって本当に割れているか」だけを確認する。**割れていなければ、この機構は自分の設定では効かない。**判定が学習なしで済む。**
3. **【要確認・30 分】生徒サイズを振った結果があるかを本文で確認する。**[On-Policy Distillation](../2026-09-02/2608.31046.md) について 09-02 に立てたのと同じ確認である。**R2 が系統則を主張するには、どの論文についてもこれが要る。**確認項目が 2 本に共通しているなら、**まとめて 1 回で済ませる。**

> **実行時期の注意:** RESEARCH_PIPELINE の **2026-09 は R1 に絞る方針**である。上記 1 は 1 時間の机上作業なので今月でも可能だが、**2 は 10 月以降。**
