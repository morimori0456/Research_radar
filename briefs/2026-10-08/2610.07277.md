# Distribution-Transfer Safe-Horizon MPC: 障害物の mode 分布が不明でも衝突リスクの保証を保つ

- 対象: P1 (Planner AI + 評価)
- 元論文: http://arxiv.org/abs/2610.07277v1
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
Scenario-based MPC (Model Predictive Control; 先を予測して制御入力を最適化する手法で、不確実性は sampling した複数 scenario で近似する) は、sampling 分布が真の分布とずれると衝突リスクの保証が崩れる。障害物が切り替わる dynamic mode (例: 直進/右折) を持ち、その確率が未知の場合に、有限回の観測から保証を維持する方法を与える。

## 手法の核心
- 有限個の mode 観測から、未知の categorical mode law (mode の出現確率) の confidence set を作る。
- multiplicative domination bound により、選んだ sampling 分布で成り立つ Safe-Horizon の衝突リスク certificate (証明書) を confidence set 内の全分布へ transfer する。
- Wasserstein geometry (分布間の距離) で、予測軌道が似た mode 間でのみ確率を再配分するよう regularize する。
- 衝突リスクの surrogate で、危険な mode に sampling を寄せる。
- 分布ずれに必要な追加の tightening 量と、複数障害物の factor を掛け合わせた際の multiplicative conservatism を明示する。

## 適用可能性 (P1)
- planner の安全性を「保証付き」で評価・設計する話。他車の挙動予測が外れる状況での planner の衝突リスク評価に使える考え方。
- 注意: abstract に実験規模の記載なし。保守性 (conservatism) が実用上どの程度かは本文で確認が必要。

## 試すべき実験
1. 2D toy (他車が 2〜3 mode で切り替わる) で、sampling 分布をわざとずらし、certificate なしの scenario MPC の実衝突率が理論値を超えることを再現する。
2. confidence set の幅 (観測数) と tightening 量の関係をプロットし、必要な観測数の目安を出す。
