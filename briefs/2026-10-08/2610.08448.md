# Cross-Tokenizer On-Policy Distillation: alignment の網羅性より supervision の信頼性

- 対象: P2 (Foundation Model 蒸留)  / hf_upvotes 151
- 元論文: http://arxiv.org/abs/2610.08448v1
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
OPD (On-Policy Distillation; student 自身の生成に対し教師が feedback を与える蒸留) で、教師と student の tokenizer (文字列を token に分割する規則) が違うと、token 位置と語彙の両方を揃えないと予測を比較できない。「揃える範囲を広げれば学習が良くなるか」を検証し、広げない方が良いことを示す。

## 手法の核心
- 3 組の異種 teacher-student (数学推論・code 生成) で、strict 1:1 に対応する token だけで student 生成 token の大半をカバーできることを示す。
- 共通語彙は、strict に揃う位置で教師・student 双方の確率質量のほぼ全てを保持する。
- strict 位置で、student が選ぶ top-16 の共通語彙に限った reverse KL (student 分布を基準にした KL) が、全共通語彙の OPD と同等の精度。cross-tokenizer の既存 baseline を上回る。
- mismatch 部分に span log-probability の MSE を足して網羅率 100% にすると精度が下がる。span の gradient は strict の gradient と向きが弱く/逆で、大きさも相対的に増える。
- 結論: 網羅率の最大化でなく supervision の信頼性を優先する。

## 適用可能性 (P2)
- 異なる系列の foundation model を教師にする場合の recipe として、実装が軽い (top-16 reverse KL のみ)。
- 注意: 評価は LLM の推論・code タスク。vision/driving の蒸留に直接は移せない。「信頼できる位置の信号だけ使う」という考え方の転用になる。

## 試すべき実験
1. 手元で tokenizer が異なる小さい教師-student 組を用意し、strict 位置の被覆率と共通語彙の確率質量を測る (前提の確認)。
2. top-k の k (4/16/64) を振り、精度の飽和点を見る。
3. 追加の補助 loss を入れる前後で、新 loss と主 loss の gradient の cosine 類似度をログし、「逆向きなら外す」基準を作る。
