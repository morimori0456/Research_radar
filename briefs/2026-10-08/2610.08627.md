# PPWM: 並列に未来軌道を予測する world model で long-horizon planning を速くする

- 対象: P3 (world model)。candidates.json の topic は planner_ai で、P1 の planning にも関係する
- 元論文: http://arxiv.org/abs/2610.08627v1
- 根拠: abstract のみ (本文・コード未確認)

## 何を解決する論文か
world model を使った long-horizon planning は、予測した状態を次の入力に戻す autoregressive rollout が標準だが、horizon の長さ分の逐次計算が必要で、復元した状態のフィードバックにより後の予測ほど誤差が乗る。PPWM は有限 horizon の軌道を並列に予測する。

## 手法の核心
- 各 horizon を「その時点までの action prefix」に条件付け、未来の表現どうしは decode 前に相互作用させて因果性を保つ。
- 時間的因果性と、state ごとの出力の再帰を分離する。autoregressive rollout を causal trajectory map とみなし、PPWM が取り除く decoded-state feedback の経路を定式化する。
- 4 つの visual-control タスクで long-horizon prediction error が最小、CEM (Cross-Entropy Method; 候補 action 列をサンプルし上位で分布を更新する探索) の simulator 成功率も最高。
- autoregressive な LeWM baseline 比で CEM planning が平均 3 倍超高速。

## 適用可能性 (P3 / P1)
- 世界モデルを planner の内側ループで使う場合の計算量対策。GeoWM と併せ、「再帰しない予測」が共通テーマ。
- 注意: 評価は小規模な visual-control タスク。driving の multi-agent 環境での検証は未確認。

## 試すべき実験
1. 手元の world model で horizon を伸ばしたとき、autoregressive と並列予測の誤差・遅延の増え方を比較する。
2. CEM の候補数を固定して planning latency と成功率の trade-off を測る。
