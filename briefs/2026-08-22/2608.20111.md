# Planning-Oriented End-to-End Autonomous Driving: Architectures, Evaluation, and Emerging Paradigms

- arXiv: https://arxiv.org/abs/2608.20111
- topic: planner_ai (P1) / relevance **5.0** / hf_upvotes 0
- 種別: survey

## 何を解決する論文か

end-to-end autonomous driving (カメラ画像から制御出力までを1つの学習モデルで繋ぐ自動運転方式) は、この数年で「画像→操舵の回帰」から「planning を主役に据えた構成」へ移った。本 survey はその移行を、behavior cloning (人間の運転ログを教師にして行動を真似させる学習) から world-model ベースの planner、VLA (Vision-Language-Action; 画像と言語指示から行動を直接出すモデル) 系までを通して整理する。

著者の主張は、現代の end-to-end driving を分ける本質は「中間表現を持つか否か」ではなく、**その中間表現が学習され・教師づけられ・評価されているか**である、という点にある。そして「benchmark を揃えずに architecture の進歩を読むことはできない」と繰り返し述べる。

## 手法の核心

- **4 軸での分類法**: input representation (入力の持ち方) / planning output (何を出力するか: 軌道か制御か) / supervision signal (何を教師にするか) / evaluation protocol (どう測るか)。architecture の話と評価の話を同じ表の上に並べる構成になっている。
- **カバー範囲**: behavior cloning、conditional imitation learning (経路指示などの条件を与えて模倣する方式)、privileged distillation (シミュレータ内でのみ得られる特権情報を使う teacher から、実際に使えるセンサ入力だけの student へ蒸留する手法)、BEV (Bird's-Eye View; 俯瞰図に投影した中間表現) と vectorized planning、perception-prediction-planning を1本に統合した構成、world-model ベース planner、VLA 系。
- **benchmark の移り変わりを明示的に扱う**: open-loop の軌道一致度 → closed-loop simulation (planner の出力が環境に反映され、その結果をまた入力する評価) → non-reactive real-log evaluation (実ログを再生するが他車は ego に反応しない評価) → long-tail testing → human-preference-aware metrics。
- **最も強い結論**: displacement 系の open-loop 指標 (ADE/FDE; 予測軌道と正解軌道の平均・最終時点の位置誤差) だけでは、安全で人間に沿った運転の証拠としてほぼ何も言えない。
- **open challenges として挙がるもの**: uncertainty-aware planning、learner-expert mismatch (学習した方策が自分で作った状態分布の上で評価されない問題)、runtime safety assurance、language-action grounding、world-model validation、reproducible benchmarking。

## P1/P2/P3 への適用可能性

**P1 (planner + 評価) にとって、本日の最重要文献。** R1 (HIL 評価 × conformal 安全指標) が立てている問い —— 「benchmark のスコアが高い planner は、閉ループで本当に良い planner なのか」 —— は、この survey が open challenge として名指ししている runtime safety assurance と reproducible benchmarking にそのまま重なる。つまり R1 は「誰も言っていないこと」ではなく「survey が未解決と認定した穴」を埋める位置にある。これは論文の導入で引くのに最も強い形である。

**08-21 の 2 本との接続**: [Decision-Metric Alignment](../2026-08-21/2608.18746.md) は world model のコスト関数について「指標が判断を保証しない」を示し、[DA-WAM](../2026-08-21/2608.19085.md) は NAVSIM で最高性能を出した。本 survey は、その NAVSIM 的な non-reactive real-log evaluation が evaluation protocol の階梯のどこに位置し、何を原理的に測れないかを俯瞰の側から書いている。3 本を合わせると「性能を出した論文 / 指標を疑った論文 / 階梯を描いた論文」が揃う。

**W34 課題カード1 (規制が「臆病すぎる」と「強引すぎる」を別制度で罰し始めたが、トレードオフ曲線を出せる者がいない)** に対しては、本 survey の evaluation 軸がそのまま骨格になる。過保守側のコストは non-reactive な評価では原理的に計上されない、という論点を survey の言葉で裏付けられる。

### 試すべき実験アイデア

1. **survey の 4 軸表を、自分の手元の planner 候補に対して埋める。** 特に evaluation protocol の列を埋めると、「今どの階梯で測っているか」が一目で出る。R1 の position paper の Table 1 の原型になる。
2. **同一 planner を 3 つの protocol (open-loop displacement / non-reactive real-log / reactive closed-loop) で測り、順位が入れ替わるかを見る。** 入れ替われば、それ自体が R1 の主張の一次証拠になる。survey は「入れ替わる」と主張しているが、自前の数字で示せると強い。
3. **survey の open challenges リストを、conformal prediction (予測の外れ率を、データ分布に仮定を置かずに有限サンプルで保証する統計手法) で答えられるものと答えられないものに二分する。** R1 の射程を確定させる作業になる。
