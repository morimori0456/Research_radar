# Orthogonal JEPA: Factorized Predictive States for Latent World Models

- arXiv: https://arxiv.org/abs/2608.20065
- topic: next_arch (P3) / relevance **4.5** / hf_upvotes 0

## 何を解決する論文か

JEPA (Joint-Embedding Predictive Architecture; 観測のピクセルを再構成せず、表現空間の中で「未来の表現」を当てにいく world model の学習方式) は、latent world model を作る素直な手段として広く使われている。だが標準的な JEPA は、予測できる内容のすべてを **1 つの target embedding と 1 本の予測経路**に通す。

この一枚岩の構成が、複雑な系で問題を起こす、というのが本論文の出発点である。支配的な信号 (大きく動く・分散の大きい成分) が容量を独占し、目立たないが予測可能な構造には弱い勾配しか届かない。あるいは互いに衝突する勾配が届く。結果、latent state は「派手な成分の予測器」に退化する。

## 手法の核心

- **orthogonal predictive factorization**: 学習される basis matrix (基底行列) が target state を複数の成分に分解し、成分ごとに専用の予測 branch が、共有された context 表現から推定する。1 本の予測経路を N 本に割る。
- **predictive regression が factor の大きさを保存する**: 分解した成分から latent state を再合成できる必要があるため、方向だけでなくスケールも予測対象に含める。
- **orthogonality objective**: 分解方向が互いに重ならないように罰則をかける。同じ成分を複数の branch が担当する冗長を防ぐ。
- **factor-activity regularization + online variance regularization**: 前者は射影後の target が変動を保つよう促し、後者は encoder が座標ごとに定数へ潰れる collapse (すべての入力を同じ表現に写して loss を下げる自明解) を抑える。JEPA 系の定番の失敗モードに対する 2 段の防御になっている。
- **target の定義が広い**: target は「時間的に未来」でも「空間的に隠れた部分」でも「同じ系の別の部分観測」でもよい。同じ predictive-state 機構が全部に効く、という設計。
- **評価対象の幅が異様に広い**: controlled vision、single-cell transcriptomics (単一細胞の遺伝子発現量)、longitudinal health records、continuous control、molecular dynamics。representation の質・forecasting・planning・long-horizon stability の 4 観点。

## P1/P2/P3 への適用可能性

**P3 (次世代アーキテクチャ) の world model 側に、直接効く構造上の提案。** 自動運転の world model が抱える病はまさにこの形である —— 自車の並進運動と背景の流れが分散の大半を占め、他車の意図・遠方の小さな物体・信号の状態といった「小さいが判断を左右する成分」に容量が回らない。orthogonal factorization は、この偏りに対する architecture 側の回答として読める。

**08-21 の [Decision-Metric Alignment](../2026-08-21/2608.18746.md) と組で読むと価値が上がる。** あちらは「latent の幾何が判断の順序を保存しているかを測れ」と言い、こちらは「latent を成分に割れば、支配的成分に潰されない」と言う。**測る手段 (08-21) と、直す手段 (本日) が揃った。** factorize した各成分に対して decision-metric alignment を個別に測る、という組み合わせが自然に書ける。

**P1 への波及**: 成分ごとに予測 branch が分かれているので、予測誤差も成分ごとに出る。「どの成分の予測が外れたときに planner が誤るか」を対応づけられれば、world-model validation (survey [2608.20111](2608.20111.md) が open challenge に挙げたもの) の具体的な手段になる。

### 試すべき実験アイデア

1. **driving log で ego-motion 成分と他車成分を強制的に別 factor に割り当て、後者の予測誤差だけを取り出す。** 一枚岩の JEPA では他車の予測誤差が全体の loss に埋もれて見えない、という仮説の検証。small scale で先に回せる。
2. **factor 数を振って long-horizon stability を測る。** 論文は 4 観点で評価しているが、factor 数と rollout の破綻時点の関係は、P3 が知りたい形の系統則になる。R2 (蒸留の capacity gap 系統則) と同じ「軸を振って破綻境界を見る」型の実験設計が流用できる。
3. **factor ごとの decision-metric alignment を測る。** 「表現全体としては判断に使えないが、ある factor だけは使える」が観測できれば、planner に渡すべき latent の部分集合を選ぶ根拠になる。
