# What Matters for Latent Actions in Robot Learning

- arXiv: https://arxiv.org/abs/2608.19613
- topic: **next_arch (P3)** — candidates.json では fm_distill_finetune に分類されていたが、内容は LAM/VLA の設計選択の研究なので本枠で採用 (下記「トピック再配置」参照)
- relevance **4.5** / hf_upvotes 0

## 何を解決する論文か

LAM (Latent Action Model; 動作ラベルの付いていない大量の動画から、連続する2フレームの差を説明する「潜在的な行動」を教師なしで取り出し、それを本物の行動の代用として方策学習に使うモデル) は、ロボット学習が web 規模の動画を使うための本命として急速に伸びた。だが分野が散らかっている。各手法が別々の設定で別々の設計選択を評価しており、**下流のマニピュレーション性能を本当に決めている要因がどれなのか、誰も切り分けていない。**

本論文は LAM の初の包括的 empirical study である。代表的な手法を1つの autoencoding の枠組みに統一したうえで、41 の設計選択を横断比較する。

## 手法の核心

- **共通の autoencoding 枠組みへの統一**: 各手法を「前後フレームから潜在行動を encode し、それを条件に次フレームを decode する」という同一形式に書き直す。この正規化が比較を可能にしている。
- **3 次元 × 41 の設計選択を系統的に振る**: (1) latent action modeling paradigm (潜在行動をどう表現するか: 連続ベクトルか離散コードか等)、(2) learning objective と regularization、(3) latent action integration strategy (取り出した潜在行動を下流の方策にどう繋ぐか)。
- **proxy metric の妥当性そのものを検証する**: 潜在行動の質を測るとされる 4 つの proxy 指標を取り上げ、**それらが下流のマニピュレーション性能を実際に予測できるか**を評価する。ここが本論文でいちばん効く部分である。
- **主要な結論**: VLM (Vision-Language Model) の backbone を潜在行動で fine-tuning したものが、下流の方策学習の初期値として最も強い。
- 3 つの標準ベンチマーク + 実機での検証。

## P1/P2/P3 への適用可能性

**P3 にとって「読む価値の密度」が最も高い型の論文。** 新手法ではなく ablation 集なので、そのまま設計判断の根拠表として使える。R3 (VLA × world model 統合アーキテクチャの分類マップ) は今「調査中」の状態にあるが、本論文の 3 次元分類はマップの軸候補としてそのまま採れる。自前で軸を発明するより、既に 41 通りで検証された軸を引くほうが速く、かつ主張が強い。

**最も重要なのは proxy metric の検証パートである。** 「潜在行動の質を測る指標が、下流性能を予測しない」が示されているなら、それは 08-21 の [Decision-Metric Alignment](../2026-08-21/2608.18746.md) と**完全に同型の指摘**になる —— 中間表現の良さを測るつもりの指標が、最終的な判断の良さを保証しない。世界モデルのコスト関数 (08-21)、planner の benchmark ([2608.20111](2608.20111.md))、そして潜在行動の proxy metric (本日) で、同じ穴が 3 つの別分野に開いていることになる。**R1 の主張を「自動運転固有の話ではなく、学習された中間表現一般の話」として一段上に持ち上げる材料になる。**

### 試すべき実験アイデア

1. **論文の 4 つの proxy metric と下流性能の順位相関を、自前のタスクで再測定する。** 手法を作らずに数字が出る。R1 の横展開の証拠として最も安い。
2. **「VLM backbone を潜在行動で fine-tuning すると初期値として強い」を、蒸留の文脈に移す (P2 との交差)。** 潜在行動での fine-tuning を、teacher からの蒸留の前段に置いたときに capacity gap がどう動くか。R2 の系統則実験に 1 軸足す形になる。
3. **41 の設計選択のうち、driving 系のデータで意味が反転するものを探す。** マニピュレーションでは手先の動きが潜在行動の主成分になるが、driving では自車運動が支配的になる。[Orthogonal JEPA](2608.20065.md) の問題意識と同じ構造なので、2 本を同時に扱える。
