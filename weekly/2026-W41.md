## 4. 記憶チェック (5問)

**Q1. world model の MSE が小さいのに planning が悪くなるのはなぜか? 診断は何で行うか? (`2610.05550`)**
A. 誤差の大半を占める成分 (全候補に共通する偏り = center error) と、行動の順位付けに効く成分 (action-relative response) が別だから。16 セル中 14 で center が MSE を支配するが、6 セルでは action-relative だけを直した方が順位相関 (Spearman) も top-30 候補も良い。診断は、同じ開始状態・複数候補 action 列で「予測 vs 実際の終端」の順位相関を MSE と並べる。ただし設定で結論が変わり、結果は小規模な control task のみ。

**Q2. JEPA の world model が「行動を使っていない」ことを、論文はどう示したか? (`2610.02860`)**
A. 同じ状態から行動だけ変えて分岐させた。次の画像の 41.5% は行動を変えても画素が同一 (見えない分は予測できない)。見える場合でも、行動を変えた出力の差は、同じ大きさのノイズを足した差の 1/50〜1/190 しかない。P1 では、閉ループ simulator の他車が ego の行動に反応するかの検査に転用できる。

**Q3. Cross-Tokenizer OPD で、token の対応づけを広げると精度が下がったのはなぜか? (`2610.08448`)**
A. 対応が不確かな位置に足した span の loss は、確実に対応する (strict 1:1) 位置の loss と gradient の向きが弱く、または逆で、大きさも相対的に増えるから。strict 位置の top-16 共通語彙だけの reverse KL が、全語彙と同等の精度。補助 loss を足す前に、主 loss との gradient cosine を見る習慣に転用できる。

**Q4. fine-tuning の忘却はどこに集中し、1 行の対策は何か? (`2610.09835`)**
A. 新データにほぼ出ない token の output embedding に集中する。そうした token は softmax から一方向の勾配を受け続け、Adam の二次モーメントによる正規化が全幅の更新に増幅するため。対策は出力 projection だけ Adam の epsilon を大きくすること。8 設定中、安定な 7 設定で忘却が 39.4〜67.9% 減り、target の学習は劣化しなかった。対象は LLM で、視覚モデルは未確認。

**Q5. Dynamic Hazard の benchmark で、classical planner と RL policy の勝者を分けた要因は? (`2610.12249`)**
A. 部分観測かどうかでなく、障害物の動きの不確実性 (stochasticity)。deterministic なら classical が成功率ほぼ 100%、stochastic では同じ分布で学習した PPO が latency・成功率・path 品質で上回る。online search は計算 budget に強く依存する。評価では「success rate を budget とセットで、環境の確率性ごとに切って」報告する。2D の toy 環境で、運転への移行は未検証。
