## 2. 今週の精読1本

**→ [2608.18746 Decision-Metric Alignment in Latent World Models: Diagnostics and Actionable Fixes](../briefs/2026-08-21/2608.18746.md)**

選定理由: **hf 15 と話題性はほぼゼロ。それでも選ぶのは、これが「指標」ではなく「測り方の手続き」だから**である。
主張は一行 —— **潜在表現から中身がよく読み取れること (probe 精度) は、その表現で候補を並べ替えてよいことを意味しない。**
読み取れることと並べ替えられることは別の能力であり、**改善策を入れると成功率は上がるのに probe スコアは動かない**という
形で、分離が改善の側からも実証されている。**今週これと同型の指摘が独立に3本出た** ——
[survey](../briefs/2026-08-22/2608.20111.md) の「displacement 系 open-loop 指標は安全運転の証拠にならない」、
[What Matters for Latent Actions](../briefs/2026-08-22/2608.19613.md) の proxy metric 検証、W33 の 12959。
**分野が3つ違って構造が同じなら、それは分野の話ではなく測り方の話である。**
そして R1 にとってこれは**発明ではなく移植**として書ける (「planner の benchmark スコアは、閉ループでの良さを並べているか」) ——
**査読で最も通しやすい形。** ブリーフでなく原論文を読む必要があるのは、**価値の全部が指標の定義の細部に乗っている**ため。

読むときの問い(3つ):
1. **2つ目の指標 (探索の各段階で測る順位相関) は、具体的にどの段で切っているか。** 論文の主張の芯は
   「全体では順位が合っていても、絞り込んだ後の拮抗した候補の間で崩れる」ことにある。**だが CEM の反復途中で
   候補集合は分布が変わる** —— 段が進むほど候補は互いに似てくるので、**順位相関が下がるのは「幾何が壊れている」からではなく
   「差が測定誤差に埋もれている」からかもしれない。** **各段での実コストの分散が報告されているかを最初に探す。**
   無ければ、この指標は劣化の検出ではなく識別限界の測定であり、主張は一段弱まる。
2. **改善策 (行動を条件に含める目的関数) は、なぜ probe を動かさずに順位だけ直せたのか。**
   **「probe が飽和していただけ」なら分離の証拠にならない** —— 元の probe 精度が既に天井付近なら動かないのは当然である。
   **probe のベースライン値と、probe が動く条件 (表現を意図的に劣化させた対照) が置かれているかを見る。**
   置かれていれば「読み取りやすさと判断可能性は独立」という主張は強い。置かれていなければ「動かなかった」に留まる。
3. **運転に移したとき、「実コスト」に相当するものを我々は持っているか。** 論文は実タスクの進み具合を正解として使えるが、
   **運転の「実コスト」は閉ループを最後まで回さないと出ない。** ここが移植の唯一の急所である。
   **NAVSIM のような non-reactive 評価を実コストの代用にすると、W34 カード1 が問題にした過保守さが
   そもそも計上されない** —— つまり「順位が合っている」と出ても、**それは過保守さを無視した順位に合っているだけ**でありうる。
   **代用を使うなら、その代用が何を測っていないかを先に書くこと。**

## 4. 記憶チェック (5問)

1. **Q**: 閉ループシミュレーションでシナリオを N 本走らせて衝突が出なかったとき、我々は何を知ったことになるか。
   そして**サンプル数を増やしても原理的に届かない領域**とは何か?
   **A**: 確率 r の稀な臨界事象を N 本の独立試行が**全て取り逃す確率は、ちょうど (1-r)^N**。
   **r = 10⁻³ に対し N = 1,000 本走らせても、全て見逃す確率は約 37% ある。**
   届かない領域は**不連続なモード切替**。滑らかに食い違うモデル同士は必ず**体積を持った**食い違い領域を作るので
   ランダムに試せばいずれ当たるが、**ある条件を跨いだ瞬間に挙動が変わる境界はこの体積を一切持たない** ——
   **稀だから見つからないのではなく、測度が無いから原理的に見つからない。** 運転では黄→赤の判断境界、
   譲る/譲らないの切替、緊急ブレーキの発動閾値。**そして conformal prediction が与えるのは交換可能性の下での
   平均的な被覆であって、測度ゼロの臨界集合を捕まえるものではない** —— R1 は「何を保証しないか」を明示して初めて保証を名乗れる。
2. **Q**: S²VOPD は teacher と student の容量比をいくつにしたか。効いているのが「正則化」ではなく「非対称性」だと、
   どの対照実験の符号から言えるか。そして**やりすぎると壊れる**のはどういう加工か?
   **A**: **容量比 1.0 —— teacher と student は同じモデルでよい。** teacher に元画像、student に**強く加工して情報を落とした
   同じ画像**を見せ、student 自身の出力に teacher が評価を与える (on-policy distillation)。
   根拠は符号: **試した4系統すべての加工で性能が上がり、teacher と student に同じ入力を与える対称な自己蒸留では逆に性能が落ちた。**
   壊れるのは**答えの根拠そのものを消してしまう加工**。消してよいのは「あってもなくても答えが変わらない情報」だけ。
   → **R2 の支配変数は容量ではなく情報の差。** 08-17 が「差は teacher の監督できる時間の長さで埋まる」、
   08-18 が「差は student の入力情報量で作れる」、08-19 SOPD が「効き方を決めるのは監督の粒度」。**3日で3方向から同じ結論。**
3. **Q**: Decision-Metric Alignment は何と何が別の能力だと言い、それを測る指標を2つどう定義したか?
   **A**: **潜在表現から中身が読み取れること (probe 精度) と、その表現で候補を実タスクの順に並べ替えられること**は別の能力である。
   指標は2つ。① ランダムな行動列について「潜在コストの順位」と「実コストの順位」の **Spearman 順位相関**。
   ② **探索が候補を絞り込んでいく各段階で同じ一致度を測る** —— **全体で順位が合っていても、
   絞り込んだ後の拮抗した候補の間で崩れるなら、探索は最後の一歩で誤る。** こちらが本質的。
   決定打は改善側から出た: **行動を条件に含める目的関数を足すと成功率は上がるのに probe スコアは変わらない。**
4. **Q**: MANIGUARD が実測した「成功したロールアウトのうち仕様違反だった割合」は? 判定器に何を使い、何を使わないと明記したか?
   そしてこの週、R1 の規範は最終的にどう書き換わったか?
   **A**: **6〜21%。** つまり**成功率だけを見ていると、成功例の2割近くを誤って良いものとして数えている。**
   判定は **LTL_f (有限長の実行系列に「常に〜」「〜するまで」を書ける論理) に基づくオートマトン監視器**が
   **物理量に接地した述語**の上で行い、論文は **"rather than learned classifiers or LLM judges"** と明示している。
   規範の変遷: 「審判に学習モデルを使わない」(08-18) → 「使うなら判断を検証可能な粒度に分解し、
   何を保証しないか明記せよ」(08-21) → **[Zetta](../briefs/2026-08-23/2608.16590.md) を経て
   「学習モデルは審判を*書いて*よいが、審判を*務めて*はならない」(08-23)。**
   Zetta の critic は**学習された判定器ではなくコード**で、速く・人が読め・なぜ発火したかを説明できる。
   **但し書きから役割分担の言明に戻ったので、査読で通しやすくなった。**
5. **Q**: GS-VLA が示した数字は? そして今週、適合 (adaptation) を行える層は何層に整理されたか?
   **A**: **VLA は標準ベンチで9割成功するが、カメラの取り付け位置をわずかにずらすと最悪ケースで1割まで落ちる (90% → 10%)。**
   解き方は「方策の問題」を「画像の問題」に作り替えること —— カメラの動きが作業空間に対して十分小さければ、
   視点の正規化は**「視点が動いて新たに見えるようになった領域を埋める」というシーンにも方策にも依存しない課題**に縮約される。
   だから **400万パラメータの 3D Gaussian Splatting ベース正規化器を、凍結した方策の手前に挿すだけ。パラメータ更新ゼロ = 忘却なし。**
   適合の層は今週**4層**に揃った: **観測** (GS-VLA / 入力を学習時の基準に引き戻す) / **表現**
   ([Projector Is All You Train](../briefs/2026-08-22/2608.19726.md) / 境界面だけ学習) / **データ**
   ([SDGC](../briefs/2026-08-22/2608.19490.md) / 学習分布をモデル自身の rollout で補う) / **手続き**
   ([RP1](../briefs/2026-08-21/2608.18669.md) / 探索規則を差し替える)。
   **戦略として書けるのは一行: gap を一枚岩で埋めようとせず、分解して層ごとに最も安い手段で埋める。
   そして力学の根本的な違いはどの層でも埋まらない —— この最後の一行を書けることが重要。**
