## 4. 記憶チェック (5問)

**Q1. driving score が同じ 2 つの agent を、なぜ・どう見分けるか。(`2611.06453`)**
A. score は「障害物の前で止まる」と「接触しながら押し通る」を区別できない。通路幅や対向車 gap の 1 因子だけ動かし、各場面を「通れる/止まるべき」と certify し、agent ごとに commitment (通ろうとする確率) と competence (接触なく通れる確率) の 2 本の曲線を出す。TFv6 の判断正解率 0.60 (rule-based 0.74)。

**Q2. 単独では小さい 2 つの変動が、合わせると危ないとは? (`2611.02101`)**
A. 400 ms の遅延は学習時と同じ視点では違反率 +3.5 pp、60 度の camera ずれがあると +37 pp で、**単独の和より 33.5 pp 大きい** (interaction contrast: 同時のリスクから単独リスクの和を引いた量)。単独要因の試験に合格しても組み合わせでは分からない。対象は pi0.5 × LIBERO (manipulation)。

**Q3. VLA の action expert の勾配を VLM に流すべきか。(`2611.05249`)**
A. open-loop の軌道誤差では、action token の supervision があれば遮断 (insulation) と同程度で差が見えない。だが closed-loop の route progress は、勾配を流したほうが約 17% (token あり)・約 40% (なし) 上がる。open-loop だけで recipe を選ぶと誤る例で、遮断を default にする根拠は弱い。

**Q4. OPD の更新が「言い回しの真似」に使われる問題と、OPD が崩れる機構は? (`2611.07722` / `2611.08016`)**
A. 数学では言い回しの位置の teacher–student 差が内容の位置の 3.5 倍あり、更新の力が文体の模倣に流れる。SD-OPD は student と base の差を係数にし、teacher の feedback と符号が合う token だけ残す (pass@1 +7.76〜10.37 pp)。Learning Dynamics は loop を「信号が更新になる段階 (conversion)」と「更新が別の prefix と rollout 分布を変える段階 (broadcast)」に分け、offline 蒸留を先に挟むと後の OPD が伸びると示す。どちらも LLM の数学のみ。

**Q5. 逐次の fine-tuning で前の段階が壊れるとき、安く戻す手は? (`2610.40857` / `2610.38001`)**
A. 物理の基盤 model は simulation での適合で元の 1 step 予測誤差が最大 35 倍に悪化し、実験データでの学習中に simulation データを 1% 混ぜる replay で大半が戻る。LLM の safety (Mistral) では、replay は ASR (有害依頼に応じる率) を 51.1 pt 下げるが安全な依頼まで断る率が +53.4 pt 上がる。元の model の logit への distillation 単独は +5.1 pt にとどまる (ASR の低下は 5.4 pt と小さい)。併用で過剰拒否が和らぐ。どちらも vision・運転での割合は未確認。
