## 4. 記憶チェック (5問)

**Q1. Waypoint-OPD が RL 前後の差 (endpoint shift) をそのまま転送せず、中間 checkpoint を使うのはなぜか? (`2610.21601`)**
A. 始点と終点の差だけでは、学習中に好みが一貫して動いたのか、前半と後半で逆向きに動いて打ち消し合ったのかを区別できないから。「初期→中間」「中間→終点」の 2 shift を作り、student が訪れた prefix ごとに action preference の向きが一致する所だけ endpoint shift を通す (逆向きは抑制)。追加コストは frozen teacher の scoring 1 回。Qwen3 の 6 設定で最高だが、数学・コードの LLM のみ。

**Q2. VLA に world model を足す 4 方式の比較で、何が分かったか? (`2610.19825`)**
A. 4 paradigm = Implicit Future Alignment / Explicit Future Query / MoT Future Expert (行動と別の future 専用 expert) / External World Predictor。万能な方式は無いが、decoupled な MoT Future Expert が総合で競争的で OOD に強い。2D semantic な世界表現は方式を横断して安定して効く。manipulation 中心で、運転は未検証。

**Q3. SafeDriveVLA は危険なナビ指示にどう対処するか? (`2610.20609`)**
A. 従う/注意して従う/拒否の 3 段階の compliance mode を先に予測し、判断と action 生成を分ける。さらに「指示に厳密に従った未来」を world model で想像して安全か判定する。Bench2Drive で Driving Score 88.16、危険指示での衝突は 60 → 38。world model の計算コストと benchmark の公開状況は未確認。

**Q4. Uncertainty-Driven Self-Play は、手設計なしで難シナリオをどう作るか? (`2610.19714`)**
A. agent の半分を exploring agent にし、隣接 agent の epistemic uncertainty を上げることを報酬にする。policy が最も自信のない状況を探し続けるので curriculum が自動で出る。uncertainty 上位の agent は下位の 14.8 倍失敗し、ラベル無しで難シナリオを優先づけできる。nuPlan Val14 で 99.12% (標準 self-play 97.97%)。

**Q5. Reflex が視覚学習を scalable にした分解は? (`2610.12772`)**
A. (1) 箱の真の状態を入力に RL で全身 catching を学習 → (2) 遅延・欠損のある観測から dynamics を推定する policy → (3) RGB-D encoder がその dynamics 表現だけを復元 (controller は固定)。end-to-end RL が低次元の回帰になる。privileged 87.9% → 視覚のみ 85.7%。simulation の humanoid のみで、転用できるのは「学習の分解方法」だけ。
