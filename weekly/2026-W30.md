## 4. 記憶チェック (5問)

1. **Q**: 標準 KD が Bangla 要約で ROUGE-L を +0.0003 しか上げなかった原因を、KD Hurt はどう説明した? 処方は?
   **A**: 訓練サンプルの **約 51%** が student の validation loss を実際に**悪化**させているため、利得が相殺されていた。
   処方は per-sample の **gradient alignment**(その蒸留勾配が validation を下げる方向と揃うか)で有害サンプルを
   gate で弾く選別型蒸留 (CHAD)。さらに capacity-proportional constraint (CPDP) で capacity gap を補い、
   60M student が 50倍の Qwen2.5-3B を上回った。
2. **Q**: 「World Model Remembers, Actor Forgets」で、continual learning 中に忘れているのは何で、どう回復した?
   **A**: 忘れているのは記憶(world model)でなく **actor の出力経路**。world model は旧タスクの reward/value/終了構造を
   retention ≈ 1.0 で保持。world model を凍結して夢の中で RL しても回復しない (0/3) が、world model 自身の
   **"採点済みの夢"への self-imitation (dream rehearsal)** なら**環境対話ゼロで 3/3 回復**。
3. **Q**: HyWorldVLA が pixel 予測と latent 予測をどう使い分けるか(pre-train と co-fine-tuning で)?
   **A**: pre-train では **video latent を予測しつつ pixel を再構成**して latent を実映像に接地 (grounding)。
   co-fine-tuning と推論では **latent 予測だけに絞り** pixel 生成を切る。pixel の細かさと latent の頑健性を両取り。
4. **Q**: Experience Distillation が「素朴な SFT はダメ」と言う根拠と、代替 recipe は?
   **A**: 集めた経験を SFT で焼くと in-context learning の利得の **3.8% しか回収できない** (=96% を捨てる)。
   代替は **context distillation**(文脈に入れ ICL で得た振る舞いを重みに内在化)で、追加の環境対話ゼロで
   **64.8% 以上を保持**、RL 同等性能を **9.6倍少ない環境サンプル**で達成。
5. **Q**: KineBench が world model 評価で IDM を捨てた理由と、代わりの手段は?
   **A**: 生成映像から行動を逆推定する **IDM (Inverse Dynamics Model)** が分布外で壊れると「world model が悪いのか
   抽出器が悪いのか」区別できない (**attribution ambiguity**)。代わりに**汎用視覚 FM で手先の 6D pose を直接抽出 →
   物理シミュで再実行**して closed-loop 検証する。
