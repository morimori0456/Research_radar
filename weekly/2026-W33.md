## 2. 今週の精読1本

**→ [2608.12959 The Objective Is the Bottleneck: Latent World Models Encode What Their Planners Cannot Use](../briefs/2026-08-15/2608.12959.md)**

選定理由: **hf 0・著者無名・実験は2部屋の2D迷路**という、話題性がゼロの側から選ぶ。それでも選ぶのは
**機構が次元に依存しない**から —— ユークリッド的な潜在距離が障害物を無視するのは玩具環境の性質ではない。
今週 5本(VIScore / 11601 / 12078 / 10145 再現 / 本論文)が独立に「world model の良し悪しを何で測るか」に
着地しており、**本論文はその中で唯一「符号が反対」という最も強い形を主張し、しかも修正が再学習ゼロ**
(到達率 26.0% → 98.0%、予算 1/3 でも 92.0%)。**R1 の「保証をかける対象は予測器ではなく planner のコスト関数」
という設定変更と、R3 マップの新しい列「その潜在空間は距離として単調か」を同時に生む。** ブリーフでなく原論文を
読む必要があるのは、**主張の重みが全部 ablation の作り方に乗っている**ため。

読むときの問い(3つ):
1. **temporal distance head が学習したのは本当に reachability か。** 壁越えコストを 24% 高く見積もる(二乗潜在距離は
   4% 低く見積もる)という挙動が根拠だが、これは **CEM が壁を跨ぐ行動列をそもそもサンプルしにくいこと**の反映かもしれない。
   **真の最短経路長(ユークリッド距離ではなく)との相関を本文が出しているか**を最初に探す。出していなければ主張は
   「planner にとって単調になった」までで、「到達しやすさを学んだ」とは言えない。
2. **「予測精度と planning が逆順」の 4 checkpoint は、どう作られたか。** 同一 run の学習途中の点なら、これは
   **「学習が進むほど表現が予測に特化して距離構造を失う」という過学習の一形態**であって、モデル選択の一般則ではない。
   seed 違い・アーキ違いの独立な4点なら主張は桁違いに強い。**n=4 で順位一致を語っている以上、ここが最大の弱点。**
3. **運転で「壁」に相当するのは何で、そのとき temporal distance は何を学ぶか。** TwoRoom は静的・単一目標・障害物固定
   だが、運転の到達コストは**時間依存**(他車が動く)で、行きにくさは幾何ではなく**優先権と交通規則**から来る。
   **走行ログからフレーム間隔を教師に学習すると、拾うのは「到達しやすさ」ではなく「人間の運転者がそうしなかった」
   という選好ではないか** —— つまり**専門家の過保守さをコストとして焼き付ける**。これは R1 が測ろうとしている
   過保守さと正面から衝突するので、移植前に必ず切り分ける。

## 4. 記憶チェック (5問)

1. **Q**: 12959 で planning が最も上手かったコストは「最も正確なコスト」ではなかった。何を学習したヘッドが勝ち、なぜか?
   **A**: **フレーム間隔(この2フレームは何ステップ離れているか)だけを教師にした temporal distance head**。
   空間距離の予測としては劣る(r = 0.819 対 0.9897)のに planning は上手い。理由は挙動に出ていて、
   **このヘッドは壁を越えるコストを 24% 高く見積もり、二乗潜在距離は 4% 低く見積もる。**
   学習されたのは **proximity(近さ)ではなく reachability(到達しやすさ)**。壁の向こうは「近いが行きにくい」。
   world model は凍結のまま、**コストを差し替えるだけで到達率 26.0% → 98.0%**(再学習なし・GPU 不要)。
2. **Q**: TIDE の言う degenerate agreement とは何か。mismatch をどう2つに割り、それぞれどう直すか?
   **A**: on-policy distillation で **student が同じフレーズをループすると、teacher も「いま出ている繰り返しの続き」
   として同じ語に高確率を振るので、一致度がほぼ満点になる** —— **応答は壊れているのに指標は完璧に見える。**
   処方は mismatch を**方向で2つに割る**: **excess**(student が出すのに teacher がほぼゼロを振る語。補正量が発散して
   更新を壊す → **上限のある関数に置き換えて殺す**)と **deficit**(teacher が出したいのに student がまずサンプルしない語 →
   **teacher の上位 K 語を直接 loss に入れて**、サンプルされるのを待たない)。
   **「on-policy は student が踏まない道を学べない」という原理的な穴を、サンプリングを介さない項で回避している。**
3. **Q**: R1 にとって今週最大の収穫は「保証の型が3つ揃ったこと」と「空き地の存在証明」。それぞれ何か?
   **A**: 型は3つ —— **conformal 型**(黒箱可・確率的、校正データが現実を代表していれば成立)、**DPC 型**
   (**白箱の model-based であることを要求**・決定論的で厳密、著者自身が「RL や黒箱の近似 MPC では構造的に不可能」と明言)、
   **clustered randomized smoothing 型**(黒箱可・**モードの和集合に対する下界**)。**E2E の学習型 planner は黒箱側なので
   使えるのは1番目と3番目**、そして3番目は「多峰性を保ったまま保証を書く」言語を提供する。
   空き地は、**UnsDrive / DPC / 12198 / 11451 の4本が独立に安全層を提案しながら、4本とも
   その安全層が生む「過保守さ」を測っていない**こと。過保守さの第一候補は **モード取り逃し率**
   (真の分布にあったモードのうち planner が候補に残さなかった割合)で、平均速度の低下や介入頻度より因果的に上流。
4. **Q**: 「driving world model は反実仮想シミュレータとして使えない」と 11601 が言うとき、欠けている段は何か?
   **A**: **abduction(実際に起きた結果から、その裏にあった条件を遡って特定する段)**。action だけ差し替えて生成すると
   **もっともらしい未来は出るが、それは「あのとき実際に起きていた条件のもとでの未来」ではない。**
   著者は事実側の結果と「action だけ差し替えた正解」を対で持つ検証環境を作り、代表的 world model 2つが外れることを示した。
   処方は**学習ゼロ・モデル凍結** —— 事実側の続きに含まれる情報を反実仮想側に移し、残りだけを凍結モデルに埋めさせる。
   **痛みどころは log-replay 評価**(「このログで我々の planner ならどうしていたか」)で、これは R1 の評価基盤の中核。
   留保: **代替 action が周囲の車の挙動を変えない短い区間に限定**されており、割り込み・譲り合いはその外側。
5. **Q**: 今週「teacher/student の容量比 1.0」の蒸留が何本出て、R2 の設計をどう変えたか?
   **A**: 08-15 に **4本同時**(FIRE-VLA 採用 / HPSD・SSPO・TraVEL 落選)。**4本とも比 1.0 で、非対称なのは
   「teacher だけが何かを見ている」ことだけ**(FIRE-VLA は凍結した自分のコピーに実際の未来軌道だけを見せる)。
   さらに 08-16 の AI4AI は**パラメータ更新ゼロ**で 0.49 → 0.91。
   → **R2 を「容量比の1次元」から「容量軸 × 情報軸」の2次元に組み替える。** 既存研究がこの2つを混ぜて論じている以上、
   **分離すること自体が主張になる。** 予備実験は **比 {1.0, 2, 8} × 特権情報 {なし, 未来の一部, 未来の全部} の 3×3**、
   対照として **AI4AI の「更新ゼロ」を水平線**として格子の外側に引く。**どんな蒸留手法もこの水平線に勝たねばならず、
   このベースラインは学習コストがゼロで、誰も回していない。**
