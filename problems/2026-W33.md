## 課題カード (3枚)

### 課題: 規制が「合否試験」より先に「運行中の監視指標」を課した — だが *inappropriate stop* を客観的に測る手段が誰にもない

- **誰が困っているか / 深刻さ**: Zoox と、この exemption を先例に狙う全社 (Tesla Cybercab が筆頭)。2年・年2,500台という**免許の実体**が報告義務の履行に紐づく。W30 で追った rulemaking は**今も pre-rule で NPRM (規則案) が出ていない** ([Sidley 7/9](https://environmentalhealthsafetybrief.sidley.com/2026/07/09/the-department-of-transportations-2026-regulatory-agenda-acceleration-of-autonomous-vehicle-rulemaking-and-future-action-on-fuel-economy/))。**NHTSA は試験基準を作る前に、exemption の条件として先に運用指標を課した。** 順序の逆転が今週最大の構造変化 (推測)。
- **なぜ未解決か**: 衝突は事後に定義できるが "inappropriate stop" は**文脈依存の主観判断**。同じ停止が交差点で3秒なら安全余裕、消防車の前で30秒なら重大違反。判定には反実仮想 (counterfactual: その場面で停止しなかったらどうなったか) が要り、W30 の "objective・practicable・repeatable" 要件と正面衝突する。さらに MRC (Minimal Risk Condition: 異常時に安全側へ停止する設計上の機能) の発動と不適切停止が**同じログに見える**。
- **既存プレイヤーと限界**: NHTSA の SGO 報告は衝突中心で停止事象の分類体系がない。Applied Intuition / Foretellix 等は「衝突しないか」を回す設計で、**過剰保守の側を罰する指標を持たない** (推測)。
- **対象者の技術との接続**: **P1 (planner 評価) のど真ん中**、しかも 08-12 digest と噛み合う。**UnsDrive** の unknown 侵入ペナルティは「過保守さのつまみ」そのもので、そこから「衝突率 vs 過保守さ (不要停止回数・到達時間悪化)」の曲線が直接描ける — **規制が要求し始めた量が、R1 が測りたかった軸と一致した。** 停止の正当性判定は VLA の場面理解の応用でもある。
- **最初の一歩 (1週末)**: 手法を作らず**分類体系だけ**作る。公開の停止事例 (SF 7/4 の立ち往生、Zoox の火災現場進入、Waymo の school bus 事例) を「(a) 正当な MRC / (b) 不確かさによる過保守 / (c) 明確な不適切」に振り、**各分類の判定に何の情報が要るか**を列挙した1枚の表にする。× が並ぶ欄が測定不能=空白地帯。

### 課題: frontier VLA が商用可 open weights で降ってきた — 差別化が「モデルを持つこと」から「車載化とその評価」へ移った

- **誰が困っているか / 深刻さ**: 自社 E2E スタックを持つ OEM・Tier-1・AV スタートアップ全て。34B の VLA が fine-tune・派生・商用再配布可のライセンスで配られた以上、基盤モデル保有の希少性は消えた。差が付くのは (a) 量産 ECU で回るサイズへ落とす作業と (b) 落とした後も性能が残る証明。**34B は車載できない** (推測: 現行量産 SoC の演算量と桁が合わない) ため、蒸留は選択肢でなく必須経路。
- **なぜ未解決か**: この VLA の売りは**軌道と同時に因果説明と meta-action を出す**こと、つまり価値が中間の推論構造にある。しかし蒸留は通常**出力 (軌道) の一致**で測るため、**説明能力が蒸留を生き延びたかを測る指標がない**。加えて公表指標の Lingo-Judge は **LLM-as-judge (別の言語モデルが回答を採点する方式)** による言語課題で、**79.2 が実走安全性と相関する証拠は示されていない** (事実: 相関の提示なし / 推測: 相関は弱い)。「言語で測って車で使う」ギャップが業界標準として固定されつつある。
- **既存プレイヤーと限界**: NVIDIA は weights とベンチを出すが**車載サイズへの落とし方と落とした後の合否基準は提供しない**。学術の VLA 蒸留は主に manipulation 対象で、運転の安全余裕を保存する制約は扱わない (推測)。
- **対象者の技術との接続**: **P2 (FM 蒸留) と P3 (VLA/E2E) の交点で、業務3本のうち2本が同時に当たる稀な題材。** 08-12 digest の **TIDE** が指摘した degenerate agreement (student がループすると teacher との一致率が満点に見える) は、**「軌道は一致しているが説明が崩壊した蒸留」の運転版**として直接移植できる。capacity gap を振り「軌道誤差」と「説明の妥当性」がどこでズレ始めるかを描けば、それが R2 の中心 figure になる。
- **最初の一歩 (1週末)**: Alpamayo 2 Super を HF から落とし、**1シーンだけ推論して軌道・因果説明・meta-action の3出力を並べる**。次に同一シーンへ軽い摂動 (別車線の車を消す等) を与え、**軌道は変わらないのに説明が変わる / 逆に説明は同じで軌道が変わる**例を1つ見つける。この非整合が見つかれば「説明を保存する蒸留」という問いが立つ。

### 課題: 「1箇所で証明した性能」を次の箇所へ持ち越せない — 都市 (AV) でもサイト (robot) でも、検証コストが展開数に比例したまま

- **誰が困っているか / 深刻さ**: 展開を急ぐ全事業者。Waymo は10都市規模の拡大を掲げ Uber は12万台を宣言する一方、**証拠の要求元が都市ごとにバラバラになった** (SF 市長の強化要請、Mullin 法案、Teamsters 訴訟)。robotics 側も同型: 倉庫の求人50万件・78%採用難という需要があり humanoid に $8.6B が入ったのに、**K-Scale は $2M の受注を持ったまま資金枯渇で死んだ** ([36Kr](https://eu.36kr.com/en/p/3657117189890433))。デモから配備までの距離を資本では埋められなかった、という同じ失敗。
- **なぜ未解決か**: 安全の証拠は現状**その土地・そのサイトのログ**でしか作れず、転移の理論がない。「Phoenix で無事故だから Nashville でも安全」を言うには**運行環境の差を定量化し、その差の下で保証がどれだけ劣化するかを見積もる**必要がある。これは distribution shift の定量化そのものだが、**運転ドメインで「都市間距離」を測る標準指標が存在しない** (推測)。結果、各社は都市ごとに人手で走り込みコストが線形に増え、地域単位の政治的拒否権 (Teamsters・市長) がそれを更に高くする。
- **既存プレイヤーと限界**: scenario ベンダーはシナリオを回すが「この都市の分布が既存とどれだけ違うか」は出さない (推測)。UL 4600 の safety case は書式であって転移を論じない (W28・W30 と同じ限界)。倉庫側では導入前に顧客サイトの成功率を予測する受け入れ試験の商業提供者が依然見当たらない (推測、W29 カード2 の継続観察)。
- **対象者の技術との接続**: **P1 の評価技術を「単一環境の合否」から「環境間の転移予測」へ拡張する筋。** 08-12 digest の **LDR** が示した作法 ——「分布内の誤差ではなく、分布内と分布外の*差*で報告せよ」—— がそのまま指標設計の出発点。同 digest の 2608.09100 (合成→実のギャップが実データ 9.5% 混入で大半埋まる) は、**「新環境で必要な最小データ量」を測る実験設計の雛形**になる。
- **最初の一歩 (1週末)**: 公開運転データセット (nuScenes 等) の**都市分割を疑似「新都市」として扱い**、都市 A で学習した planner を都市 B で評価し、(1) 性能低下幅と (2) 事前に計算できる分布距離 (画像特徴・軌道統計) の相関を散布図1枚にする。相関が立てば「走らずに劣化を見積もる」入口、立たなければ「何が距離の正しい定義か」が次の問い。

## ストックへの示唆

- **3週の空白の答え合わせ。** W30 は「W31 で public comment 開始を必ず追跡」と書いたが W31・W32 のカードは作られなかった。今回の追跡結論: **rulemaking は今も pre-rule で NPRM は出ていない。代わりに NHTSA は exemption + 報告義務という別ルートで実質的な規制を先に敷いた。** 仮説は否定されず、実現形が変わった —— 標準化は「試験基準」より先に「運行監視指標」から来る。
- **反復テーマ (W28→W33 で不動): 「学習方策の性能を、誰がどう客観的に測るか」。** W28 誰が検証するか → W29 証拠の要求 → W30 試験法の公募 → **W33 免許の条件としての監視指標**。抽象度が下がり続け、今週ついに**事業許可に直結する報告義務**まで降りた。このストックで最も強い連続シグナル。
- **今週入った新しい軸: 「作る側」の希少性が消えた。** W28-30 で繰り返した「資金は作る側に殺到し、測る側は空いている」の前提を Alpamayo の open weights が一段強めた —— 作る側は今やタダで配られる。空いているのは依然、**測る側と載せる側 (蒸留)**。
- **推し (4回目・不動): 「自律システムの評価 / 転移する安全証拠 (evaluation・safety case・testable competency)」を深掘りドメインとして確定してよい。** 今週の補強3点: (1) 評価指標が**免許の条件**になった、(2) frontier モデルが無料になり差別化が評価と車載化へ移った、(3) 拒否権が**地域単位**に分散し証拠の転移が事業速度そのものになった。
- **次の一手 (期限イベント)**: ① Zoox の exemption 報告が**いつ・どの粒度で公開されるか** — 公開されれば "inappropriate stop" の事実上の定義が世に出る、年に一度級の観測機会。② Teamsters 訴訟の Alameda 郡での初動 (経済影響評価の欠如が認められれば他州の AV トラック解禁が同じ論法で止まる)。③ NPRM が実際に出るか。**W34 では①を最優先で追う。**
