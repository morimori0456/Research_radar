## 課題カード (3枚)

### 課題: 規制当局が測りたいのは「事故」ではなく「何も起きていない普通の運転」に変わった — だがそれを repeatable に採点する手法は誰も持っていない

- **誰が困っているか / 深刻度**: NHTSA、州の認可当局、そして FMVSS (連邦自動車安全基準) を待っている全社。ASCEND の資金は **3年 $5M** で、単独 robotaxi 企業の年間 R&D と比べれば桁が2〜3つ小さい (推測: 実質は手法の合意形成が成果物で、データ取得は会員企業持ち寄り)。にもかかわらずこの成果物が **FMVSS の下敷き**になる予定で、影響は市場全体に及ぶ。
- **なぜまだ解決されていないか**: **測る対象が反転したから。** 過去7週このレーダーが追ってきた指標は全て**異常側** (衝突・逸脱・不適切停止・recall) だった。異常側は「起きた/起きない」が二値で数えられる。ところが ASCEND の優先事項は **"good driving under normal conditions"** — 事故が一度も起きない大多数の走行に**順序を付けろ**という要求で、正解ラベルが存在しない。加えて **repeatable** (同じ試験を別の主体が再実行して同じ答えが出る) が条件に入っており、各社の内部 simulation は原理的に失格になる。
- **既存プレイヤーとその限界**: **SAE ITC のコンソーシアム = 会費制で、会員は測られる側の企業。**(推測だが) 測られる側が試験法を書く構造には、厳しすぎる指標が合意されにくいバイアスが入る。**NHTSA 自身**は暫定ガイダンスへの意見も業界要求で1ヶ月延ばしており、ペースの主導権を持っていない (事実: 延長要求者は Auto Innovators)。**学術側**の naturalistic driving 研究は「人間の運転の記述」であって「方策の採点」ではない。**空席は「測られる側でない第三者が、公開データで再実行できる採点法」。**
- **対象者の技術との接続**: **P1 (planner 評価) と R1 の中心にほぼ完全一致する。** R1 が定義しようとしている **solvability (その瞬間に残っている逃げ道の本数)** は、まさに「衝突が起きていない走行に順序を付ける量」であり、ASCEND が言う **surrogate safety metric** の定義そのものである。しかも solvability は走行ログから決定的に計算できるので **repeatable** の条件を構造的に満たす — 内部 simulator を持たない第三者でも再実行できる。**この一致は偶然ではなく、R1 の主張を「学術的に新しい」から「規制の公募要件に答えている」に言い換えられる**ことを意味する (これは投稿時の位置づけの話で、技術内容は変わらない)。
- **最初の一歩 (1週末)**: **RESEARCH_PIPELINE の 09-06 gate の図1を、ASCEND の3要件で採点する形で作る。** ①走行ログ (または 2D toy) で solvability を後付け計算し、衝突が一度も起きていない区間だけを取り出して分布を出す。②その図の下に **objective / repeatable / proactive** の3行チェックを付け、自分の指標が各条件をどう満たすか (または満たさないか) を1行ずつ書く。所要は半日、必要なのは既に手元にあるログのみ。**図1が無ければ 09-06 に RoboPAD 投稿を取り下げる規則が既にあるので、今週の全作業のうち最優先はこれ。**

### 課題: humanoid の評価が「投資の是非」から「$6B の支配権を買うか」に上がったのに、自律度を開示する規格が存在しない

- **誰が困っているか / 深刻度**: 直接には SoftBank と 1X の投資家、間接には humanoid セクター全体。1X は $6B の値付けで交渉されている (事実) が、**NEO が実運用でどれだけ teleoperation (遠隔操作) に依存しているかの数字は公開されていない** (事実: 公開資料に自律度の定量開示は見当たらない)。humanoid の2026年調達は YTD $8.6B = 2025年通年の1.8倍 (W35 記載) で、この不透明さの上に載っている資本の総量が大きい。
- **なぜまだ解決されていないか**: **開示させる主体がいないから。** 自動車には NHTSA の crash report 制度があり、W34 の Avride の件のように **remote operator の関与が事後に文書として出てくる**。humanoid には対応する制度が一切ない。技術的にも、「自律度」は連続量ではなく **どのサブタスクが誰の指示で動いたか**の分解を要し、そこは動画からは原理的に見えない。加えて売る側に開示のインセンティブが無い (推測: 自律度が低いほど評価額が下がる方向にしか効かない)。
- **既存プレイヤーとその限界**: **ベンチマーク側** (RoboArena 等の実機評価) はタスク成功率までで、**teleop 混入を検出する設計になっていない**。**投資家の DD** は非公開かつ一回限りで、業界の共通言語にならない。**W29 のカード5 (「買い手が実際に何ができるか確かめる手段がない」)** から3ヶ月経ち、買い手が LP から**支配権を取る戦略投資家**に上がったが、確かめる手段は増えていない。
- **対象者の技術との接続**: **P3 (VLA) と P2 (蒸留) の両方に直接効く。** VLA (Vision-Language-Action model: 視覚と言語から直接行動を出すモデル) が実機で teleop 無しに動くかは、**車載/機体搭載の計算資源に載る大きさまで蒸留できたか**とほぼ同義で、P2 の capacity gap の問題そのものである。つまり「自律度の開示」は事業の問いに見えて、中身は**蒸留後にどの能力が落ちたかの測定**であり、W35 で書いた「student が teacher の稀な挙動を落としていないか」と同じ道具で測れる。
- **最初の一歩 (1週末)**: **公開デモ動画から teleop の痕跡を採点するルーブリックを1枚作り、3社 (1X / Figure / Apptronik) の直近デモに適用する。** 見る観点は (a) 動作開始までの遅延と、その分散 (自律なら分散は小さい)、(b) カメラのカット割り (連続1カットか) と再生速度の表記、(c) 失敗時の復帰の型 (自律的な再試行か、途中で切れるか)、(d) 同一タスクの反復回数の開示有無。**採点結果より「何が公開されていれば判定できたか」の欠落リストの方が成果物**で、それは「humanoid 版の自律度開示フォーマット」の下書きになる。半日。英語で出せば発信物 (Phase 1 の3目標のひとつ) を兼ねる。

### 課題: 物流の人手不足は「採用できない人数」でしか語られず、自動化の投資判断に必要な「その人が実際に何をしているかの時間分布」が測られていない

- **誰が困っているか / 深刻度**: 倉庫・運送の現場と、そこに売る robotics 企業の両方。数字の桁: 米 ATA の2026年 driver 不足は **約82,000人** (2031年に16万人超の見込み)、IRU の世界推計は **2026年末に240万人超**。倉庫側は **回転率 平均36%**、**労働費が運営費の50〜70%**、運営者の **40%が「労働力不足が最大の operational risk」**と回答。[ATA/IRU まとめ](https://otrucking.com/resources/guides/truck-driver-shortage-2026/) / [倉庫側](https://www.tawi.com/lifting-insights/logistical-issues-in-2026)
- **なぜまだ解決されていないか**: **不足の単位 (人数) と自動化が代替する単位 (作業時間) が噛み合っていないから。** 「82,000人不足」は採用の話で、robot が代替できるのは職務の**一部のタスク**である。ある倉庫作業員の勤務時間のうち picking が何%、歩行が何%、例外処理が何%かの分布が分からないと、**タスク1つを自動化しても残りが人を張り付けたままにする**ため ROI が出ない。この分布は各社の WMS (倉庫管理システム) に断片的にあるが、公開された共通の時間研究がなく、投資判断は「台数×時給」の粗い掛け算で行われている (推測。ただし W35 カード17 の「実顧客を持つ倉庫自動化企業が資金繰りで死ぬ」現象は、この掛け算が現場で外れることの傍証)。
- **既存プレイヤーとその限界**: **Exotec / Locus / GreyOrange / Dexory / Mytra** など $190M 超調達組は**搬送と保管**に集中しており、そこは時間分布のうち比較的読める部分。**Agility (Digit)** など humanoid 系は「人と同じ場所で人と同じ作業」を掲げるが、**その「同じ作業」の中身が定義されていない**。コンサルの市場予測 (倉庫 robotics が2030年に $21B 等) はトップダウンで、現場の時間分布からは積み上がっていない。
- **対象者の技術との接続**: **P3 (VLA) の評価設計に直結する。** いま VLA のデモは「タスク」単位 (物を掴む・置く) で示されるが、事業側が必要としているのは **「1シフト8時間の何%を覆えるか」**である。この橋渡しは **long-horizon / 例外処理を含む評価集合の設計**であり、対象者が P1 で作っている「起きなかったことを測る」道具 (逃げ道が無くなる手前を検知する = 人を呼ぶべき瞬間の検知) がそのまま **W35 カード17 の「自分が分からない時を分かる」能力の測定**になる。
- **最初の一歩 (1週末)**: **公開データだけで「タスク被覆率」の図を1枚作る。** ① BLS (米労働統計局) の O*NET から倉庫作業員 (Laborers and Freight, Stock, and Material Movers) の task 一覧と重要度を取る。② 直近の VLA / 倉庫 robot の公開デモが、その task 一覧のどれに対応するかを手作業でマップする。③ **カバーされた task の重要度合計 ÷ 全体** を出す。数字が仮に20〜30%なら、「残り70%が人を張り付けたままにする」ことが1枚で言え、**なぜ実顧客を持つ企業が赤字なのか**の説明になる。データは全て公開・無料、必要なのは表計算のみ。

- **反復テーマ (W28→W36 で8週不動): 「学習方策の性能を、誰がどう客観的に測るか」。** 今週の増分は**測る対象の反転**である。W35 までのカードは全て**異常側** (事故・逸脱・停止・recall) を測る話だった。ASCEND が最優先に置いたのは **normal conditions での good driving** — つまり**何も起きていない走行の採点**。これは8週で初めて、規制側の要求が**対象者の R1 (衝突率の隣に置く量) と同じ側**に来たことを意味する。
- **今週入った新しい軸: 「誰が試験法を書くか」が問題になった。** これまでは「試験法が無い」という欠落の指摘だったが、今週それを埋める主体が**会費制の業界コンソーシアム**に決まった。埋まる場所は決まったが、**埋める主体は測られる側である** (事実: SAE ITC は会員制)。空席は「試験法が無いこと」から「**独立に再実行できる試験法が無いこと**」へ移った (推測だが、この読み替えは repeatable が公募要件に明記されている以上、自然である)。これは事業機会としては条件が良い方向で、**公開データで再現できることそれ自体が差別化になる。**
- **推し (7回目・不動): 「自律システムの評価 / 転移する安全証拠」を深掘りドメインとして確定。** 今週の補強3点: (a) 規制の公募要件が **objective / repeatable / proactive** という具体語で出た (R1 の自己採点軸がタダで手に入った)、(b) 測る対象が異常側から正常側へ反転し、solvability の位置が中心に来た、(c) 買い手が **$6B の M&A** にまで広がった (W34 の「買い手が投資家へ広がる」の延長線上、桁がひとつ上)。
