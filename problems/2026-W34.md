## 課題カード (3枚)

### 課題: 規制は「臆病すぎる」と「強引すぎる」を*別々の制度*で罰し始めた — が、両者のトレードオフ曲線を出せる者がいない

- **誰が困っているか / 深刻さ**: 商用運行中の全 AV 事業者。制度が両極から挟んだのが今週見えた構図。片極は W33 で追った **Zoox の FMVSS 免除条件 = "inappropriate stops" (不適切な停止で交通を塞ぐ事象) の即時報告義務**、つまり**過保守を罰する側** ([Federal Register 7/31](https://www.federalregister.gov/documents/2026/07/31/2026-15485/zoox-grant-of-temporary-exemption-from-portions-of-various-requirements-of-the-federal-motor-vehicle))。もう片極は NHTSA ODI (欠陥調査部) の **Avride 調査** — Uber 上で運行する約200台で 16件の衝突 (2025/12〜2026/03) を「**inappropriate assertiveness and insufficient competence** (過剰な積極性と能力不足)」と表現 (事実: 調査開始は 2026年5月であり今週の news ではない) ([TNW](https://thenextweb.com/news/avride-uber-robotaxi-crashes-nhtsa-investigation) / [Drive Tesla](https://driveteslacanada.ca/news/avride-robotaxi-crash-investigation-nhtsa/))。**同一の planner のつまみを、免除条件と欠陥調査という別系統が反対向きに引いている。**
- **なぜまだ解決されていないか**: 技術というより**指標の非対称性**。衝突は事後に一意に定義でき SGO (NHTSA の標準事故報告) で集計されるが、「不要な停止」には母数がない — 分母が「停止すべきでなかった場面の総数」で、これは観測不能。結果、事業者は**片側 (衝突) しか最適化対象として定量化できず**、もう片側は「苦情が来たら直す」運用になる。加えて両者を1本の曲線として出すと**自社の過保守さが公開データになる**ため、報告インセンティブが構造的に負 (推測)。
- **既存プレイヤーとその限界**: NHTSA は両極の語彙を持ったが**共通尺度を定義していない** (片方は免除条件、片方は defect の文言)。Applied Intuition / Foretellix 等の scenario ベンダーは「衝突しないか」を回す設計で、過保守側にペナルティを置く指標を標準では持たない (推測、W33 から継続)。
- **対象者の技術との接続**: **P1 (planner 評価) の中核。** ML の ROC 曲線 (閾値を振って2種の誤りの交換率を描く図) に相当するものが運転 planner には無い、と言い換えられる。「衝突率」対「不要停止率 (+ 到達時間の悪化)」を**一本の operating curve** として出す評価プロトコルは、規制文書2件が名指しした量にそのまま対応する。論文の figure 1 が最初から決まっている稀な題材。
- **最初の一歩 (1週末)**: 手法は作らない。**公開シミュレータ (nuPlan / CARLA) で planner の保守性パラメータを1つだけ選び (例: 前方車との最小 headway、不確実物体への reaction threshold)、5点振って「衝突率 vs 平均遅延・停止回数」の散布図を1枚**描く。曲線が単調に引ければ「両極は1本のつまみ」という主張が立ち、折れ曲がれば「別々の失敗モード」という別の主張が立つ。どちらでも次の問いが確定する。

### 課題: 建設の自律化は「新車を売る」から「他社の既存機に載せる」に賭け先が移った — 機種を跨いだ性能保証の手段がない

- **誰が困っているか / 深刻さ**: 建設業とその自動化ベンダー。米国だけで**2026年に49.9万人の労働者不足**とされ、構造的 (循環的でない) と整理されている (出典はブログ記事 [Buildcheck](https://buildcheck.ai/insights-case-studies/autonomous-construction-why-2026-is-make-or-break)、一次統計は未確認)。Gravis の $200M はこの不足に対する**単一で最大の賭け**であり、賭けの形が重要 — fleet を買い替えさせず**既存機に retrofit する**。顧客に Holcim・Taylor Woodrow・HD Hyundai。
- **なぜまだ解決されていないか**: retrofit は商流の答え (資本負担ゼロで導入できる) だが、**技術的には最も難しい形態**を選んだことになる。同じ policy が Caterpillar と John Deere と HD Hyundai の**油圧特性・遅延・アクチュエータ限界が異なる車体**で動く必要がある = cross-embodiment (異なる身体をまたぐ方策転移) の産業版。さらに対象が土砂という**変形する媒体**で、行為が環境そのものを不可逆に書き換えるため「正解軌道」が定義できない。「生産性+30%」も**測定条件が公開されていない**ベンダー自己申告 (事実: 条件の記載を確認できず)。
- **既存プレイヤーとその限界**: Caterpillar / Komatsu の自律は**自社機・鉱山という閉じた現場**で成立しており、機種横断は射程外。Built Robotics 等の後付け系は先行するがスケールしていない (推測)。共通するのは、**新しい現場・新しい機種で「動くか」を事前に言う手段がなく、毎回パイロットを回す**こと — W33 カード3の「検証コストが展開数に比例」が、都市でもサイトでもなく**機種**の軸で再出現している。
- **対象者の技術との接続**: **P2 (FM 蒸留) × P3 (VLA) の建設版で、かつ本業より制約が緩く実験しやすい。** 「1つの大きな policy を N 種類の車体へ落とす」は蒸留そのものであり、capacity gap ではなく **embodiment gap** を軸に取った同型の問題。評価側 (P1) では「新しい機種で必要な最小適応データ量」が KPI になる。
- **最初の一歩 (1週末)**: 公開の cross-embodiment データ (Open X-Embodiment 等) で、**embodiment A で学習した policy を B〜N で評価し、(1) 性能低下幅と (2) 事前計算できる body 間距離 (行動空間の次元・遅延・到達域の統計) の相関**を散布図1枚に。W33 カード3で「都市間距離」に対して立てた同じ問いを、より安価に回せるデータで先に潰す。相関が出れば「走らせずに移植可否を見積もる」の最小証拠になる。

### 課題: 「人が見ている」が安全策と原価の両方を担っているのに、その効き目も台数もどこにも数字がない

- **誰が困っているか / 深刻さ**: robotaxi 事業者と、その安全性を信じるよう求められる規制当局・自治体。**Avride の16件の衝突は全て、運転席に in-vehicle operator が着座し監視している状態で起きた** (事実、NHTSA 記載)。失敗の中身は車線変更・前方車への反応・車線を塞ぐ静止物への反応 — つまり**人が数百ミリ秒で介入できない類の失敗**。安全側の話がそのまま原価側の話でもある: 週70万回まで拡大した業界で **Pony.ai の gross margin は 17.5%、純損失 $45.4M/四半期**、WeRide の損失は前年比 -1% とほぼ改善していない。**「1台あたり何人の remote operator が必要か」が公開されていない**ため、外から見て**この赤字が規模で解消するのか、原理的に解消しないのかを判別できない** (推測: 未公開なのは比率が投資家に不利だから)。
- **なぜまだ解決されていないか**: 監視の有効性を測るには「介入がなければ事故だった」という反実仮想が要り、W30 以来ずっと同じ壁 (objective・practicable・repeatable) に当たる。加えて remote assistance の人員比は**競争上最も秘匿したい数字**で、規制も今のところ要求していない (事実: Zoox の免除条件は remote operator の**米国内居住**は課すが**人数比の報告**は課していない)。技術でなく開示設計の欠落。
- **既存プレイヤーとその限界**: 加州 DMV の disengagement report は**公道テスト段階の指標**で、商用運行の remote assistance をカバーしない。SGO は衝突しか集めない。第三者が autonomy の実質度を測る系は存在しない。だから Teamsters (8/5 に加州 DMV を提訴、20万人の運転手への経済影響評価の欠如を主張) のような主体も、**雇用影響を論じる数値的な足場を持てない** ([Teamsters](https://teamster.org/2026/08/teamsters-california-sues-dmv-to-protect-public-from-driverless-truck-dangers/))。
- **対象者の技術との接続**: **P1 の評価軸を「安全」から「自律度」へ拡げる筋。** 必要なのは *takeover lead time* — 「システムが自分の失敗を、人が介入できるだけ手前で予告できたか」の分布。これは planner の introspective uncertainty (自分の能力外を自分で検知する能力) の評価そのもので、W30 カード2 (倉庫の「分からない時が分かる」) と同じ問いが運転で再出現している。VLA の場面理解は「なぜ危ないか」を先に言語化できる分、lead time を稼げる可能性がある (推測)。
- **最初の一歩 (1週末)**: 公開の disengagement / near-miss ログ (加州 DMV の disengagement report は CSV で入手可) を10-20件読み、**各事象を「(a) 人が0.5秒で介入可能 / (b) 2秒あれば可能 / (c) 事前予告以外に手段なし」に分類**する。(c) の比率が高ければ「監視付き運行」は安全策として機能していないことになり、lead time 分布を測る研究の動機が数字で立つ。

## ストックへの示唆

- **W33 の宿題3件の答え合わせ**: ① **Zoox の "inappropriate stop" 報告は今週時点で公開データとして出ていない** (免除は 7/31 発効、報告は NHTSA へ直接で公開義務の記載を確認できず) — 「定義が世に出る」という期待は当面持ち越し。② **Teamsters 訴訟に判断は出ていない**。③ **NPRM は依然出ていない**。代わりに **AV Framework 暫定ガイダンスの意見提出期限が 8/31** に迫っており、W35 はここを見る (提出コメントは公開される)。
- **反復テーマ (W28→W34 で6週不動): 「学習方策の性能を、誰がどう客観的に測るか」。** 今週の増分は**測る対象が両極になった**こと。W33 までは「過保守を測れない」だったが、Avride の文言で**過剰積極も同じく測られていない**ことが確定した。1本の operating curve という具体形が初めて見えた週。
- **W29 の空白が5週で埋まった (自己検証として重要)**: W29 カード3で「建設の労働不足に robotics がほぼ手を付けていない」と書いた。今週 **$200M が建設の retrofit 自律に入った**。カードの指摘は正しく、かつ**5週で資本が動く速度**だった — このレーダーの解像度と、思いつく頃には資本が動いている、という時間感覚の両方の目盛りになる。次に同種の空白を見つけたら「動くまで5週」を基準に置く。
- **今週入った新しい軸: 赤字の構造が読めない。** これまでのカードは全て「測れない → 安全が保証できない」だったが、今週は「測れない → **事業として成立するか判定できない**」が加わった (remote operator 比率)。事業機会の観点ではこちらの方が直接的で、**「測る」ことの買い手が規制当局だけでなく投資家・保険・自治体に広がる**ことを意味する (推測)。
- **推し (5回目・不動): 「自律システムの評価 / 転移する安全証拠」を深掘りドメインとして確定。** 今週の補強: (a) 規制が両極の語彙を持ったことで**評価指標の形 (曲線)** が具体化した、(b) 同じ「転移」の問いが都市 → 機種 (embodiment) へ横展開し、**本業より安いデータで先に試せる入口**が見つかった、(c) 買い手が安全から**採算判定**へ広がった。
